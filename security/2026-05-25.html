1. CDN — 共有インフラを悪用する「Underminr」脆弱性が活発に悪用（2026-05-24 公表）

項目詳細
名称Underminr（アンダーマイナー）
深刻度Critical（アーキテクチャ脆弱性）
CVEなし（ソフトウェアバグではなく CDN アーキテクチャ上の設計悪用）
影響Cloudflare, Akamai, AWS CloudFront, Fastly など主要 CDN プロバイダー。推定 8,800万ドメインが影響を受ける可能性
公開日2026-05-24（ADAMnetworks が詳細を公表）

主要 CDN プロバイダーの共有インフラストラクチャにおけるアーキテクチャ上の脆弱性「Underminr」が公表されました。攻撃者は CDN に自身のドメインを登録し、HTTP Host ヘッダーや TLS SNI（Server Name Indication）を操作することで、信頼されたドメインの背後に悪意あるトラフィックを隠蔽できます。これにより C2 通信、マルウェア配信、フィッシングキャンペーンが正当なトラフィックに偽装され、従来のセキュリティ製品による検知が困難になります。

本脆弱性は従来のドメインフロンティング（Domain Fronting）の進化版であり、HTTP/2 多重化や SNI ベースルーティングの悪用により、より大規模かつ検知困難な攻撃を可能にします。ADAMnetworks の調査によれば、すでに活発な悪用が確認されています。

推奨対応:

  • ディープパケットインスペクション（DPI）の導入検討
  • CDN プロバイダーのテナント分離状況を確認
  • SNI ベースのフィルタリングのみに依存しない多層防御の実施
  • WAF で Host ヘッダー検証を強化

2. AWS — CISA 請負業者が AWS GovCloud キーを GitHub に公開、議会が説明要求（2026-05-24 追報）

項目詳細
分類クラウド認証情報の深刻な露出インシデント
影響CISA（米国サイバーセキュリティ・社会基盤安全保障庁）の AWS GovCloud 環境、内部 Artifactory システム
発生日2025年11月〜2026年5月中旬（リポジトリ「Private-CISA」が公開状態）
公表2026-05-18（KrebsOnSecurity 第一報）→ 2026-05-24（議会追及の続報）

CISA の請負業者が AWS GovCloud の高権限キー、SSH キー、認証トークン、デプロイログを含む大量の機密情報を「Private-CISA」という名称のパブリック GitHub リポジトリに誤って公開していたことが判明しました。KrebsOnSecurity の Brian Krebs が5月18日に第一報を報じ、5月24日には上下両院の議員が CISA に対して説明を要求する事態に発展しています。

当該リポジトリは GitHub の認証情報検出保護が無効化されており、2025年11月から約6ヶ月間公開状態でした。一部の AWS キーは CISA への通知後も約48時間有効だったと報告されています。連邦サイバーセキュリティを所管する機関自身の認証情報管理の不備として、厳しい視線が注がれています。

AWS 利用者への教訓:

  • GitHub Push Protection（シークレットスキャニング）は必ず有効化する
  • AWS IAM アクセスアナライザーで外部公開された認証情報を定期監査
  • 認証情報のローテーションと最小権限の原則を徹底
  • 開発用スクラッチパッドであってもパブリックリポジトリに認証情報を置かない
