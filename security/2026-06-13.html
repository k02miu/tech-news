1. Spring Cloud Sleuth — Spring TX 計装経由の DoS 脆弱性 HIGH

項目詳細
CVECVE-2026-41708
深刻度High
公開日2026-06-11（Spring Security Advisory）
影響対象org.springframework.cloud:spring-cloud-sleuth-instrumentation を使用するアプリケーション
修正影響を受けるバージョンから対応する修正バージョンへアップグレード
  • Spring Cloud Sleuth の Spring TX 計装において、攻撃者が細工された呼び出しを提供することで DoS（サービス拒否）状態を引き起こせる脆弱性
  • spring-cloud-sleuth-instrumentation を利用するアプリケーションが影響を受ける。トレーシング計装を有効にしている Spring Boot アプリケーション全般が対象
  • Spring 公式アドバイザリで「追加の緩和策は不要、影響を受けるバージョンから修正バージョンへアップグレードせよ」と明記
  • CERT-Bund（ドイツ連邦情報セキュリティ局）でも 2026-06-12 に複数脆弱性として警告公開（CVE-2026-41708 と CVE-2026-47825 を同時掲載）
  • 〈SpringBoot / Java スタックに直接関連〉

2. Spring Cloud Gateway — 信頼できないプロキシからのヘッダ転送による IP スプーフィング HIGH

項目詳細
CVECVE-2026-47825
深刻度High（CVSS 7.0）
公開日2026-06-11（Spring Security Advisory）
影響対象Spring Cloud Gateway Server（WebMVC / WebFlux 両方）
修正影響を受けるバージョンへアップグレード。WebFlux の NettyServerCustomizer はデフォルトで無効化
  • Spring Cloud Gateway Server が、特定の設定シナリオで信頼できないプロキシからの X-Forwarded-For および Forwarded ヘッダをそのまま転送する脆弱性
  • 攻撃者はこの脆弱性を利用し、送信元 IP アドレスを偽装可能。IP ベースのアクセス制御やレート制限をバイパスできるリスク
  • WebMVC と WebFlux 両方の Gateway Server が影響を受ける
  • 修正後、WebFlux の NettyServerCustomizer はデフォルトで無効化される。必要に応じて spring.cloud.gateway.server.webflux.httpserver.customizer-enabled=true で明示的に有効化が必要
  • 報告者: samarthd（責任ある開示）
  • 〈SpringBoot / Java スタックに直接関連〉

3. Claude Code v2.1.176 — availableModels バイパス修正とセキュリティ強化 MEDIUM

項目詳細
バージョンClaude Code v2.1.176（2026-06-13 リリース）
分類セキュリティポリシー強化 / 設定バイパス修正

  • availableModels 制限のバイパスを修正 — ANTHROPIC_DEFAULT_*_MODEL 環境変数経由で、ブロックされたモデルにエイリアスモデルピックをリダイレクト可能だった脆弱性を修正。また /fast が許可リスト外のモデルへの切り替えを拒否するように
  • enforceAvailableModels managed setting（v2.1.175）— 有効化すると、availableModels 許可リストが Default モデルにも適用される。不許可モデルに解決される Default は最初の許可モデルにフォールバック。ユーザー/プロジェクト設定が managed リストを拡張できなくなる
  • hook if 条件のパスマッチ修正 — Edit(src/**)、Read(~/.ssh/**)、Read(.env) のようなドキュメント化されたパターンが正しくマッチするように
  • サンドボックス起動時のシンボリックリンク処理修正（Linux）、Remote Control のモデル切り替え防止
