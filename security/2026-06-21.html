1. Gravity SMTP (WordPress) CVE-2026-4020 — 大規模能動悪用、API鍵・OAuthトークンを流出 MEDIUM

項目詳細
CVECVE-2026-4020（CVSS 5.3、情報公開）
公表・報道2026-06-20（The Hacker News / Wordfence）
影響Gravity SMTP WordPress プラグイン（約10万サイト導入）
修正バージョンv2.1.5
悪用状況能動的悪用確認済み（Wordfence が1700万件超ブロック）
  • 概要 — 認証不要の REST API エンドポイント /wp-json/gravitysmtp/v1/tests/mock-data で permission_callback が無条件で true を返す欠陥。?page=gravitysmtp-settings を付与すると約365KBのシステムレポート（PHP/拡張/ウェブサーバ/DB種別と版/WordPress版/アクティブプラグイン一式/DBテーブル名）と、Amazon SES・Google・Mailjet・Resend・Zoho 等のAPI鍵・OAuthトークンを認証なしで取得可能
  • 被害状況 — Wordfence が1700万件超の攻撃試行をブロック。2026年5月初旬から活動開始、6月6日頃に急増（1日400万件超）。主な攻撃元IP: 45.148.10.95・193.32.162.60・176.65.148.139・173.199.90.188・185.8.106.x 系等
  • 影響 — 流出したメール統合資格情報でサイトを騙って送信可能。詳細なシステムレポートにより追加攻撃の調査コストが大幅に低下
  • 対応 — v2.1.5 に即時更新。第三者メール統合のAPI鍵・OAuthトークンをローテーション。サーバログを上記IPからの /wp-json/gravitysmtp/v1/tests/mock-data アクセスで監査し、侵害を疑う
  • 〈web / WordPress スタックに直接関連〉

2. libheif CVE-2026-47178 — 非圧縮HEIF画像処理のヒープバッファオーバーフロー（RCE可能性） CRITICAL

項目詳細
CVECVE-2026-47178
公表日2026-06-20（Amazon Linux ALAS / Project Zero）
影響バージョンlibheif v1.21.2 以前
最大深刻度Critical（ヒープベースバッファオーバーフロー、RCE可能性）
影響コンポーネント非圧縮HEIF画像（ISO/IEC 23001-17, unci item type）のデコード処理
  • 概要 — クロマサブサンプリング（4:2:0 / 4:2:2）を伴うタイル化HEIF画像を処理する際、クロマプレーンの空間オフセットのスケーリングを行わないため、左上以外のタイルをデコードすると範囲外メモリ書き込み（ヒープバッファオーバーフロー）が発生。リモートコード実行に至る可能性
  • 発見元 — Google Project Zero（issue 507396184）。Amazon Linux 向け ALAS アドバイザリとして6月20日に公開された
  • 影響 — ユーザー任意のHEIF画像をアップロード・処理するウェブサービスや画像処理パイプラインで、細工した画像によるRCEが成立し得る。Amazon Linux（AWS）上で libheif を利用するコンテナ/サービスが直接対象
  • 対応 — libheif を修正版に更新。ユーザーアップロードHEIF画像の処理経路を確認し、未修正版での外部画像処理を停止
  • 〈AWS (Amazon Linux) / web 画像処理スタックに直接関連〉

🔴 Splunk Enterprise CVE-2026-20253 — CISA KEV修正期限が本日6月21日、認証不要RCE（CVSS 9.8） CRITICAL

項目詳細
CVECVE-2026-20253
CVSS9.8
CISA KEV2026-06-18 追加 / 連邦修正期限: 2026-06-21（本日）
影響バージョンSplunk Enterprise 10.0.0〜10.0.6 / 10.2.0〜10.2.3
修正バージョン10.0.7 / 10.2.4（10.4 は非影響、Splunk Cloud は非影響）
実害状況限定的な能動的悪用を Splunk PSIRT が6月18日に確認
  • 概要 — PostgreSQL サイドカーサービスの /v1/postgres/recovery/backup および /v1/postgres/recovery/restore エンドポイントに認証制御がなく、ネットワーク到達可能な認証不要攻撃者が任意のファイル作成・切り詰めを実行可能
  • 攻撃チェーン（watchTowr Labs が6月19日に技術詳細公開） — 攻撃者管理DBのダンプを任意ファイルに書き出し（backup）→ .pgpass でローカルPostgreSQLにリストア（restore）→ SQL関数 lo_export で任意ファイル書き込み → Splunk が定期実行するPythonスクリプト（例: ssg_enable_modular_input.py）を上書きしてRCE成立
  • 影響 — Splunk はCisco傘下のSIEM基盤。侵入されれば監視インフラ自体が盲点化し、検知能力が消失する
  • 対応 — 10.0.7 / 10.2.4 に即時更新（本日がCISA修正期限）。管理インターフェースとPostgreSQLサイドカーエンドポイントのネットワークアクセスを制限。未認証ファイル操作のログ監査を実施
  • 注記 — 本脆弱性の初出は6月17-18日だが、CISA KEVの連邦修正期限が本日6月21日に設定されており、前号で未取り上げのため緊急掲載

🔴 The Gentlemen RaaS — GentleKiller EDRキラーフレームワーク、48製品400プロセスを標的 HIGH

項目詳細
公表日2026-06-20（ESET Research / Broadcom Protection Bulletin）
脅威アクターThe Gentlemen RaaS（リーダー: ロシア人 Alexander Andreevich Yapaev / "hastalamuerte"、元Qilinアフィリエイト）
被害規模504件の被害を主張（Ransomware.live、主に東南アジア/南米/西欧）
主な手法BYOVD（脆弱ドライバ持ち込み）によるEDR無効化 → 暗号化
  • 概要 — GentleKiller は8つのバリアントで構成されるEDRキラーフレームワーク。各バリアントが異なる脆弱または悪意あるドライバを BYOVD 攻撃で悪用し、48のセキュリティ製品に関連する400プロセスを終了対象とする。悪用ドライバ: Kaspersky (eb.sys)・FACEIT Anti-Cheat (nseckrnl.sys)・Valorant (GameDriverX64.sys)・Javelin (stpm_old/new.sys)・WatchDog (dmx.sys)・Network Blocker (360netmon_wfp.sys)・Cleaner (IMFForceDelete.sys)・G11 (PoisonX.sys)
  • 特徴 — 新規公開の BYOVD PoC を数日以内に実戦化する異常な敏捷性。第三製/リークツール（HexKiller・ThrottleBlood・HavocKiller）も統合。バイナリ保護に Enigma/Themida を使用し、正規セキュリティベンダを模倣したファイル名・バージョン情報・デジタル署名・アイコンで検出回避
  • 追加ツール — Rust製クレデンシャルスティーラー OxideHarvest（buildx641）も検出。Chrome・Edge・Firefox・Brave・Opera 等16種のブラウザからデータ収集
  • 関連（CERT/CC UEFI Secure Boot バイパス警告） — 同時期に CERT/CC が複数ベンダ署名UEFIアプリの BYOVD 経由 Secure Boot バイパス警告を発令（Acer・AMD・ASUS・ECS・Getac・GIGABYTE・Toshiba・Uniwill）。管理者権限/物理アクセスでプレブート段階の任意コード実行が可能。UEFI Forbidden Signature Database (DBX) の更新で信頼を失効させる必要
  • 対応 — EDR のタンパープロテクションを最大設定、BYOVD 緩和（Microsoft Vulnerable Driver Blocklist の有効化）、DBX 更新の適用、EDRキラー検出のテスト
