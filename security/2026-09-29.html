Authlib（Python製OAuth／JWTライブラリ）— 署名検証が回避される脆弱性（CVE-2026-96760 / JVNVU#99151548）

深刻度CVSSv3.1 未採点（CERT/CCは影響度が大きいとして注意喚起）
CVECVE-2026-96760（CERT/CC VU#762428 の日本語版ミラー、JVNVU#99151548）
影響Authlib 1.7.2 まで（Python製の OAuth／OpenID Connect／JWS ライブラリ）
修正版本件執筆時点で公式パッチは未提供。ベンダへ2026-08-21に通知したが応答なしとされ、GitHubリポジトリを監視し修正版公開後に更新することが推奨されています
公開日CERT/CC 2026-09-28／JVN 2026-09-29 09:15（※本朝刊の対象期間直後の公開）
  • JsonWebSignature.deserialize_json() が、空の signatures 配列を持つJWSオブジェクトを「検証成功」とみなしてしまうため、鍵素材なしで任意のペイロードを改ざん・偽造できます。具体的には jws.deserialize_json({"payload":"...","signatures":[]}, key=None) および jws.deserialize('{"payload":"...","signatures":[]}', key=None) の双方が該当します。
  • 影響は sub=admin などへのなりすまし・権限昇格、マイクロサービス間の署名メッセージ注入、scope／role／permission の偽造、署名付きデータの完全性バイパスに及びます。
  • 公式パッチが未提供のため、暫定策として Authlib のJWS検証経路で空の signatures 配列を明示的に拒否する、あるいはJWS general JSON シリアライズ形式の入力を受理しない構成にする、といった緩和をご検討くださいませ。
  • 公開が本朝刊の対象期間直後（本日09:15）であるため、詳細・影響バージョンは CERT/CC アドバイザリ（VU#762428）およびAuthlibリポジトリでご確認くださいませ。

Claude Code 2.1.284 — 権限・MCP・マネージド設定まわりを修正

深刻度セキュリティ関連の不具合修正（CVE採番なし）

  • マネージド設定で allowManagedPermissionRulesOnly が有効な場合に、マーケットプレイス・claude.ai・npm 由来のプラグインが allowed-tools 経由で自ツールを事前承認していた問題を修正。Anthropic公式ソースか、マネージド設定が明示的に承認したソースのプラグインのみが事前承認を維持します。
