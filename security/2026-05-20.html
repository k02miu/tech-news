1. Azure — CVE-2026-42822 Azure Local Disconnected Operations 権限昇格（Critical, CVSS 10.0）

項目詳細
CVECVE-2026-42822
深刻度Critical（CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H — 10.0）
影響Azure Local Disconnected Operations (ALDO)
修正ALDO バージョン 2604 以降へ更新（フルシステム更新が必要）
公開日2026-05-18（NVD公開）
CWECWE-287（不適切な認証）

Azure Local Disconnected Operations に不適切な認証（CWE-287）に起因する権限昇格の脆弱性が存在します。認証されていない攻撃者がネットワーク経由で特権を昇格させる可能性があります。CVSS は最高値の 10.0 です。

対応:

  • Microsoft 運用の Azure Resource Manager 環境: Microsoft 側で緩和策が既に展開済み。顧客側の対応は不要。
  • ALDO を自前運用している顧客: ALDO バージョン 2604 以降へのフルシステム更新が必須。更新は Azure ポータル経由で実施。変更ウィンドウ・前提条件・ステージング・検証・ロールバック計画を含む慎重な計画が必要。
