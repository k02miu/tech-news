Metabase：認証不要のSQLインジェクションで管理者権限を取得される脆弱性（CVE-2026-72898） CRITICAL

製品Metabase（OSS BIツール）
CVECVE-2026-72898（関連: CVE-2026-72899）
CVSS10.0（Critical） CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H
影響x.63.5 / x.62.9 / x.61.11 / x.60.17 / x.59.21 / x.58.24 より前（58系未満は影響なし、Metabase Cloudは対策済み）
公開日時2026-08-14（JPCERT/CC注意喚起 JPCERT-AT-2026-0023）
情報源JPCERT/CC 注意喚起 / GitHub Advisory (GHSA-vwf4-m7j8-wcjf)
  • 認証されていない遠隔の攻撃者が細工したリクエストを送信し、Metabaseのアプリケーションデータベースへ不正なSQLクエリを実行して管理者権限を取得できる脆弱性。設定変更、接続先DBの保存済み認証情報窃取、データ読出・外部送信などが可能。
  • Metabaseは本脆弱性のゼロデイ悪用を確認しており、海外では複数の組織が被害を公表。PoCとみられる情報も公開済みのため、悪用拡大に注意が必要。
  • 直ちに更新できない場合は、一時回避策としてエンドポイント「/api/session/reset_password」へのアクセスを遮断。同エンドポイントをインターネット公開していた場合は、侵害有無の調査（POST /api/session/reset_password の400応答後、GET /api/user/current の200応答のパターン等）と接続先DB認証情報の変更を推奨。
  • 関連情報として、公開ダッシュボード経由のSQLインジェクション（CVE-2026-72899、GHSA-r8h2-qpfx-mx59）にも注意。

上記以外の対象スタック（Next.js / React / Java / Python / Django / Hono / GCP / AWS / Azure / Spring Boot / OpenClaw / Claude / Hermes Agent）について、直接関連する新規セキュリティ情報は本対象期間では確認されませんでした。

情報源TENTIAL公式発表 / ScanNetSecurity
  • 同社が利用するメール送信サービスのアクセスキーが第三者に不正利用され、正規の送信環境（noreply@tential.jp 等）から約110,000通のフィッシングメール（件名「Abonnement PrimeVideo」等）が送信された。
  • 不正利用されたアクセスキーはメール送信に特化したもので、顧客情報を閲覧する権限はなく、顧客DBへの不正アクセスや個人情報漏えいは現時点で確認されていない。
  • 同社は検知後、アクセスキーの無効化と不正送信経路の遮断を実施済み。
