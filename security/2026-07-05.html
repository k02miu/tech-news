🔴 Bad Epoll (CVE-2026-46242) — Linux カーネル Use-After-Free 特権昇格、成功率 99% CRITICAL

項目詳細
CVECVE-2026-46242 — Linux カーネル epoll の use-after-free 競合状態（CWE-416）。CVSS 3.1 7.8（AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H）
発見者Jaeyoung Chung（Google kernelCTF プログラムに 0-day として提出）
影響範囲Linux カーネル 6.4 以上（6.18.33 未満）、Android も影響。epoll は無効化不可のため回避策なし
修正修正パッチ公開済み（commit a6dc643c6931）。各ディストリビューションのバックポート適用を推奨
特筆点成功率約 99%。Chrome のレンダラーサンドボックス内からもトリガー可能。Anthropic の最強 AI モデル Mythos が同一コード領域の類似バグ（CVE-2026-43074）を発見していたが本件は見逃した
  • 概要 — Linux カーネルの epoll サブシステムに存在する use-after-free 脆弱性。ep_remove() の競合ウィンドウ（約6命令幅）で file 構造体と eventpoll 構造体が同時に解放され、カーネルメモリ破壊→root 権限取得が可能。Chung のエクスプロイトはタイミングウィンドウを拡張し、99% の成功率を達成
  • AI と脆弱性発見 — Anthropic Mythos は同一の 2023 年コミットに起因する最初のバグ（CVE-2026-43074）を発見・修正したが、Bad Epoll を見逃した。これは小さなタイミングウィンドウと KASAN 検出不能という特性による。AI による脆弱性発見の限界を示す事例として注目される
  • Android への影響 — 多くの Linux カーネル特権昇格バグは Android に到達しないが、Bad Epoll は到達可能。Android 向けエクスプロイトも開発中
  • 対応 — 修正パッチ（commit a6dc643c6931）を適用、または各ディストリビューションのバックポートを適用。epoll は無効化不可のため回避策は存在しない。カーネル 6.18.33+ / 7.0.10+ / 7.1+ で修正済み
