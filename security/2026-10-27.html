Microsoft .NET 定例外セキュリティ更新 — Brotli のバッファオーバーフロー（CVE-2026-111497、CVSS 8.1）ほか Critical

CVECVE-2026-111497 / CVE-2026-114148 / CVE-2026-70197 / CVE-2026-102870
CVSS8.1（CVE-2026-111497、CVSSv3.1）／7.8（CVE-2026-114148）
影響.NET 10 / 同 9 / 同 8、ASP.NET Core
公開現地 2026-10-25 公開、2026-10-26 報道
  • マイクロソフトは 2026年10月25日（現地）、「.NET 10」「同 9」「同 8」向けの定例外セキュリティアップデートを公開した。新規2件に加え、10月13日の月例更新で修正が不十分だった2件にも再度対応している。
  • CVE-2026-111497（CVSSv3.1 8.1、重要度は4段階中もっとも高い「緊急（Critical）」）は、データ圧縮形式「Brotli」の展開処理を行うGoogle製ライブラリに判明したバッファオーバーフロー。細工した圧縮データを処理させるだけで認証不要に成立し、メモリ上の情報の読み取り、サービス拒否、権限の昇格などが生じるおそれがある。Brotli API で外部から受け取った圧縮データを展開する場合のほか、既定では無効ながら「ASP.NET Core」のリクエスト展開機能や「HttpClient」のレスポンス自動展開機能を有効化している場合も影響する。Brotli のみを除外する回避策も案内されている。
  • CVE-2026-114148（CVSS 7.8、重要度「重要（Important）」）は、「ASP.NET Core」などの Linux 向け配布ファイルに確認された権限昇格。配布ファイルに含まれる所有権情報の処理に起因し、ローカル環境でファイルの改変や権限昇格につながるおそれがある。
  • 10月13日の月例更新で修正が不十分だったリモートコード実行の脆弱性 CVE-2026-70197 と CVE-2026-102870 についても、あらためて修正が実施された。
  • 実行環境をアプリケーションに組み込んで配布している場合やコンテナ環境では、更新した環境でのアプリケーション再ビルドと再配布が必要となる。早急な適用が呼びかけられている。
  • 出典: Security NEXT 2026/10/26、Microsoft MSRC

Arista VeloCloud Orchestrator（VCO）— SQL インジェクションで管理機能へ権限昇格、すでに悪用を確認（CVE-2026-114625、CVSSv4.0 9.4 / CVSSv3.1 9.9） Critical

  • ベンダは「6.4.2.12」「6.1.3.10」「5.2.3.18」で修正版を公開している。米 CISA は 2026年10月23日（現地）に本件を「悪用が確認された脆弱性カタログ（KEV）」へ追加し、米政府機関の対応期限を10月26日に指定、脆弱性の解消だけでなく侵害の有無の調査も求めている。
  • 出典: Security NEXT 2026/10/26、Arista Security Advisory 0199

MacCMS v10 — msg_to 未検証で未認証のアカウント乗っ取り（CVE-2026-116214、CVSSv3.1 9.1） Critical

CVECVE-2026-116214
CVSS9.1（CVSSv3.1）／9.3（CVSSv4.0）
影響MacCMS v10（maccms10）2026.1000.4054 未満
公開NVD 登録 2026-10-26 14:16 UTC（JST 23:16）
  • check_msg() が msg_to を比較しないため、未認証の攻撃者が任意の会員のパスワードをリセットできる。まず user/findpass_msg で自分宛の復旧コードを取得し、それを user/findpass_reset へ被害者のメールアドレスまたは電話番号とともに送信するだけでアカウントを乗っ取れる。
  • 出典: NVD、maccms10 Issue #30
