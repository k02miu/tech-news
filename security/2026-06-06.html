1. IronWorm — Rust製自己複製型ワームがnpmエコシステムを襲撃、36以上のパッケージに感染 Critical

項目詳細
分類サプライチェーン攻撃（CVE未割当）
発見日2026-06-05
影響対象npmエコシステム全体（Web / React / Node.js 開発者環境）
深刻度Critical — 環境変数・クラウド認証情報・暗号通貨ウォレットが窃取対象

新たに発見されたRust製のサプライチェーン攻撃「IronWorm」が、npmパッケージレジストリを標的にしています。JFrogによって「IronWorm」と名付けられたこのキャンペーンは、正規のnpmパブリッシングワークフローを乗っ取り、悪意あるパッケージアップデートを通じて自己複製型ワームを拡散させます。

  • 36以上のパッケージが感染し、Rust製の情報窃取マルウェアが仕込まれている
  • マルウェアは環境変数、クラウド認証情報（AWS/GCP/Azure）、暗号通貨ウォレットを標的に
  • eBPFカーネルルートキットを使用して隠蔽、従来のセキュリティツールによる検出を回避
  • 自己複製によりカーゴカルト的に感染を拡大、影響が連鎖的に広がる
  • 特にWeb3/暗号通貨開発者環境を重点的に標的

本攻撃は同時期に発生したMiasmaワーム（binding.gyp経由）とは別のキャンペーンと見られており、npmエコシステムが複数のサプライチェーン攻撃に同時に晒されている状況です。

2. React Router — 複数のセキュリティ脆弱性を公表 (CVE-2026-33245, CVE-2026-33244, CVE-2026-40181) High

分類複数CVE（XSS・Open Redirect）
公開日2026-06-02 〜 2026-06-05
影響対象React Router v7.x（+ Remix v2）
修正バージョンv7.13.2 以上

CVE-2026-33245 HIGH (CVSS 8.0)

  • React Router v7.7.0〜7.13.1 の unstable RSC（React Server Components）API 使用時におけるXSS脆弱性
  • RSCリダイレクト処理で javascript: スキームのリダイレクトターゲットを許可していたため、クライアントサイドXSSが成立
  • v7.13.2 でプロトコル許可リストを追加し修正

CVE-2026-33244 HIGH

  • React Router v7.5.1〜7.13.1 の Pre-rendering（Framework Mode）使用時における格納型XSS
  • HTTP Location ヘッダー値のエスケープ不備により、静的に生成されたHTMLにXSSが混入
  • v7.13.2 で修正

CVE-2026-40181 MEDIUM (CVSS 6.5)

  • React Router v7.0.0〜v7.14.3 の redirect 関数における Open Redirect 脆弱性
  • 同一オリジンリダイレクトのパスが // で始まる場合、プロトコル相対URLとして解釈され任意の外部サイトへ誘導可能

3. Miasma Wave 2 — binding.gyp 経由の npm サプライチェーンワーム、57パッケージに拡大 Critical

項目詳細
分類サプライチェーン攻撃（CVE未割当、進行中）
発見日2026-06-03（第2波、継続中）
影響対象57パッケージ、286悪意バージョン、647,204週間ダウンロード

6月1日に@redhat-cloud-services名前空間の32パッケージを標的にしたMiasmaワームが、6月3日に第2波を発動。57パッケージにわたり286以上の悪意バージョンが2時間足らずで公開されました。最大の標的は @vapi-ai/server-sdk（Vapi.ai音声AIサーバーSDK、月間40万DL超）です。

  • binding.gyp ファイルを悪用し、package.json の postinstall スクリプトを経由せずにコード実行
  • 従来の npm install 監視ツールを完全にバイパス
  • 有効なSigstore署名証明書を取得しており、署名済みパッケージとして配布
  • CI/CD認証情報を窃取し、さらなるパッケージ乗っ取りに悪用
  • 前週にテイクダウンされたGlassworm以降も、npmエコシステムへの攻撃は衰えを見せない
