1. Netty incubator codec-ohttp に Critical な OOB メモリアクセス脆弱性 CRITICAL

項目詳細
CVECVE-2026-48040
CVSS9.1 (Critical)
影響対象netty-incubator-codec-ohttp < 0.0.22.Final
公開日2026-06-04 (NVD 公開: 2026-06-05)
  • Oblivious HTTP (RFC 9458) 実装ライブラリ netty-incubator-codec-ohttp において、BoringSSL の HPKE C ライブラリを JNI 経由で使用する際にネイティブメモリアドレスを不適切に導出
  • sun.misc.Unsafe が利用不可の環境（-Dio.netty.noUnsafe=true、SecurityManager 制限下、非 HotSpot JVM など）で PooledDirectByteBuf のフォールバックパスが発動
  • 未認証のネットワーク攻撃者が細工した OHTTP リクエストを送信することで、同じ Netty バッファアリーナを共有する他の接続のメモリを破壊・隣接プールバッファの内容を開示可能
  • 情報漏洩により、漏洩データを抽出するための暗号鍵が攻撃者に渡るため、全接続の機密性と完全性が侵害される
  • 〈Java / Spring Boot スタックに影響〉

2. Netty incubator codec-ohttp にサイレントゼロ鍵脆弱性 MEDIUM

項目詳細
CVECVE-2026-41207
CVSS5.3 (Medium)
影響対象netty-incubator-codec-ohttp < 0.0.21.Final
公開日2026-06-04 (NVD 公開: 2026-06-05)
  • HKDF_expand が失敗時に非 NULL を返し、結果の byte[] がゼロで埋められる。成功/失敗の区別がつかないため、サイレントに全ゼロの AEAD 鍵が生成される
  • EVP_HPKE_CTX_export 失敗時も同様に空のゼロ埋め byte[] が返り、攻撃者が予測可能な決定論的 AEAD 鍵が生成される
  • 同じく Java / Spring Boot スタックに影響

🔗 GitHub Advisory GHSA-f659-372h-6x3x

3. quic-go HTTP/3 実装に QPACK トレイラーベースの DoS 脆弱性 HIGH

項目詳細
CVECVE-2026-40898
CVSS7.5 (High)
影響対象quic-go < 0.59.1
公開日2026-06-04 (NVD 公開: 2026-06-05)
  • quic-go の HTTP/3 実装において、QPACK 圧縮された HEADERS フレームが巨大なトレイラーフィールドセクションに展開される問題
  • エンコードサイズのみ制限され、デコード後のフィールドセクションサイズに制限がないため、http.Header のメモリ割り当てが爆発的に増加
  • 悪意のあるピアがサーバー/クライアント双方にメモリ枯渇 DoS 攻撃を仕掛けることが可能
  • CVE-2025-64702（HTTP ヘッダー版）に類似 — 本件は HTTP トレイラーを攻撃ベクトルとする点が異なる
  • 〈Go / ネットワークスタックに影響。HTTP/3 を使用するアプリケーション全体に関係〉
