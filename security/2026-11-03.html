python-jose（Python / JWTライブラリ）3.5.0以下 - 空のHMACシークレットでJWT偽造（認証バイパス） Critical

CVECVE-2026-120459
深刻度CVSSv3.1 9.1（Critical）
影響python-jose 3.5.0以下（HS256 / HS384 / HS512 を検証に使うアプリ）
公表NVD登録 2026-11-02 15:17 UTC（JST 2026-11-03 00:17）
  • HMACKey / CryptographyHMACKey が長さゼロのHMACシークレットを受け入れてしまう。アプリケーションの検証鍵が空に解決される場合（k が空の oct JWK など）、未認証の攻撃者が任意のクレームを持つトークンを偽造でき、jwt.decode がこれを受理する。
  • JWT を認証・セッションの根拠にしている Python サービスは検証鍵の設定が空になっていないか至急確認が必要。
