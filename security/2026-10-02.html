  • CVE-2026-56154（9.8）：mod_rewrite で先読み式（%{LA-U:HTTP:...}）を使った際の Use After Free。

  • High 7.5 が多数：mod_proxy_uwsgi の HTTP レスポンススマグリング（CVE-2026-63718）、mod_xml2enc の NULL 参照（63686）、mod_vhost_alias のスタックバッファオーバーフロー（63292）、mod_proxy_ftp の PASV 検証不備（63045）、Windows の 8.3 名展開による境界外書き込み（59685）、mod_proxy_html（56449）、mod_charset_lite（56153）、mod_auth_digest の認証欠如（48005）、mod_session_cookie の情報露出（47360）、mod_heartmonitor の NULL 参照（46729）。
  • 対策は 2.4.69 以降への更新。前バージョン 2.4.68 も直近に大量修正が入っており、複数世代まとめての更新が望ましい。
