openEQUELLA に FreeMarker 経由の任意コード実行（CVE-2026-94109） HIGH

CVECVE-2026-94109
深刻度CVSSv3.1 8.8（High）
影響openEQUELLA 2026.1.0 未満（Java ベースの教育機関向けコンテンツ・リポジトリ管理基盤）
公開NVD 登録 2026-09-20 21:17 JST（2026-09-20 12:17 UTC）
対策2026.1.0 以降へ更新
  • FreeMarker のテンプレートコンパイルで TemplateClassResolver がサンドボックス化されておらず、認証済みの攻撃者が細工したテンプレート式を注入できる。
  • 注入経路はコレクションのサマリー、ダッシュボードのポートレット、MIME テンプレートなど。freemarker.template.utility.Execute などの危険なクラスをインスタンス化し、Runtime.exec を呼び出して任意のコードを実行されるおそれがある。
  • Java 製 Web アプリケーションを運用している環境では、該当バージョンの有無を確認のうえ速やかに更新されたい。

getID3 1.9.26 未満に OS コマンドインジェクション（CVE-2026-94106） HIGH

CVECVE-2026-94106
深刻度CVSSv3.1 8.8（High）
影響getID3 1.9.26 未満（PHP 製のメディアメタデータ解析ライブラリ）
公開NVD 登録 2026-09-20 21:17 JST（2026-09-20 12:17 UTC）
対策1.9.26 以降へ更新
  • 外部コマンドを呼び出す shell-out ハンドラでファイル名がエスケープされておらず、シェルのメタ文字を含むファイル名を解析させると、getID3 を組み込んだプロセスの権限で任意のコマンドを実行されるおそれがある。
  • アップロードされたメディアファイルを PHP 側で解析する構成（旧来の CMS・EC パッケージ等）では、攻撃者がファイル名を制御できる経路がないか併せて確認されたい。
