1. CVE-2026-47774 — Envoy HTTP/2 HPACK メモリ枯渇 DoS HIGH

項目詳細
CVECVE-2026-47774
CVSS7.5（CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H）
公開日2026-06-17（NVD / GitHub Advisory）
CWECWE-405: Asymmetric Resource Consumption (Amplification)、CWE-770: Allocation of Resources Without Limits or Throttling
影響コンポーネントEnvoy Proxy（HTTP/2 downstream リクエスト処理）
修正バージョン1.35.11 / 1.36.7 / 1.37.3 / 1.38.1
  • 概要 — Envoy の HTTP/2 downstream リクエスト処理において、Cookie ヘッダのバイト数がリクエストヘッダサイズ検証に完全に計上されない問題と、oghttp2/quiche の HPACK ヘッダブロック制限がエンコード済みバイトに対してのみ適用されデコード済みサイズに制限がない問題が組み合わせることで、攻撃者は細工した HTTP/2 Cookie ヘッダにより Envoy プロセスのメモリ枯渇（OOM）を引き起こせる
  • 影響 — 認証不要、ネットワーク経由で悪用可能。テストでは 3GiB メモリ制限の Envoy エッジプロセスが数秒で OOM キルされた。フローコントロールの停滞により攻撃効果が増幅される
  • 対応 — 影響を受けるバージョン（<1.35.11、1.36.0〜1.36.6、1.37.0〜1.37.2、1.38.0）をアップグレード。一時緩和策として downstream HTTP/2 の無効化、リクエストヘッダ／Cookie の厳格な制限設定が可能
  • 報告者 — Ryoga Yamashita
  • 〈AWS / GCP スタックに直接関連 — Envoy は Istio、Google Cloud Load Balancing、AWS App Mesh 等で広く使用〉

2. CVE-2026-48710 — Starlette "BadHost" Host ヘッダ検証バイパス MEDIUM

項目詳細
CVECVE-2026-48710
CVSS6.5（CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N）
公開日2026-05-26（GitHub）/ NVD 最終更新: 2026-06-17
CWECWE-444: Inconsistent Interpretation of HTTP Requests、CWE-1289: Improper Validation of Unsafe Equivalence in Input
影響コンポーネントStarlette（Python ASGI フレームワーク）0.8.3 〜 1.0.0
修正バージョンStarlette ≥ 1.0.1
  • 概要 — Starlette の HTTP Host リクエストヘッダが request.url の再構築前に検証されないため、不正な形式の Host ヘッダにより request.url.path が実際にリクエストされたパスと異なる値になる。これにより、request.url ベースのセキュリティ制限（CSP、リダイレクト検証、CSRF 保護等）をバイパス可能
  • 影響 — 認証不要、ネットワーク経由で悪用可能。FastAPI、Litestar 等の Starlette ベースフレームワーク全般に影響。RFC 9112 §3.2 / RFC 3986 §3.2.2 に準拠する Host ヘッダ検証で修正
  • Hermes Agent への影響 — Hermes Agent v0.16.0 で Starlette のバージョンをピン留めし、本脆弱性への対応を完了
  • 〈Python / web スタックに直接関連〉
