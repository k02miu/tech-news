@fastify/express・@fastify/middie - パススコープのミドルウェア回避により保護ルートへ到達（CVE-2026-124626 ほか計5件、各 CVSSv3.1 9.1） Critical

公開2026-11-21（NVD 登録）
CVECVE-2026-124626 / CVE-2026-129504 / CVE-2026-133120 / CVE-2026-133867（@fastify/express）、CVE-2026-133250（@fastify/middie）
影響@fastify/express 4.0.10 未満（4.0.0〜4.0.9）／@fastify/middie 9.3.8 未満（9.3.7 以下）
深刻度CVSSv3.1 9.1（Critical、各）
出典https://nvd.nist.gov/vuln/detail/CVE-2026-124626 ほか
  • Fastify 上で Express ミドルウェアを動かす互換レイヤー @fastify/express と、Fastify のミドルウェアエンジン @fastify/middie に、パススコープのミドルウェアがスキップされる不備が複数見つかった。5件はいずれも CVSSv3.1 で「9.1（Critical）」と評価されている。
  • ルーターが配送に用いるパスと、ミドルウェアのマッチャが判定するパスが食い違う場合（動的セグメントやワイルドカードの空値、先頭スラッシュを持たないリクエストターゲット、正規表現マウントとパラメータ付きプレフィックスの組み合わせ、バックスラッシュや二重パーセントのデコード差など）に、ルーターはハンドラへ配送する一方でミドルウェアは実行されない。認証・認可・レート制限をパススコープのミドルウェアで実装している構成では、未認証のクライアントが保護対象のハンドラへ到達し得る。細工したリクエストや非既定のオプションは不要。
  • 対策は @fastify/express 4.0.10、@fastify/middie 9.3.8 以降への更新。

WordPressプラグイン2件 - 未認証のリモートコード実行と管理者権限昇格（CVE-2026-120539 / CVE-2026-125294、各 CVSSv3.1 9.8） Critical

公開2026-11-21（NVD 登録、Wordfence 採番）
CVECVE-2026-120539（Restrictions for BuddyPress）／CVE-2026-125294（Nexter Blocks Pro）
影響Restrictions for BuddyPress 1.5.4 以下／Nexter Blocks Pro 5.0.10 以下
深刻度CVSSv3.1 9.8（Critical、各）
出典https://nvd.nist.gov/vuln/detail/CVE-2026-120539 ほか
  • CVE-2026-120539（Restrictions for BuddyPress）は、攻撃者制御のリクエストURIをダブルクォート文字列内のPHP式へ連結し eval() で評価するため、URLパスに {${...}} 形式のペイロードを送るだけで未認証の遠隔コード実行が成立する。影響する条件は既定で有効かつログイン判定より前に評価され、設定変更は不要。サイト側に BuddyPress と Paid Memberships Pro が有効である必要がある。
  • CVE-2026-125294（Nexter Blocks Pro）は、新規登録処理のパラメータ検査がASCII基準の拒否リストである一方、データベースの照合順序がアクセント非依存（utf8mb4_unicode_ci 系）であるため、Unicodeの類似文字（例「ẇp_çapabilities」）で wp_capabilities を上書きでき、未認証で管理者権限のアカウントを登録される。nonce はログイン／登録ブロックを含むページに公開されるため、既定構成かつユーザー登録が有効な環境で到達可能。
  • いずれも該当プラグインの更新・無効化を検討されたい。

  • OpenRemote（CVE-2026-134287、9.2）: MQTTの UserAssetProvisioningMQTTHandler が秘密鍵の所持を検証しないため、未認証の攻撃者が既知の機器の公開証明書を送るだけで機器になりすませる。1.34.0 で修正。
  • Admidio（CVE-2026-134258、9.3／CVE-2026-134262、9.2）: ファイル名変更（renameFile）のパストラバーサルでスクリプト入りSVGを公開領域へ移動させ格納型XSSに至る問題と、ロール名の未エスケープによる格納型XSS（管理者のCSRFトークンを窃取し権限昇格）。5.0.18 で修正。

  • 早稲田大学は、ポータルサイト「MyWaseda」のログインに用いるユーザー情報を管理するシステムが第三者によって侵害され、管理していたユーザー情報の一部が外部に流出したことを明らかにした。PHPの脆弱性へ対応するためシステムの状況を確認していたところ、2026年8月31日に行われた侵害の痕跡を確認。さらに調査を進めた結果、システムに侵入され一部の情報を取得されていたことが判明した。
  • 窃取されたのは、職員などの氏名・メールアドレス・教職員番号・所属部署名・資格名・暗号化されたパスワードなどののべ3,261件。うち教職員・学生・卒業生に関する81件については、氏名のほか資格名・メールアドレス・暗号化されたパスワードなどが含まれる。
  • 大学は外部協力のもと、侵入経路やさらなる情報取得の有無、影響範囲について詳細な調査を進め、関係機関への報告を行うとしている。大学・教育機関は学認系のSSO基盤を狙った攻撃が続いており、認証基盤の点検が望ましい。
