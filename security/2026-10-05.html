Claude Code 2.1.289 - 権限ルール・サンドボックス・プラグイン隔離まわりを修正 MEDIUM

バージョンClaude Code 2.1.289（最新）
リリース2026-10-03 23:07 UTC（JST 2026-10-04 08:07）
主な内容複合シェルコマンドの入れ子部分に対する deny / ask ルールの適用、シンボリックリンク経由の Read 拒否ルール、サンドボックス自動許可時の権限バイパス、プラグインによる組織管理設定の書き換えの修正
  • マネージド端末におきまして、複合シェルコマンドの入れ子部分に設定された deny または ask ルールが、ユーザーが導入したmodの承認を打ち消せていなかった問題が修正されました。承認の持ち越しが意図どおりに効くようになり、組織側のポリシーが優先されますわ。
  • Read の拒否ルールが、シンボリックリンク経由で @ メンション・IDEからの変更操作・選択されたファイルに適用されていなかった問題も修正されております。リンク越しの参照でファイル保護をすり抜けられておりました。
  • サンドボックスの自動許可が働く構成で、環境変数のプレフィックス付きコマンド（例：TZ="$HOME" rm -rf build）や、コマンド前に単独の変数代入が置かれた場合に Bash の deny / ask ルールが素通りしていた問題も修正されました。破壊的なコマンドを抑止したい運用では重要な修正ですわ。
  • 加えて、ユーザー導入プラグインが組織管理のMCPサーバのサインインツールの説明文を書き換えられていた問題、アップグレード後の初回セッションで導入済みmodが読み込まれない問題なども修正されています。2.1.289 以降への更新をご検討くださいませ。
