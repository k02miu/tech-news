1. React エコシステム — CVE-2026-30691 @cyntler/react-doc-viewer XSS（Medium）

項目詳細
CVECVE-2026-30691
深刻度Medium（NVD CVSS 評価未了）
影響@cyntler/react-doc-viewer ≤ 1.17.1
修正現時点でパッチバージョン未確認。当該パッケージの使用を再評価し、必要に応じて代替手段を検討
公開日2026-05-20（NVD公開）
CWECWE-79（クロスサイトスクリプティング）

React 用ドキュメントビューアコンポーネント @cyntler/react-doc-viewer v1.17.1 に XSS 脆弱性が存在します。TxtRenderer コンポーネントがファイル内容をサニタイズせず、生データを ReactNode として直接キャストするため、細工された .txt ファイルを介してリモートの攻撃者が任意の JavaScript を実行可能です。

対応: 影響を受けるバージョン（≤ 1.17.1）を使用している場合は、修正バージョンがリリースされ次第アップデートしてください。それまでの間、信頼できないソースからの文書をビューアで開かない、または代替ライブラリへの移行を検討してください。

🔴 GitHub — TeamPCP による内部リポジトリ侵害（約3,800件）、悪意ある VS Code 拡張機能が侵入経路（5/20 確認）

  • GitHub が 5月20日、サイバー犯罪グループ TeamPCP（UNC6780 としても追跡）による内部リポジトリ約 3,800 件の不正流出を確認
  • 侵入経路は GitHub 従業員がインストールした悪意ある VS Code 拡張機能。VS Code 拡張機能は開発マシン上の認証情報・SSH キー・クラウドキーなどに広範なアクセス権を持つ
  • TeamPCP は窃取したソースコード・内部組織データをサイバー犯罪フォーラムで 最低 $50,000 で販売。買い手が現れなければ公開すると脅迫
  • GitHub は重要シークレットのローテーションを完了し、調査を継続中。現時点で顧客データへの影響は確認されていない
  • TeamPCP は 2026年に入り Trivy, Checkmarx, Bitwarden CLI, TanStack など複数のサプライチェーン攻撃を実行してきたグループで、今回も 開発者ツールを標的とした攻撃
