2. React — CISA KEV 追加: CVE-2026-45321 (TanStack npm サプライチェーン攻撃)

項目詳細
CVECVE-2026-45321
深刻度Critical（CVSS 9.6）
種別npm サプライチェーン攻撃（認証バイパス + クレデンシャル窃取マルウェア）
影響42 の @tanstack/* パッケージ（React エコシステム）に 84 の悪意あるバージョンが公開
発生2026年5月11日（インシデント発生）、5月27日（CISA KEV 追加）
脅威グループTeamPCP（通称 Mini Shai-Hulud キャンペーン）

CISA は5月27日、TanStack の npm パッケージ群に対する大規模サプライチェーン攻撃 CVE-2026-45321（CVSS 9.6）を Known Exploited Vulnerabilities（KEV）カタログに追加し、積極的悪用を確認したと発表しました。

本攻撃は、GitHub Actions の pull_request_target 設定不備、キャッシュポイズニング、OIDC トークンの実行時メモリ抽出という3つの脆弱性を連鎖させ、正規の Trusted Publisher 証明書を保持したまま悪意あるパッケージを npm に公開するという極めて高度な手口です。影響を受けるパッケージには React Router など React 開発で広く使用されるものも含まれます。

悪意あるバージョンは npm により検出・削除済みであり、TanStack は全パッケージの現在の公開バージョンが安全であることを確認しています。ただし、侵害ウィンドウ（5月11日 19:20〜19:26 UTC）に該当バージョンをインストールした環境は完全な侵害（AWS/GCP クレデンシャル、GitHub トークン、SSH 鍵、暗号通貨ウォレットなどの窃取）を想定し、全クレデンシャルのローテーションを強く推奨します。
