1. GCP — Apigee SSRF + サービスアカウントトークン流出（CVE-2026-2264 / GCP-2026-034, High）

項目詳細
CVE / BulletinCVE-2026-2264 / GCP-2026-034
深刻度High
影響Apigee（Google Cloud 版 + Apigee Hybrid）— SetIntegrationRequest ポリシー
修正Google Cloud Apigee: 自動パッチ適用済み（1-16-0-apigee-5）。Apigee Hybrid: 1.14.4 / 1.15.2 / 1.16.1 へアップグレード
公開日2026-05-20（GCP Security Bulletin）
CWEServer-Side Request Forgery (SSRF)

Apigee の SetIntegrationRequest ポリシーにおいて、IntegrationRegion パラメータの検証不備により Server-Side Request Forgery (SSRF) が可能となる脆弱性が確認されました。攻撃者がフロー変数を操作できる場合、リクエストが攻撃者の制御するホストに送信され、サービスアカウントトークンが流出する可能性があります。

対応:

  • Google Cloud 版 Apigee: 修正はリリース 1-16-0-apigee-5 に適用済み。ユーザー側の対応は不要。
  • Apigee Hybrid: メジャーバージョンに応じて 1.14.4 / 1.15.2 / 1.16.1 へのアップグレードが必須。

🔗 GCP Security Bulletin GCP-2026-034 · Apigee Security Bulletin

3. Python — ChromaDB 認証バイパスによるリモートコード実行（CVE-2026-45829, Critical）

項目詳細
CVECVE-2026-45829（通称: ChromaToast）
深刻度Critical（CVSS 4.0: AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H）
影響ChromaDB Python FastAPI サーバー v1.0.0 〜 v1.5.8
修正v1.5.8 時点で未パッチ。修正バージョンのリリースを待ち、速やかにアップグレード
公開日2026-05-20（NVD 公開）
CWECWE-94（コードインジェクション）

オープンソースのベクトルデータベース ChromaDB（月間 1,300 万 pip ダウンロード）の Python FastAPI サーバーに、認証前リモートコード実行（Pre-Auth RCE）の脆弱性が発見されました。認証されていない攻撃者が /api/v2/tenants/{tenant}/databases/{db}/collections エンドポイントに対し、悪意ある Hugging Face モデル参照と trust_remote_code: true を送信することで、認証チェック前に任意のコードをサーバー上で実行できます。

HiddenLayer の調査によれば、Shodan で検出されたインターネット公開 ChromaDB インスタンスの 73% が脆弱なバージョン（1.0.0+）を実行中です。

対応:

  • 修正バージョンがリリースされ次第、速やかにアップグレード
  • それまでの間、ChromaDB API を信頼できるネットワークにのみ公開するよう制限
  • インターネットに直接公開しているインスタンスは直ちにアクセス制限を適用

🔗 NVD · HiddenLayer 詳細レポート · GitHub Issue #6717

4. Next.js — Turbopack 環境で CVE-2026-44575 修正が不完全（CVE-2026-45109, High）

項目詳細
CVECVE-2026-45109
深刻度High（NVD CVSS 評価未了。CVE-2026-44575 同等と推定）
影響Next.js 15.2.0 〜 15.5.17、16.2.0 〜 16.2.5（Turbopack 使用時のみ）
修正15.5.18 以降 / 16.2.6 以降
公開日2026-05-21（NVD 公開）
CWECWE-288（代替パスを用いた認証バイパス）

先日修正された CVE-2026-44575（Next.js App Router のミドルウェア認証バイパス）の修正が、Turbopack 環境では不完全であることが判明しました。middleware.ts を使用した認可チェックが、Turbopack 使用時に .rsc およびセグメントプリフェッチリクエストに対して適切に適用されません。

背景: CVE-2026-44575（5月11日公開）では、App Router のミドルウェアマッチャーがトランスポート固有のリクエスト（.rsc、セグメントプリフェッチ）を捕捉できず、認可バイパスが発生していました。今回の CVE-2026-45109 は、その修正が Turbopack 環境に正しく反映されていなかった問題です。

対応:

  • Turbopack 使用環境: Next.js 15.5.18 以降 または 16.2.6 以降へアップグレード
  • Turbopack 非使用環境: 既存の CVE-2026-44575 修正（15.5.16 / 16.2.5）で対応済み
