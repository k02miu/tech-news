「PHP2Shell」の悪用を確認 — 米当局が KEV 登録、対応期限を10月29日に指定（CVE-2026-109618 / CVE-2026-109619、CVSSv4.0 9.2） Critical

CVECVE-2026-109618 / CVE-2026-109619
CVSS9.2（CVSSv4.0）
影響PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 未満（Web リクエストを処理する全インストール、サポート終了版を含む）
公開CISA KEV 追加 現地 2026-10-26、Security NEXT 2026-10-27 報道、IPA 注意喚起 2026-10-27 更新
  • 米サイバーセキュリティインフラストラクチャセキュリティ庁（CISA）は現地2026年10月26日、通称「PHP2Shell」と呼ばれる CVE-2026-109618・CVE-2026-109619 を「悪用が確認された脆弱性カタログ（KEV）」へ登録した。実際に悪用されていることが確認されている。
  • いずれも認証を必要とせず、リモートからコードを実行されるおそれがある。CVE-2026-109618 はメモリ不足時の処理、CVE-2026-109619 は解放済みメモリに関連する内部状態の管理に起因する。外部からのリクエストを処理する PHP 環境、とくにウェブサイトではリスクが高い。
  • PHP 開発チームは 10月21日に 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 を公開して修正した。サポート終了済みの 7.4 / 8.0 / 8.1 向けにもソースコードへ適用する修正が提供され、一部 Linux ディストリビューションではバックポートも行われている。
  • CISA は米行政機関の対応期限を現地時間10月29日と指定し、脆弱性の解消だけでなく侵害の有無の確認も求めている。国内では IPA が2026年10月27日に注意喚起を更新している。
  • 出典: Security NEXT 2026/10/27、CISA KEV Catalog、IPA 注意喚起

「Brotli」脆弱性の影響が拡大 — Windows 版 PHP と PowerShell が相次いで更新（CVE-2026-111497、CVSSv4.0 9.2） Critical

CVECVE-2026-111497
CVSS9.2（CVSSv4.0）
影響PHP（Windows 版、cURL 拡張で自動展開を有効化している場合）／PowerShell 7.6.9・7.5.13・7.4.22 未満
公開PHP 修正版 現地 2026-10-26、PowerShell アドバイザリ 現地 2026-10-25、いずれも 2026-10-27 報道
  • Google 製の圧縮ライブラリ「Brotli」に判明したバッファオーバーフロー（前日報の .NET 定例外更新で対応済み）について、影響範囲が他製品へ広がっていることが明らかになった。細工した圧縮データをデコード処理させると域外メモリへの書き込みが生じ、任意コード実行・情報漏えい・サービス拒否などにつながるおそれがある。
  • Windows 版 PHP: cURL 拡張モジュールが HTTP レスポンスの自動展開を有効化している場合に Brotli デコーダを経由し得る。既定設定では自動展開は無効だが、アプリケーションや HTTP クライアントライブラリが有効化する場合もある。現地2026年10月26日公開の PHP 8.5.12-1 / 8.4.27-1 / 8.3.36-1 / 8.2.35-1 で Brotli 1.2.1 に更新され修正された。
  • PowerShell: マイクロソフトは現地2026年10月25日、CVE-2026-111497 に対応するセキュリティアドバイザリを公開。「Invoke-WebRequest」「Invoke-RestMethod」でウェブサイトへアクセスした場合に影響し、権限昇格などに悪用され得る。Windows に加えて macOS・Linux 環境も影響を受け、PowerShell 7.6.9 / 7.5.13 / 7.4.22 で修正されている。
  • 出典: Security NEXT 2026/10/27（Windows 版 PHP）、Security NEXT 2026/10/27（PowerShell）
