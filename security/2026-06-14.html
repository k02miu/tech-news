項目詳細

公開日2026-06-11（Apache Security Advisory / oss-security ML）

🔴 Linux カーネル nf_tables ルートエクスプロイト公開 — CVE-2026-23111 CRITICAL

項目詳細
CVECVE-2026-23111
深刻度High〜Critical（ローカル権限昇格）
公開日2026-06-08（The Hacker News / Ars Technica / Security Affairs）
影響対象nf_tables を有効にした Linux カーネル（RHEL、Ubuntu、Debian 等すべての主要ディストリビューション）
PoC公開済み
  • 1文字の誤りが引き起こした深刻な脆弱性 — Linux カーネルの nf_tables パケットフィルタリングサブシステムで、論理演算子「!」が余計に入った1文字のバグにより、use-after-free が発生。ローカル攻撃者がroot 権限を取得可能
  • 2026-06-08 に複数の主要セキュリティメディア（The Hacker News、Ars Technica、Security Affairs）が報道。PoC（概念実証コード）が公開済みの状態
  • コンテナ環境でも影響 — Kubernetes ノードや CI/CD ランナー上で nf_tables が有効な場合、コンテナブレイクアウトのリスクあり
  • Google Cloud（GKE）でも CVE-2026-46300（Fragnesia）と合わせてセキュリティアドバイザリを公開中。AWS / Azure のコンテナ環境も影響範囲
  • 既存パッチが適用されているか /proc/config.gz またはカーネルビルド設定で nf_tables の状態を確認することを推奨
