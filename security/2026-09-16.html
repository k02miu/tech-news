Node.js「proxy-addr」に X-Forwarded-For 偽装を許す脆弱性（CVE-2026-90711）Critical

脆弱性CVE-2026-90711
深刻度Critical（CVSSv3.1 9.1）
影響proxy-addr 1.1.0 〜 2.0.7（Express の req.ip／req.ips が依存）
  • ::ffff:10.0.0.0/8 のように IPv4 マップ IPv6 表記で IPv4 サイズのプレフィックス（正しくは /104）を指定すると、エラーにならずインターネット上の全 IPv4 アドレスを信頼してしまう。
  • ソケットのピアが hop 0 で信頼済みになるため、認証なしの任意クライアントが X-Forwarded-For を自由に指定でき、IP ベースのアクセス制御・レート制限・位置情報判定・監査ログがすべて無効化される。
  • リバースプロキシ配下でクライアント IP に依存した制御を行っている構成は、依存パッケージの更新とトラスト設定の見直しが必要。
