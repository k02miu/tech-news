Python 非同期基盤「AnyIO」— IDNA 2003 変換を突いた証明書検証バイパス（CVE-2026-63374） CRITICAL

CVECVE-2026-63374（GHSA-82r6-8w77-94w6）
深刻度CVSSv4.0 9.3（Critical、AV:N/AC:L/PR:N/UI:N）
影響AnyIO 4.14.2 未満（Python。asyncio / Trio 上で動作する非同期並行・ネットワークフレームワーク）
公開NVD 登録 2026-09-23 01:17 JST（2026-09-22 16:17 UTC）
対策AnyIO 4.14.2 以降へ更新。非 ASCII ドメインへ接続する箇所の依存関係を実測で確認
  • connect_tcp() と TLSStream.wrap() が、国際化ホスト名を標準ライブラリが IDNA 2003 で ASCII 化した後に検証してしまう。IDNA 2003 と IDNA 2008 では同じ非 ASCII 名が別の ASCII 名へ変換されうるため、攻撃者がその別名に対して正規の証明書を取得して提示すると、悪性エンドポイントの証明書が検証を通ってしまう。
  • 非 ASCII ドメインへの接続が乗っ取り・リダイレクトされた場合に、中間者としてサーバーなりすましが成立する。HTTPX など AnyIO を基盤とする非同期 HTTP クライアントや、FastAPI / Starlette 系サービスでは依存として取り込まれている可能性が高い。
  • 修正コミットは 68f5891、PR #1208、修正版は 4.14.2。同じ NVD バッチでは AnyIO を含む非同期スタックの再確認が推奨される。
