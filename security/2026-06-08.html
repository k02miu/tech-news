🔴 "Miasma" — RedHat npm パッケージを標的とした大規模サプライチェーン攻撃が発覚 CRITICAL

項目詳細
分類サプライチェーン攻撃 / npm マルウェア配布
標的@redhat-cloud-services npm 名前空間（週間約 80,000 ダウンロード）
公開日2026-06-01（Wiz Research 発見）、6/4 に追加アドバイザリ
  • Wiz Research が 6/1 に発見。Red Hat 社員の GitHub アカウントが侵害され、@redhat-cloud-services の npm 名前空間から32 以上のパッケージリリースに不正な改ざんが行われた
  • マルウェアのペイロードは TeamPCP の「Mini Shai-Hulud」をベースとした派生版で、"Miasma: The Spreading Blight"というリポジトリが作成される
  • 先行版と異なる点として、GCP / Azure のアイデンティティ収集機能が追加されており、クラウド環境全体へのアクセス拡大を狙う攻撃の進化が見られる
  • 感染ごとに一意の暗号化ペイロードを生成するため、ハッシュベースの IOC 検出が困難。2 波目の攻撃では binding.gyp を悪用したインストール時実行コードも追加
  • 侵害された GitHub アカウント経由で OIDC トークンを取得し、正当な SLSA provenance 証明付きで npm パッケージを公開 — TanStack 攻撃と同じ手法
  • 影響を受ける環境では、GitHub トークン、SSH 鍵、クラウドクレデンシャル、CI/CD シークレットの露出を前提とした即座のローテーションが推奨
  • 依存関係の allowlisting、SBOM 生成、パッケージ検証の導入を推奨
