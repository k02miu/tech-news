1. CVE-2026-48710 (BadHost) — Starlette / FastAPI 認証バイパス

項目詳細
CVE IDCVE-2026-48710
深刻度High（NVD CVSS 未評価、アドバイザリ上は High）
公開日2026-05-28
影響範囲Starlette < 1.0.1（FastAPI, vLLM, LiteLLM, MCP サーバー, AI エージェントフレームワーク含む）
修正Starlette 1.0.1 にアップグレード

Python の非同期 Web フレームワーク Starlette（FastAPI の基盤）において、HTTP Host ヘッダの検証不備により request.url.path を用いたパスベースのセキュリティチェックをバイパスできる脆弱性が公開されました。

  • 攻撃手法: 不正な Host ヘッダ（例: Host: example.com/abc?bar=）を送信することで、request.url.path が実際のリクエストパスと一致しなくなり、認証ミドルウェアやパス制限を迂回
  • 特筆すべき影響: LLM 推論サーバー（vLLM）、AI プロキシ（LiteLLM）、MCP ゲートウェイも影響対象。MCP サーバーは仕様上 非認証 OAuth ディスカバリエンドポイントが必須であるため、特にリスクが高い
  • 修正内容: Starlette 1.0.1 では Host ヘッダを RFC 9112 §3.2 に従って検証し、不正な値の場合は scope["server"] にフォールバック
  • 検出方法: コードベース内の request.url.path をミドルウェア内で grep することを推奨（badhost.org にスキャナあり）

2. CVE-2026-47675 — Hono serialize() Set-Cookie インジェクション

項目詳細
CVE IDCVE-2026-47675
深刻度Medium（NVD CVSS 未評価）
公開日CVE 番号発行: 2026-05-28（脆弱性修正は 2026-05-19）
影響範囲Hono < 4.12.21（hono/cookie モジュール）
修正Hono 4.12.21 以降にアップグレード
CWECWE-113: HTTP ヘッダへの CRLF シーケンスの不適切な無害化

Hono の hono/cookie モジュールにおいて、serialize() 関数が sameSite および priority パラメータに対し CRLF インジェクション対策（;, \r, \n のバリデーション）を適用していなかった問題に CVE 番号が正式発行されました。

  • 脆弱性自体は 2026-05-19 公開の Hono v4.12.22（GHSA-3hrh-pfw6-9m5x）で修正済み。5月28日付で CVE 番号が NVD に登録
  • ユーザー入力由来の値を sameSite または priority オプションに渡しているアプリケーションが影響対象
