1. Claude Code GitHub Action — 間接プロンプトインジェクションでCI/CDシークレット漏洩の脆弱性 HIGH

項目詳細
分類Indirect Prompt Injection / Sandbox Bypass
公開日2026-06-10（DevOps.com 記事公開、Microsoft 研究者による報告）
影響対象Claude Code GitHub Action ユーザー（CI/CD ワークフロー統合環境）
修正バージョンClaude Code v2.1.128（Read ツールによる /proc/ ファイルアクセスを制限）
  • Microsoft セキュリティ研究者（Dor Edry、Amit Eliahu）が Claude Code の GitHub Actionにおける間接プロンプトインジェクション脆弱性を発見。攻撃者が GitHub Issues・PR の本文・コメントに悪意あるプロンプトを埋め込むことで、AI エージェントが秘密情報を窃取
  • Read ツールが Bubblewrap サンドボックスをバイパス — Bash 実行パスはサンドボックスで分離されていたが、Read ツールはプロセス内直接呼び出しとして動作し、環境変数（API キー、クラウド資格情報など）にフルアクセス可能だった
  • 実証テストでは、Claude の安全性レイヤと GitHub Secret Scanner の両方を回避し、Read ツール経由で API キーの取得に成功
  • Anthropic は 2026年4月下旬に報告を受け、Claude Code v2.1.128 で /proc/ 配下のファイルへの Read アクセスを無条件拒否する修正を適用
  • 研究者は「自然言語が実行可能コードとなる時代に入っている。GitHub Issues のような信頼できない入力は、デフォルトで敵対的として扱うべきだ」と警告
  • 〈Claude Code スタックに直接関連〉

CVE 数208 件（過去最高。前回記録は2025年10月の170件）

公開日2026-06-10（Patch Tuesday）
  • CVE-2026-45586（Windows CTFMON 権限昇格）— Windows Collaborative Translation Framework のリンク解決不備。認証認証済みローカル攻撃者がSYSTEM 権限まで昇格可能。公開済みゼロデイ
  • CVE-2026-49160（HTTP/2 Bomb DoS）— HTTP.sys カーネルドライバの脆弱性。小規模リクエストでサーバーに過大なメモリ割り当てを強制し、リソース枯渇・サービス停止を引き起こす「HTTP/2 Bomb」。フロー制御設定の悪用で攻撃増幅が可能
  • CVE-2026-50507（BitLocker バイパス / YellowKey）— 物理アクセスを持つ攻撃者が BitLocker 暗号化をバイパス。TPM のみ認証構成が主な影響範囲。USB デバイスに特殊ファイルを配置し Windows RE 起動時に CTRL キーでコマンドシェルを起動する攻撃手法
  • Critical 33 件中 28 件がリモートコード実行（RCE）。インターネット公開サーバー、ドメインコントローラー、管理端末への早急なパッチ適用を推奨
  • Windows、Office、Edge（Chromium）、Azure、SQL Server など Microsoft 製品全般に影響。企業環境でのパッチ管理負荷が過去最大規模に
  • 影響を受ける主要環境: Windows Server、Azure Virtual Desktop、Azure Arc 接続マシン、AWS/GCP 上の Windows Server インスタンス
