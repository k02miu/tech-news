1. CVE-2026-47835 — Spring AI Vector Store メタデータフィルタインジェクション HIGH

項目詳細
CVECVE-2026-47835
CVSS8.6（CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:L/A:L）
公開日2026-06-15（VMware / Spring.io）
CWECWE-943: Improper Neutralization of Special Elements in Data Query Logic
影響コンポーネントspring-ai-elasticsearch-store、spring-ai-opensearch-store、spring-ai-gemfire-store
修正バージョンSpring AI 1.0.9 / 1.1.8
  • 概要 — Spring AI の Vector Store 実装（Elasticsearch / OpenSearch / GemFire）で、メタデータフィルタの特殊文字サニタイズが不十分。攻撃者は特殊文字を含むメタデータクエリを細工することで、任意クエリの実行を強制可能
  • 影響 — 認証不要、ネットワーク経由で悪用可能。Spring AI を利用した RAG（検索拡張生成）アプリケーションの機密性・整合性・可用性に影響
  • 対応 — Spring AI 1.0.x → 1.0.9、1.1.x → 1.1.8 にアップグレード。追加の緩和策は不要
  • 報告者 — Nitro Cao（@NitroCao、Alibaba Cloud）による責任ある開示
  • 〈Java / SpringBoot スタックに直接関連〉

影響対象Claude Code の auto mode を使用する環境
  • オートモードのサブエージェント起動前分類評価 — auto mode でサブエージェントを起動する前に分類器（classifier）による評価が行われるようになった。これにより、ブロックされたアクションをレビューなしにリクエストできたセキュリティホールを閉鎖
