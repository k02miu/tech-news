Next.js 16.3.6 — ImageResponse（Node.js実装）にリモートコード実行（CVE-2026-94545、CVSSv4.0 9.5）

深刻度Critical（CVSSv4.0 9.5）
CVECVE-2026-94545（GHSA-vcvr-r3jv-pc5j）
影響Next.js の画像生成モジュール「ImageResponse」（next/og）の Node.js 実装
修正版Next.js 16.3.6
公開日GitHubアドバイザリ 2026/09/22、Security NEXT報道 2026/09/25
  • 上流コンポーネントの脆弱性の影響により、攻撃者が制御可能な値が SVG のコンテンツ・属性・スタイルに渡され、画像が生成される過程でリモートからのコード実行に至るおそれがあります。
  • next/og の ImageResponse を OGP画像生成や動的画像生成に利用しているアプリは、外部入力（クエリパラメータ・CMS由来のテキスト等）がそのまま描画されていないか確認のうえ、速やかに 16.3.6 へ更新ください。
  • 直ちに更新できない場合、開発チームは回避策の適用を求めています。同リポジトリでは2026年8月にも Image Optimization API の未認証RCE（GHSA-2xp9-vwfh-vxw4）等が公表されており、Next.js 利用環境は継続的な追従が必要です。
