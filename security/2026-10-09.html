Hermes Agent v0.21.6 - ダッシュボード認証・git filter・メールゲートウェイのセキュリティ修正

深刻度High相当（CVE未採番）
対象Hermes Agent（NousResearch）v0.21.5 以前
公開2026-10-08 20:51 JST（同日 11:51 UTC）
  • ダッシュボード認証の強化として4件を修正。詐称された X-Forwarded-For ヘッダでパスワードログインのレート制限をリセットしてIP単位の上限を回避できた問題、未認証のログイン要求が認証監査ログへ無制限の値を書き込めた問題、公開 /auth/ ルートにリクエストボディのサイズ上限がなかった問題、ネイティブサインインが非ループバックのリダイレクト先へログインコードを送信しセッション奪取につながりうる問題。Tenable Research が報告（TRA-725〜728）。
  • リポジトリの git filter 強化。信頼できないリポジトリ自身の設定で定義された clean/smudge/process フィルタプログラムが、最初のプロンプトより前に自動実行されうる問題を修正。
  • メールゲートウェイの送信者検証強化。From ヘッダの引用符付き表示名（例: "Victim <victim@example.com>" <attacker@evil.test>）により、攻撃者のメッセージが許可送信者としてアローリストを通過しうる問題を修正。
  • v0.21.5 以降の約2,100 PRを集約したパッチリリースで、安定版パイプラインによる最初のタグ。Docker／Hermes Cloud は nousresearch/hermes-agent:stable、CLIは hermes update で更新。

Claude Code 2.1.294 / 2.1.295 - フック・権限ルール・ツール制限の挙動を修正

深刻度Medium相当
対象Claude Code 2.1.294 未満
公開2.1.294 = 2026-10-08 14:03 JST ／ 2.1.295 = 2026-10-09 04:48 JST
  • 2.1.295では、コマンドおよびHTTPフックに onFailure: "block" を追加。起動できない・タイムアウトする・想定外の終了コードで終わるフックが、処理を素通しさせずにブロックするようになった。
  • --tools／--restricted が、起動後に登録される組み込みツールへ適用されず、非推奨のツール名が呼び出し元のツールセット外のツールへ到達していた問題を修正。
  • マネージド設定下で、複合シェルコマンドのネスト部分に対する deny／ask ルールが、ユーザーが導入したmodの承認を上書きして成立しなかった問題を修正（2.1.289系の修正）。
  • プロンプトにタブや双方向制御文字が含まれる場合の描画崩れ、端末のハイパーリンク生バイトが偽のリンクとして描画される問題なども併せて修正。

OpenClaw 2026.9.9 - 失敗した更新からの復旧とセッション保守の安全性を改善

深刻度Medium相当（セキュリティ専用修正の記載はなし）
対象openclaw 2026.9.8 以前
公開2026-10-08 19:23 JST（同日 10:23 UTC）

  • 112 PR・91コントリビュータ。npmパッケージ openclaw@2026.9.9 として公開。
