🔴 Megalodon サプライチェーン攻撃 — 5,500 超の GitHub リポジトリに悪意ある CI ワークフロー注入 CRITICAL

項目詳細
分類サプライチェーン攻撃 / CI/CD セキュリティ
公開日2026-06-10（CM-Alliance 解説記事公開）
影響範囲5,561 の GitHub リポジトリ（5,718 の悪意あるコミット）
攻撃手法GitHub Actions ワークフロー注入 / workflow_dispatch 悪用
  • 2026 年 5 月 18 日に大規模な自動化キャンペーンが実行。攻撃者は偽の「build-bot」アイデンティティを使用し、workflow_dispatch トリガーを悪用して GitHub リポジトリに悪意あるワークフローを注入
  • 悪意あるワークフローは認証トークン、API キー、クラウド資格情報を窃取するよう設計。GitHub Actions が自動実行・信頼されるプロセスであるため、開発者の注意を引かずに実行
  • CI/CD パイプラインは「特権を持つ信頼された従業員」のような役割を持つため、攻撃者にとって格好の標的。侵害されたワークフローを通じてクラウドインフラ、本番環境、顧客データにアクセスされるリスク
  • 対策推奨: ワークフロー権限の見直し、トークン使用の最小化、自動化アカウントの監視、サードパーティ統合の監査、リポジトリアクセス制御の強化
  • 2026 年に入り npm サプライチェーン攻撃（Axios 事件、TanStack 事件）と並んで、ソフトウェア開発プロセス自体への攻撃が加速。開発パイプラインを重要インフラとして扱う意識が求められる
