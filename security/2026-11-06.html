Apache Juneau（Java）9.2.0以下 — パストラバーサル・任意クラス初期化など10件、うち9件がCVSSv4.0 10.0

CVECVE-2026-121489／73095／73098／73099／73100／73101／73116／73117／96677
深刻度Critical 9件（CVSSv4.0 10.0） High 1件（8.7）
影響Java製 REST／マイクロサービスフレームワーク Apache Juneau。ディレクトリ配信のルート外読み書き削除、java.lang.Class への変換時の静的初期化子実行、contentパラメータによるCSRF、ログへのAuthorization／Cookie平文記録、エラー応答からの内部情報漏えい、リダイレクト跨ぎの資格情報送信、CRLFヘッダインジェクション、chrome内変数の未エスケープによるXSS、MessagePack解析の無制限確保によるDoS
修正9.2.1（Apache 2026-11-05 21:17 JST 登録）
  • CVE-2026-121489（10.0）は microservice DirectoryResource が要求パスを設定ルート内に留めず、view／upload／delete を有効化したアプリ（いずれも既定は無効）でサーバプロセスの権限が届く範囲の任意ファイルを読み書き削除できる。
  • CVE-2026-73098（10.0）は既定のクラススワップが初期化有効でクラスをロードするため、クラスパス上のクラス名を指定されると静的初期化子が実行される。
  • CVE-2026-73099（10.0）は REST サーバが既定で全HTTPメソッド（GETを含む）の content クエリパラメータによるボディ差し替えを受け付けるため、CORSプリフライトなしのクロスサイトリンクで任意ボディを送り込める（disableContentParam で回避可）。
  • CVE-2026-73100（10.0）はサーバエラー時に要求ヘッダをマスクせずログへ記録し、CVE-2026-73116（10.0）は RestClient がリダイレクト後も資格情報ヘッダを保持する。
  • CVE-2026-73095（8.7）は MessagePack パーサが入力長からバッファを確保するため、未認証の数バイトで数ギガバイトの確保と OutOfMemoryError を誘発できる。

深刻度Critical 6件（9.3〜9.4） High 15件（7.2〜8.7）
影響Kyverno 1.19.2未満。名前空間スコープの利用者が他名前空間の Secret・Deployment・RoleBinding などを上書き／改変し、クラスタ権限を取得できるほか、ポリシーエンジンを停止させるDoSも多数
修正1.19.2（VulnCheck 2026-11-05 12:17 JST 登録）
  • CVE-2026-122311（9.4）は resource.get()／resource.post() の resource 引数のパス区切りを検証しないため、NamespacedValidatingPolicy 作者が「..」を挿入して admission controller の ServiceAccount で任意のクラスタオブジェクトを読み書きできる。CVE-2026-122310（9.4）は urlPath を clean 後に生パスを実行するため「#」「?」の後ろに「..」を隠してクラスタ管理者権限に到達できる。
  • CVE-2026-122303／122313（9.4）は NamespacedMutatingPolicy の targetMatchConstraints.expression が返す CEL マップで他名前空間を指定でき、背景コントローラがクラスタ全体のリソースを改変する。CVE-2026-122302（9.3）は generate ルールの admission 検査が作成者ではなくコントローラの権限を見るため、名前空間管理者が RBAC を越えてリソースを作成できる。
  • DoS系（CVE-2026-122305〜122309、122314、122315、122319、122322、122323 ほか）は、自己参照テンプレート・ワイルドカード・型アサーション不備・圧縮アテステーション層などでポリシーエンジンを停止させる。CVE-2026-122318（7.2）は署名証明書に SAN が無い場合に verifyImages の subject 検査を飛ばす認証バイパス、CVE-2026-122321（8.5）は検証結果のキャッシュ鍵がイメージ参照文字列のみでダイジェストに束縛されない署名検証バイパス。
