1. HTTP/2 Bomb (CVE-2026-49975) — 主要Webサーバーに影響するリモートDoS脆弱性 Critical

項目詳細
CVE IDCVE-2026-49975
CVSS v39.8 (Critical) — NVD 暫定スコア
公開日2026-06-03
影響対象NGINX, Apache HTTPD, Microsoft IIS, Envoy, Cloudflare Pingora（デフォルトHTTP/2設定）
影響規模全世界 88万以上の Web サイトが潜在的に影響

カリフォルニアのセキュリティ企業 Calif が6月3日、HTTP/2 Bomb と名付けられた新たなリモートDoS攻撃手法を公開しました。この攻撃は HTTP/2 のヘッダー圧縮方式 HPACK に対する圧縮爆弾（HPACK Bomb）と Slowloris 型の接続保持を連鎖させ、主要 Web サーバーのメモリを数秒で枯渇させます。

攻撃の仕組み

  • HPACK Bomb: ワイヤ上ではほぼ空のヘッダーが、サーバー側で1エントリごとに完全なメモリ割り当てを発生させる。従来のデコード済みサイズ制限をバイパス
  • Slowloris 型ホールド: ゼロバイトのフロー制御ウィンドウを広告し、サーバーが確保したメモリを解放できないよう拘束
  • 家庭用 100Mbps 回線からでも、脆弱なサーバーを数秒でダウンさせることが可能
  • Apache HTTPD / Envoy に対しては、単一クライアントから約20秒で 32GB のサーバーメモリを消費・保持可能

修正状況

  • NGINX: 1.29.8 以降にアップグレード（max_headers ディレクティブ追加、デフォルト 1000）。アップグレード不可の場合は http2 off; で HTTP/2 無効化
  • Apache HTTPD: mod_http2 v2.0.41 で修正済み。アップグレード不可の場合は Protocols http/1.1 で HTTP/2 無効化
  • Microsoft IIS, Envoy, Cloudflare Pingora: 本稿執筆時点でパッチ未提供

2. Django 6.0.6 / 5.2.15 — 5件の脆弱性を修正するセキュリティリリース Low

項目詳細
公開日2026-06-03
修正バージョンDjango 6.0.6, Django 5.2.15
影響バージョンDjango main, 6.1 alpha, 6.0, 5.2

Django チームは6月3日、5件のセキュリティ脆弱性を修正するリリースを公開しました。すべて深刻度「Low」ですが、キャッシュ関連のデータ漏洩リスクを含むため、早期のアップグレードが推奨されます。

修正された脆弱性

  • CVE-2026-6873: get_signed_cookie() の署名ソルト連結における名前空間衝突。異なる name/salt ペアが同一の連結文字列を生成した場合、署名されたCookieが意図しないコンテキストで受理される可能性
  • CVE-2026-7666: SMTP バックエンドの STARTTLS ハンドシェイク失敗時に、暗号化されない状態でメールが送信される可能性（EMAIL_USE_TLS + fail_silently=True 時）
  • CVE-2026-8404: UpdateCacheMiddleware が Cache-Control: Private（大文字混在）を正しく認識せず、プライベートデータがキャッシュされる可能性
  • CVE-2026-35193: Authorization ヘッダー付きリクエストのレスポンスに Vary: Authorization が付与されず、キャッシュ汚染の可能性
  • CVE-2026-48587: Vary ヘッダー値の先頭・末尾の空白が正規化されず、Vary: *（末尾スペースあり）がワイルドカードとして認識されない問題
