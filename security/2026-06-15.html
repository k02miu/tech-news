公開日2026-06-14（CPANSec / NVD）
影響対象Config::IniFiles 3.001000 未満の Perl モジュール利用アプリケーション
修正Config::IniFiles 3.001000 へアップグレード
  • 2引数 open() によるコマンドインジェクション — Config::IniFiles::_make_filehandle 関数が Perl の2引数 open() を使用しており、ファイル名がパイプ（| cmd、cmd |）で始まる/終わる場合、またはリダイレクト（> path、>> path）で始まる場合、コマンドとして実行されてしまう
  • 影響範囲 — new(-file => $thing) 経由で ReadConfig に到達するすべての呼び出し元。信頼できない入力を -file 引数に渡すアプリケーションは、任意コマンド実行やファイル上書きのリスクあり
  • 修正内容 — 3引数 open() への移行。GitHub コミット 3e48f962 で修正
  • CPANSec が 2026-06-14 08:16 UTC に CVE を登録。WebアプリケーションやCLIツールで Perl の INI ファイル処理を利用している場合は早急な更新を推奨
