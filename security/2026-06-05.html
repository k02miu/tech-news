1. Claude Code v2.1.163 — 管理バージョン強制・TMPDIRサンドボックス回帰修正・権限ルール修正 Security Fixes

項目詳細
分類セキュリティ関連バグ修正（新規CVEの公表ではない）
公開日2026-06-04
  • 管理バージョン強制: requiredMinimumVersion / requiredMaximumVersion 管理設定を追加。承認されたバージョン範囲外では起動を拒否し、ユーザーを承認済みバージョンに誘導
  • TMPDIR サンドボックス回帰修正: v2.1.154 で導入されたリグレッションにより、全 Bash コマンドに $TMPDIR が /tmp/claude-{uid} に上書きされていた問題を修正。サンドボックス化されたコマンドのみに分離を適用するよう修正（bazel や EDR 保護下の Go ワークフローに影響していた）
  • $HOME 経由の Deny ルールバイパス修正: Read(~/Desktop/**) のようなホームディレクトリパスの deny ルールが $HOME 変数経由で参照される Bash コマンドをブロックしていなかった問題を修正
  • 組織管理権限ルールの適用タイミング修正: 起動時の managed settings 取得が設定ディレクトリ作成中に完了した場合、組織管理の権限ルールがセッション全体に適用されない問題を修正
  • Stop/SubagentStop フック改善: フックが hookSpecificOutput.additionalContext を返せるようになり、ターンを継続しつつフィードバックを提供可能に
  • その他: --tools で Grep/Glob の明示的指定が機能するよう修正（以前は無視されていた）、読み取り専用設定ディレクトリでの起動ハング修正、MCP タイムアウト設定の安全性向上、Windows パーミッションルールの修正（バックスラッシュ・大文字小文字対応）、WebFetch 権限ルールの修正など

🔓 VS Code (github.dev) GitHub トークン窃取ゼロデイ — 研究者が MSRC をバイパスして完全公開 (6月4日)

項目詳細
分類ゼロデイ脆弱性（パッチ未提供）
公開日2026-06-04
影響対象github.dev（ブラウザ版 VS Code）利用者全般
深刻度Critical（実質） — GitHub OAuth トークンの窃取により全プライベートリポジトリへの read/write アクセスが可能

セキュリティ研究者 Ammar Askar が、github.dev に存在する深刻なゼロデイ脆弱性を MSRC（Microsoft Security Response Center）を経由せず一般公開しました。過去の MSRC 対応への不信（脆弱性を無断修正・クレジットなし・セキュリティ影響なしと分類）が理由とされています。

攻撃の仕組み

  • 攻撃者が細工したリポジトリの .vscode/extensions.json に悪意ある拡張機能を指定
  • 被害者が github.dev 上でこのリポジトリを開くと、悪意ある拡張機能がユーザー確認なしで自動インストールされる（Jupyter Notebook に隠した HTML がキーボードショートカットを自動実行し、インストール承認ダイアログをバイパス）
  • インストールされた拡張機能が GitHub OAuth トークンを窃取 — このトークンはリポジトリ単位ではなく全プライベートリポジトリへの read/write 権限を持つ

影響

github.dev を日常的に使用する Web / Next.js / React 開発者に広く影響。攻撃の成立には被害者がリンクをクリックするだけで十分であり、極めて危険な攻撃ベクトルです。

本稿執筆時点で GitHub / Microsoft からのパッチは提供されていません。開発者は github.dev 経由での信頼できないリポジトリの閲覧を避け、通常のローカル VS Code を使用することが推奨されます。
