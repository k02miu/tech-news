Claude Code - Edit ツールの TOCTOU 競合によりワークスペース外へファイル書き込み（CVE-2026-88968、High） High

CVECVE-2026-88968（GHSA-5xjx-9qx6-jcrv、GitHub 評価 High）
影響npm @anthropic-ai/claude-code 2.1.251 未満
修正2.1.251（通常の自動更新を利用している場合は適用済み）
公開2026-11-09 22:42 UTC（JST 2026-11-10 07:42）
  • Edit ツールの対象検証が「その時点の」パス名とシンボリックリンクの解決に依存しており、検証結果が実際のディレクトリ inode やファイルディスクリプタに束縛されていなかった。macOS 上では、Claude Code の Bash サンドボックス内で動くプロセスが、検証完了後にワークスペース内の親ディレクトリをシンボリックリンクへ原子的に差し替えることで TOCTOU の窓を突き、サンドボックス外で動作する Edit 実装に、攻撃者が選んだユーザー書き込み可能ファイル（ワークスペース外）を上書きさせられた。
  • 成立には、悪意あるリポジトリや依存スクリプトなどを通じてサンドボックス内で攻撃者のコードを実行できることが必要。修正は 2.1.251 で、報告者への謝辞（Sunder Singh 氏）が付されている。
