Hermes Agent — Bot Desktopの環境変数注入によるエージェント機でのコード実行（CVE-2026-130164、High 7.8）

CVECVE-2026-130164（GHSA-p22p-9ph6-gmrh）
深刻度CVSSv3.1 7.8 High（AV:L/AC:H/PR:L/UI:N/S:C/C:H/I:H/A:H）
影響Hermes Agent v0.21.6 〜 v0.23.1
修正v0.23.2（現行安定版は v0.23.3）
  • NVD登録 2026-11-23 21:16 UTC（JST 11-24 06:16）。terminal.backend が docker もしくは ssh のとき、Bot Desktop がバックエンド内の書き込み可能な env ファイルを鍵・値の検証なしに読み取り、エージェント機側で起動するプロセスの環境変数へ無条件にマージしていた（CWE-15／CWE-426）。
  • バックエンド内で動く依存関係やスクリプトは、LD_PRELOAD（macOSは DYLD_INSERT_LIBRARIES）などを仕込み、ブラウザハーネス等の次回起動時にゲートウェイ実行ユーザー権限でコードを実行できる。プロバイダ鍵・トークン・セッション履歴が窃取され得る。
  • 修正の v0.23.2 では、読み取るキーをランチャが書く6件のみに限定し値を検証、バックエンド内の画面が発行した値はエージェント機側プロセスへマージしないよう変更。暫定回避は bot_desktop.placement: gateway の指定、または既定の local バックエンドの使用。

CVECVE-2026-123886

AWS — AWS-LC の境界外書き込みと SSM Agent の既定鍵（CVE-2026-134056、CVE-2026-134069）

CVECVE-2026-134056（8.3）／CVE-2026-134069（8.2）
