🔴 LiteLLM CVE-2026-42271 + CVE-2026-48710 連鎖 — AI API ゲートウェイでの認証不要 RCE（CVSS 10.0） CRITICAL

項目詳細
リリース日2026-06-19（beta）
バージョン2026.6.9-beta.1
セキュリティ修正デバッグ/設定出力からのシークレット再編集、内部 HTTP セッション上書きのブロック、オープン DM ツール露出の監査、プラグイン書き込み所有権チェックの保持
項目詳細
CVECVE-2026-42271（LiteLLM コマンドインジェクション）+ CVE-2026-48710（Starlette ホストヘッダー認証バイパス）
CVSS10.0（連鎖時）
CISA KEV 追加日2026-06-08（連邦修正期限: 2026-06-22）
影響コンポーネントLiteLLM 1.74.2 〜 1.83.7 前、Starlette 1.0.1 前
修正バージョンLiteLLM 1.83.7 / Starlette 1.0.1
実害状況能動的悪用確認済み
  • 概要 — LiteLLM の MCP サーバープレビュー エンドポイント（/mcp-rest/test/connection、/mcp-rest/test/tools/list）がリクエストボディ内のコマンドをそのままサブプロセスとして実行するコマンドインジェクション。単体では認証が必要だが、CVE-2026-48710（Starlette の Host ヘッダー検証不備による認証バイパス）と連鎖することで、認証不要のフル RCE が可能
  • 影響 — LiteLLM は OpenAI、Anthropic、Azure OpenAI、Google Gemini 等への AI API トラフィックをルーティングするゲートウェイ。侵入された場合、設定済みの全 AI プロバイダーの API キーにアクセス可能
  • 対応 — LiteLLM を 1.83.7 以上に、Starlette を 1.0.1 以上に即座に更新。インターネット公開されている LiteLLM インスタンスの緊急確認を推奨

🔴 JetBrains Marketplace サプライチェーン攻撃 — 15個の悪意あるプラグインが8ヶ月間 AI API キーを窃取 CRITICAL

項目詳細
公表日2026-06-16（JetBrains）/ 2026-06-19 報道
影響範囲15 プラグイン（うち2つが 25,000 ダウンロード超）、合計 70,000+ インストール
窃取対象OpenAI、Anthropic、DeepSeek 等の AI プロバイダー API キー
潜伏期間2025年10月〜2026年6月（約8ヶ月間）
  • 概要 — CodeGPT AI Assistant、DeepSeek AI Assist を含む15個のサードパーティ JetBrains プラグインが、開発者が API キーを設定して「Apply」を押した瞬間に、キーをプレーンテキストの JSON ペイロードとして HTTP（非暗号化）で C2 サーバー（39.107.60[.]51）に送信。検出回避のため JVM レベルの X509TrustManager をインストールして TLS 証明書警告を無効化
  • 影響 — 窃取された API キーは LLM 使用量の請求不正利用、AI 統合ワークフローへの侵入、処理データへのアクセスに悪用可能
  • 対応 — JetBrains が6月16日に全15プラグインを削除・無効化済み。IDE 内で該当プラグインを確認し、API キーをローテーションすること

CVSS9.1（RCE）/ 7.5（情報漏洩）
公開日2026-06-17（Cisco Security Advisory）
影響コンポーネントCisco Identity Services Engine (ISE) / ISE-PIC
  • 概要 — CVE-2026-20181: ユーザー入力の検証不備により、管理者資格情報を保有する攻撃者が細工した HTTP リクエストで RCE が可能。root 権限への昇格を含む。単一ノード構成では DoS も発生。CVE-2026-20190: 認可チェックの不備により、認証不要の攻撃者がハッシュ化された資格情報を含む機密情報にアクセス可能

🔴 FortiBleed — 74,000件の Fortinet 管理者資格情報がクラックされる CRITICAL

  • 概要 — ロシア語話者の犯罪グループが FortiGate デバイスから SSL VPN 設定ファイルを体系的に抽出し、GPU クラスターで管理者資格情報のハッシュをクラック。FortiOS 7.2.11/7.4.8/7.6.1 以降にアップグレードしても、管理者が再認証しない限り従来の SHA-256 ハッシュが残存するという設計上の問題を悪用
  • 影響 — クラックされた資格情報で FortiGate のフル管理者権限を取得可能。LDAP/RADIUS/AD ネットワークスニッファーの投入が確認されている
  • 対応 — 全 Fortinet 管理者アカウントに強制再認証を実施し、PBKDF2 への移行を完了確認。Hudson Rock の無料資格情報ルックアップツールで自組織の影響を確認

🔴 Arista EOS CVE-2026-7473 — CISA KEV 追加、ベンダーがパッチ拒否 HIGH

項目詳細
公表日2026-06-18（Australian Cyber Security Centre）
CVE該当なし（設計上の問題）
影響規模73,932 件の管理者資格情報、194カ国
攻撃手法SSL VPN 設定ファイルの抽出 → SHA-256 ハッシュの GPU クラック（45 GPU Hashtopolis クラスター、11.6億回試行）
  • 概要 — VXLAN/decap-groups/GRE トンネル構成がある場合、スイッチがトンネルプロトコルタイプを検証せずに予期しないトンネル化パケットをデカプセル化・転送する論理欠陥。信頼されていない外部トンネルトラフィックを内部ネットワークセグメントに注入可能
  • 影響 — ハイパースケールデータセンター、大規模エンタープライズコアネットワーク、金融インフラに影響。Arista は「ファームウェア修正が本番構成を壊すリスク」を理由にパッチ拒否
  • 対応 — 上流デバイスまたは影響を受けるスイッチ自体に ACL を実装して予期しないトンネルトラフィックを選択的にブロック
