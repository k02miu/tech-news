2. CVE-2026-47291 — Windows HTTP.sys リモートコード実行 CRITICAL

項目詳細
CVECVE-2026-47291
CVSS9.8（CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H）
公開日2026-06-10（Microsoft Patch Tuesday / NVD）
CWECWE-190: Integer Overflow, CWE-122: Heap-based Buffer Overflow
影響コンポーネントWindows HTTP.sys（IIS および HTTP/HTTPS を公開する Windows サーバー）
修正バージョン2026年6月 Patch Tuesday 累積更新
  • 概要 — HTTP Protocol Stack の整数オーバーフローおよびヒープベースバッファオーバーフローにより、認証不要のリモート攻撃者が特別に細工したパケットを送信するだけでコード実行が可能
  • 影響 — デフォルト MaxRequestBytes 値（16KB）のシステムは影響なし。値が 65,534 バイトを超える場合に脆弱
  • 対応 — 6月累積更新の適用。暫定対策として MaxRequestBytes を 65,534 バイト以下に設定
  • 〈web スタックに直接関連 — IIS / Windows Server で Web サービスを公開する環境に影響〉
