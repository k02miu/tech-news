🔓 Claude Code GitHub Action サプライチェーン攻撃の詳細が公開 — 単一の Issue から CI/CD 乗っ取りが可能に CRITICAL

項目詳細
分類AI サプライチェーン攻撃 / Prompt Injection
公開日2026-06-05（Microsoft Blog / Flatt Security Research）
影響対象Claude Code GitHub Action (claude-code-action) < v1.0.94
  • GMO Flatt Security の RyotaK 氏が Claude Code GitHub Action の脆弱性を詳細報告。ボット名で終わる Actor を自動的に信頼する判定ロジックの穴を突き、悪意ある GitHub App 経由で任意の Issue からワークフローを起動可能
  • 間接的プロンプトインジェクションにより、Claude に /proc/self/environ からシークレットを読み取らせ、Issue 経由で攻撃者に外部送信させるチェーンを実証
  • OIDC トークンを窃取し Anthropic バックエンドと交換することで、リポジトリへの書き込みアクセスを獲得可能。最悪の場合、Action 自体を改ざんしてダウンストリーム全プロジェクトに悪影響
  • Anthropic は v1.0.94 で修正済み。また Anthropic の公式 Issue トリアージワークフロー例が allowed_non_write_users: "*" という危険な設定を含んでいたため、これをコピーした多くのリポジトリに同様の脆弱性
  • Microsoft も 6月5日に本件に関するセキュリティブログを公開。AI エージェントの CI/CD 統合における新たな攻撃面として警鐘
  • 〈Claude / AI スタックに関連〉
