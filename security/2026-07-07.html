Hermes Agent v0.18.0 — 包括的セキュリティ強化ラウンド HIGH

対象Hermes Agent
リリースv0.18.0 (v2026.7.1) — The Judgment Release
公開日2026-07-01
深刻度HIGH（複数の認証情報漏洩ベクター修正）
  • cron 経由の認証情報漏洩をブロック: cron ジョブ設定の base_url オーバーライドを悪用したプロバイダー認証情報の引き出しを防止 (#50476)
  • MCP-config 永続化の攻撃面を封鎖: 設定ファイル経由の攻撃ベクターを制限 (#56196)
  • ファイル読み取り時のプレフィックスシークレット保護: 使い捨て不可のセンチネル値でファイル読み取り経由の秘密情報漏洩を防止 (#54166)
  • Slack トークン (xapp-) の自動墨消し: ログ・出力からのアプリレベルトークン漏洩を防止 (#56227)
  • ブラウザ経由クラウドメタデータ取得の防止: 全バックエンドでブラウザからのクラウドメタデータエンドポイント（169.254.169.254 等）へのアクセスをブロック (#52349)
  • aiohttp CVE フロアの強制: 遅延メッセージングパス全体で aiohttp の最低バージョンを既知の脆弱性がないバージョンに固定 (#56237)
  • 加えて、P0/P1 チケット全件クローズ (計692件) を達成。うち credential-exfil 関連の脆弱性修正を含む

プロンプトインジェクションや設定ミスによるセッションからの認証情報漏洩経路を包括的に削減するセキュリティアップデートです。Hermes Agent ユーザーは v0.18.0 へのアップグレードを推奨します。

その他のスタック（web / Next.js / Java / Python / Django / Hono / GCP / AWS / Azure / React / SpringBoot / Claude Code / OpenClaw）については、本対象期間内に直接関連する新規 CVE・セキュリティアドバイザリは確認されませんでした。
