1. Adobe ColdFusion — Path Traversal による RCE（CVE-2026-48282, CVSS 10.0） CRITICAL

項目詳細
CVECVE-2026-48282（CVSS 10.0）— RDS（Remote Development Services）経由の Path Traversal による任意ファイル書き込み・RCE（CWE-22）
公表日Adobe セキュリティ公告 APSB26-68: 2026-07-08。直後よりアクティブエクスプロイテーション確認。本対象期間内に複数ベンダーが実証
影響ColdFusion 2025 Update 9 以前、ColdFusion 2023 Update 20 以前。未認証リモート攻撃者が RDS エンドポイント経由で任意ファイル書き込みから RCE へ昇格可能
修正ColdFusion 2025 Update 10 / ColdFusion 2023 Update 21 で修正済み（APSB26-68）
悪用状況公開数時間でアクティブエクスプロイテーション確認。Resecurity・BleepingComputer 等が実証。PoC 公開済み
  • 概要 — Adobe ColdFusion の RDS エンドポイントに存在する Path Traversal 脆弱性。CVSS 10.0（最大深刻度）で、認証不要のネットワーク経由攻撃が可能。攻撃者は RDS 経由でサーバ上の任意ファイルに書き込み、最終的に任意コード実行に至る
  • 波及範囲 — ColdFusion は政府・金融・医療のレガシーシステムで広く利用。BleepingComputer は「公開から数時間で攻撃が開始された」と報道。Check Point も防御アドバイザリ（CPAI-2026-8444）を即時公開
  • 対応 — ColdFusion を直ちに最新アップデートへ更新。RDS が不要な場合は無効化。WAF で Path Traversal パターンをブロック。内部ネットワークへのアクセス制限を強化
  • 〈Web アプリケーションサーバとして全スタックに間接的に関連〉

CVECVE-2026-53539 — python-multipart QuerystringParser のアルゴリズム複雑性 DoS（CWE-400）。CVSS 7.5
公表日NVD 公開: 2026-06-22。GitHub Advisory GHSA-5rvq-cxj2-64vf。本対象期間内に複数ベンダーが追跡開始
影響python-multipart 0.0.30 未満。FastAPI・Starlette 等の application/x-www-form-urlencoded パースに影響
修正python-multipart 0.0.30 で修正済み
悪用状況攻撃容易性は高い（認証不要・ネットワーク経由・少量ペイロードで CPU 消耗）。実際の攻撃報告は現時点で確認なし
  • 概要 — python-multipart の URL エンコードフォームパーサにおいて、セパレータ検索の二段階スキャンにより O(B²) の計算量が発生。セミコロン区切りのフォームボディを送信するだけでワーカプロセスの CPU を枯渇させ、DoS を引き起こす

  • 対応 — pip install --upgrade 'python-multipart>=0.0.30' で即時更新可能。WAF/Middleware でセミコロン区切りのフォームボディを拒否するワークアラウンドも有効
