1. OpenClaw — 2026.5.31 pre-release: エージェント・Codex ランタイム回復性、チャネル配信安定性、Skill Workshop

分類セキュリティ強化リリース（新規 CVE の公表ではない）
公開日2026-05-31 19:19 UTC（日本時間 6月1日 04:19）

前日までの継続的セキュリティ強化に続き、OpenClaw は5月31日付 pre-release で以下の改善を実施しました。

  • エージェント・Codex ランタイム回復性の強化: 中断されたツール呼び出し・古いセッションバインディング・コンパクションハンドオフ・メディア配信リトライからの復旧を改善。Codex アプリサーバーの最終回答ストリーミング・ACP メタデータ永続化・ワークスペース/セッションメタデータ保存を強化
  • チャネル・モバイル配信の安定性向上: Telegram、WhatsApp、iMessage、Slack、Discord、Microsoft Teams、Google Chat、Google Meet、iOS リアルタイム Talk の各チャネルで配信の堅牢性を改善
  • Gateway 設定とセキュリティ: Tailscale Serve サービス名バインディングのサポート、Communication 通知設定の追加、エージェント追加時の安全性向上、Discord/Telegram/Slack/Matrix/Teams のプログレスドラフト信頼性改善
  • Provider・プラグインのタイムアウト保護: タイマー、リトライ、OAuth/デバイスコード有効期限、メディアダウンロード、ローカルサービスプローブ、生成コンテンツポーリングのバウンドを強化し、ハングアップを防止
  • Skill Workshop（新機能）: ガバナンス付きスキル作成・レビュー・承認フロー。スキル提案の適用/拒否/隔離、サポートファイルのスキャン・ハッシュ・ロールバック保護、バージョン付き提案フロントマター
  • 認証・セッション保護: 認証プロファイルのアトミック書き込み、強制再ログイン回復、OpenAI API キーの Codex アプリサーバー認証との混同防止、OAuth セッション永続化の保護
  • プラグインエコシステム拡張: Tokenjuice および GitHub Copilot ランタイムを公式 @openclaw プラグインとして外部化、SecretRef プロバイダー統合マニフェストの追加

🔴 Carnival Corporation — クルーズ大手で約600万人の個人情報流出（ShinyHunters 関与）

  • Carnival Corporation（カーニバルクルーズ）は5月末、約600万人の顧客・従業員の個人情報が流出したことを正式に公表
  • 攻撃経路: 4月14日、ソーシャルエンジニアリング（なりすまし電話）により従業員アカウントを侵害 → IT システムの一部に不正アクセス → 4月22日までにデータの不正コピーを確認
  • 流出データ: 氏名、住所、メールアドレス、電話番号、生年月日、パスポート番号、運転免許証番号（影響は個人により異なる）
  • 攻撃グループ ShinyHunters が4月に犯行声明（870万件の窃取を主張）。Carnival の正式届出では約600万人
  • ShinyHunters は2026年に入り、Charter Communications（1,300万件超）、Canvas/Instructure（3,000万件超）、Panera（500万件超）、ADT（550万件）、7-Eleven（18.5万件）と、大規模侵害を連続実行中
  • 🔗 Malwarebytes · SecurityWeek · The Record

🟠 npm サプライチェーン攻撃 — 「codexui-android」が OpenAI リフレッシュトークンを窃取、OpenClaw/Claude コミュニティも標的

  • Aikido Security の研究者が5月27日、npm パッケージ codexui-android（週間約 27,000 ダウンロード）に悪意あるコードが含まれていることを発見
  • 攻撃手法: 正規の有用なツールとしてユーザーベースを構築した後、dist-cli/index.js の先頭行で隠しスクリプトを読み込み、ローカルの auth.json から OpenAI の access_token、id_token、refresh_token を窃取。refresh_token は無期限であり、攻撃者は被害者に永続的に成りすますことが可能
  • 盗んだトークンは sentry.anyclawstore に送信（正規の Sentry エラーレポートを偽装）
  • モバイル展開: Google Play Store 上の Android アプリ（「OpenClaw Codex Claude AI Agent」を含む）に同一のマルウェアが同梱。APK はクリーンに見えるが、インストール後に Node.js を展開し悪意ある npm パッケージを取得
  • 開発者コミュニティへの教訓: AI 開発ツールのトークンは高価値かつ長寿命であるため、攻撃者は正規プロジェクトを偽装して信頼を獲得する手口が増加している
  • 🔗 Hackread · Aikido Security (分析ブログ)
