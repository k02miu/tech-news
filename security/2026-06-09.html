1. PyPI サプライチェーン攻撃 — "nhmpy" による NumPy タイポスクワットが発覚 CRITICAL

項目詳細
分類サプライチェーン攻撃 / PyPI マルウェア配布
アドバイザリGMS-2026-575（GitLab Vulnerability Research）
公開日2026-06-07
影響対象Python / PyPI エコシステム（nhmpy パッケージ）
  • GitLab Vulnerability Research が Shai-Hulud コピーキャット攻撃の一部として nhmpy パッケージを検出。NumPy のタイポスクワット
  • .pth ファイルを含み、Python 起動時に自動実行。Bun JavaScript ランタイムをダウンロードし、難読化されたクレデンシャル窃取コードを実行
  • 窃取対象: GitHub、AWS、Azure、GCP、HashiCorp Vault、NPM、PyPI、RubyGems、SSH 鍵、Kubernetes、Sigstore
  • ワーム型自己増殖: アクセス可能な GitHub リポジトリへの悪意あるコミット push、他のレジストリへのポイズンパッケージ公開
  • このパッケージがインストールされている環境は完全に侵害されたとみなすべき。すべてのシークレットと鍵を別マシンから即座にローテーションすること
  • 依存関係のピンニング、SBOM 生成、lock ファイル検証の徹底を推奨

🔴 Shai-Hulud コピーキャット攻撃の波 — npm から PyPI へ拡大 CRITICAL

項目詳細
分類サプライチェーン攻撃 / ワーム型マルウェア拡散
標的PyPI（nhmpy）、npm エコシステム
公開日2026-06-07（nhmpy 検出）
  • 2026 年 5 月に発見された Shai-Hulud ワームのソースコードが公開されて以降、コピーキャット攻撃が npm と PyPI の両エコシステムで相次いで発生
  • 6/7 に検出された nhmpy（NumPy タイポスクワット）は、.pth ファイルによる自動実行、Bun ランタイム経由のクレデンシャル窃取、GitHub リポジトリ経由の自己増殖という攻撃チェーンを実装
  • 窃取対象はクラウド（AWS/Azure/GCP）、シークレットマネージャー（HashiCorp Vault）、パッケージレジストリ（npm/PyPI/RubyGems）、CI/CD（Kubernetes/Sigstore）と広範
  • 6/1 に発覚した Miasma 攻撃（RedHat npm パッケージ標的）と同じ攻撃手法の進化版。GCP/Azure アイデンティティ収集機能が追加されている
  • 感染環境では全クレデンシャルの即座のローテーションが必要。依存関係の allowlisting、SBOM 生成、パッケージ署名検証の導入を強く推奨
