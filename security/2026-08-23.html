情報源piyolog / Rust Blog / GitHub Advisory（CVE-2026-77651）
  • 同一メンテナのアカウントが公開する arrayref・internment・append-only-vec に、タイポスクワット版「proc-macro1」への依存が追加され、ビルドスクリプト（build.rs）経由で二段目ペイロードをダウンロード・実行する手口。arrayref は累計ダウンロード数約2.45億回で、全環境の35%超に存在すると分析されています。
  • Rust Security Response Team は悪性クレートを削除し、悪意をもって yank された正規版を復元・メンテナアカウントをロック。Wiz は攻撃インフラが近年の北朝鮮系アクターのキャンペーンと「大きく重複する」と指摘しています。
  • 手元の Cargo.lock や ~/.cargo/registry/cache に該当クレートのキャッシュが残っていないか確認するよう呼びかけられています。本対象期間内（8/22）に piyolog で詳細がまとめられ顕在化したサプライチェーンインシデントとして掲載します。
