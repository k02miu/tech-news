1. Claude Code — v2.1.160 / v2.1.161: シェル設定ファイル書き込み時の安全確認・シークレット漏洩防止などセキュリティ強化

項目詳細
分類セキュリティ強化リリース（新規 CVE の公表ではない）
公開日2026-06-02（v2.1.160 / v2.1.161 同日リリース）

Anthropic は6月2日、Claude Code のセキュリティ関連の改善を含む2つのバージョン（v2.1.160、v2.1.161）をリリースしました。

v2.1.160 — 安全確認プロンプトの追加

  • シェル起動ファイル書き込み時の確認追加: ~/.zshenv、~/.zlogin、~/.bash_login、~/.config/git/ への書き込み前にプロンプトを表示。これにより意図しないコマンド実行のリスクを防止
  • ビルドツール設定ファイル書き込み時の確認追加: acceptEdits モードにおいて、コード実行権限を付与する設定ファイル（.npmrc、.yarnrc*、bunfig.toml、.bazelrc、.pre-commit-config.yaml、.devcontainer/ など）への書き込み前に確認プロンプトを表示
  • grep 実行後の Read 省略: 単一ファイルへの grep/egrep/fgrep 実行後は、ファイル内容を既読扱いとし Edit 前の Read 要件を満たすように改善

v2.1.161 — シークレット漏洩防止・各種修正

  • claude mcp コマンドでのシークレット漏洩を修正: list/get/add で ${VAR} 参照の展開を停止し、認証情報ヘッダーと URL シークレットをマスク
  • 管理設定ポリシーの修正: forceLoginOrgUUID/forceLoginMethod がサードパーティプロバイダーセッションを誤ってブロックする不具合を修正（v2.1.146 のリグレッション）
  • OpenTelemetry ログイベントの欠落を修正: テレメトリ初期化前に発生したログイベントがサイレントにドロップされる問題を修正
  • OTEL_RESOURCE_ATTRIBUTES: メトリクスデータポイントにラベルとして含まれるようになり、チームやリポジトリなどのカスタムディメンションで使用量をスライス可能に
  • その他多数のバグ修正（Windows フック、ワークツリー編集、ターミナルレンダリングパフォーマンス改善など）

🛳️ Carnival Corporation データ侵害 — 約600万人の顧客情報が流出

発生日2026年4月14日（侵害発覚）、2026年6月2日（被害通知・公表）
影響規模約 5,995,277 人（メイン州司法長官への届出）
攻撃経路従業員アカウントへのソーシャルエンジニアリング → システム侵入 → ファイル窃取
流出情報氏名、住所、生年月日、メールアドレス、電話番号、政府発行ID番号
  • クルーズ大手 Carnival Corporation が6月2日、約 600万人の顧客個人情報が流出したことを公表
  • 攻撃手法: ソーシャルエンジニアリングにより従業員アカウントを侵害 → システムにアクセスしファイルを窃取
  • 犯行声明: 恐喝グループ ShinyHunters が関与を主張。4月下旬に約870万件のレコードをリークサイトで公開
  • HaveIBeenPwned の分析: Holland America の Mariner Society ロイヤルティプログラムに関連する約750万アカウントが影響を受けた可能性
  • 対応: 影響を受けた顧客に24ヶ月間の無料クレジットモニタリングサービスを提供
