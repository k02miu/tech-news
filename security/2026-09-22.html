CVECVE-2026-86473（ほか CVE-2026-82355 / CVE-2026-75158）
深刻度CVSSv3.1 9.1（Critical）、4.2・4.3（Medium）
影響apache-airflow 3.3.2 未満
公開Apache Software Foundation が 2026-09-21 公開（NVD 登録 2026-09-22 00:17 JST）
対策apache-airflow 3.3.2 以降へ更新
  • Core API のログアウトエンドポイントは _token Cookie として提示されたセッショントークンのみを失効させる。認証情報を Authorization: Bearer ヘッダーで提示してログアウトすると、通常のログアウト応答を返しながら何も失効させない。
