1. OpenClaw — ブラウザアップロード機能のパストラバーサル（CVE-2026-26329）

項目詳細
CVECVE-2026-26329
深刻度Medium（認証済みパストラバーサル）
影響OpenClaw 2026.2.14 未満の全バージョン
CWECWE-22（パストラバーサル）
修正OpenClaw 2026.2.14 以降へアップグレード
公開日2026-05-24（NVD 公開 / アップデート）

OpenClaw のブラウザアップロード機能（upload アクション）にパストラバーサル脆弱性が確認されました。認証済みの攻撃者が絶対パスまたはパストラバーサルシーケンスを含むファイルパスを指定することで、Gateway ホスト上の任意のファイルを読み取ることが可能です。Playwright の setInputFiles() API に渡されるパスがセーフルートに制限されていないことが原因です。

攻撃の前提条件として、Gateway HTTP サーフェスへの到達、有効な Gateway 認証（ベアラトークン / パスワード）、および対象セッションでの browser ツール許可が必要です。初期設定では Gateway はループバックにバインドされますが、LAN やテールネット、リバースプロキシ経由で公開している環境では影響度が大幅に上がります。

修正バージョン: OpenClaw 2026.2.14 では、アップロードパスが DEFAULT_UPLOAD_DIR に制限され、トラバーサルパスは拒否されるようになりました。
