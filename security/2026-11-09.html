  • CVE-2026-123538（7.5）: SAML 1.x の署名済みアサーション／レスポンスが発行者として名乗るパートナーの署名かを検証せず、キーストア内のどの証明書の署名でも受理するため、信頼済みパートナーが他パートナーを騙るアサーションを偽造できる。
  • CVE-2026-123542（7.6）: OAuth 2.0 デバイス認可フローで PKCE を強制せず code verifier を検証しない。ほか、保存型XSS（CVE-2026-123539、4.8）、オープンリダイレクト／XSS（CVE-2026-123546、5.3）、SSRF（CVE-2026-123536・123537・123552）、既定の組み込みID残留（CVE-2026-123553、6.9）など。
