🔴 Red Hat npm サプライチェーン攻撃「Miasma」— 32 パッケージが侵害、クラウド認証情報を窃取

項目詳細
発見日2026-06-01（Wiz Research が検出・公開）
影響範囲@redhat-cloud-services 名前空間の少なくとも 32 パッケージリリース（週間約 80,000 DL）
攻撃経路Red Hat 従業員の GitHub アカウント侵害 → 悪意ある orphan コミットを push → GitHub Actions OIDC 経由でバックドア入りパッケージを npm に公開（SLSA 証明書付き）
ペイロードTeamPCP の Mini Shai-Hulud マルウェア改変版。GCP/Azure クラウド ID 収集機能が新たに追加。感染ごとに一意の暗号化ペイロードを生成
  • Wiz Research が6月1日、npm 名前空間 @redhat-cloud-services の少なくとも 32 パッケージリリースに不正な改変が含まれていることを発見
  • 攻撃手法: Red Hat 従業員の GitHub アカウントを侵害 → 2波にわたり悪意ある orphan コミットを RedHatInsights リポジトリに push → GitHub Actions OIDC トークンを悪用して改変パッケージを npm に公開。有効な SLSA 来歴証明書付きで公開されたため、自動セキュリティチェックを回避
  • 窃取対象: GCP および Azure のクラウド ID（本バリアントで新たに追加）、GitHub トークン、SSH キー、CI/CD シークレット、npm トークン
  • マルウェアの特徴: TeamPCP が公開した Mini Shai-Hulud の改変版（コードネーム「Miasma」）。感染ごとに一意の暗号化ペイロードを生成し、ハッシュベースの検出を困難化。Dune テーマがギリシャ神話テーマに置き換えられている
  • Red Hat の対応: 即座に調査を開始し、影響を受けたパッケージを npm レジストリから削除。Red Hat によれば、侵害は内部開発ツールに限定され、顧客向け本番環境（console.redhat.com）への影響は確認されていない
  • 推奨アクション: 6月1日以降に影響パッケージをインストールした組織は、CI シークレット、クラウド認証情報、SSH キー、npm トークンをすべてローテーションすること
  • npm サプライチェーン攻撃の連鎖: 前日報告の codexui-android（OpenAI トークン窃取）に続き、2日連続で npm エコシステムを標的とした大規模サプライチェーン攻撃が発覚。開発者コミュニティ全体での警戒が必要
