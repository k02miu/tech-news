Medium Next.js 15.5.29／16.4.5 未満 — 7件の脆弱性（Cookie ヘッダ露出・SVG 処理・レスポンスデシンク・キャッシュ汚染）

深刻度CVSSv3.1 6.0 〜 6.9（Medium）
CVECVE-2026-119346 / 119347 / 119348 / 119349 / 119350 / 119351 / 119790
影響Next.js 15.0.0〜15.5.29 未満、16.0.0〜16.4.5 未満（セルフホスト構成を含む）
公開NVD登録 2026-11-16 19:17 UTC（JST 2026-11-17 04:17）
出典NVD
  • CVE-2026-119346（6.0）：Edge runtime で NextResponse により Cookie を設定すると、内部ヘッダ x-middleware-set-cookie が公開レスポンスに含まれてしまいます。Cookie 値と属性が重複して出力されるため、同一オリジンで動く JavaScript が HttpOnly 指定のセッショントークンを読み取れてしまいます。App Router の route handler と Pages Router の Edge API routes が対象です。
  • CVE-2026-119347（6.9）：セルフホストの /_next/image オプティマイザが、既定（dangerouslyAllowSVG=false）でも攻撃者の SVG を処理してしまいます。意図的に無効化していたパーサに到達し、DoS や SVG デコード側の脆弱性への露出が増大します。
  • CVE-2026-119348（6.3）：上流レスポンスをそのまま返す構成で、宣言したフレーミングと実際のボディが食い違うレスポンスを生成します。HTTP/1.1 のリバースプロキシでパイプライン応答キューイングを許可している場合、レスポンスデシンクにより他クライアントの応答が混入・漏えいするおそれがあります。
  • CVE-2026-119349（6.3）：App Router で use cache を使う関数に Uint8Array／Blob などのバイナリ引数を渡すと、異なる引数で同一のキャッシュキーが生成されます。クロスユーザーでキャッシュ結果が共有され、情報漏えいやキャッシュポイズニングが成立します（16.0.0〜16.4.5）。
  • CVE-2026-119350（6.3）：cacheComponents 有効かつ partialPrefetching 未設定／false のセルフホスト構成で、未認証リクエストが共有フォールバックシェルを汚染できます（16.4.0〜16.4.5、next start）。
  • CVE-2026-119351（6.3）／CVE-2026-119790（6.3）：ネストした use cache や unstable_cache() と next/root-params の組合せで、root param を欠いたキーに結果が永続化され、root param をまたいでキャッシュが漏えいします（それぞれ 16.2.0〜16.4.5、16.3.0〜16.4.5）。
  • 対策は 15.5.29 または 16.4.5 以降への更新ですわ。Next.js をご利用の構成は早めの更新をお願いいたします。
