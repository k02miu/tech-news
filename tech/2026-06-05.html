🧠 Claude Code — v2.1.163

2026年6月4日付で v2.1.163 がリリースされました。バージョン管理の強制、プラグイン管理、UX改善、および多数のバグ修正が含まれています。

🔧 新機能・改善

  • マネージドバージョン設定: requiredMinimumVersion / requiredMaximumVersion が追加され、許可されたバージョン範囲外の Claude Code は起動を拒否し、承認済みバージョンへの誘導を表示
  • /plugin list コマンド追加: インストール済みプラグインの一覧表示（--enabled / --disabled フィルター付き）
  • /btw にコピーショートカット: "c to copy" で Markdown 回答をクリップボードにコピー、貼り付け時の書式を保持
  • Hooks 改善: Stop / SubagentStop フックが hookSpecificOutput.additionalContext を返せるように。フックエラー扱いされずにフィードバックを継続可能
  • Skills 改善: コマンド本文で \$ エスケープ構文を追加（数字の前のリテラル $ を表現可能）
  • stdio MCP サーバー改善: --resume 時に hooks/Bash と同じ CLAUDE_CODE_SESSION_ID を受け取るように

🐛 主な修正（14件以上）

  • claude -p のハング修正: バックグラウンドコマンドが終了しない場合に最終結果後ハングしていた問題を修正（stdin クローズ後 ~5秒で停止）
  • Bedrock/Vertex/Foundry 環境修正: CI=true 時に "ANTHROPIC_API_KEY required" エラーが発生していた問題を修正
  • Bash 環境変数修正: $TMPDIR が全コマンドで上書きされていたリグレッション（2.1.154 で混入）を修正
  • Windows Bash 修正: "EEXIST: file already exists" エラー（OneDrive / 読み取り専用属性）を修正
  • 組織管理権限ルール修正: 起動時のマネージド設定取得完了時にセッション全体に適用されない問題を修正
  • バックグラウンドセッション修正: アップデート後に再アタッチするとバックグラウンドタスクが消失する問題、バックグラウンド更新のコールド再起動待ち問題を修正
  • 端末表示修正: エージェントビュー終了時の端末位置ずれと数秒のハングを修正
  • キーボード入力修正: ペースト操作後に入力が永久に無反応になる問題を修正
  • Hook 条件式修正: if: "Bash(...)" が $() や $VAR を含む全コマンドで発火していた問題を修正
  • 拒否ルール修正: Read(~/Desktop/**) の deny が $HOME 経由の Bash コマンドをブロックしない問題を修正

🛡️ Django — セキュリティリリース 6.0.6 / 5.2.15

2026年6月3日、Django チームは 5件のセキュリティ修正を含む 6.0.6 および 5.2.15 をリリースしました。すべての Django ユーザーに速やかなアップグレードが推奨されます。

🔴 修正された脆弱性（全5件）

  • CVE-2026-6873 — Signed cookie salt 名前空間の衝突: get_signed_cookie() で署名 salt の導出が cookie 名と salt の単純な連結だったため、異なる名前+salt の組み合わせが同じ連結を生成する可能性があった（深刻度: low）
  • CVE-2026-7666 — SMTP STARTTLS 失敗時の平文送信: EMAIL_USE_TLS 使用時に STARTTLS ハンドシェイクが失敗すると、後続のメールが暗号化なしで送信される可能性（深刻度: low）
  • CVE-2026-8404 — Cache-Control ディレクティブの大文字小文字: UpdateCacheMiddleware が Private など大文字混在の Cache-Control を正しく認識せずキャッシュ（深刻度: low）
  • CVE-2026-35193 — Authorization ヘッダー付きレスポンスのキャッシュ: Vary: Authorization が欠落した状態でキャッシュされ、他ユーザーの認証付きレスポンスが漏洩する可能性（深刻度: low）
  • CVE-2026-48587 — Vary ヘッダーの空白パディング: Vary: *（末尾スペース付き）がワイルドカードとして認識されず、キャッシュされるべきでないレスポンスがキャッシュ（深刻度: low）

📋 影響範囲と推奨アクション

  • 影響バージョン: Django main, 6.1 (alpha), 6.0, 5.2
  • 推奨: 6.0.x 系は 6.0.6 へ、5.2.x 系は 5.2.15 へアップグレード
  • 全脆弱性の深刻度は low だが、キャッシュ関連の3件はデータ漏洩の可能性があるため注意
