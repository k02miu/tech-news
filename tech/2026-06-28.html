🧠 Claude Code — v2.1.195

対象期間内に Claude Code の v2.1.195（pubDate: 2026-06-27 00:32:40 UTC = 2026-06-27 09:32:40 JST、期間開始から32分後）がリリースされました。前号後半に続いて v2.1.193（auto-mode classifier 拡張・OTel 応答ロギング・バックグラウンドエージェント信頼性向上）の内容を踏まえ、今号の1本は「異文化対応」の脆さを直す破綻修正が主役です。日本語など空白区切りでない言語の音声入力 auto-submit が発火しないバグ、macOS で入力デバイス切替後に沈黙を拾くバグ、ハイフン入り MCP / プラグイン ID が部分 match して hook が誤発火するバグなど、日本語使用者にとって直効のある修正が並びます。加えて CLAUDE_CODE_DISABLE_MOUSE_CLICKS でフルスクリーンモード時のマウス操作を無効化、claude agents のレイアウト改善、Remote プロビジョニングチェックリスト導入が入りました。

✨ 新機能・改善

  • CLAUDE_CODE_DISABLE_MOUSE_CLICKS 設定を追加: フルスクリーンモードでマウスのクリック / ドラッグ / ホバーを無効化し、ホイールスクロールのみ残すことが可能に。マウス操作が邪魔なターミナル環境・誤操作回避に有効
  • Linux の voice mode で SoX 検出を改善: SoX 自体は置いているが audio capture デバイスがないケースを「マイク無し」と「SoX 未導入」で正しく区別するようメッセージを切り分け
  • claude agents 完了リストの表示を改善: 利用可能な縦幅を自動で埋めるようになり、短いターミナルではヘッダーが縮退して live session が常に見える状態を維持
  • Remote session 起動時に provisioning checklist を表示: コンテナ起動待ちの間にプロビジョニング手順を順表示し、進捗を追えるように

🐛 主な修正

  • ハイフン入り ID の hook matcher が部分 match していた問題を exact match 化（code-reviewer, mcp__brave-search などが意図せず他の matcher も引いていた）。特定 MCP サーバ全部出したい場合は mcp__brave-search__.* と明示する運用に変更
  • macOS で長時間実行中にデフォルト入力デバイスが変わると音声入力が沈黙を拾き続ける問題を修正
  • 日本語・中国語・タイ語など空白区切りでない言語で音声入力の auto-submit が発火しない問題を修正 — 日本語話者に直接効く fix
  • プロジェクト .claude/settings.json でのみ有効化した外部プラグインがローダーごとに install consent を要求していた問題を修正
  • /plugin の Enable/Disable が plugin.json の name と marketplace entry name 異なるプラグインで効かない問題を修正
  • 新 Claude Code バージョンが書いた background jobs が claude agents から消えたりデータ欠損する問題を修正
  • クラッシュした background task を再開すると再起動でなく白画面が最大5秒出る問題を修正
  • 制御ソケットの起動に失敗した background agent daemon が到達不能のまま停止し restart を block していた問題を修正
