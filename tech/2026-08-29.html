🧠 Claude Code — v2.1.250 / v2.1.251

対象期間内に2つのリリースがありました。v2.1.250（8月28日 09:55 JST）は小規模なバグ修正・安定性改善リリース。v2.1.251（8月29日 03:33 JST）は大規模リリースで、モデル切り替えフック、サブエージェントのツール呼び出しのライブストリーミング、コスト・キャッシュ可視化の強化に加え、多数のセキュリティ修正が含まれます。

🔧 新機能・改善（v2.1.251）

  • PreModelSwitch / PostModelSwitch フック: モデル切り替えをブロック・確認・注記できる新しいフックイベント。SessionStart resume フックにはセッションの陳腐化と再キャッシュ推定コストも渡されます
  • サブエージェントのライブストリーミング: フォアグラウンドのサブエージェントのツール呼び出しと結果を Remote Control クライアントにリアルタイム表示（バックグラウンドは従来どおりステータスのみ）
  • 使用上限バー: /usage に Spend limit バー、ステータスラインに rate_limits.spend_limit フィールドを追加
  • プロンプトキャッシュの可視化: /cost にセッション単位のキャッシュヒット率・再キャッシュトークン等を表示し、ステータスラインスクリプト用の prompt_cache オブジェクトも提供
  • バックグラウンドセッション管理コマンド: claude attach/logs/stop/respawn/rm を --help に追加
  • 効率改善: 対話セッションの CPU 使用量削減、ネイティブバイナリ約 5MB 縮小、希少言語6種のシンタックスハイライト削除でさらに 2.5MB 縮小
  • 動作変更: Enterprise サブスクリプションのデフォルトモデルを Opus 5 に、/effort がモデルごとにデフォルト effort を保存、CLAUDE_CODE_SUBAGENT_MODEL はサブエージェントのデフォルト指定に変更

🐛 主な修正（v2.1.251 — セキュリティ中心）

  • 権限チェック後にワーキングディレクトリ内で差し替えられたシンボリックリンクをファイルツール（Read/Write/Edit）が追跡し、承認範囲外の読み書きが可能だった問題を修正
  • マーケットプレイス宣言のプラグインコマンドがプラグインディレクトリ外を指せる問題（パストラバーサル）を修正
  • プロジェクト設定が詳細ベータトレースや生API本文ログを有効化でき、管理設定で固定された OTLP コレクターを回避できていた問題を修正
  • Grep/Glob がシンボリックリンク経由の検索パスで Read(...) deny ルールを適用していなかった問題を修正
  • Bash 権限チェックが整数シェル変数への算術式代入（例: OPTIND=1/0）を自動承認していた問題を修正
  • サンドボックス内のコマンド出力ファイルの扱いを変更し、サンドボックス化されたコマンドがリダイレクトや置換で出力ファイルを操作できないよう強化
  • 管理設定・プロジェクト設定からの ANTHROPIC_CUSTOM_HEADERS で認証情報等を設定する場合に承認を必須化
  • 思考のみのターン後の「text content blocks must be non-empty」エラーで会話が固まる問題を修正
  • tmux over SSH で開いたバックグラウンドセッションのテキスト選択が tmux バッファにコピーされない問題を修正
  • 多数の並列サブエージェントで TUI が重くなる問題を修正
  • agent team でチームメイトの最終回答がリーダーに届かない問題を修正

🐙 OpenClaw — 2026.9.1-beta.1

🔧 新機能・改善

  • ワーカー復旧: admission-deadline 起動を再アームし、停止したワーカーのターンを確定させて委譲作業が未解決のまま残らないように
  • Control UI: エージェントファイルの確認済み保存を保護、外観設定をユーザープロファイルごとに保存、設定可能なモデル選択スコープを追加
