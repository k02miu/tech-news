  • ultrathink: 対話端末での ultrathink が、Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 の Anthropic API 経由で xhigh effort のターンを実行するようになりました。レインボー表示は実際に effort を引き上げられる箇所のみに限定されます。

  • 権限ルールの起動警告: settings ファイルの権限ルールに関する警告が、ルールが変わるまでユーザーごとに1回だけ表示されるようになりました。
  • Bedrock / Mantle / Vertex / Foundry: モデル設定を downloads.claude.ai の署名済みファイルから読み込むよう変更（CLAUDE_CODE_MODEL_CATALOG=off で無効化）。
  • Ctrl+D: エージェントビューで、空入力時に2回押すと終了するプロンプトの挙動に揃えられました。

🐋 Orca — v1.4.241

対象期間内に2件のリリースが確認されました。デスクトップ版 v1.4.241（2026-10-26 12:48 JST 公開）と、モバイル版 mobile-android-v0.0.59（2026-10-26 13:21 JST 公開）です。今回は「期待どおりに動くチャットとブラウザ」が主題で、設定に追従するチャット、Chrome に近づいた内蔵ブラウザ、SSH 接続と管理サーバの復旧性の底上げが柱です。

🔧 新機能・改善

  • 設定に追従するチャット: 新規チャットは「設定 → Agents」の各エージェント権限を使用し、名前を変えたチャットは Session History で名前を保持します。ターミナルが実行中の会話にチャットが書き込むこともなくなりました。
  • Chrome に近づいたブラウザ: DevTools をペイン内にドッキングでき、音を鳴らしているタブのミュート、ホバー時のリンク URL 表示、ページ内での Orca ショートカットとマウスの戻る／進むに対応しました。
  • エージェントの閲覧を目視: カーソルとバッジでエージェントがどこをクリック／入力しているかを示し、チャットから該当ページへジャンプできます。ターミナルやチャットからのリンクは元のソースの隣で開きます。
  • 行き止まりの少ない SSH: 保存したポートフォワードが再起動後も復帰し、失敗理由を説明します。証明書のみのホストはシステムの ssh 経由で接続し、管理サーバはターミナルを閉じずに更新されます。
  • 起動・再開の信頼性: Hermes と Kimi のペインが安定し、チャットの書体設定やエージェントのライブ閲覧表示が加わりました。
  • [モバイル] 起動の高速化: コンピュータ側の更新後に Orca を開く処理が約2倍高速化され、ダウンロードは差分のみを取得します。進捗バーが滑らかに伸び、既に開いている画面への「戻る」は複製を開かずそこへ戻ります。
