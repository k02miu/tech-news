🐙 OpenClaw — v2026.11.2

v2026.11.2（2026-11-09 04:31 JST 公開）は、プライバシーと信頼境界の強化を最上位の柱に据えたリリースです。診断ログへの機密情報・会話内容の混入防止、アカウント識別の維持、Gateway の可用性改善が中心で、機能追加よりも堅牢性の底上げに振り切った内容となっています。

🔧 主な変更

  • プライバシーと信頼境界: 設定シークレット、会話内容、ツールのエラー、チャネルのペイロードを診断ログに出さないようにしました。選択されたプロバイダとナビゲーションの信頼境界を強制し、ウォームな CLI ターン終了後には MCP の付与を解放します。
  • アカウント安全性の担保: 永続リトライとスケジュール配信をまたいで送信者・アカウントの識別を保持。WhatsApp の識別子解決を復旧し、Teams のルーティングと許可リスト設定を再読み込み後も維持します。
  • Gateway の可用性: 診断キャプチャの処理量を削減し、プラグインのクリーンアップや異常に肥大した Telegram テーブルで Gateway がブロックされないようにしました。シャットダウン時にはチャネル起動をキャンセルし、一時的なスキーマリース競合から復帰します。
  • 復旧とアップデートの安全性: アップデート時に設定済みのプラグイン実行ファイルと環境参照を保持。macOS で Trash へのアクセスが拒否された場合のサービス復旧を修復し、アップデートの自己フェンシングと中断時のハングを回避します。
  • ネイティブクライアントの復旧: iOS の再接続ナビゲーションの応答性、Android のチャット起動状態、Apple モデルと computer-use リソースの一時的な初期化失敗からの復帰を改善しました。
  • インストールと状態の正確性: Ubuntu の既定パーミッション環境でもブラウザ拡張のインストールが通るよう修正。Windows の状態ディレクトリの大文字小文字、worktree 容量確保時や認証失敗記録時のデータベース所有権も正しく扱います。
  • 診断キャプチャの上限: 任意の診断コンテンツキャプチャは属性・候補ペイロードのサイズに上限を設け、巨大な画像データは省略するようになりました（プロンプトや会話履歴には影響しません）。

🐋 Orca — v1.4.254

v1.4.254（2026-11-09 08:25 JST 公開）は「Git Graph」「スマホでのオンデバイス音声入力」「チャットを脱線させないサイド質問」を三本柱とする機能リリースです。

🔧 新機能・改善

  • Git Graph タブ: ローカル・リモートのブランチとタグを一覧でき、各コミットの詳細と変更ファイルまで確認できます。フォルダ型ワークスペースでも Source Control が使えるようになり、ヘッダーのブランチ名からその場でブランチの切り替え・作成が可能になりました。
  • /btw と /fork: Chat UI で /btw を入力すると、元のチャットを走らせたまま隣のフォークでサイド質問ができます。/fork は最新の応答から分岐します。チャットが開いた・push した PR の CI 結果も短い行で表示されます。
  • オンデバイス音声入力: iPhone（iOS 26 以降）と Android で端末内文字起こしが可能になり、失敗時はコンピュータ側をフォールバックに使えます。コンピュータ・スマホ・Web クライアントが同時に音声入力でき、音声エンジンは別プロセスで動くためクラッシュやハングが Orca 本体を巻き込みません。
  • スマホの耐障害性: デスクトップに到達できない間はチャット送信をキューに積み、復帰後に順序どおり送信します。チャットの下書き、添付、未保存のファイル編集、自動化の下書きがアプリ強制終了後も保持されます。
  • Codex アカウント履歴による入力遅延の解消: アカウント間で Codex 履歴を紐付ける処理がアプリ全体のタイピングをブロックしなくなりました。リモートターミナルも単独キーストロークを即送信し、圧縮された出力を読み取ります。
  • ペアリングと信頼の強化: ペアリングコードは、それを使った端末が自身のサインインを保存した時点で無効になります。デスクトップと CLI のリモート接続は新しい暗号化方式を使用し、orca serve は明示的な許可がない限りパブリックなインターネットアドレスからの接続を拒否します。新しいリポジトリはエージェントに渡す前に一度だけ信頼確認を求めます。
  • 見た目のカスタマイズ: 独自のアプリアイコンを取り込み、テーマプラグインがループ背景動画や独自フォントを配布できるようになりました。Claude Code のターミナルテーマを Orca に合わせることもできます。
  • エージェント対応: Antigravity のチャットがホスト側の agy で動作（Full access チャットを含む）。Muse はサブスクリプションのクォータをステータスバーに表示します。
