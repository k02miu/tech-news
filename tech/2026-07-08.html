🧠 Claude Code — v2.1.202

2026年7月7日にリリースされた Claude Code v2.1.202 では、ワークフロー機能の改善と多数のバグ修正が行われました。

🔧 新機能・改善

  • Dynamic workflow size 設定: /config に動的ワークフローのサイズ設定（small/medium/large）を追加。アドバイザリーガイドラインとして機能し、強制的な上限ではありません
  • OpenTelemetry 属性追加: ワークフローから生成されたエージェントに workflow.run_id および workflow.name のOpenTelemetry属性を追加し、OTelデータからワークフロー実行のアクティビティを再構築可能に
  • /workflows エージェント一覧のレイアウト改善: より広いタイトル、専用の時間列、短縮モデル名、行ごとのツール呼び出し回数を廃止
  • MCP エラーメッセージ改善: url はあるが type がないサーバー設定に対して、誤解を招く「command: expected string」の代わりに "type": "http" を提案する明確なエラーメッセージを表示
  • /review の動作変更: /review <pr> を高速な単一パスレビューに戻しました。複数エージェントによるレビューには /code-review <level> <pr#> をご使用ください

🐛 主な修正

  • Ctrl+R 履歴検索のクラッシュ修正: インラインのCtrl+R履歴検索で、スキャン中に受け取り/キャンセルした際のクラッシュを修正
  • バックグラウンドセッションの /rename 修正: ジョブ再起動時にリネームが元に戻る問題を修正
  • mTLS ハンドシェイク失敗修正: クライアント証明書ローテーション中に設定が再適用された際の一時的なmTLSハンドシェイク失敗を修正
  • Remote Control コマンド修正: モバイル/ウェブからインタラクティブセッションに送信されたコマンドが「Unknown command」で失敗する問題を修正
  • Remote Control 画像・ファイル修正: キャプションなしで送信された画像やファイルがサイレントにドロップされる問題を修正
  • SSH経由のサインインURL修正: claude auth login のサインインURLがSSH接続で折り返し時にクリック不可になる問題を修正し、単一ハイパーリンクとして出力
  • claude agents のセッション修正: claude agents からチャットを開く際に「currently running as a background agent」エラーとワーカークラッシュ/リスポーンループが発生する問題を修正
  • ワークフローのUnicode修正: Unicode引用符エスケープを含むワークフロースクリプトが解析前に破損する問題を修正。パースエラー時に問題のある行を表示
  • 音声ディクテーション修正: マイクまたはオーディオレコーダーが失敗した際に無制限にリトライする問題を修正。連続キャプチャ失敗時は音声入力を一時停止
  • Git worktree パフォーマンス修正: 多くのgit worktreeを持つリポジトリで、セッション名での再開やレジュームピッカーが数分かかり大量のメモリを使用する問題を修正
  • インストーラーのダウンロード修正: プロキシやネットワークが接続をドロップした際に「aborted」で即座に失敗する問題を修正。一時的な接続ドロップ時はリトライ
  • スキル重複読み込み修正: 既に読み込み済みのスキルを再呼び出しした際に、コンテキストに重複コピーが追加される問題を修正
