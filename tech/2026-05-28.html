☁️ GCP — 5月27日付アップデート

🆕 gcloud CLI 570.0.0

gcloud CLI の新バージョン 570.0.0 がリリースされました。主な変更点は以下の通りです。

  • Windows バンドル Python: cryptography 46.0.7 / pyOpenSSL 26.0.0 で再ビルド
  • Linux バンドル Python: 3.14.5 に更新
  • 認証キャッシュ: Regional Access Boundary (RAB) データのネイティブ保存・更新対応
  • Windows PuTTY: 不具合のため 0.81 に差し戻し

🆕 Cloud Run — SSH アクセス対応（beta）

gcloud beta run deploy および gcloud beta run services update に --[no-]ssh フラグが追加され、Cloud Run サービスのコンテナインスタンスへの SSH アクセスを有効化/無効化できるようになりました。また、--domain フラグでデプロイ時にドメインマッピングを同時作成可能に。プロジェクト未指定時にはインタラクティブプロンプトが表示されるように改善されています。

🆕 Compute Engine — 注目の更新

  • Post-Quantum Key Exchange (GA): SSL ポリシーの --post-quantum-key-exchange フラグが GA 昇格。耐量子暗号対応の強化
  • Resource Manager Tags: Commitments、Instant Snapshots、Disks、Snapshots、Images、各種 VPN リソースで --resource-manager-tags が beta/GA 対応
  • 新OS対応: CentOS/RHEL/Rocky 10、Debian 13、Ubuntu 24.04/25.10 が Ops Agent ポリシーの OS 指定に追加
  • Autoscaler 改善: --stabilization-period フラグでスケールイン前の負荷安定化期間を設定可能に
  • Org Rollouts: gcloud compute org-rollouts / org-rollout-plans が beta 昇格
  • IPv6 セカンダリ範囲: サブネットの IPv6 セカンダリ範囲関連フラグが beta 昇格
  • インスタンス柔軟性: MIG の --instance-flexibility-policy が beta 対応

🆕 GKE — Agent Sandbox (GA)

--enable-agent-sandbox フラグが GA に昇格しました。GKE クラスターでのエージェントサンドボックスが本番環境で利用可能になりました。

🆕 BigQuery — CLI 機能強化

  • テーブル識別子 project.catalog.namespace.table 形式に対応
  • データセット識別子 catalog.namespace 形式に対応
  • bq show / bq rm で行アクセスポリシーの表示・削除が可能に
  • 予約割り当ての principal フィールド対応、割り当て名の指定対応

🆕 Cloud KMS — プロジェクトレベル Autokey 設定

gcloud kms autokey-config コマンドがプロジェクトレベルの Autokey 構成に対応し、key-project-resolution-mode フィールドも設定可能になりました。

🆕 BigLake — Hive カタログ (beta)

gcloud biglake hive catalogs および gcloud biglake hive databases が beta に昇格。Iceberg カタログの --primary-location フラグは GA に昇格しました。
