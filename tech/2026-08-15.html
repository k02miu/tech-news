🧠 Claude Code — v2.1.233 / v2.1.232

対象期間内に2件の更新が公開されました。v2.1.232ではサブエージェントフォークのデフォルト有効化やセッション間メッセージング、GitLab対応の拡充が入り、続くv2.1.233ではGitLab MR対応、Linux向けメモリcgroup、WindowsのNTLM資格情報漏えいベクターの修正などが含まれます。

🔧 新機能・改善（v2.1.233）

  • GitLab MR対応: --worktreeフラグとclaude agentsビューでGitLabのマージリクエストURLをサポート（MRは!N形式で表示）。
  • アプリゲートウェイ: Anthropic upstreamでサインインユーザー身份をヘッダー送信するopt-in設定forward_user_identityを追加（プロキシ経由でユーザー別支出の帰属が可能に）。
  • Linuxサンドボックス: Bashツールにopt-inのメモリcgroup対応（CLAUDE_CODE_TOOL_MEMORY_LIMIT）を追加し、暴走ビルドによるセッション停止を防止。
  • WebFetch: セッションURLキャッシュTTLを設定するCLAUDE_CODE_WEBFETCH_CACHE_TTL_MS環境変数を追加。
  • セルフホストRunner: セッション開始時に作業ツリーを書き換えず、サーバー往復も削減して起動を高速化。

🐛 主な修正（v2.1.233）

  • WindowsでNTの\\??\デバイスプレフィックスによるUNCパス検証の迂回を修正し、NTLM資格情報漏えいベクターを塞ぎました。
  • MCP v2接続が固定タイムアウトでストリームを終了するサーバーでlistenストリームを無限に張り直す問題を修正しました。
  • Claude Desktop / VS Code実行時に権限プロンプトでNotification hooksが発火しない問題を修正しました。
  • サンドボックス有効時のLinuxアイドルセッションがCPUコアを100%占有する問題を修正しました。
  • Todo/タスク追跡ツール（TaskCreate/Get/Update/List、TodoWrite）がOpus 4.8・Sonnet 5・Fable 5・Mythos 5以降のモデルで利用不可に（CLAUDE_CODE_ENABLE_TODO_TOOLS=1で復元可能）。
  • 2.1.232で導入したBash権限変更のうち、Cygwin風シンボリックリンクと入力リダイレクト（< file）関連はロールバックされました。

🔧 新機能・改善（v2.1.232）

  • サブエージェントフォーク: subagent_type: "fork"が会話全体とプロンプトキャッシュを継承し、デフォルトで有効に。対話セッションの非チームメイトエージェント生成もデフォルトでバックグラウンド実行に。
  • セッション間メッセージング: プロンプトで@を入力して他のClaudeセッションをメンションでき、SendMessageは完全一致するライブセッション名へ直接配信。
  • GitLab対応: トークン系列（glrt-等）のシークレット秘匿化、glab CLI設定ストアの保護、プラグインマーケットプレイスでのGitLabリポジトリクローン対応。
  • 設定: ダイアログ有効期限と他セッションからのメッセージ受信を制御する/config行を追加。マーケットプレイス設定のエイリアスも導入。
  • Remote Control: ネットワーク障害後も約30分間再接続を継続し、会話再開時のセッション奪取を回避。mTLS証明書の自動ローテーションにも対応。

🐛 主な修正（v2.1.232）

  • PowerShellの変数書き込みパラメーターで$PSDefaultParameterValuesを上書きする権限バイパスを修正しました。
  • Git BashがCygwin風シンボリックリンクを辿るWindows権限バイパスを修正しました。
  • ネストしたgitリポジトリが親ディレクトリの信頼を継承する問題を修正し、リポジトリごとの信頼確認を必須化しました。
  • MCP接続がプロトコルプローブに応答しないサーバーで30秒フルにハングする問題を修正しました。
  • Remote Controlセッションの転写・資格情報の継承、クラウドセッションでの会話履歴復元、休止中の到達不能表示などを修正しました。
