🐋 Orca — v1.4.271

対象期間内に v1.4.271（2026-11-23 05:13 JST 公開）がリリースされました。ひとつの Bot グループがペアリング済みの複数コンピュータの Bot を抱えられるようになり、Bot が Qwen Code 上で動くようになりました。スマートフォンアプリだけでエージェントの設定から共有・取り込みまでを完結でき、チャット周りも軽くなっています。

🔧 新機能・改善

  • Bot がコンピュータをまたぎ、Qwen Code に対応: ひとつの Bot グループに、ペアリング済み各コンピュータの Bot を収容可能に。Bot が Qwen Code 上で実行できるようになり、グループルームではエージェントが @メンション したメンバー全員にフォローアップのターンが渡ります。
  • スマートフォンからエージェントを運用: エージェントのオートメーション編集、Slack・Linear・GitHub・Google・Composio の接続、リンクによるエージェント共有、OpenClaw や Hermes からのインポート、soul の閲覧、メモリとスキルの管理、履歴セッションの別エージェントへの引き渡しに対応（対応するモバイルビルドが必要）。
  • チャットの扱いやすさ: チャットの削除、使用量制限後の自動継続が既定に、@ メニューでのフォルダ一覧表示、行表示の抑制、入力欄の案内文が読みやすく保たれるようになりました。
  • Windows・WSL の安定化: WSL ホストがキープアウェイクのために稼働中エージェントを数えるようになり、WSL 上での Codex アカウントと設定の挙動を修正。フォルダを WSL ホストへ移動する際は事前に確認を求めます。
  • 全体の軽量化: ターミナルのタイトル変更、エージェントの状態更新、Bot 一覧、スマートフォン側の更新で、再スキャンや再構築を抑制。非表示のアニメーションは停止します。
  • 複数の GitHub アカウント連携: 複数の GitHub アカウントをリンク可能に。リンクプレビューとコメントのポーリングも軽量化されました。
  • Bots（ベータ）の記憶と再開: 終了したアイテムとその PR をジャーナルに記録し、再起動や使用量制限による中断の後も未完了のリクエストを保持して一度だけ継続します。アイテムのコメント欄には入力欄と同じメンション・スラッシュのピッカーが付き、「Replying to」から回答先の質問へ移動できます。

⚠️ 既知の問題

  • アプリの再起動後、または使用量制限などのエラー後に、Bot が作業の途中で停止することがあります。次のバージョンで修正予定とされています。
