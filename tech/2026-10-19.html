🐙 OpenClaw — v2026.10.5

2026-10-19 06:47 JST に v2026.10.5 が公開されました。更新処理の自己回復、再起動に強い会話、ゲートウェイの高速化・軽量化が柱となっています。

🔧 新機能・改善

  • アップデートの完遂と自己回復: openclaw update が各種デバイス・ファイルシステム・pnpm 12・Windows の昇格・macOS のログインシェルをまたいで完了するようになり、滞留したハンドオフリースやパッケージ有効化ジャーナルを解消します。--no-restart 指定時の成功報告も正確になりました。
  • 再起動に強い会話: 中断されたターン、worktree 準備中に届いた最初のメッセージ、サブエージェントの作業、遅延タスクがゲートウェイ再起動後に再開されます。
  • より高速で軽量なゲートウェイ: セッション・トランスクリプト・履歴・メタデータの読み取りがワーカースレッドへ移り、1ターンあたりの SQLite 処理が大幅に減少しました。
  • ターンとサブエージェントの信頼性: ストールしたストリーム、ツールコール ID の再利用、失効した ChatGPT WebSocket、不正な OpenAI / Google ストリームから復旧します。
  • X チャンネル: X（Twitter）のメンションに新チャンネルプラグインで応答可能に。ストリーミング、リポジトリ質問向けのゲストモード、API コスト上限の強制を備えます。
  • 音声通話: 通話ごとのブリーフ、通話レポート、ライブステアリング、コールバック、ボイスメール検出が追加されました。
  • モデルピッカーの改善と新モデル: 各プロバイダーの推奨モデルを先頭に表示し、新規追加された Claude / ChatGPT / Ollama モデルを OpenClaw のリリースを待たずに表示。Google は Gemini 4 Argon と Gemini 3.8 Flash を追加しました。
  • ゲートウェイ内の ClawHub: ゲートウェイから ClawHub のプラグインとスキルを閲覧・検索でき、プラグインは対応する最新の公式リリースを自動的に選択します。
  • ツール承認フックの変更: 通常のフックが、信頼済みインライン承認されたツール引数を再承認なしに書き換えることはできなくなりました。変換系プラグインは最終引数に別途承認を求める必要があります。
