🧠 Claude Code — v2.1.219

対象期間内に v2.1.219 が公開されました。Claude Opus 5 を既定のOpusモデルとして追加し、1Mコンテキストとfast modeに対応したほか、sandboxの厳格なネットワーク許可リスト、DirectoryAdded hook、stream-jsonのネストしたサブエージェント転送などが加わりました。

🔧 新機能・改善

  • Claude Opus 5: claude-opus-5 を追加し、既定のOpusモデルに設定。1Mコンテキストとfast modeをサポート。
  • サンドボックス制御: sandbox.network.strictAllowlist で、許可リスト外ホストへの接続をプロンプトなしで拒否可能に。
  • hookとstream-json: /add-dir 後に発火する DirectoryAdded hook、および深い階層のサブエージェント転送を追加。
  • 動的workflow: workflowサイズ指針を設定ファイルから指定でき、既定値をmedium（15エージェント未満の目安）に変更。サブエージェントの既定ネスト深度も3に拡大。

🐛 主な修正

  • claude -p のストリーム途中のAPIエラー時に、すでに生成済みの回答が失われる問題を修正。
  • MCP接続失敗時にHTTPステータスとエラー内容を表示し、設定値の前後にある不可視の空白も警告。
  • self-hosted runnerの再起動・終了処理、権限承認の復元、Remote Controlのfast mode表示などを改善。
  • GNU screenのコピー、Vimモード、スクリーンリーダー、Windowsのbashパス処理など複数の不具合を修正。
