🧠 Claude Code — v2.1.218

対象期間内に v2.1.218 が公開されました。コードレビュー、MCP接続診断、バックグラウンド実行、アクセシビリティ、Windowsパス処理などが改善されています。

🔧 新機能・改善

  • バックグラウンドレビュー: /code-review がバックグラウンドサブエージェントとして実行され、会話を占有しないよう変更
  • MCP接続診断: claude mcp list と /mcp に、接続失敗時のHTTPステータス・エラー文を表示
  • レビュー操作: /ultrareview の説明付き引数に対応し、/code-review ultra は非対話セッションでクラウドレビューを起動
  • 自動モード・計画モード: 危険なコマンドの判定や読み取り専用判定を分類器中心に改善し、/deep-research は手動呼び出し時のみ開始
  • アクセシビリティ: スクリーンリーダーモードで削除文字の読み上げ、カーソル追従、入力・VoiceOver案内を改善

🐛 主な修正

  • Windowsパスの \u で始まる部分がCJK文字へ壊れる問題を修正
  • 左矢印キーで会話が取り消しなしに破棄される問題、貼り付けた改行が一行化する問題を修正
  • compact後の /context の古いトークン使用量、ツール中断時の不正なトランスクリプトを修正
  • Bedrockのアプリケーション推論プロファイルARN等に対する利用料金計測、セットアップウィザード、セッション再開、PRイベントの信頼性を修正
  • 深くネストした監視ディレクトリやUIツリーでのクラッシュ、プロンプト履歴の競合、コンテキスト超過時の再送ループを修正
