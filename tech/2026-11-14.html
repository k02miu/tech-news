🧠 Claude Code — v2.1.325 / v2.1.323

対象期間内に v2.1.323（2026-11-13 09:24 JST 公開）と v2.1.325（2026-11-14 06:02 JST 公開）の 2 件が公開されました。いずれも新機能の追加と、サンドボックス権限まわりの挙動変更が中心ですわ。

🔧 新機能・改善（v2.1.325）

  • VS Code のプロンプト候補: ターミナルで候補が表示される場面すべてで VS Code でも提示され、Tab で次のプロンプトを承認できます。promptSuggestionEnabled: false で無効化可能です。
  • API キーを作らないコンソールサインイン: VS Code 拡張に追加されました。
  • MCP サーバーのサインイン（SSH / WSL / コンテナ）: パネルからリダイレクト URL を貼り付けられる欄が追加されました。
  • Jupyter ノートブックのヒント: ノートブックを読む・編集した後に、セル再実行に関するスピナーのヒントが一度だけ表示されます。
  • 組織ポリシーでブロックされた際の案内: エラー行に /rewind でメッセージを変更するか /clear するかの継続方法が示されます。

⚙️ 挙動の変更（v2.1.325）

  • サンドボックス化された Bash が既定で通常の権限フローに従う: プロンプトなしで実行し続けるには sandbox.autoAllowBashIfSandboxed: true を設定します。マネージド設定でサンドボックスを有効化している場合も同様です。
  • 信頼していないリポジトリでの読み取り専用 git コマンド: 実行前に確認を求めるようになりました。プロンプトなしで許可するには additionalDirectories ではなく --add-dir で指定します。
  • スケジュールタスクと /loop: allowed-tools やフックを宣言したスキルの実行前に確認が入ります。無人実行するには permissions.allow に Skill(name) を追加してください。
  • サンドボックスの書き込み制限を拡大: 追加ディレクトリ内の .claude（settings・skills・agents・commands・hooks）への書き込みが拒否されます。
  • CLAUDE_CODE_MAX_CONTEXT_TOKENS: claude- で始まる未認識モデル ID（ゲートウェイの claude-sonnet-latest など）のコンテキストウィンドウにも適用されるようになりました。
  • 認証情報の分離: サンドボックスが自前で起動するプログラム（ネットワークブリッジ等）や、ripgrep・ローカル git コマンド・サンドボックスランタイムの補助プログラムが、サインイン用トークンや API キー、mTLS クライアント鍵のパスフレーズを環境に持たずに実行されるようになりました。

⚙️ 主な変更（v2.1.323）

  • Code Mode（実験的・オプトイン）: Claude がツール呼び出しのために JavaScript を書く方式が追加されました。組織単位での無効化も可能です。
  • 未認識モデル ID の既定コンテキストを 200K → 1M に変更: 200K のままにしたい場合は CLAUDE_CODE_DISABLE_1M_CONTEXT=1 を設定します。ウィンドウの小さい他社モデルでは、満杯後に毎ターン失敗し続けることがあるため事前設定が推奨されます。
  • 同一マシン上のセッション間メッセージ上限: 約 20 通から 100,000 通へ引き上げられました（Claude Desktop の Code タブも同様）。
  • /security-review: 実行前に確認を求めるようになりました。
  • MCP クライアント v1 の削除: MCP_SDK_GENERATION=v1 は v2 クライアントの互換モード（早いハンドシェイク、緩和された OAuth サインイン検査）として動作します。
  • 長時間フックのハートビート: claude -p と SDK セッションで 30 秒ごとに進捗を通知し、ホスト側がハングと誤認してターンを打ち切るのを防ぎます。
  • サンドボックスのシンボリックリンク検査: macOS・Linux・WSL で、書き込み可能フォルダ内のシンボリックリンク経由で付与された書き込み権限を無視するようになりました。
  • シークレットらしき許可ルール: 「今後確認しない」で保存されたルールが秘密情報を含むと見なされる場合、または git 管理下の settings.local.json に保存される場合は、そのセッション限りとなり永続化されません。
  • プラグイン: plugin.json の engines["claude-code"] によりバージョン範囲外のプラグインは導入・更新・読み込みされず、範囲内で最新のものが選択されます。
