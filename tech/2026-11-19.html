🐙 OpenClaw — v2026.10.33

2026-11-18 13:15 JST に v2026.10.33 が公開されました。LTS 相当の extended-stable チャネル（Gateway 専用）で、2026年10月末時点の OpenClaw に重要セキュリティ更新・信頼性修正・性能改善・新モデル対応を積んだリリースです。配布対象は core npm パッケージ、対応する公式 npm プラグイン、Gateway の Docker イメージで、ネイティブアプリは含まれません。

🔧 主な改善

  • 大規模セッションの安定化: 長い会話や巨大なセッションストアで、エクスポート・復旧処理を上限付きに変更。チャット、メモリのエクスポート、Doctor による修復、Gateway 起動時のメモリ枯渇（OOM）を削減。
  • 更新失敗からの復旧: 更新を実行したプロセスが落ちても Gateway がオフラインのまま固まらず復旧。バージョン不整合のチェックで、稼働中サービスが使用中の状態を保護。
  • 返信の取りこぼし防止: 再起動・再接続の経路をまたいで元のプロンプトを保持し、Telegram の応答復旧、WhatsApp の返信欠落や Signal のメッセージ飛ばしを回避。
  • 共有セッションのプライバシー強化: Side chat を閲覧者本人のみに限定し、内部モデルプロンプトを表示出力から除外。コンパクション時は引用サマリー内の認証情報を伏字化。
  • 自動化の拡張: ポーリング条件や MCP イベントへの反応、繰り返し実行できるスクリプト、明示的に許可した MCP サーバーの利用が可能に。
  • スキルのオンデマンド参照: インストール済みスキルを検索・読み出しできるようになり、全スキルをプロンプトに載せずに済むようになりました。
  • セッションの移行: 既存の Claude Code / Codex のトランスクリプトを取り込み、ローカルとクラウドの環境間を移動可能に。

🐛 その他の保守修正

  • 同一プロバイダの認証情報・モデル変更時にサーバー側コンパクションのチェックポイントを保持し、不要な履歴再生を回避。
  • macOS のシェルインストール時に制御端末を保持し、オンボーディングのプラグイン導入が切り離された Node サブプロセスで中断しないよう修正。
  • Doctor 実行時に、起動前の変更を受け入れずに Gateway 起動成功の記録のみを残すよう修正。

🐋 Orca — v1.4.263

2026-11-18 20:02 JST に v1.4.263 が公開されました。チャット起動の軽量化、Chat からの Hermes 会話再開、ブラウザ拡張のサイドパネル対応が主な柱です。

🔧 新機能・改善

  • チャット起動の軽量化: 大量のチャットを含むワークスペースでもメモリ使用量と起動時の処理を削減。復元したチャット UI は初回表示時に読み込み、起動時にすべての保存済み会話を書き換えないようになりました。開いていたチャットは下書きとスクロール位置を保持します。
  • Chat で Hermes 会話を継続: New Tab メニューから Hermes を起動できるほか、Session History の「Resume in New Chat」で、ターミナルの会話を元のワークスペースとプロファイルで継続できます。
  • 拡張機能のサイドパネル: サイドパネルを使う Chrome 拡張を Orca のブラウザ内でリサイズ可能なパネルとして表示。拡張のポップアップでも貼り付け・コピー・すべて選択が可能になりました。
  • リモート作業の強化: 管理対象 SSH ポートに Forward ボタンを追加。Windows では WSL のドライブレター経由で開いたプロジェクトを、そのディストリビューションの WSL ホストへ移動できます。
  • ターミナル出力の復元: macOS と Linux で、シェルが停止したターミナルの保存出力を新しいプロンプトの上に復元可能に（Windows は従来の挙動を維持）。
  • Linear を CLI から接続: orca linear connect が標準入力経由の API キーを受け取り、指定ホスト（ヘッドレスサーバーを含む）に接続。ホストごとに個別の接続を保持し、--limit 省略時は Issue・プロジェクト一覧が全件返るようになりました。
  • Windows でのエージェント導入: Claude / Codex のチャットで、エージェント未導入時に Install、導入後に Check again を提示。orca agent installed でホスト上の有効なエージェント CLI を一覧できます。

⚠️ 互換性・アップグレード注意

  • Hermes 要件: Chat 機能はワークスペースを実行するマシン上で Hermes 0.23.0 以降が必要です。非常に長いインポートでは直近のメッセージのみ表示されます（Hermes 側は会話全体を保持）。SSH ワークスペースでは Chat は利用できず、ペアリング済みの Orca サーバーが必要です。また Hermes のゲートウェイ停止後の最初のチャットは起動に1分ほどかかる場合があります。
  • ブラウザの識別: Native が既定になり、従来の既定で発生していた Cloudflare の検証ループに対処。明示的な設定は保持されます（設定 → Browser → Browser identity）。

☁️ AWS — AI エージェント向けメモリ機能が一般提供

対象期間内に多数のアップデートが公開されました。実務影響の大きいものを抜粋いたします。

🔧 主な発表

  • Amazon OpenSearch Memory が一般提供: Amazon OpenSearch Service の新しいサーバーレス機能で、AI エージェントに永続メモリを付与します。エージェントのやり取りを検索可能なイベントとして保存し、有用な記憶を非同期的に抽出、キーワード・セマンティック・ハイブリッド検索で横断的に文脈を取得。会話履歴全体をモデルに再投入せずに、過去の判断やユーザー設定を思い出せます。メモリストア単位の IAM 制御、actor／session スコープ、イベントと記憶の有効期限設定に対応。東京リージョンを含む5リージョンで提供。
  • AWS Lambda が GPU インスタンスに対応: Lambda Managed Instances 上で、EC2 G 系インスタンスを用いた GPU アクセラレーション付き Event Functions を実行可能に。AI 推論、メディア処理、3D レンダリング、科学技術計算、金融シミュレーションなどをサーバー管理なしで動かせます。
  • Amazon RDS for MySQL が MySQL 9.7（メジャー）に対応: MySQL コミュニティの最新 LTS リリースで、コミュニティ版 9.7.4 を搭載。Replication Applier Metrics、JSON Duality Views、Hypergraph Optimizer のサポートが追加されました。併せてマイナーバージョン 8.4.13 にも対応。
  • Amazon Cognito のポイントインタイムリカバリ: ユーザープールのユーザーデータを任意の時点へ復元可能に。従来必要だった独自のエクスポート／リストア運用が不要になり、復元後もユーザー識別子が維持されます。
  • Apache Spark Optimization Agent for AWS Glue ETL: 完了した Spark ジョブを分析し、コストまたは性能の目標を選ぶと、テレメトリの根拠とともに具体的な設定変更を数分で提示するエージェント。Glue コンソールのほか、SageMaker Unified Studio の MCP サーバー経由でも利用できます。
  • Amazon SageMaker AI のクロスリージョン推論ルーティング: リージョンのキャパシティ不足時に、他リージョン・他アカウントのエンドポイントへリクエストを振り分け。ルーティング、ヘルスチェック、リトライを自前で実装する必要がなくなります。
  • その他: CloudFront オリジン mTLS の WebSocket／gRPC 対応、CloudFront 標準ログの CMCD 対応、Lambda のカスタマー管理ランタイム、Aurora DSQL の監査ログ、S3 Replication の除外設定とマルチリージョンキー解決、EKS Hybrid Nodes の大型ホスト価格改定など。
