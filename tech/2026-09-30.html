🧠 Claude Code — v2.1.285

2026-09-30 04:37 JST 公開。CLI・プラグイン・サンドボックス・クラウドセッション・VSCode 拡張まで広範に手を入れた大型のリリースです。新機能は6点、修正は100項目を超えます。

🔧 新機能・改善

  • CLAUDE_CODE_DISABLE_WEB_FETCH: 環境変数で WebFetch ツール自体を無効化できるようになりました。
  • claude --desktop: カレントディレクトリ、または --continue / --resume <id> で指定したセッションを Claude デスクトップアプリで開けます。
  • claude plugin configure <plugin>: プラグインのオプションと未設定項目を表示し、--values-stdin で標準入力から新しい値を保存できます。
  • allowedProviders 管理設定: マシンが利用できる API プロバイダ（Anthropic API、カスタムエンドポイント、Bedrock、Mantle、Vertex AI、Foundry、AWS 上の Claude Platform、Cloud ゲートウェイ）を制限できます。
  • CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES: タイムアウトした非ストリーミング・フォールバック要求の再送上限を指定できます。
  • claude plugin install --config に <server>.<key>=<value> 形式を追加。バンドルされた .mcpb MCP サーバー設定をインストール時に指定でき、/plugin → Configure を経由せず起動します。
  • 改善: Claude in Chrome のネイティブホストがコンピュータ名を報告するようになり、接続ブラウザが「Browser 1」ではなくマシン名で識別されます。Bedrock / Vertex AI で既定モデルへのアクセスが管理者に剥奪された場合、同一ティアの旧モデルへ自動的に切り替わるようになりました。
  • 改善: 背景 Bash / PowerShell コマンドに実行時間上限（既定30分、最大2時間）が設けられ、停止時には Claude に通知されます。
  • 変更: カスタム ANTHROPIC_BASE_URL 配下のセッションでも、1M コンテキスト対応モデル（Opus 4.7+、Sonnet 5+、Fable）は 1M ウィンドウを使用します（ゲートウェイが 200K で止まる場合は /autocompact 200k）。

🐛 主な修正

  • claude -p + CLAUDE_CODE_FORK_SUBAGENT=1: サブエージェント自身の Agent 呼び出しがフォアグラウンドで動作し、子の結果を受け取れるようになりました。
  • プラグイン / マーケットプレイスの SSH 導入: GIT_SSH や git config の core.sshCommand が無視されていた問題を修正。
  • managed settings ファイル: OS が読み取りを拒否した場合に起動を拒否していた挙動を修正。警告のうえポリシーなしで起動します（その他の読み取りエラー・パース不能ファイルは従来どおり全セッションを停止）。
  • セッション途中のモデル切替: set_model（Agent SDK の setModel 等）で切替後、再起動まで出力トークン上限と自動コンパクト枠が旧モデルのままになる問題を修正。
  • サンドボックスの自動許可: python3 -c や node -e など = を含むだけのインラインスクリプトで毎回承認を求められる問題を修正。
  • MCP サーバー名の出力: claude mcp list / get や削除・ログイン・ログアウトの not-found エラーが、サーバー名や値に含まれる改行・端末エスケープシーケンスを表示していた問題を修正。
  • フックのハング: 同期フックが起動した背景プロセス（例: some-daemon &）が出力を開いたままにすると Claude Code が固まる問題を修正。
  • API リトライ: ストリーミング失敗時に最大21回再試行されることがあった問題を修正。非ストリーミング・フォールバックが要求本体のリトライ予算を共有するようになりました。
  • VSCode 拡張: スラッシュコマンド入力後の Enter がファジーマッチで無関係なメニュー項目を実行する問題、拡張再起動後にタブが空白のままになる問題、エディタが自動保存に応答しないとファイル Read/Write/Edit が10分間停止する問題など、20件超を修正。
