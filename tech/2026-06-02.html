🐙 OpenClaw — 2026.6.1 Pre-release

▲ Next.js — v16.2.6 / v15.5.x バックポートバグ修正リリース

📦 v16.2.6 (June 1, 2026) — バックポートバグ修正

Next.js 16.2 系のバックポートリリースで、複数のバグ修正が含まれています。

  • Hydration 修正: ページが HTTP キャッシュから提供された場合の Dev モード hydration 失敗を修正
  • ルーター修正: catch-all ルートで basePath + rewrites 使用時の router.query 破損を修正
  • キャッシュタグ: 非ASCII文字を含むキャッシュタグのエンコードを修正
  • Server Actions: ミドルウェア rewrites 使用時の Server Action 転送ループを修正
  • FormData: FormData エントリがドロップされる問題を修正（React 側の同修正と連携）
  • Turbopack: ハッシュエンコーディングを base40 → base38 に切り替え
  • standalone/adapters: プロジェクトディレクトリに "type": "module" がある場合の動作を修正

⚛️ React — Server Components: FormData エントリ消失の修正

🐛 Server Actions の FormData 不具合を修正 (June 1, 2026)

React 19.2.6 / 19.1.7 / 19.0.6 の Server Actions において、FormData エントリが欠落するリグレッションが修正されました。3バージョンすべてにバックポートされています。

  • 影響範囲: React Server Components で action 経由のフォーム送信時に FormData エントリが欠落していた
  • 修正バージョン: 19.2.6 / 19.1.7 / 19.0.6（それぞれパッチリリース）
  • 推奨アクション: React 19.x 系を使用中で Server Actions を利用している場合は、該当するパッチバージョンへの更新を推奨
