🤖 Hermes Agent — v0.21.4 (v2026.9.21)

対象期間内（2026-09-22 03:10 JST 公開）に v0.21.4（タグ v2026.9.21）がリリースされました。v0.21.3 以降にマージされた約 1,800 件の PR を、Docker イメージ・Hermes Cloud・ホスト型デプロイメントなどの下流利用者向けに安定タグとしてまとめたパッチリリースです。本ウィンドウの正式なキュレーション済みノートは v0.22.0 に持ち越されます。

🔧 新機能・改善

  • ゲートウェイのシングルトンロック: ホスト全体でゲートウェイを単一インスタンスに保つシングルトンロックとランデブーレコード、および Desktop が 2 つ目のバックエンドを起動せず稼働中のホストバックエンドへ接続する挙動が入りました。
  • CLI の構造化出力: --format stream-json による JSONL 形式の出力に対応しました。
  • スキルの常時ロード: skills.auto_load で指定したスキルを、新規セッションのプロンプトへ常に固定して読み込めます。
  • Desktop の強化: チャット／UI のフォントピッカー、ローカルエンジンのワンクリック更新、Plugins ハブからのプラグイン削除が可能になりました。コネクタ操作の一部はバックエンド所有となり、Desktop・TUI・CLI で同じセットアップカードを利用できます。
  • ゲートウェイの安全性: 未許可の DM を拒否する挙動が追加されました。
  • MCP とセッション検索の調整: MCP ディスカバリの接続上限（mcp.discovery_concurrency）、session_search の after/before 範囲指定と OR 緩和付きの再検索、hermes sessions set-journal-mode が追加されました。
  • カタログの拡充: 動画カタログに LTX 2.5 と Kling O3 が加わり、ウェブサイト上で全カタログプラグイン・作者のページ（README のコミット固定表示、追加日・更新日ソート付き）が閲覧できるようになりました。コミュニティプラグインも tailscale・ssh・shodan・terminal・rss・resetwatch・done-bell・kiwi・cognee・Octen など十数件が追加されています。
  • その他の修正: プロファイル／多重化の分離、cron、Kanban、Desktop、state.db に関する広範な修正が含まれます。
