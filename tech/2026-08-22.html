🧠 Claude Code — v2.1.239

対象期間内（8月22日 06:09 JST公開）に v2.1.239 がリリースされました。コスト見積・フルスクリーンレンダラー拡充・Python SDK移行ツールなどの新機能に加え、Bedrock/プロキシ関連や起動挙動を含む多数の不具合修正が含まれます。

🔧 新機能・改善

  • コスト見積の精度向上: /cost、ステータスライン、--max-budget-usd が、データレジデンシー対応ワークスペースの US 限定推論プレミアム（1.1×）を反映するようになりました。
  • フルスクリーンレンダラー提供拡大: Bedrock・Vertex・Foundry など従来除外されていた構成にも提供開始。新規インストールはフルスクリーンで開始します。
  • /claude-api upgrade: Python プロジェクトを anthropic 0.x から 1.x へ移行するコマンドを追加。スキルの Python リファレンスも 1.x 向けに更新され、timeout は httpx.Timeout ではなく anthropic.Timeout を使用します。
  • クラウドセッションのプラグイン同期: claude.ai から同期されたプラグインが name@synced として表示され、同名で自分でインストールしたプラグインを上書きしません。
  • Alpine/musl ビルド強化: ネイティブの画像貼り付け・クリップボード・音声キャプチャアドオンが読み込めるようになりました。
  • Windows 版のクロスセッションメッセージング: macOS/Linux と同様、マシン間で SendMessage／ListAgents を使えるようになりました。

🐛 主な修正

  • Content-Type ヘッダを除去するプロキシ背後での Bedrock ストリーミングで、非ストリーミング再実行による二重課金が発生する問題を修正しました。
  • SSO プロファイル＋awsAuthRefresh＋HTTPS プロキシ併用時に起動がハングする問題を修正（認証前チェックが HTTPS_PROXY を尊重します）。
  • 存在しないディレクトリからの起動時クラッシュを、明確なメッセージ表示に改善しました。
  • JetBrains IDE ターミナルで Claude Code プラグイン接続時に Edit/Write 呼び出しが約5秒停止する問題を修正しました。
  • WebFetch が期限切れページコンテンツをセッション中ずっと保持していた問題を修正（本来は15分で解放）。
  • フルスクリーン表示の MCP elicitation フォームが端末より高い場合に切れる問題を修正しました。

🐋 Orca — v1.4.187

対象期間内（8月21日 16:44 JST公開）に v1.4.187 がリリースされました。プライベートスキルバンドルの共有・パスキーサインイン・ワークツリー作成位置の選択・ターミナル入力の信頼性向上などが含まれます（着地 PR は通常48〜72時間後にリリース）。

🔧 新機能・改善

  • プライベートスキルバンドルの安全な共有: Orca ホスト間で共有できるようになりました。
  • パスキーサインインのアカウント選択: Web サイトがパスキーでサインインを求める際、アプリ内ブラウザで使用アカウントを選べます。
  • ワークツリー作成時位置選択: 作成時に場所を選べるようになり、後から移動する必要がなくなりました。
  • ターミナル入力の信頼性向上: IME（インプットメソッドエディタ）を使う言語で特に改善。CLI から実行場所の確認と画面の読み取りも可能になりました。
  • アーティファクトページ刷新: 全幅テーブル＋ドロワーのデザインに再設計されました。

🐛 主な修正

  • セキュリティスキャン中に一時的にロックされる Codex ファイルが原因で、サインアウトやセッション状態損失が起きにくくなりました。
  • オーケストレーションのタスクディスパッチ状態不変条件と受信者ルーティングの整合性を強化しました。
  • UI 周りではワークスペース作成・タブ検索・固定ピン表示などの諸問題を修正しました。
