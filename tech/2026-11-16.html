🤖 Hermes Agent — v0.23.1+canary.20261115T064406Z

2026-11-15 16:52 JST に canary ビルド v0.23.1+canary.20261115T064406Z が公開されました。今回の canary はプラグインカタログの拡充が中心で、多数のサードパーティ製プラグインの追加・再ピンがまとめて取り込まれております。安定版の最新は v0.23.1（2026-11-10 10:42 JST 公開）のままです。

🔧 新機能・改善

  • プラグインカタログの拡充: video-xray（動画解析ワークベンチ）、PrintWatch（Bambu Lab アダプタ追加）、QMD Workspaces、hermes-eye-memory、dosbox-mcp、AutoRAG（ローカル文書・アーカイブ検索）などが追加されました。
  • カタログの権限ティア: プラグインカタログに permission-tiers を導入し、プラグインの権限要求を段階付けして提示する仕組みが入りました。
  • プラグイン設定ファイル: hermes-hostd および hive.yaml によるプラグイン構成に対応。
  • Gateway: gateway tickets にプロファイル単位およびプロファイル管理用のチケットを追加。
  • 秘匿情報の扱い: 設定値のマスキング処理を config_secret_display へ集約し、表示経路ごとのばらつきを解消。

🐛 主な修正

  • OpenRouter のプロンプトインジェクション用ガードレールが返す 403 を、ファイアウォールやAPIキーの障害と誤認しないよう修正。
  • ピア（peer）から渡される制御テキストをターミナル出力前にサニタイズ。
  • コンパクション要約器への指示をシステムメッセージ、会話をユーザーメッセージとして送る構成に変更（OpenHands/software-agent-sdk からの移植）。
  • カタログ側では、作者撤回プラグイン（follow-through、eyes、card-grader）の削除や、レビュー指摘に伴う多数の SHA 再ピンを実施。

🐙 OpenClaw — v2026.11.5-beta.3

2026-11-15 09:31 JST に v2026.11.5-beta.3 が公開されました。大型セッションのメモリ負荷、再起動時のメッセージ配送、コールドスタートの復旧性に焦点を当てたベータです。

🔧 新機能・改善

  • 大型セッションの信頼性: トランスクリプトのインデックス作成・トリミング・コンパクション時のメモリ負荷を低減。ハイドレーション用ペイロードを選択的にストリームし、要約文字数の上限を設定可能にしました。
  • 再起動・配送の安全性: 再起動をまたいでキュー済みメッセージの権限上限と受理済みイングレスを保持し、ハンドオフ前に最終チャット書き込みをドレイン。最終配送の所有権を RPC 完了まで維持します。
  • 復旧とセットアップ: コールドスタート初期化、中断されたワークスペースの復旧、インストーラの権限、iMessage Automation のステータス表示を改善。
  • モデル・ツール: コンテキストサイズに応じた既定出力バジェットを復元。遅延ロードされる MCP ツールを実効ベースで公開し、入力ヒントに上限を設定。ラップされた構造化 MCP 結果の重複を排除。
  • コンパクション: 要約文字数上限を設定可能にしつつ、フォアグラウンドのリクエストバジェット制約は維持。引用された要約内容からは認証情報を伏字化。
  • ブラウザ・ワークスペース: Lightpanda のナビゲーションをサポートされる接続経路へルーティングし、サンドボックスファイルの準備完了を待機。

🐛 主な修正

  • 起動・更新系として、共有状態スキーマの一時的な競合に対するリトライ、コールドスタート時ランタイム初期化の遅延、更新リハーサル時の外部プラグインデータ保持、アイドル状態の cron ワーカーの無効化、SQLite ヘッダプローブのタイムアウト分離を実施。旧形式の exec-approval ファイルが競合しても起動を妨げないよう修正。
  • セッション・ストレージ系として、大型トランスクリプトのインデックス／トリミングの上限設定、セッションローテーションをまたぐ実行中ターンの保持、中断された子孫セッションの決着、永続化された内部 wake タイトルの修復。
  • 権限・配送系として、委譲された変更に実効権限を要求し、準備済み画像にも入力ポリシーのフックを適用。タイムアウト後も受理済みの ClawHub 試行を保持。
  • チャネル系として、iMessage の Automation 警告を送信受理まで保持、Slack の reasoning ストリームのフリーズ回避、送信者リストが空の IRC チャネル処理、履歴へのローカル最終応答の保持。cron およびシステム応答が閉じたプラグインスコープを使わないよう修正。
  • プロバイダ設定系として、Z.ai Coding Plan のカタログモデル保持、同時実行されるプロバイダカタログ取り込みの重複排除、設定書き込み時のモデルAPI課金設定の保持、キャンセルされた Claude CLI ログイン更新の復旧。
