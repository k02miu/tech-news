🔧 新機能・改善

  • セッションとメモリ: レジストリ変更をまたいだ使用量の保持、リモートワークスペースからのワーカー添付の配信、キューされたキャンセルやトランスクリプトエイリアスによるアクティブターンの停止防止、継続署名の整合、埋め込みキャッシュの分割バッチ移行（超過行のレポート付き）。
  • 返信とメディア: ローカル動画のインライン再生を復旧、拒否されたメディアリンクを有用なエラーへ置き換え、Telegram の進行状況更新からプレビューカードを除去、reasoning 有効時の音声のみ返信を修正。
  • 更新と Doctor: serving-verdict の復旧ガイダンスを改善、読み取り専用の managed config でも修復が動作、config・backup・metadata・pnpm-root の重複探索を削除、起動途中の Gateway を警告として扱うように。
  • Windows ワークスペースとブラウザ起動: 空・ネストした Windows worktree 作成を修正、Linux の Chromium 検出を改善、ARM64 で Playwright Chromium を自動起動。
  • クラウドワーカーと Crabbox: クラウドワーカー障害の実体を可視化、Linux リースを強制、ワーカーバンドルのダウンロードをブートストラップと重ねて実行。
  • プラグイン・Codex・MCP: Bun のパッケージインポートキャプチャを保持、プレリリースのメタデータ要求を削減、期限切れの remote-exec 承認が認証プロファイルを汚染しないように、node ポリシーフックを復旧、MCP のフォーム・ファイル・コンテキストを同期。
  • Changes: Claude Haiku 5.5 をサポート。Code Mode の store／load の値がセル・返信・Gateway 再起動をまたいで保持されるように。Workboard のサイドバーナビゲーションと個人ボードのピン留め、MCP Apps がビューを開いたままツールを呼び出せるように、Control UI チャットの YouTube インライン再生、シールドされたイミュータブルなインストール世代（有効化・復旧付き）、選択中のメモリプラグインが pre-compaction フラッシュを所有、プラグインごとの分離された状態と ingress キュー、エンタープライズリポジトリのクラウドワーカー対応、RPC レスポンスサイズとメインスレッドヒープの診断、既存エージェントのローカル Claws への移行、Sessions ボードのオーバーヘッド削減。

🐋 Orca — v1.4.224

対象期間内に v1.4.224 が 2026-10-10 13:30 JST に公開されました。Automation ごとのモデル・effort 指定、SSH ホストの managed Orca server、ネイティブチャット（実験的）の拡充が中心の更新です。

🔧 新機能・改善

  • Automation が実行ごとにエージェントのモデルと effort を設定可能に: Automation エディタの Advanced にある Extra agent arguments（CLI では --extra-agent-args）で指定します（例: -model haiku --effort high）。Claude・Codex・Grok・CodeBuddy（モデルと effort）、Cursor（モデル）、OMP（モデル）に対応。各実行は新しいセッションで開始し、他の Automation はホスト既定のままです。あわせて Orca サーバー上の既存ワークスペースでのスケジュール実行が、Aider・Goose・Amp のように開始後にタスクを読むエージェントへ受け渡されるようになりました。
  • SSH ホストが managed Orca server を実行: Orca が独自ランタイムを同梱し接続時にセットアップするため、ホスト側の Node バージョンやビルドツール不足による接続失敗がなくなります。ターミナルが開いていないホストは次回接続で有効化され、プロジェクト・フォルダ・開いているエディタタブも引き継がれます。Settings → Managed servers で確認・更新・ロールバック・Recover・Forget が可能です。
  • ネイティブチャット（実験的）: Chat UI を既定にしている場合、対応エージェントは構造化チャットで開きます。ターミナルを既定にしていた場合は新しいエージェントタブはターミナルのまま残り、一度だけ表示されるヒントからチャットモードを有効化できます。タブの右クリックメニューや Agent Session History（Resume in New CLI / Resume in New Native Chat）でチャットとターミナルを行き来できます。
  • ネイティブチャットの拡充: OpenCode（2.x を含む）・Pi・OMP が構造化チャットで開くように。エージェントが返信内にチャート・図・モックアップを描画（Settings → Chat → Inline visuals で無効化可能）、Cmd/Ctrl+F でチャット内検索、Add to chat で返信の一部を引用、上下キーで送信済みプロンプトを呼び出し、数字キーでエージェントの質問に回答、長文や連続するツール呼び出しは1行に折りたたみ。モデルピッカーがエージェントの起動を待たなくなり、Grok はサブエージェントを表示、Grok・OpenCode・OMP は /compact に対応しました。
  • SSH とリモートターミナル: ネットワーク障害中に入力したキーが正確に1回・順序どおりに届くように、スクロールバックとペインサイズが再接続後も保持されるように、managed server 更新後も開いているタブが再接続されるように。シェル起動ファイルがテキストを出力する環境、数万エントリのフォルダ、64-bit ARM Linux サーバーでの切断・不具合も修正。
  • その他: ステータスバーの使用量メーターは既定でコンパクト表示（Detailed も選択可）、Stage All は一覧が1,000件で打ち切られていても全変更をステージ、gh ランチャーがハングしても GitHub CLI を検出。

⚠️ 既知の問題

  • SSH ホスト上の orca コマンドは、既定ではそのホスト自身のターミナルとオーケストレーション経由のメッセージにしか到達しません。ホスト側のエージェントから worktree 作成やターミナル起動を行わせるには、Settings → SSH Hosts → Advanced Connection の「Allow this host's orca CLI to control Orca」を有効にする必要があります。
  • v1.4.223 へダウングレードする場合、v1.4.224 で開始したターミナルには到達できません（再度アップデートするまで）。
