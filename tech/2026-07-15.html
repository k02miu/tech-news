🆕 v2.1.210（最新）

  • 経過時間ライブカウンター: 折りたたまれたツールサマリー行に、実行時間のライブカウンターが表示されるように。長時間のツール呼び出しが「固まっている」ように見えなくなります
  • パーミッションルール警告: Write(path) / NotebookEdit(path) / Glob(path) の代わりに Edit(path) / Read(path) を使うよう起動時に警告
  • Worktree 隔離の修正: isolation: 'worktree' のサブエージェントが、本来隔離された worktree ではなくメインリポジトリに対して git 変更操作を実行できてしまう問題を修正
  • ultracode キーワード誤検出の修正: Webhook ペイロードや PR コメントなど、人間以外の入力に対して ultracode キーワードが誤って発火する問題を修正
  • claude attach の信頼性向上: 「job not found」「agent is still starting」エラーを解消し、デーモンが安定するまで待機するように
  • フックコールバックのタイムアウト修正: タイムアウトが「ユーザー拒否」と誤ってモデルに報告され、非対話セッションが停止してしまう問題を修正
  • プラグイン MCP サーバーの生存性: MCP サーバー再同期時にプラグイン提供の MCP サーバーが破棄される問題を修正
  • データ可視化スキルの色検証改善: OKLab 色差と色覚多様性閾値の再調整により、バンドルされた dataviz スキルのチャート色検証を改善
  • 間接プロンプトインジェクション対策: サブエージェントが読み取った内容を介した間接プロンプトインジェクションに対して Agent ツールを強化
  • その他多数の修正（crash telemetry、ペーストマーカーリーク、bigint レンダラー、cd バックグラウンド化の誤認識、Grep ページネーション、プラグインキャッシュ、git worktree ロック放置など）

🆕 v2.1.209

  • 背景セッションでのダイアログブロック修正: claude agents の背景セッションで /model などのダイアログがブロックされる問題を修正（過度に広範だったガードを差し戻し）

🆕 v2.1.208（メジャーアップデート）

  • スクリーンリーダーモード: claude --ax-screen-reader / CLAUDE_AX_SCREEN_READER=1 でプレーンテキスト表示に切替可能。画面読上げユーザー向け
  • vimInsertModeRemaps 設定: Vim モードで jj などの2キーインサートモードシーケンスを Escape にマッピング可能に
  • CLAUDE_CODE_PROCESS_WRAPPER: 企業ランチャー経由での自己スポーンを強制する設定。エンタープライズ環境向け
  • 自動モード改善: Bedrock / Vertex / Foundry の外部セッションで権限分類器が Sonnet 5 をデフォルト化
  • 多数のメモリリーク・安定性修正: 長時間セッションでのメモリ使用量削減（MCP stderr 64MB キャップ、LSP 50ドキュメント LRU、非同期フック出力保持の修正など）、編集履歴のトランスクリプトサイズ最大79倍削減
  • パフォーマンス改善: 高ツール数環境でのツールラウンド最大7倍高速化、権限ルールキャッシュによる複数ルールセッションの高速化
  • 背景エージェントの UX 改善: 停止中のエージェント添付時に即座にトランスクリプト表示、完了エージェントがクリーンアップまで一覧に残るように
  • その他50件以上の修正（HTTP/2 GOAWAY クラッシュ、ストリームJSON出力切り捨て、科学的記法の環境変数誤解析、大規模Markdownテーブルのレンダリング停止、SDKセッション損失、Bedrock認証など）
