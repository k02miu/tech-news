🧠 Claude Code — v2.1.169

Claude Code v2.1.169 がリリースされました（前号では v2.1.168 を報告）。トラブルシューティング用の --safe-mode フラグ、セッション内でワーキングディレクトリを変更できる /cd コマンド、バンドルスキル非表示設定など、3つの新機能と多数のバグ修正が含まれています。

🔧 新機能・改善

  • --safe-mode フラグ: CLAUDE.md、プラグイン、スキル、フック、MCP サーバーといったすべてのカスタマイズを無効化して Claude Code を起動できるトラブルシューティングモード（CLAUDE_CODE_SAFE_MODE 環境変数でも有効化可能）
  • /cd コマンド: プロンプトキャッシュを維持したまま、セッション中のワーキングディレクトリを変更可能に
  • disableBundledSkills 設定: バンドルスキル、ワークフロー、組み込みスラッシュコマンドをモデルから非表示にする設定と CLAUDE_CODE_DISABLE_BUNDLED_SKILLS 環境変数を追加
  • パフォーマンス改善: レスポンスストリーミング中およびスピナーアニメーション中の CPU 使用率を削減
  • /workflows 即時起動: ターン実行中でも即座にワークフロー画面を開けるように改善
  • TaskCreate 信頼性向上: 不正な入力が自動修復され、未ロードツールのバリデーションエラーにスキーマが含まれるように
  • 「CLAUDE.md is too long」警告の動的調整: 警告しきい値がモデルのコンテキストウィンドウに応じてスケールするように変更
  • Vertex/Foundry アイドルタイムアウト復活: ストールしたストリームが5分でデフォルト中断（API_FORCE_IDLE_TIMEOUT=0 で無効化可能）

🐛 主な修正

  • エンタープライズ MCP ポリシー強化: 再接続時、IDE 設定、初回インストール後の --mcp-config サーバー、リモート設定読み込み前でも allowedMcpServers/deniedMcpServers が正しく適用されるように修正
  • macOS UI ストール修正: claude.ai 認証ユーザーで各ターン開始時に発生していた30〜50ms の UI ストールを解消
  • Windows claude -p ハング修正: スラッシュコマンド/スキルスキャン待ちで遅延またはハングする問題を修正（v2.1.161 のリグレッション）
  • Remote Control 再接続修正: セッション再開時に OAuth トークンリフレッシュが同時発生すると「reconnecting」で停止する問題を修正
  • Git Credential Manager ポップアップ修正: Windows 起動時にバックグラウンド git コマンドがキャッシュされていない資格情報で実行されると GitHub 接続ポップアップが表示される問題を修正
  • セキュリティ修正: 信頼されていないプロジェクト設定が OTEL クライアント証明書パスを設定できてしまう問題を修正
  • MCPB プラグインキャッシュ修正: Windows で不要な再抽出が発生する問題を修正
  • プラグイン PID ロックファイル肥大化修正: クラッシュしたセッションのマーカーが無制限に蓄積する問題を修正（1日1回の掃除機構を追加）
