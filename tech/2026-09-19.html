🧠 Claude Code — v2.1.277 / v2.1.276

対象期間内に v2.1.277（9月19日 03:18 JST 公開）と v2.1.276（9月18日 11:20 JST 公開）の2件がリリースされました。RSS フィード（code.claude.com/docs/en/changelog/rss.xml）の pubDate を全件照合した結果です。なお v2.1.275 は 9月18日 07:42 JST 公開で、対象期間の開始（9月18日 09:00 JST）より前のため本号の対象外です。

🔧 新機能・改善（v2.1.277）

  • AGENTS.md 対応: CLAUDE.md が存在しないプロジェクトでは AGENTS.md をプロジェクト指示として読み込むようになりました。/config の「Project instructions」で切り替え可能です（Bedrock / Vertex / Foundry では未対応）
  • CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1: 外向き通信がフォワードプロキシのみの Claude apps gateway 向け。全ての送信リクエストはローカルで名前解決せず、ホスト名をそのままプロキシへ渡します
  • gateway upstream の静的ヘッダー: プロバイダ前面のプロキシへ送る固定ヘッダーを headers: マップで指定できるようになりました
  • プロンプトの無害化: プロンプト中の不可視 Unicode 書式文字・タグ文字を除去し、送信前にクリーニング済みのプロンプトを確認表示します
  • バックグラウンドタスク通知: /tasks などのパネルを開いている間にタスクが完了した場合、「更新が待機中」である旨の行を表示します
  • サブエージェント結果の明示: サブエージェントの結果は「サブエージェント出力」と分かるヘッダー付き・インデント付きでメインエージェントへ届くようになり、結果本文がセッション自身の指示として誤解されにくくなりました
  • 危険な rm の許可プロンプト改善: 該当する rm コマンド名を提示し、${VAR:?} ガードを提案するようになり、ヘッドレス実行でも復旧しやすくなりました
  • /ultrareview の改善: レビュー対象がない場合にどのケースかを明示し、最新コミットをレビューするコマンドを案内。新規リポジトリの初回コミットは全体をレビューします
  • SDK / ヘッドレス起動の高速化: SDK および claude -p の初回ターンがディレクトリ単位の CLAUDE.md 検索を待たなくなりました
  • 廃止: deprecated だった TaskOutput ツールを削除。バックグラウンドタスクの出力は Read で読む方式になり、taskOutputMaxChars 設定と TASK_MAX_OUTPUT_LENGTH は無効になりました
  • [VSCode]: パネルメニューに Sign out 行を追加（/logout）。エージェントマップにバックグラウンドシェル等の実行中タスクと Stop、/tasks を追加。応答の Copy ボタンと /copy、非アクティブセッションの自動アーカイブ通知と「Unarchive all」、プラン制限が適用されない環境でのコスト・トークン使用量表示を追加
  • [Claude Code on the web]: 環境ピッカーに Personal / Organization セクションを追加し、管理者が個人環境を組織へ共有可能に。管理者設定の「Web」ラベルを「Cloud sessions」へ変更

🐛 主な修正（v2.1.277）

  • claude -p と Agent SDK が内部エラー後に結果を返さずハングする問題を修正。エラーを報告して終了コード 1 で終了します
  • 以前の assistant ターンが空の text ブロックを保持していると、--resume 後も含め毎リクエストが「text content blocks must be non-empty」で失敗する問題を修正
  • 同一マシンで古い Claude Code ビルド（IDE 拡張の同梱 CLI など）が動作していると、予期せずログアウトされる問題を修正
  • Write ツールの対象パスが既存ディレクトリの場合、無言で権限拒否としてターンを終了していた問題を修正（明示的なエラーを返すように）
  • Edit ツールが「エスケープされたバックスラッシュ + uXXXX」を Unicode エスケープと誤認し、非 ASCII 文字の編集でエスケープ列を書き換えてしまう問題を修正
  • プロセス・メモリ・ファイルハンドル枯渇で検索を開始できない場合に、Grep / Glob が「該当なし」と誤報告する問題を修正（エラーを返すように）
  • 使用中バージョンのプラグイン再インストールでインストール済みコピーが壊れる問題、/plugin・/skills の各種クラッシュ（constructor 等の名前、壊れた claudeAiMcpEverConnected / theme 値、ターミナル配色コードを含むプロンプトでの起動時クラッシュ等）を修正
  • プロキシが不正なバージョンを返した際に更新チェックが30分ごとにエラーになる問題、および最小／最大バージョン設定時に claude update がハングする問題を修正（不正な minimumVersion は無視されるように）
  • プロンプトキャッシュ関連: resume / relaunch 後に以前の添付ファイルが再描画され extended thinking が失われる問題、/clear 後の継続で SessionStart フック出力によりプロンプトキャッシュが全損する問題、resume したサブエージェントが MCP ツール定義を再描画しキャッシュを壊す問題を修正
  • シェル関連: サンドボックス有効時にサンドボックス外で走る Bash で $TMPDIR が空展開される問題、sandbox.excludedCommands の glob が複合コマンドの一部一致だけで全体を免除してしまう問題を修正
  • [VSCode]: プラン制限が無い環境でのコスト・使用量表示、/fast が既定として保存されない問題、effort スライダーの値が後続セッションへ引き継がれない問題、Auto がモードピッカーに表示されない問題などを修正

🐛 主な修正（v2.1.276）

  • v2.1.275 のリグレッション修正: ANTHROPIC_BASE_URL がプロキシやゲートウェイを指している環境で、全リクエストが 400 … Input tag 'advisor_20260301' で失敗する問題を修正。プロキシ経由で Claude Code を使っている場合はこのバージョンへの更新が推奨されます

🐙 OpenClaw — v2026.9.5

対象期間内に v2026.9.5（9月19日 05:40 JST 公開、コミット ec9c1a1・署名検証済み）がリリースされました。リポジトリは openclaw/openclaw（nicepkg/openclaw ではない）です。なお GitHub Releases API のタグ照会は 404 を返したため、リポジトリ内の CHANGELOG/2026.9.5.md（タグ v2026.9.5）を一次ソースとして確認しました。

🔧 主な内容

  • より安全なアップグレードと履歴保持: Doctor がセッション履歴と繰り返し修復の状態を保持し、不正な残存履歴があってもアップグレードを完了。起動中の Gateway を繰り返し停止・スタールさせないよう改善（#149741, #149956, #148901, #149308, #149823, #149760）
  • ライブ プラグイン管理: Gateway を再起動せずに対応プラグインのインストール・リロードが可能に。稼働中のエージェント会話やマネージド Codex 会話のツールも更新され、1つの CLI コマンドで複数プラグインを管理できます（#145484, #145710, #145713, #145648, #145917, #149910）
  • マルチエージェントの可視性向上: 実行と結果配信を区別し、親への完了ハンドオフを非公開化。スコープ付きセッション一覧の再開と、ステアリング入力ごとに1つの回答を返す挙動を整理（#147571, #147206, #150065, #148051, #149925）
  • デスクトップ優先の Systems ワークスペース: Web ログイン経由で Gateway 接続を管理し、Primary とは独立に保存済み Gateway を切り替え可能に。iOS / Android ではサイドバー切り替えに対応（#147519, #148526, #147684, #146641, #148209）
  • 音声（Live voice）の柔軟化: 通話・会議をまたいで GPT Live を利用でき、アカウント単位の Talk 既定値を選択、通話中に音声を変更できます（#145382, #146546, #146676）
  • 引用とレビュー: Web / ネイティブチャットで引用元をプレビューし、選択したチャット本文を編集可能なコメント化。Android の Review で選択行の参照、ワードラップ切り替えに対応（#148431, #148904, #148906, #148649）
  • モデルのサインインと選択: ネイティブ サインインとランタイム選択の整合、モデルを変えずにサインイン、エージェント ハーネス横断の選択、Radius モデルのブラウザ サインイン＋ネイティブ ストリーミング接続（#143588, #144329, #147994, #145377）
  • Plugin SDK 移行（Gateway V2）: Gateway ハンドラと node-session のインポートが、物理 WebSocket・汎用フレーム・HTTP ポーリングの能力を明示する形に変更。node のワイヤ プロトコル自体は不変です
  • 主な修正: 2026.9.4 → 2026.9.5 のアップグレード時に openclaw update のサービス環境更新が失敗する問題（#151977）、送信者アイデンティティをメッセージ本文から推測していた問題、コンパクションをまたぐ文脈・所有権の保持、サブエージェントのモデル継承と fork 制限、Telegram / Discord / Slack のシャットダウン時の取りこぼし、大きなセッション詳細読み取りの応答性（#149749, #149853, #149901）などを修正
