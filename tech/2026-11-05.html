🧠 Claude Code — v2.1.318

2026-11-04 09:08 JST 公開。mod（拡張）まわりの権限記録、Claude apps gateway の AWS ロール引き受け、認証情報の有効期限表示など、企業運用と統制のための追加が中心となったリリースです。

🔧 新機能・改善

  • mod の回答記録: セッション中に Claude Code が書き込む mod の有効化を求めた際、利用者の回答内容を記録するようになりました。
  • gateway の assume_role: Claude apps gateway の mantle アップストリームで、別の AWS アカウントのロールを引き受けられるようになりました。開発者ごとの AWS コスト按分に利用できます。
  • mod の $.model.fork に effort: 短い副次作業を、セッションの effort に関係なく low で実行できます。結果には送信した effort が表示されます。
  • サインイン有効期限の可視化: claude auth status に保存済み claude.ai サインインの終了日（loginExpiresAt）を、claude -p の JSON 結果に credential_expires_at を追加しました。終了10日前から claude -p のテキスト出力に stderr の1行警告が出ます。
  • セルフホストランナー: 起動フック環境に CLAUDE_RUNNER_SPAWN_REASON を追加（runner_lost、resumed など Anthropic が要求した理由）。--release-idle-session-min の引数不備も起動時に警告します。
  • Cloud sessions: リポジトリを選ばずにクラウドセッションを開始できる「No repository」オプション、google-chrome と CHROME_PATH 経由で組み込み Chromium を参照できるようにする対応、環境削除時のカードへの「New session」ボタンを追加しました。

🔄 主な変更

  • IDE 拡張の扱い: IDE のターミナル内から起動した場合、IDE 拡張のインストール・更新を行わなくなりました。外部ターミナルから /ide を使うか、エディタの拡張機能ビューから導入します。
  • サブエージェントのモデル切替: 「メッセージにフラグが立ったらモデルを切り替える」が「毎回確認」の場合、モデルを切り替えるのではなく停止するようになりました。
  • バックグラウンドのシェルコマンド: 全プロバイダーで、3分経過したシェルコマンドをバックグラウンドへ移すようになり、実行中のプロンプトキャッシュ失効を防ぎます。
  • deniedMcpServers: URL 指定の拒否エントリが、上流 URL が一致する Anthropic 提供サーバーや、クラウドセッション・セルフホストランナー上のコネクタにも適用されるようになりました。
  • /permissions のダイアログ統一: ルール詳細・組み込みルール・削除確認が標準ダイアログを使うようになり、Ctrl+C 2回は終了ではなく戻る／キャンセルとして動作します。
  • managed-agents-onboard: 新規エージェントの組み込みツールと、クイックスタートテンプレートの MCP ツールに、既定で auto 権限ポリシー（「危険な操作を判定」）が付与されます。

🐛 主な修正

  • 2.1.288 で入れた「2.1.286 以前に開始した会話を再開した際に以前の thinking を保持する」修正を削除しました。
  • セルフホストランナーのログ行を変更（ok session=… は全ログレベルで stdout に出力し reason=… を付与、nack の末尾フィールドも reason=… に変更）。retryable=true: 等でマッチしているスクリプトは更新が必要です。
