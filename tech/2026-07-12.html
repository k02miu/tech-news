🧠 Claude Code — v2.1.207

2026年7月11日 10:01 JST、Claude Code v2.1.207 がリリースされました。Bedrock / Vertex AI / Foundry でのオートモード解禁、多数の端末・バックグラウンドセッション修正、プラグインセキュリティ強化を含む大型アップデートです。

🔧 新機能・改善

  • Bedrock / Vertex AI / Foundry でオートモードが一般利用可能に: CLAUDE_CODE_ENABLE_AUTO_MODE のオプトインなしで利用可能。無効化は disableAutoMode 設定で制御
  • Bedrock / Vertex / Claude Platform on AWS のデフォルトモデルを Claude Opus 4.8 に変更
  • エージェントビュー改善: ペースト時に同じテキストを再度貼ると既存の折りたたみプレースホルダを展開、ブロックされたセッションの覗き見で質問文と経過時間を表示
  • Deep research 改善: Fetch フェーズのエージェントが「unknown」とラベルされていた問題を修正、送信元ホスト名を表示するように

🐛 主な修正

  • 端末のフリーズ・キー入力遅延を修正: 長大なリスト・テーブル・段落・コードブロックを含むレスポンスのストリーミング中に発生していた問題
  • リモート管理設定の同意バイパスを修正: 非対話実行（claude -p、SDK）からのリモート管理設定が同意ダイアログなしで記録されていた問題
  • プロンプトインジェクションの誤検知を修正: システム生成の会話更新による誤警報
  • 自動アップデーターのランチャー上書きを修正: リリースごとに ~/.local/bin/claude のカスタムランチャーを上書きしていた問題。/doctor が外部管理ランチャーを報告するように
  • プラグインセキュリティ強化: シェル形式の hook/monitor/headersHelper における ${user_config.*} を拒否（シェルインジェクション対策）。exec 形式または環境変数経由で値を渡すように
  • プラグイン設定のスコープ変更: pluginConfigs はプロジェクトレベルの .claude/settings.json から読み込まれなくなり、ユーザー設定・--settings・管理設定のみが対象に
  • オートモード設定の読み取り元を変更: リポジトリ常駐の .claude/settings.local.json から autoMode を読み取らなくなり、~/.claude/settings.json を使用
  • エージェントチームのクラッシュループを修正: 不正なメールボックスメッセージによる毎秒エラー
  • Remote Control のタスク状態消失を修正: ネットワーク切断や認証情報更新からの回復時に発生
  • Bedrock の AWS SSO 認証情報再取得を修正: 全 API リクエストで繰り返し要求されていた問題
  • Windows での AWS 認証情報解決の無限ハングを修正: 60秒のストールガードが発動するように
  • /usage-credits の入力検証を強化: 不正な値はエラーに、$1,000 超は確認入力を要求
