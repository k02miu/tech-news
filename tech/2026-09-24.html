🧠 Claude Code — v2.1.281

対象期間内（2026-09-24 04:28 JST 公開）に v2.1.281 がリリースされました。Claude apps gateway のエンタープライズ向け機能拡充が中心で、あわせて セッション復帰・プロンプトキャッシュ・プロキシ配下のストリーム処理に関する大量の修正が含まれています。変更項目は 170 件超と、今月でも最大級のボリュームです。

🔧 新機能・改善

  • Claude apps gateway — Bedrock 上流の権限委譲に対応: Bedrock 上流に assume_role を設定できるようになり、ゲートウェイが STS 経由で IAM ロールを引き受けて Bedrock を呼び出します。別の AWS アカウントのロールも指定でき、開発者ごとに 1 セッションを割り当てる構成も可能です。あわせて guardrail: {id, version} により全リクエストへ Amazon Bedrock のガードレールを適用できます（全 Bedrock 上流に設定するか、まったく設定しないかのいずれか）。
  • Desktop 向けポリシー拡張: desktop ポリシーブロックで新しい Claude Desktop のキー（blockReadsOutsideWorkingDirectories、disableBypassPermissionsMode）に対応しました。telemetry.resource_attributes で Claude Desktop と /login セッションのテレメトリに固定ラベルを付与できます。
  • コミット／PR の帰属表示を無効化可能に: settings.json に "attribution": false を記述すると、コミットおよび PR の帰属表示をすべて非表示にできます。旧バージョンの CLI はこのキーを含む設定ファイル自体をスキップするため、複数バージョンで共有するファイルではオブジェクト形式を保つ必要があります。
  • MCP URL モードの elicitation に対応: 2026-07-28 プロトコル接続で、サーバーが Claude Code にブラウザベースのフローを開かせることができるようになりました。サーバー側に完了確認手段がない場合、待機ダイアログは画面に残りません。
  • claude plugin validate が MCP サーバーを検査: 読み込み時に黙って破棄される .mcp.json エントリ、未宣言の ${user_config.*} 参照、安全でない URL を報告します。
  • /insights に auto モードの推奨を追加: 最近のセッションで auto モードが処理できたであろう許可プロンプトの件数を見積もります。
  • UI の細かな改善: フルスクリーン時の /skills・/mcp・/plugin のインストール済み一覧にスクロールバーが付きました。タブ付きダイアログのキーボード操作、/diff のスクロールバー、狭いターミナルでの一覧行の折り返し抑制、ワークフロー行の進捗バー・経過時間・トークン表示なども改善されています。
  • 起動・復帰の高速化: git 読み取り・起動テレメトリ・Bedrock/Vertex のモデル昇格確認が最初のフレーム描画前に走らなくなり、対話起動が速くなりました。多数のファイルを読んだ長いセッション、および compact 済みの非常に長いセッションの復帰時間も短縮されています。
  • 動作変更: 「send now」（Ctrl+Enter または Ctrl+X Ctrl+S）が実行中のツールをキャンセルせずバックグラウンドへ移すようになりました。危険な rm の確認プロンプトは、auto モード／--dangerously-skip-permissions 時に 2 分待ってから書き換えヒント付きで拒否し、無人セッションが停止しないようになっています。

🐛 主な修正

  • リトライ中のクラッシュを修正: API リクエストのリトライ中にセッションが「unrecoverable interface error」で終了することがありました。また、解析不能なツール呼び出しと出力上限による切り詰めが交互に起きた場合に --max-turns を無視して無限にリトライする問題も修正されました。
  • セッション復帰の整合性を修正: 復帰時に以前のターンが別の形で再送されプロンプトキャッシュと推論が壊れる問題、巨大なセッションで直近数メッセージしか復元されない問題、許可プロンプト待ちのまま再起動した場合に履歴が変わる問題、ツール呼び出し中に終了したセッションの扱いなどが修正されました。
  • プロキシ／ゲートウェイ配下のストリーム処理を修正: ストリームが途中で切れた際に「Content block not found」で失敗する、応答が完全なものとして無警告で表示される、重複したストリームイベントでツールが 2 回実行される、stop reason が失われる、といった問題が解消されました。
  • 危険なコマンド実行の防止を強化: rm -rf "$(pwd)" のようにコマンド置換の出力のみを対象とする再帰削除が、auto モードと --dangerously-skip-permissions で無確認実行されていました。Bash の許可ルールがあっても確認するようになり、シェル変数や作業ディレクトリ由来の変数、バックスラッシュのみの対象も検出されます。
  • macOS 固有パスの事前読み取りを修正: 許可ダイアログと添付ファイル検査が、承認前に macOS の /.vol・/.nofollow・/.resolve（ネットワークマウントに到達しうる）配下のパスを読んでしまう問題が修正されました。
  • MCP 関連を多数修正: MCP サーバー切断時にプロンプトキャッシュが失われる、URL 表記の違い（ホストの大文字小文字・既定ポート・末尾スラッシュ）で同一サーバーが二重接続される、接続中の mcp_tool フックがスキップされる、といった問題が修正されました。
  • ファイル編集ツールの堅牢化: パスに NUL バイトが含まれる場合にターン全体を終了させず、そのツール呼び出しのみ明確なエラーで失敗するようになりました。
  • UI 操作の不具合を多数修正: 主要ダイアログでの Ctrl+C / Ctrl+D 2 回押しがアプリ終了になる、/permissions の削除確認でポインタが No にあるのに 1 が Yes として働く、Esc がエージェントパネルの選択解除ではなくターンを中断する、vim モードの dj/dG/cw などの挙動、などが修正されました。
  • Windows: $TMPDIR/… への書き込みが「Permission denied」で失敗する問題、同時更新時に互いの claude.exe バックアップを削除しうる競合が修正されました。

🐙 OpenClaw — 2026.9.6

対象期間内（2026-09-24 08:21 JST 公開）に 2026.9.6 がリリースされました。翌 2026.9.5 から 1 日強での続投で、管理された Gateway のアップグレード処理、再起動後の復旧、ペアリング済みノードのワークスペース対応が主要トピックです。

🔧 新機能・改善

  • 利用状況の 30 日履歴ビュー復活: 作成者別内訳・日付選択・可視リスト外のセッションを含む合計値が揃いました。
  • GitHub リーダー: 公開 Issue・PR・コミット・コメント・diff をチャットの横で開けるようになりました。明示的なプラグイン許可リストを使う構成では、プレビューを残すため github の追加が必要です。

  • モデル追加: 適応的思考と 1M コンテキストに対応した Claude Opus 5.5、および OpenAI API と組み込み ChatGPT トランスポート上に GPT-6 Sol / GPT-6 Luna が加わりました。
  • ツール探索: 組み込み実行と Copilot 実行では構造化 Tool Search が既定で有効になりました（直接スキーマを維持するには tools.toolSearch: false）。
  • その他: 設定画面からの MCP コネクタのサインイン、テーマの一覧・インポート・適用、ヘッドレスノードのランタイム自動更新、コマンドパレットからのバックグラウンドセッション開始、クラウドセッションの OS・マシンサイズ選択、Android の文字サイズ・画像ズーム・サイドバー並べ替え、デスクトップ共有の既定有効化などが含まれます。

  • ソース更新で浅い部分チェックアウトに対応し、Git 更新時のアーカイブサイズ失敗とメモリ急増を回避するようになりました。
  • MCP 接続で、長時間実行されるツールリクエストが結果を返すまで接続を維持するようになりました。
  • 更新後にワーカーが再接続した際のクラウドセッション復旧、および複数クラウドセッション時の再起動遅延を改善しました。
