🐋 Orca — v1.4.229

対象期間内に v1.4.229（2026-10-17 15:54 JST 公開）がリリースされました。ネイティブチャット（実験的機能）のレビュー体験、共有スキル、モバイル、SSH／リモートターミナル、Jira 連携が中心です。あわせてモバイル版 mobile-android-v0.0.57（2026-10-17 11:16 JST 公開、プレリリース）も公開されています。

🔧 新機能・改善

  • ネイティブチャット（実験的）: ターン単位の編集をインラインでレビューでき、図を展開してパン・ズームできます。チャットのビジュアルはクリックで共有可能になり、Claude のゴールと Codex のコンテキスト使用量も表示されます。キーボードによる回答、未読ディバイダ、Copy on Select により長い会話を扱いやすくなりました。
  • 共有スキルの対応エージェント拡大: 共有スキルのインストールが20種類のエージェントを追加でサポートし、WSL の検出範囲が広がりました。Kiro、Qoder、CodeBuddy などのツールに対して正しいインストール先が使われます。
  • モバイル（携帯アプリ）: ワークスペースのフィルター・グルーピング・ソートがデスクトップの共有設定に追従するようになりました。長押しで関連 Issue とノートを開け、サーバーワークスペースやブラウザページを扱え、対応チャットを新しいターミナル会話として継続できます。
  • SSH とリモートターミナル: 再接続時の修正により、分割ペイン、貼り付け順序、マネージドサーバーのプロジェクトグループが保持されます。スリープしていたエージェントは会話を再開し、あるマシンのプロジェクトを削除しても同一パスの別マシンのプロジェクトは影響を受けません。
  • ワークスペースと日々の使い勝手: Cmd/Ctrl+J でウェブサイトを開き、worktree の作成中にチェックアウトの進捗を確認でき、実行中のエージェントを停止する前に明示的な確認を挟んでワークスペースを整理できます。
  • Jira プランニング: Issue リストとボードを切り替え、現在のスプリントにフォーカスし、保存済みの JQL と Jira のお気に入りを再利用して、デスクトップまたは携帯からワークスペースを開始できます。エージェントは Orca CLI 経由で Jira チケットの読み取り・更新も行えます。

⚠️ 既知の問題

  • ネイティブチャット（実験的）: リモートホストに依存する機能は、そのホストが対応している場合のみ利用できます。最新機能を得るには Orca とあわせてホストも更新してください。
  • SSH ホスト上の orca コマンド: 既存ホストは保存済みの Orca CLI 制御設定を維持します。ホスト上のエージェントにワークスペース管理やデスクトップブラウザの制御を許可するには、Settings → SSH Hosts → ホスト編集 → Advanced Connection の Allow this host's orca CLI to control Orca を有効にします。
