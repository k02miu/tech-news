🧠 Claude Code — v2.1.260

Claude Code v2.1.260 がリリースされました（2026-09-04 08:55 JST 公開、対象期間内）。フルスクリーンモード用の差分パネル、プロンプトキャッシュミスの原因表示、GitLab 対応強化、多数の権限まわりの修正が含まれます。

🔧 新機能・改善

  • 差分パネル（/diff）: フルスクリーンモードで会話の横に未コミット変更を表示するパネルを追加。/diff でトグル可能
  • キャッシュミスの原因表示: /cost とステータスラインの prompt_cache フィールドに、プロンプトキャッシュミスの推定原因（ツール定義・システムプロンプトの変更、TTL 超過のアイドル等）を表示
  • ヘッドレス対応の拡充: /reload-plugins をヘッドレスセッションへ追加。デスクトップアプリ・SDK のコマンド一覧に表示されるように。また /advisor のテキスト形式（/advisor, /advisor <model>, /advisor off）をデスクトップ・Remote Control・-p/Agent SDK セッション向けに追加
  • 1M コンテキストの自動コンパクト改善: Opus / Fable セッションが 1M トークン上限直前にコンパクトされるように。大規模コンテキストでの復旧コンパクションが 10 分でタイムアウトしなくなった
  • /ultrareview 拡張: クラウドレビューの待機上限が 30 分から 45 分に延長
  • /effort 改善: Fable 5.1 でセッション途中に effort を変更してもプロンプトキャッシュが無効化されなくなった
  • パフォーマンス: 非インタラクティブ（-p / SDK）セッションのアイドル CPU 使用率を改善
  • 背景コマンドの時間制限撤廃: サブエージェントが開始した背景コマンドの 1 時間制限を削除（メインセッションと同様に終了まで実行）
  • VSCode 拡張: フッターのモデルピルに effort レベルを表示、セッション一覧に Open/Closed フィルタ追加、リトライ後の表示残骸やセッションタブの諸問題を修正

🐛 主な修正

  • セキュリティ関連: 括弧を含むパスの Edit/Write/Read 権限ルールが Bash サンドボックスに無視され「読み取り専用」フォルダが書き込み可能になる問題を修正。zsh の REPORTTIME 等の代入に隠されたコマンド置換が自動承認される問題も修正
  • 2.1.259 のリバート: Bash 引数への Read() deny ルール適用変更をリバート（npm run build 等が過剰に拒否される問題）
  • Fable 5.1 関連: /model ピッカーに Fable 5.1 が表示されない問題、ツール結果後のコンテキストがキャッシュされず毎ターン再送される問題を修正
  • 認証・設定: 企業ルート CA が OS 証明書ストアのみの場合の Bedrock 接続失敗、管理設定が読み込まれない問題、/status の重複クレデンシャル表示を修正
  • GitLab 対応: ネストしたサブグループのリポジトリ検出を修正。owner/repo#123 形式の参照が GitLab リポジトリ内で github.com にリンクされる問題を修正
  • セッション/エージェント: /rewind がバックアップ欠落時に成功と報告する問題、リワインド後のファイル読み取りトラッキング残留、バックグラウンドセッションが ListAgents に二重表示される問題、エージェントチームのトランスクリプト欠落などを修正
  • その他: 絵文字・フラグの折り返し分割、GitLab MR 参照リンク、IDE での行選択がスキル実行時に失われる問題、フルスクリーンの Ctrl+Z 動作などを修正
