🤖 Hermes Agent — v0.23.0「The Hearth Release」

2026-11-06 06:32 JST 公開。v0.22.0 以来およそ10,080コミット・約1,950 PR・666名のコントリビューターをまとめたメジャーリリースで、v0.22.1〜v0.22.7 のパッチ群も完全に取り込んでいます。テーマは「ひとつの炉端（hearth）に全サーフェスが集う」こと。Desktop ワークスペースのブラウザ提供、単一ゲートウェイによるセッション所有、ターミナル内の画像描画と会話の巻き戻しが目玉です。

🔧 新機能・改善

  • Webapp（Desktop をブラウザで）: 自前ゲートウェイから Desktop ワークスペース全体を配信します。チャット、Group Chats、プラグイン、設定がブラウザから同一に扱え、公開 URL + サインインにも対応します。既定は無効で、webapp.enabled または Settings の Web Access で有効化します。
  • 単一ゲートウェイが全セッションを所有: CLI・TUI・Desktop・エディタ（ACP）・各種ボット・cron が同じ会話に対して別々のエージェントを走らせる構造を廃止。各マシンで1つのゲートウェイが全セッションを持ち、各サーフェスはクライアントとして接続します。メッセージの二重書き込みや取りこぼしが解消され、Desktop からキュー済みプロンプトの編集・ステアも可能になりました。
  • ターミナル内の画像描画: 画像貼り付けやスクリーンショット取得時に、ファイルパスではなく実画像をチャット内に描画します。kitty・Ghostty（CLI/TUI）、iTerm2・WezTerm・Konsole（CLI）は実ピクセル、その他はカラーブロック、VS Code ターミナルは画像サポート有効時にフル解像度です。
  • 会話の巻き戻し（/rewind）: TUI・クラシック CLI で Esc 2回または /rewind により過去メッセージを選び、編集して再送信、あるいはその地点から新セッションを分岐できます。元セッションは変更されません。
  • 全マシンを1つの Desktop ウィンドウに: 複数ゲートウェイへの同時接続に対応し、ローカルと SSH／リモートの切替が即時になりました。Group Chat では異なるマシンのボットを混在させられます。
  • Group Chats の自律運用: Bot Mode のルームで、指名のないメッセージにリードボットや自動ルーターが回答者を決められます。スケジュールジョブからの投稿、ルームの目的・共有ノート、ボット同士の無限ループ抑止にも対応しました。
  • プラグインの自動更新: hermes plugins update で一括更新、CLI・チャット・Desktop・ダッシュボードに opt-in の Auto-update を追加。構成を壊す更新は適用せず保留します。カタログは約600件から1,050件超に拡大し、ベンダー製を示す Verified 層も新設されました。
  • 有料 MCP ツールの価格と上限: 3D・メディア生成などの有料 MCP ツールが呼び出し単価を宣言でき、承認プロンプトに価格と累計利用額が表示されます。上限超過時は YOLO モードでも確認を求めます。
  • 委譲の差し替え（pluggable delegation）: 既定の委譲に加え、公式 advanced-delegation プラグインでサブエージェントのタスクを特定モデルや別プロファイルへ振り分けられます。/delegation で切り替えます。
  • 省メモリ・低レイテンシ化: 定期 cron がプロンプトキャッシュを共有し、単発実行は呼び出しあたり約1,570トークン削減、LSP 有効時の patch/write_file がミリ秒応答になりました。長期稼働ゲートウェイは終了済みセッションのメモリを解放します。
  • スキル構成の整理: 組み込みスキルを58件から44件へ削減し、Word・PowerPoint・Excel を microsoft-office に統合。hermes curator lock で手調整したスキルの自動書き換えを禁止できます。
  • 実行中 cron の停止: CLI・Desktop・API・エージェント自身から実行中ジョブをキャンセルでき、停止中に取りこぼした実行の扱いをジョブ単位で設定できます。

⚠️ アップグレード注意

  • 旧ブラウザツールの削除: ブラウザ自動化は browser_exec のみになり、agent-browser と browser_* 系10ツール（browser_navigate、browser_click 等）が削除されました。プロンプトやスキル、toolset 定義で旧ツール名を使っている場合は browser_exec へ移行が必要です。
  • Desktop の要件引き上げ: Electron 44 への移行に伴い、macOS 13 以上・64bit Windows が必要になりました（macOS 11/12、32bit Windows は非対応）。
  • コマンド名変更: hermes mcp serve は hermes mcp-serve に変わりました（プラグインへ移動）。MCP クライアント側の起動コマンド更新は自動では行われません。
  • 既定モデルの変更: 未指定時のサイレント既定が GLM-5.2 から GLM-5.3 に変わりました（同価格帯・1M コンテキスト）。新モデルとして GPT-6.1 Terra、DeepSeek V4.1 Flash 1017、Gemini 4 Argon なども追加されています。

🐙 OpenClaw — v2026.11.1

2026-11-05 18:48 JST 公開の安定版です。macOS 設定保存の安全性、チャネル返信の信頼性、中断耐性、アップデート復旧の粘り強さが中心のリリースです。

🔧 主な内容

  • macOS 設定の安全性: 設定保存に失敗してもシークレットを上書きしなくなり、Tailscale 公開を無効化しても Gateway の認証が維持されるようになりました。
  • チャネル返信の信頼性: Telegram・Discord・Webhook の会話が、リクエストハンドラや直前ターンの終了後もエージェントへ到達し続けます。
  • 会話の中断耐性: 巨大なターンでも有用な履歴が保持され、最初の Claude CLI ターンを停止しても次のメッセージがゼロから始まらなくなりました。
  • アップデート復旧: クラッシュ／キャンセルされたアップデーターの停滞を解消し、検証失敗時の Windows Gateway 復旧、大規模ステート検査での全 DB コピー繰り返しを回避します。
  • サブエージェント: モデル・セッション変更をまたいでもフォローアップが保持され、カスタムセッションストア利用時も親セッションが子の承認を受け取れます。
  • プロバイダー: レート制限の待機時間をプロバイダー指定値に従うよう改善。Gemini Flash のテキストモデルは公式 API キー endpoint で既定で Interactions を使用し、カスタムプロキシは従来の既定を維持します。
  • Claude CLI 連携: 保存済みサブスクリプションアカウントで、別途ネイティブログインなしに設定済みモデルを利用可能に。ネイティブの Agent/Workflow オーケストレーションは plugins.entries.anthropic.config.managedNativeTools で opt-in（既定は無効）です。

🐛 主な修正

  • ネットワーク／ツール安全性: ClickClack と ClawHub が無関係なプライベートサービスへのリダイレクトを拒否し、Discord CDN ダウンロードがブラウザのプライベートネットワーク権限を継承しなくなりました。
  • Android の End Talk は、互換 Gateway では受理済みのエージェント処理をキャンセルせず待受のみ停止し、回答はチャットに届きます（明示的キャンセルは引き続き可能）。

  • スマホ継続性: Cmd/Ctrl+Enter 送信、ペア端末が開いたタブへの追従に対応しました。
