🔧 新機能・改善（v1.4.235）

  • Claude チャットの巻き戻し: ターンを開始したメッセージに対して「Rewind to here」を使い、プロンプトを編集して会話を別方向へ進められます。Claude は保持した履歴から続行します。
  • 会話ごとの設定保持: 各会話が固有のモデル・effort・Fast 設定を記憶します。モデルを切り替えても互換性のある選択は維持され、エージェント既定値の変更が設定記録済みのチャットを暗黙に動かすことはなくなりました。
  • エージェント出力の全文保存: 完了した返信とツール結果がプレビュー上限で切られず全文保存されます。デスクトップ・スマートフォンの「Show full output」、スマートフォンの「Show full message」で続きを読み込めます。
  • 待ち時間とバックグラウンド処理の削減: 新規チャットは即座にコンポーザーを開き、Codex チャットには起動に必要な時間が与えられます。ワークスペースジャンプパレットは事前読み込みされ、エディタはタブを開いている全ワークスペースではなく、アクティブ・直近・リスクのあるワークスペースのみを監視します。
  • モバイル体験の改善: ライブチャットは途切れた位置から再接続し、プロジェクトグループはデスクトップと同期します。スマートフォンから準備完了のクラウド音声入力モデルを選択でき、ワークスペース作成ではフォーム入力中にチェックアウトの準備が始まります。
  • 細かな磨き込み: デスクトップのキュー済みメッセージで画像編集が可能になり、プロジェクト名が衝突する場合のみマシンラベルを表示します。ワークスペース一覧・ファイル競合処理・リモートワークフローの信頼性も向上しました。

🔧 新機能・改善（v1.4.233）

  • SSH・リモートワークスペース: 双方のマシンが Node.js をダウンロードできない場合でも SSH ホストへ接続でき、Orca が記憶して再試行するワンクリックのミラーを提供します。旧来の Windows ホスト（Windows 10 1809 / Server 2019）でも Orca サーバーが動作し、古い SSH 接続がポートを占有している場合もトンネルが復旧します。
  • 設定画面の Remote Orca Servers: 6セクションに分かれていた一覧が1つに統合され、SSH ホストは一括削除して削除状態を維持できます。同一サーバーの二重保存を通知し、既存サーバーの追加は更新として扱われます。
  • エディタ: ディスク上で未確認の変更の上書き保存を拒否し、その後の Reload と Undo も予測可能に動作します。
  • その他: 異なるマシン上の同名プロジェクトは短い名前を保ちつつ所属マシンを表示します。長い保存済み会話の Session History スキャン時のメモリ使用量が大幅に削減されました。

🔧 新機能・改善（v1.4.232）

  • 自動権限（Manual / Auto / Yolo）: 設定 → Agents で選択でき、Auto は対応する Claude / Codex エージェントに承認処理を委ねます。新規ネイティブチャットもこの選択に従い、エージェントごとに別の権限モードも選べます（既存チャットは自身の設定を保持）。
  • ネイティブチャット（experimental）: OpenCode 2 をチャットで直接開けるようになり、$ 入力で Codex スキルを検索、画像プレビューのパン・ズームが可能になりました。使用量上限はリセット時刻を表示し、Continue ボタンで会話を再開できます。
  • モバイルコンポーザー: 写真に加えてファイル添付、スキルのインライン挿入、シートからのモデル・effort・権限選択が可能になりました。アプリ切り替え後の復帰とターミナルのスクロールも高速化しています。
  • アプリの軽量化と macOS 更新の高速化: デスクトップとブラウザのアセット共有、重複リソース削減、ツアーアニメーションの縮小によりフットプリントを削減。macOS 更新はバックグラウンドのインストーラ調整を回避し、より早く作業に戻れます。
