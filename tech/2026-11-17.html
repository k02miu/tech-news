🧠 Claude Code — v2.1.326

2026-11-17 07:18 JST に v2.1.326 が公開されました。エージェントチーム有効時の Code Mode 対応、権限まわりの確認動作の厳格化、サンドボックスの書き込み範囲の見直しが中心です。

🔧 新機能・改善

  • Code Mode とエージェントチームの併用: エージェントチームを有効にした状態で Code Mode をオンにできるようになり、すでにオンにしていた場合はチーム有効のセッションが Code Mode で開始されます。
  • CLI の取り違え防止: --allowedTools／--disallowedTools／--tools の値に完全なルールに見えない項目が含まれる場合、起動時に警告を表示。
  • /status の可視性向上: プロバイダや DISABLE_TELEMETRY などの環境変数によって機能が無効化されている場合、その旨を /status の行として表示。
  • MCP の管理設定: セッション中に管理者が managed-mcp.json を追加した際、MCP サーバーの読み込みが停止する理由をメッセージで説明。
  • プラグイン表示の改善: plugin.json の author や homepage など不正なフィールドが無視された場合に、/plugin と claude plugin list で注記。
  • 操作性: 起動時の非表示通知を Ctrl+O で表示、サブエージェント表示に esc to stop のヒントを追加、初回セットアップのテーマ既定を「Auto（ターミナルに合わせる）」に変更。
  • テレメトリ: OTEL_RESOURCE_INCLUDE_HOST により host.name／host.id を OpenTelemetry のリソース属性に含められるようになりました（既定はオフ）。
  • [VSCode]: プロンプト候補を無効化する claudeCode.promptSuggestions 設定を追加。

🐛 主な修正・挙動変更

  • サンドボックス化された Bash コマンドの書き込み先を縮小し、macOS・Linux・WSL で既定では一部の機密ホームフォルダへ書き込まないよう変更（sandbox.filesystem.allowWrite で許可可能）。
  • 署名関連ファイル（.credentials.json など）への書き込みをファイルツールが拒否するよう変更し、Bash 権限チェックでも同ファイルに到達するコマンドを確認するようになりました。
  • 権限フックや SDK ホストが承認時に書き換えたコマンドは、元がサンドボックス検査済みであればサンドボックス内に留まるよう変更。
  • プラグインのアンインストール時に、MCP バンドル（.mcpb／.dxt）から展開されたファイルも削除。
  • プランモードの自動コンパクションが、応答中のモデル（opusplan なら Opus）を使うよう変更。コストが増える場合があります。
  • Remote Control のプロキシ接続を CONNECT トンネル方式に変更し、--verbose 時のセッションログ出力先を ~/.claude/child-logs/ へ移動。

🐋 Orca — v1.4.261

2026-11-16 19:30 JST に v1.4.261 が公開されました。多忙なチャットワークフローの応答性改善、ブラウザタブのメモリ解放、Cursor のチャット対応、+ メニューのカスタマイズが柱です。

🔧 新機能・改善

  • チャット履歴のページ読み込み: 長い会話の履歴をページ単位で読み込み、会話切り替え時のサイドバー・非表示チャットの処理を軽量化。
  • Memory Saver: 既定で4時間表示されていないブラウザタブのページを解放し、戻った際に再読み込み。セッションCookieを使うサイトは再起動後もサインインを維持。設定 → Browser で待機時間の変更や無効化が可能。
  • Cursor をチャットで利用: 端末側で Cursor にサインインし、モデル・effort・Fast を選択、コマンド承認、会話の再開までを Orca 内で完結。
  • カスタマイズ可能な + メニュー: 新規アイコン行の歯車から並べ替え・非表示・ショートカット設定が可能。非表示にした項目も検索とショートカットから利用できます。
  • ターミナル作業の引き継ぎ精度: Copy Context／Fork／Continue がターミナルプログラムの描画する空白を保持。Edit → Paste は実際にフォーカスのある分割ペインへ貼り付け。
  • ワークスペースカード（実験的）: アクティビティ・未読・失敗・オフラインホストを一覧表示。Workspace オプションで Classic／Experimental を選択。
  • モバイル: ペアリング済みスマホ側にデスクトップのプロジェクトグループを表示。チャット／ターミナルリンクの共通設定（Ask each time を含む）、Take back all によるブラウザタブの制御返却に対応。

🐛 主な修正・注意点

  • ネイティブチャットの保存先を SQLite へ移行。既存チャットはバックグラウンドまたは初回オープン時に変換され、旧形式のチャットファイルは今回のリリースではそのまま残ります。
  • 解放されたページはその場で再読み込みされるため、スクロール位置やページ内メモリがリセットされる場合があります。未保存の編集が検出された場合は解放されません。
  • Android は新しい dev.orca.app への別途インストールへ誘導。旧アプリからの自動更新はできません。
