🐋 Orca — v1.4.240

対象期間内に1件のリリースが確認されました。v1.4.240（2026-10-25 13:02 JST 公開）です。今回の主題は「より信頼できるワークスペース」で、内蔵ブラウザへの検索可能な履歴、エージェント状態の可視性、チャットとリモート端末の復旧性の底上げが柱です。あわせて Lean / Zig のシンタックスハイライト、クイックコマンドの大量登録、開発サーバの検出ポートを一覧する新コマンド orca ports が加わりました。

🔧 新機能・改善

  • 対話が手元に残る: Orca の外で行われた Claude の会話ターンも表示され、保持されたメッセージはチャットを開き直さずに再接続後へ復帰します。クラッシュ復旧時に「送信済みメッセージが未配信」と誤判定しなくなりました。
  • 記憶力のあるブラウザ: 閲覧履歴の検索、ページの再オープン、不要なサジェストの削除、履歴クリア（Undo 付き）に対応しました。ページは File System Access を通じて選択・保存・ドロップしたローカルファイルを利用できます。
  • 中断の少ないリモート作業: 低速接続でも wake probe の取りこぼしで切断されず、再接続通知が原因を説明します。認証中に開いた端末は SSH サインインを待ち、新しい分割はペアリング済みサーバ上で開始されます。
  • 信頼できるエージェント状態: 完了した Codex サブエージェントが「Working」のまま残らず、/side の会話中も実行中のメインタスクが表示され続けます。承認が必要な Codex MCP ツールには承認カードが出ます。
  • ワークフローに余裕を: クイックコマンドを40件超保存でき、orca ports で worktree の開発サーバ検出ポートを確認、古い開発 worktree の依存インストールやビルド出力を回収できます。
  • 細部の磨き込み: Lean / Zig のハイライト、セッション検索の抜粋表示の改善、ターミナルアプリでの Mac トラックパッドスクロールの滑らかさ、Windows と WSL 間で共有される未マージブランチ・worktree の保護強化。

⚠️ 互換性・アップグレードの注意

  • ネイティブチャット（実験的）: 最新のチャット・エージェント状態・起動修正のため、ペアリング済みホストと SSH ホストも Orca と同時に更新してください。Codex の新しい承認カードはフォーム入力を要さない MCP 承認が対象で、汎用 MCP フォームや URL ベースの検証はこの変更では未対応です。
  • ブラウザ履歴: ページメニューの History、macOS は Cmd+Y、Linux / Windows は Ctrl+H から開きます。
  • 検出ポート: orca ports はワークスペース選択と JSON 出力に対応しますが、ホスト単位のポートスキャンが可能なランタイムが対象です。直接 SSH ホストは未対応で、ネイティブフォルダのワークスペースは --all が必要です。
  • 開発クリーンアップ: 手動の pnpm reclaim-space と開発起動時の自動クリーンアップが、古い兄弟 worktree の無視・未追跡の依存インストールと生成物を既定30日で回収します。選択中・実行中・除外対象の worktree は保護されます。手動実行時は兄弟アプリ・エージェント・インストール・ビルド・テストを停止し、回収後に使う場合は再インストール／再ビルドが必要です。
  • 端末のファイルリンク: 「クリックしたワークスペースでファイルリンクを開く」変更は本リリースで revert されました。

🔥 Hono — v4.13.14

v4.13.14（2026-10-25 16:19 JST 公開）が公開されました。バグ修正中心のパッチリリースです。

  • serve-static: GET / HEAD リクエストのみを提供するようになり、事前圧縮ファイルでは Accept-Encoding の q値が尊重されます。
  • JSX / CSS: cloneElement が自己閉じの void 要素を保持します。CSS ミニファイでは、引用符なし url() 内の // と、疑似クラス前の子孫結合子が保持されます。
  • ルーター / コア: trie-router が重複したパスパラメータの最初の値を保持し、hono-base は strict: false の場合に getPath を禁止します。basePath() の正規表現パラメータ照合がルーターと同じ挙動になりました。
  • アダプタ / ビルド: hono の peer レンジで Hono v5 のプレリリースを受け入れ、バンドルされた d.ts でバレルインポートが保持されます。
