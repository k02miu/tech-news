🐋 Orca — v1.4.220

2026-10-04 14:01 JST 公開。2026年10月2日のデイリービルドを基にしたパッチリリースです。実験的なネイティブチャットの「Stop」制御の信頼性向上、チャット操作やエージェント状態表示の調整、SSH ホストとワークスペース周りの改善が中心です。

🔧 新機能・改善

  • ネイティブチャット（実験的）の停止制御: 「Stop」ボタンがバックグラウンドコマンドやサブエージェントを含む Claude のプロセスを確実に終了するようになりました。Codex が停止要求を拒否した場合や無応答の場合も Orca 側でプロセスを終了します。送信しなかったメッセージは Retry まで送信されず、ステアリング済みメッセージの重複送信も防止されます。
  • チャット操作の改善: /clear で即座にチャットが切り替わり、新規チャットの最初のメッセージでエージェントが起動します。Codex の接続リトライはエラーを積み上げず1件の警告を更新する形になりました。開いているチャットへ AI ノートを送信できます。
  • エージェント状態表示: Esc によるキャンセルが Codex ペインですみやかに確定し、コピーや /side に使った Ctrl+C が割り込みとして誤表示されなくなりました。OpenCode の失敗・停止ターンも正しく表示されます。SSH 接続が遅い場合でもエージェントが消失して見えることがありません。
  • 利用量メーター: Antigravity が Gemini CLI のサインインやクォータ消費なしに自身のクォータを表示します。Cursor のサインイン確認が大規模データベースでフリーズしたり、拒否された利用量リクエストをログイン失効と誤認したりしなくなりました。
  • SSH ホスト: Node・npm・コンパイラを必要としないオプションの Orca ランタイムを利用可能になりました（既定は Auto）。標準的な Windows SSH アカウントが動作し、ターミナル再接続中に入力したキーストロークが保持されます。
  • スクリーンショットのドロップ: Mac のスクリーンショットサムネイルをローカルの Claude Code ターミナルや新規ワークスペースのコンポーザへドロップできるようになりました。
  • ターミナルとファイル: macOS の Option ショートカットがターミナルアプリに届き、バックグラウンドターミナルが元のタブに戻ります。大きな Markdown プレビューで Orca がフリーズしなくなり、レビューノートの表示とシェルファイルのハイライトも修正されました。
  • 安定性・ツール: Linux と Windows のいくつかのクラッシュループから復旧し、ウィンドウ起動失敗を再試行します。Windows の最初のブラウザコマンドがハングせず、iOS シミュレータが Xcode 27 で動作します。

🐛 主な修正・既知の問題

  • ワークスペース操作: 大規模リポジトリでの作成が高速化し、削除時にチャットやファイルが停止しなくなりました。バックグラウンドで完了したワークスペースが表示中のビューを切り替えることもなくなりました。ローカル main の更新が安全になり、サイドバーのホストタグを非表示にできます。
  • 既知の問題（Windows on ARM）: ARM64 パッケージに x64 の orca.exe が同梱されています。Windows 11 on ARM ではエミュレーションで動作しますが、Windows 10 on ARM では動作しません。
  • 既知の問題（OpenCode 2 / Codex）: 更新前に起動していた OpenCode 2 のペインは再起動するまで状態が表示されない場合があります。また Codex はアップグレード後、Orca の新しいステータスフックを承認するまで Orca 管理の Codex ホームを使用し、~/.codex を使う再開ペインが最大30秒停止することがあります。

🔥 Hono — v4.13.13

2026-10-04 12:54 JST 公開。サブアプリのマウント方法が整理されました。

  • Mount Middleware の導入: app.mount() が Mount Middleware（hono/mount）として利用可能になりました。単なるハンドラであるため app.all() で登録します（例: app.all('/itty-router/*', mount(ittyRouter.handle))）。既存の app.mount() は v4 では引き続き動作しますが非推奨となり、v5 で削除予定です。移行は1行の変更で完了します。
  • 修正: JSX の関数コンポーネントが返す JSXNode を許容するようになり、request の一部 getter の JSDoc も修正されました。
