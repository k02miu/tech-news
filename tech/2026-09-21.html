🐋 Orca — v1.4.206

対象期間内（2026-09-21 07:50 JST 公開）に v1.4.206 がリリースされました。エージェント・チャット、ワークスペースとエディタ、ターミナル、モバイルの各領域にわたる更新です。

🔧 新機能・改善

  • エージェントセッション履歴の検索: パネルから、複数コンピュータにまたがって、さらに orca search からエージェントのセッション履歴を検索できるようになりました。OpenCode 2 にも対応しています。
  • ネイティブチャットの改善: プランをプランとして扱うようになり、Orca の再起動時に実行中だったチャットを再接続します。デスクトップとモバイルの両方で OMP がモデルを選択できます。
  • Source Control AI が OMP で生成可能に: レビュー文面の生成に OMP を利用できるようになりました。
  • コンパクトなブランチピッカーが復活: コンポーザーで従来のコンパクトなブランチ選択 UI が利用できます。
  • New Workspace でベース ref を選択: 新しいワークスペース作成時に基準となるリファレンスを指定できます。
  • 差分の折りたたみ表示: ファイル差分で変更のない領域を任意に折りたためます。レビューコメントは複数行レンジの選択に対応しました。
  • worktree 操作の安全性向上: worktree の作成は Git を優先し、WSL の削除時に双子のブランチを巻き込まないようになりました。
  • ターミナルの既定シェルを選択可能に: 検索にマッチ件数表示と Cmd+F 相当の挙動を追加し、URL クリック・中クリックの動作も設定できます。Windows では指定したシェルで起動します。
  • 使用量スキャンのバックグラウンド化: Claude・Codex・OpenCode の使用量スキャンがワーカースレッド上で実行されるようになりました。
  • モバイル向け Web バンドルの配信: デスクトップがモバイル向け Web バンドルを無線配信できるようになり、タスク・ファイル・エージェント履歴がそのページシェルへ順次移行しています。戻る操作が明確になり、リレー接続が続かない場合は「host unreachable」と正直に表示します。
