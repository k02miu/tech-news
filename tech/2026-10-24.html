🔧 新機能・改善

  • [Cloud sessions] 管理設定での確認: クラウドセッションまたは Remote Control を有効にする際、確認を求めるとともに、当該権限を持つカスタムロールを列挙するようになりました。

🐋 Orca — v1.4.238

対象期間内に1件のリリースが確認されました。v1.4.238（2026-10-24 06:47 JST 公開）です。エージェント・ファイル・ブラウザ・リモートマシン間の行き来を滑らかにすることに重点が置かれています。

🔧 新機能・改善

  • 未保存の編集を共有: 同じファイルを開いたタブ間で未保存テキストがワークスペースをまたいで共有されます。コンフリクトレビューはその最新テキストを参照し、ワークスペース削除時には未保存ファイルを一覧表示します。古い Markdown やノートブックの編集が新しい作業を上書きすることもなくなりました。
  • 外部での操作に追従するチャット: Codex と Pi がチャット外で行われたターンを表示します。長い貼り付けはテキスト添付に変換でき、Codex の質問には回答カードが付き、OMP は画像送信と実行可能なプランレビューカードに対応しました。
  • エージェントの制御: ワークスペース作成時にチャットかターミナルかを選択でき、既定のエージェントにもその選択を設定できます。対応するリモートサーバ上で Claude と Codex のアカウントを追加でき、11 種類の追加エージェントに共有スキルをインストールできます。
  • ブラウザ機能の強化: ワークスペースを認識する新規タブ、アドレスバーの候補表示、サイト権限の記憶、サイトごとの外観とズーム、デスクトップとスマホでの読み込み進捗表示が追加されました。
  • スマホ体験の改善: タブでエージェントの活動を確認でき、ダブルタップで名前変更、過去のチャットメッセージのスクロールバック、ターミナルテキストの自然な選択、再開後にターミナルの閲覧位置へ復帰できるようになりました。
  • 可視性と復旧: リソースマネージャでローカルターミナルを調査でき、ホストの Orca サーバへの移行がブロックされた場合はプレーン SSH を利用でき、マネージドサーバの更新と復旧をまたいでペアリングが維持されます。
  • 日常的な改善: ブラジルポルトガル語対応、オンボーディングでの言語選択、検索可能なリリースビルド、履歴スキャンの進捗表示の明確化、そして一時停止したマージ・リベース・チェリーピックに対する Resolve with AI（ファイル競合の解消後でも利用可能）が追加されました。

⚠️ 互換性・アップグレードの注意

  • リモートアカウント: 新しい Claude / Codex の Add Account フローのため、ペアリング済みサーバを更新してください。Windows サーバや古いホストでは従来の orca account add の案内が残ります。資格情報はサーバ上に保持されます。
  • ネイティブチャット（実験的）: 最新の修正のためペアリング済みホストと SSH ホストも Orca と同時に更新してください。エージェントのバージョン検査は要件を満たす新しいリリースとプレリリースを受け入れるようになりました。
  • その他: リソースマネージャの新しい PTY ビューはローカルターミナルが対象で、終了にはホスト側のセッション検証サポートが必要です。また HTML ファイルを既定でプレビュー表示する挙動は今回のリリースでは元に戻されました。
