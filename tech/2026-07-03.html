☁️ AWS — EKS が Kubernetes バージョンロールバック機能を発表

AWS が Amazon EKS 向け Kubernetes バージョンロールバック を発表しました。本機能により、EKS クラスターのアップグレード後7日以内であれば、ワンクリックで以前の Kubernetes バージョンに戻すことが可能になります。Kubernetes のコントロールプレーンロールバックはこれまで不可能でしたが、EKS がこの制約を打破し、実質的な「元に戻す」ボタンを提供します。

🔧 主な特徴

  • 7日間のロールバックウィンドウ: アップグレード後に互換性問題を発見した場合、7日以内に以前のバージョンに復元可能
  • 1マイナーバージョン単位のロールバック: アップグレードと同じ段階的アプローチ
  • ロールバック準備チェック: Cluster Insights がノード互換性やアドオンの依存関係を自動評価し、安全にロールバック可能か事前確認
  • EKS Auto Mode 対応: コントロールプレーンと管理ノードを同時にロールバック。Pod Disruption Budget を尊重し、中断を最小化
  • キャンセルAPI: Auto Mode のノードロールバックは任意の時点でキャンセル可能
  • 追加コストなし: 標準の EKS 料金のみで利用可能
