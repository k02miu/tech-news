🧠 Claude Code — v2.1.269

対象期間内に v2.1.269（9月12日 04:25 JST 公開）がリリースされました。プラグインの eval 実行基盤、出力スタイル切替、Bash ツールの diff 表示といった開発者体験の強化と、プロンプトキャッシュ・パーミッション・日本語を含む多言語入力まわりの修正が中心です。

🔧 新機能・改善

  • claude plugin eval: プラグインの eval スイートを Claude Code に対して実行し、採点済みで再現可能な結果（JSON + HTML レポート）を取得できるように。詳細は claude plugin eval --help
  • /output-style [name]: 出力スタイルの一覧表示と切替が可能に。Remote Control 経由、およびクラウドその他のヘッドレスセッションでも利用可能
  • Bash ツールの編集 diff: Bash ツールがファイル編集を処理した場合、変更されたファイルの diff をツール結果に表示（設定 bashEditDiffEnabled）
  • OTEL_METRICS_INCLUDE_REPOSITORY: OpenTelemetry のメトリクスとイベントを vcs.* リポジトリ属性でタグ付け。OTEL_LOG_TOOL_DETAILS 併用時はコミットイベントに vcs.ref.head.* を付与
  • CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS: LLM gateway の /v1/models 検出タイムアウトを延長（既定 3 秒）
  • CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS（1〜256）: Workflow ツールの 1 実行あたり同時エージェント上限を引き上げ、推論律速のファンアウトに対応
  • プロンプトサジェスチョンの多言語改善: 日本語・中国語・韓国語テキストのフィルタリングを改善。混在スクリプトや単語 1 語の候補は保持し、メタ的・評価的な文言は英語と同様に除外
  • 日本語・中国語・タイ語などの入力修正: 単語間にスペースを置かない言語のテキストでプロンプトサジェスチョンが破棄される問題を修正
  • 長セッションの応答性: トランスクリプト更新時に会話全体を再処理して折りたたみツール要約を組み立てなくなった
  • SSH 経由のキーボード対応強化: kitty キーボードクエリに応答する端末（foot、Alacritty 0.16+ など）で Shift+Enter と Ctrl+Shift ショートカットが利用可能に
  • /diff パネル: ローディング表示を挟まず、1 ステップでレンダリング済みの状態で開くように改善。スピナーに /focus を提案するヒントを追加
  • [VSCode] エージェントマップ: 「N agents」フッターピルからサブエージェントのマップを開き、エージェントごとのカード・Stop agent・読み取り専用トランスクリプトを表示
  • [VSCode] Hooks / Permission rules ダイアログ: コマンドメニューからフックとパーミッションルールの表示・追加・編集・削除が可能に（managed・plugin・session の各ルールは読み取り専用）
  • [Claude Code on the web]: クラウドセッションで Claude が読む前にキュー内メッセージを取り戻せるように（キューから削除、または Esc / Up でメッセージボックスへ復帰）

🐛 主な修正

  • プロンプトキャッシュの部分無効化: 出力トークン上限で応答が打ち切られ自動再開した翌ターンでキャッシュが部分的に無効化される問題を修正
  • 「Prompt is too long」の恒久スタック: 自動圧縮に要約対象となる完全な過去のやり取りがない場合にセッションが永久にスタックする問題を修正（巨大プロンプトの Agent SDK セッションで多発）
  • /goal の無言停止: API エラー・ネットワーク断・トークン上限の後に黙って停止する問題を修正。バックオフ付き再試行、または理由（利用上限のリセット待ちを含む）を表示して一時停止するように
  • パーミッションルールの適用範囲: ! で始まる deny / ask ルールが、それを記述した設定ソースを越えて適用される問題を修正（自ソース内のみ適用、単独の ! 否定は無視）
  • Bash tee 経由の書き込み: Edit() deny ルールと書き込みパスチェックが tee の出力先に適用されない問題を修正。Bash(tee:*) allow ルールは作業ディレクトリ外の出力先を対象にしなくなった
  • FTS 関連の復旧: プラグインアーカイブ展開時に他ローカルユーザーから読み取り可能だった問題、展開ファイルがアーカイブの world-writable ビットを保持する問題、再展開時に古いファイルが残る問題を修正
  • 端末描画の回帰: kitty プロトコル端末で F1/F2/F4 が効かない、st で Delete が効かない、rxvt-unicode で Alt+矢印が Escape 扱い、WezTerm で Shift+句読点が非シフト文字になる問題（2.1.247 の回帰）を修正
  • リモート／ヘッドレスセッションの状態表示: バックグラウンドエージェントが動作中のまま「waiting for your input」と報告される問題を修正（CLAUDE_CODE_BG_TASKS_REPORT_RUNNING=0 で旧挙動に戻せる）
  • 圧縮後の git status: Claude に伝えられる git status がセッション開始時点のものではなく現在の状態になった
  • CMYK JPEG の添付: 「cannot decode」で添付できない問題を修正（他の JPEG と同様に変換・リサイズ）
  • プラグイン LSP の終了処理: shutdown パラメータを拒否するプラグイン LSP サーバー（rust-analyzer 等）がセッション終了時も残る問題を修正（shutdown 失敗時も exit を送信）
  • /insights: 既定の Opus モデルに到達できない Bedrock・Vertex・Foundry・gateway 環境で失敗する問題を修正（そのセッションのモデルを使用）
  • MCP 再接続: 更新された設定がサーバー URL のクエリパラメータ順のみを変更した場合に MCP サーバーが再接続する問題を修正
  • 起動時の不要文字混入: 低速接続（ssh、ブラウザ端末）で端末のカラー／バージョン応答や 22c のような文字がプロンプトに混入する問題を修正

🤖 Hermes Agent — v0.21.2（v2026.9.11）

9月12日 04:20 JST に「The state.db Patch Release」こと v0.21.2 がリリースされました。v0.21.0 のセッションストア接続処理の大規模書き換えで state.db が壊れやすくなっていた問題群を根本から塞ぐリリースです。v0.21.1 以降の4日間に 947 件の非マージコミット・312 件のマージ PR・1,869 ファイルの変更（+182,504 / −15,564）が取り込まれ、140 名の貢献者が関わっています。

🔧 ハイライト

  • state.db 信頼性キャンペーン（6 PR・44 issue クローズ）: プロファイル gateway が 5 秒ごとにルート state.db へ書き込んでいた問題、ダッシュボードが起動時に書き込み可能ハンドルを開いていた問題、cron のライフサイクルガードが生の open() でゲートウェイの POSIX ロックを打ち消していた問題（SQLite 破損の典型例）、doctor --fix が稼働中ホルダー下でチェックポイントしていた問題をすべて解消。hosted room は shared-state.db、ダッシュボードは読み取り専用オープン、ガードは tracked connection registry 経由に
  • 健全な WAL データベースの wedge 解消: OpenZFS の (deleted) ディレクトリエントリ、close() と append_message の競合で発生していた粘着性 DeletedWalGenerationError などを修正。WSL2 の一時的な disk I/O error や、ロックが解消済みなのに「state.db locked」バナーが流れる問題も修正
  • FTS 破損が会話を止めない: 全文検索インデックスに限定されたエラーがファイル全体の破損と誤分類され会話をフェイルクローズしていた問題を修正。fts_index として扱われ、検索が劣化し後でインデックス再構築、トランスクリプトは無傷。ダッシュボードの analytics ポーラーが 1 日 52 万件のトレースバックを出す代わりに 503 を返すようにも
  • 1 行の破損で全体が落ちない: TEXT のタイムスタンプや 1e30 の epoch が sessions list・export・insights をクラッシュさせる問題を修正。全リーダーに coerce_epoch() を適用（不良行はセッション名付き WARNING とともに ? 表示）、json_valid ガード、IN リストのチャンク化、export の一括ハイドレーションを追加
  • プロファイル間の DB 混線防止: HERMES_HOME 上書き競合で Desktop 起動バックエンドが別プロファイルの state.db に固定される問題、session_search が裸の ID で全プロファイルを走査し他人のトランスクリプトを返す問題などを修正
  • ロック取得の適正化: 書き込みが不要な場合に state.db を開くだけで書き込みロックを取っていた問題を修正。ビジーな gateway 配下で 4〜20 秒停止して「database is locked」で失敗していたのが 0.01 秒に
  • マルチプロファイル分離の強化: セカンダリプロファイルの bot が既定プロファイルの許可リストを継承する問題、認証情報が既定プロファイルのホストへ送られる問題、stdio MCP サーバーが既定プロファイルの vault シークレットを受け取る問題、MEDIA: 配信が他プロファイルの .env・auth.json・state.db を添付し得る問題を修正
  • Desktop のバックエンド大量起動を解消: Bot Mode が起動時とロースター更新ごとにプロファイルごとのバックエンドを起動していた問題、Bots ロースターにカーソルを合わせると行ごとに起動していた問題を修正
  • パスワードを見ない資格情報保管庫: 1Password・Bitwarden・ローカル Hermes vault から、シークレットをエージェントに一切見せずにサインイン・支払い・住所入力を実行可能に。2 要素コードも保存済み認証キーから取得、またはユーザーの UI 上で入力
  • プラグインカタログと Plugins ページ: SHA 固定のキュレーション済みプラグインインデックス（CLI・admission CI・ドキュメント・ダッシュボード）を追加。Desktop では agent プラグインと desktop プラグイン、インストール、カタログ、コミット単位の固定を 1 つのページで管理
  • Nous 無料枠とガイド付き初回起動: コマンド 1 つでサインインするだけで無料推論とコネクタが利用可能に（チャットからの /login も対応）。Gmail・Linear・Notion などのコネクタツールは tool_search から検索可能

🐛 主な修正

  • プロバイダー／ルーティング: /model と auxiliary auto が選択していないプロバイダーに課金する問題、資格情報のないプロバイダーへ自動切替する問題を修正。Bedrock の Claude/Converse/Mantle モデルが /model・フォールバック・復元を跨いで維持されるように。MCP OAuth のリフレッシュでリフレッシュトークンが消える問題も修正
  • エージェントループ／圧縮: ブロックされた定期コールバックがリース更新を止める問題、ターン途中の /steer が独立した user 行として永続化されない問題、部分ストリーミング後のコンテキストオーバーフローがターンを終了しない問題を修正。Desktop↔TUI の切り替えでシステムプロンプトが再構築されプロンプトキャッシュが壊れる問題も修正
  • プラットフォーム: config.yaml の裸の display: キーが全 gateway ターンをクラッシュさせる問題、停止した WebSocket 送信が後続イベントをすべてブロックする問題、Telegram の bot 間ループ、Matrix の LaTeX 表示、Signal の markdown テーブル、WhatsApp の view-once 引用などを修正

🐙 OpenClaw — 2026.9.4

9月11日 12:46 JST に OpenClaw 2026.9.4 がリリースされました。失敗したアップデートからの安全なロールバック、プラグイン管理の統合、クラウドセッションの準備済みワーカーが主な内容です。

🔧 ハイライト

  • 互換性のある失敗アップデートからの復旧: スキーマと設定のチェックでロールバックが安全と証明できた場合、以前のパッケージを前回の設定・サービスごと復元するように（DB マイグレーションを伴う場合は検証済みの事前バックアップが必須）
  • プラグインの一元管理: バンドル済みプラグインと ClawHub プラグインを検出し、Control UI からインストール、セットアップ・設定・アクセスを統合された Plugins ワークスペースで管理
  • 準備済みクラウドセッション: 準備済みローカルプロジェクトまたは公開 GitHub リポジトリから Linux セッションを起動し、会話開始前に Control UI で再利用可能なスナップショットを構築可能。既定の予備はプロジェクト／プロファイルあたり 1 台、Gateway 全体で最大 4 台（稼働中は課金に注意）
  • ターミナルでの質問応答: Gateway 接続セッション・ローカル TUI の両方で、キーボード駆動の選択肢、自由記述回答、複数質問プロンプトに対応（/question で保留中のプロンプトを再表示）
  • GPT Image 2.5: OpenAI / fal 経由で新しい Flare・Sunburst バリアントを画像生成・編集に選択可能（既定モデルは変更不要）
  • 会話履歴の信頼性向上: 中断されたストリームからの最終返答復旧、リロード後もタイムアウト通知を保持、ライブチャットから保存済み履歴への引き継ぎ時の重複最終回答を防止
  • 音声が委任作業を完了: 複数ラウンドの委任を経てもサブエージェントの結果を Talk に返し、最終回答を配信
  • 外部管理設定: OPENCLAW_CONFIG_READONLY=1 で、デプロイメント管理の設定を OpenClaw が書き換えないように（読み取り専用診断と通常のランタイム状態は維持）
  • スキル学習・コマンドレビュー: 過去の作業から学習を通常セッション内で開始し、検査・継続可能に。自動コマンドレビュアーが限定的な会話コンテキストで許可・拒否・エスカレーションを判断（実行ポリシーの権限は維持）
  • ロールバック以外の運用改善: Node.js ランタイム非互換時の更新提案と診断、長時間セッションの診断でライフサイクルキューの滞留原因を特定、Cloud workers のスナップショット操作（ビルド・再ビルド・検査・固定・削除・ロールバック）を Settings から実行可能に

🐛 主な修正

  • アクセス境界: セキュリティ修復時に既存の WhatsApp グループ許可リストを保持、プライベート IPv6 例外有効時もクラウドメタデータアドレスを遮断、Slack HTTP リクエストボディの上限設定、Tlon の引用取得を引用元の投稿に限定。古い署名の Feishu Webhook コールバック拒否、兄弟エージェントサンドボックスからの添付読み取り防止も実施
  • ワークスペースとバックアップ: 同時ワークスペース編集の保持、完全バックアップへの必須外部設定ファイルの同梱、スナップショット後の消滅する SQLite サイドカーの許容
  • 返信配信と履歴: 終了したストリームや以前のツールエラーからの最終返信復旧、失敗ターンの部分テキストとタイムアウト結果の保持、段落・コードブロック境界の維持、切り詰められた Responses 返信を incomplete として報告
  • プロバイダー／モデル選択: エイリアス併存時やカタログ更新時の作成済みカタログ行・モデル同一性・メタデータ・資格情報の保持。モデル上書き、コンテキスト上限、思考設定、ビジョン、圧縮、ツール一覧を選択中のモデルとプロバイダーに紐付け
  • 各チャネル: Telegram のプロキシ経由での返信保持と bot ID メンション認識、Discord のギルドメッセージからの委任復旧と再接続直後のプレゼンス表示、Slack の Enterprise ワークスペース所有権解決、Mattermost・Signal・Matrix・Teams・Feishu の各種表示不具合を修正
  • Android／モバイル: 添付選択後にキャプションを送信する前に待機、完了済みツールアクティビティの復元、接続状態とチャット準備状態の区別、折りたたみ画面でのペイン内維持、到達不能な Gateway の失敗・復旧表示
