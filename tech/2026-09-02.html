🧠 Claude Code — v2.1.257 / v2.1.258

対象期間内に2つのリリースがありました。v2.1.257（JST 9/2 03:00）は大型リリースで、新モデル追加と自動モードのセキュリティ強化が目玉です。v2.1.258（JST 9/2 07:39）は続報の修正リリースですわ。

🔧 新機能・改善

  • Claude Fable 5.1 追加（v2.1.257）: claude-fable-5-1 が新たなデフォルト Fable モデルに。1M コンテキスト、$10/$50 per Mtok、キャッシュ読み取り $0.25/Mtok。
  • 時刻フォーマット設定: timeFormat と timeZone 設定を追加。12時間/24時間/24時間UTC/strftime パターンに対応し、ターン終了時刻やトランスクリプト表示に反映。
  • 自動モードに Containment Escape ルール: クラウドメタデータ認証情報の取得、エグレス回避、クロステナント到達を、環境が「想定内」と明示しない限り自動承認しないよう変更。
  • CLAUDE_CODE_SUBAGENT_MODEL_FORCE: すべてのサブエージェントにメインモデル（または指定モデル）を強制適用できる環境変数。
  • /effort に s オプション: 現在のセッションのみ effort を変更可能に（/model と同様）。
  • 作業ディレクトリ外の読み取りで確認プロンプト: 自動モードで初回にワーキングディレクトリ外のファイルを読む前に確認を表示。ブロック設定（permissions.blockReadsOutsideWorkingDirectories）も追加。
  • ゲートウェイモデル説明の表示対応: /model ピッカーでゲートウェイ提供の description を表示可能に。
  • レンダリング性能改善: 長時間会話でのターン毎の再レンダリング削減、ストリーミングが応答の増大に伴って遅くならないよう改善、入力のキーストローク毎の処理も軽量化。
  • サブエージェントの自動継続: スリープ・接続切断・サーバーエラーで応答が途切れても、完了ではなく自動的に続行するように。

🐛 主な修正

  • macOS 12 (Monterey) で起動に失敗する 2.1.255 由来のリグレッションを修正（v2.1.258）。
  • リモート・スケジュールセッションで「user messages must have non-empty content」エラーが出る問題を修正（v2.1.258）。
  • シンボリックリンク経由でプラグインが自身のディレクトリ外のファイルを読めるセキュリティ問題を修正（拒否してエラー表示）。
  • 複合コマンド・サブシェル内で permissions.ask ルールがスキップされ確認なしで実行される問題を修正。
  • Bedrock / Bedrock Mantle の長時間 thinking 中にリクエストが無音になりアイドルタイムアウトで切断される問題を修正。
  • 大量画像を含む長時間セッションで毎ターンプロンプトキャッシュミスが起きる問題を修正。
  • スクリーンショット多用セッションのトークンカウンター凍結、claude --bg の削除済みディレクトリでの挙動、バックグラウンドセッションの各種不具合など多数修正。
