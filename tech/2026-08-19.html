🧠 Claude Code — v2.1.235

対象期間内（8月19日 07:28 JST公開）にv2.1.235がリリースされました。プロンプト入力のスペルチェック機能をはじめ、ターミナルUI・権限ダイアログ・クラウドセッションの改善と、多数の不具合修正が含まれます。

🔧 新機能・改善

  • スペルチェック設定: オプションのspellcheck設定を追加。インストール済みのaspell／hunspell／ispellを使用し、プロンプト入力中のスペルミス単語に下線を表示します。
  • クラウドセッションのリソース改善: /ultrareviewや/autofix-prなどのクラウドセッションがバックグラウンドで動作中、イベントストリームの再スキャン・再レンダリングを廃止し、メモリ・CPU使用量を改善しました。
  • 権限ダイアログの整合性向上: 表示テキストと「次回から確認しない」オプションが許可内容と常に一致するようにし、内容を完全表示できない場合は「次回から確認しない」を出し分けません。
  • 組み込みgrepの強化: ネイティブmacOS/Linuxビルドで、病的なパターンはメモリを枯渇させずに即時失敗し、-m Nと-A/-C併用時のコンテキスト出力も正確になりました。
  • Vimモード: 詳細トランスクリプト（ctrl+o）の切り替えやパネルクローズ時に、NORMALモードとカーソル位置を維持するようになりました。
  • Remote Control: claude rcがインタラクティブ起動と同じエンタープライズゲートウェイ可用性チェックを適用するようになりました。

🐛 主な修正

  • 言語サーバがセッション途中で切断・再接続した際にwhole-prompt-cacheが無効化される問題を修正しました。
  • ネストしたMarkdownリスト項目（深さ3以上）の位置ずれを修正し、折返しリスト項目にぶら下げインデントを追加しました。
  • 複数行プロンプトでスラッシュコマンド・キーワード・メンションのハイライトが1文字以上ずれて表示される問題を修正しました。
  • 権限プロンプトのコメント欄でShift+Tabを押すと、欄を閉じる代わりに編集を承認しセッション全体の編集権限を与えてしまう問題を修正しました。
  • 利用できないエージェントのセッションでAgentツールが汎用デフォルトを宣伝する問題を修正し、subagent_type省略時に利用可能なエージェント一覧付きの明確なエラーを出すようにしました。
  • ノートブックのセル削除・置換の承認ダイアログで、ノートブック／セルを読み取れない場合に既存セル内容が黙って省略される問題を修正しました（理由を表示）。
  • SendMessageがクロスセッション配信に大きすぎるメッセージを黙って破棄するのではなく、事前に拒否するようになりました。
  • VSCodeで複数のClaudeパネルがあるウィンドウを復元・リロードした際に、フォーカスが勝手にタブ間で移動する問題を修正しました。

🤖 Hermes Agent — v0.20.4 (v2026.8.18)

対象期間内（8月18日 16:26 JST公開）にパッチリリースv0.20.4（v2026.8.18）がリリースされました。v0.20.3以降にマージされた約74件のPR・約146コミット（+21,697 / −2,217、265ファイル）を安定タグ付きリリースに取り込んだロールアップで、Dockerイメージ・ホステッドデプロイ・新規インストール向けです。キュレーション済みの詳細リリースノートはv0.21.0で公開予定です。

🔧 主な改善点

  • デスクトップUI: ガラス／半透明サーフェス対応（matte glass、frost picker、macOSプリセレクト）を追加しました。
  • SESSIONS|BOTSサイドバー: タブ式サイドバーを追加し、ボットごとの表示／非表示切替に対応しました。
  • Bot Modeグループチャット修正: 長時間実行メンバーターン、Markdownレンダリング、クロスマシンルーティングの問題を修正しました。
  • NVIDIA SkillEvaluator Tier 1: スキルインストール時にライセンス＋セキュリティのアドバイザリスキャンを実行する機能を追加しました。
  • cronメディア送信の強化: 設定可能なタイムアウト、手動実行時の添付対応、missed-fireの表示を追加しました。
  • その他: SessionDBのイベントループスレッド・競合修正、hermes updateのparked-branch問題修正、kanbanのネイティブOS通知を追加しました。
