🧠 Claude Code — v2.1.234

対象期間内（8月18日 06:06 JST公開）にv2.1.234がリリースされました。新環境変数・キーバインドアクション・GitLab統合強化に加え、NT名前空間パスを利用したNTLM資格情報漏えい経路のさらなる緩和を含むセキュリティ修正と、多数の不具合修正が含まれます。

🔧 新機能・改善

  • CLAUDE_CODE_PROJECT_DIR_NAME: セッションごとに専用設定ディレクトリを持つホスト向けに、プロジェクト別トランスクリプトディレクトリの短い名前を指定できる環境変数を追加しました。
  • selection:clear: アプリ内のテキスト選択をクリアするキーバインドアクションを追加（エージェントビューでも動作）。
  • GitLab MRバッジ: GitLabリモートかつglab CLI認証済みのリポジトリで、フッター／ステータスラインにMR !N（draft/pending/green状態）を表示するようになりました。
  • 利用制限リセット時の自動継続: claude.aiの利用制限がリセットされるとセッションを自動的に継続するように（/configで無効化可能）。
  • コンテキストコスト削減: 組み込みclaude-apiスキルのコンテキストコストを約200kトークンから約25kトークンへ削減（リファレンスドキュメントのオンデマンド読込化）。
  • 作業中の対話操作: /permissionsと/add-dirがClaude作業中でも利用可能になり、フルスクリーンTUIでは複数ダイアログがターン途中で開けるようになりました。
  • /goalのチェックイン: バックグラウンドタスクが30分以上ゴールを待たせる場合にClaudeが確認を行うように（CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0で無効化可）。
  • セキュリティ: リモートファイル読み取り・セッション復元・CLAUDE.mdインクルード・ワークフロースクリプト・ファイルアップロードでWindows NT名前空間（\\??\）パスを拒否し、NTLM資格情報漏えいベクトルをさらに緩和しました。

🐛 主な修正

  • 長時間セッションでコンパクション後にサンドボックス化コマンドのネットワークアクセスが再チェック・拒否され続けるauto modeの問題を修正しました。
  • セッションスコープの許可回答（拒否を含む）がバックグラウンドサブエージェントのツール許可プロンプト対応時に失われる問題を修正しました。
  • 非ストリーミングフォールバック経路（サードパーティゲートウェイ経由など）でthinking/textブロック欠落時にクラッシュする問題を修正しました。
  • 特殊なUnicodeシーケンスを含むメッセージでMarkdownレンダリングが極端に遅くなる問題を修正しました。
  • セッション名が200文字上限または絵文字多数の際にSendMessageがListAgentsからコピーした受信者を拒否する問題を修正しました。
  • MCP診断で解決済みシークレットが出力される問題を修正（${VAR}形式で表示、接続失敗時はサーバー発信元のみ表示）。
  • フルスクリーンでの/login OAuth URLコピー時の文字欠落、---水平線のレンダリング崩れ、連続シェルコマンドの分割表示問題などを修正しました。
  • Remote Control: Desktop/VS Codeホストのセッションでユーザーに送るファイルがアップロードされない問題、別アカウントへのサインイン時に数時間後に誤解を招くHTTP 404を返す問題を修正しました。

🐋 Orca — v1.4.184

対象期間内（8月17日 09:14 JST公開）に安定版v1.4.184がリリースされました。前日公開のリリース候補v1.4.184-rc.0の内容を安定版として取り込んだもので、UI／ワークスペース、WSL経路の安定化、ターミナル・デーモンの回復性、ブラウザのCookie周りの修正、パフォーマンス改善を中心としています。

🔧 新機能・改善

  • オートメーションページ: フィルタとソート機能を追加しました。
  • ワークスペース: ボードショートカットをトグル化し、貼り付けたLinear Issue URLの認識に対応しました。
  • リモート環境: ダッシュボードでSSH／リモートホストを識別できるようにしました。
  • パフォーマンス: Git-adminフィンガープリントによる30秒ごとの全リポジトリ再スキャン停止、エージェントステータスバーストの1回化、スキル探索スキャンの上限・共有化を実施しました。

🐛 主な修正

  • WSLのトランスクリプトfs操作をタイムアウト・容量制限付きでゲートし（STA-4049）、Windowsの新規プロファイル起動を修正しました。
  • SSH再接続によるターミナル多重化とエージェントの二重再開を修正しました（STA-3077）。
  • デーモンがセッションを報告できない際に稼働中のコーディングエージェントを強制終了する問題、リタイアしたデーモンの接続判定（トークン読み取りではなく接続で証明）を修正しました。
  • ブラウザのGoogle Cookie分割保持（インポート時）と、失敗したインポートクリア後のCookie復活防止（STA-4061）、部分インポート後のフェイルクローズなCookieクリア（STA-4090）を修正しました。
  • git shimを削除し、検出されたエージェント許可リストなしの場合はフェイルクローズするようエージェントフックを修正しました。
  • POSIXでの読み取り専用ファイルのfsync、Fishレディネスエスケープバイトの保持、モバイルのフォルダワークスペース・エミュレータ接続などを修正しました。
