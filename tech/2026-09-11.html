🧠 Claude Code — v2.1.268

対象期間内に v2.1.268（9月11日 05:44 JST）がリリースされました。Claude apps gateway まわりの機能追加と、サードパーティエンドポイントでの HTTP 400 回帰修正、パーミッション周りのセキュリティ修正など大規模な修正波が含まれます。

🔧 新機能・改善

  • Claude apps gateway の料金連携: gateway.yaml に pricing: を設定すると、サインイン済みの Claude Code クライアントが managed settings 経由で同じレートを受け取り、/cost とテレメトリが支出メーターと一致するように
  • gateway 向け警告の追加: access_control.allow_cidrs が空の場合の起動時警告、およびパブリックアドレスからリクエストが到達した際の1回限りの警告
  • gatewayInternalNetworks managed setting: 管理者が組織自身のパブリック IPv4 ブロック上の Claude apps gateway への /login を許可可能に
  • self-hosted runner のセッション状態削除: claude self-hosted-runner --remove-session-state（デフォルト off）でセッション終了時に <base-dir>/_sessions/ 配下のセッションごとのディレクトリを削除
  • JSON 出力の拡充: claude auth status --json に configDirectory を追加。plugin install/uninstall/update/enable/disable に --json を追加し、claude plugin list --json の各行に errorDetails/noteDetails を追加
  • パブリッシュ済みアーティファクトのタブアイコン: ページに合わせて Claude が選んだブラウザタブアイコンを追加
  • フルスクリーンモードの高速化: プロンプト行の追加/削除（Shift+Enter）が1文字のタイピング並みの速度で再描画されるように
  • --continue / --resume の即時表示: SessionStart hooks を待たずに会話が即座に表示され、最初のメッセージでトランスクリプト全体を再読込しない
  • auto mode の拒否メッセージ改善: Claude が受け取るメッセージがブロックしたルールを明示し、より安全な方法と無関係な作業の継続を促すように
  • /plugin の即時反映: プラグインのインストール・有効化・無効化がメニューを閉じた時点で反映され、/reload-plugins が不要に
  • Bedrock / Vertex / Foundry の整合性: 環境・モデル・設定情報をアタッチメントとして配信し、ツールリストを会話全体でバイト安定化（ファーストパーティセッションと一致）

🐛 主な修正

  • HTTP 400 回帰修正: 2.1.265 以降、サードパーティの Anthropic 互換エンドポイント（ANTHROPIC_BASE_URL）で Artifact ツール入力スキーマの正規表現が拒否され毎ターン HTTP 400 で失敗する問題を修正
  • WebFetch の無限ハング修正: レスポンスを開いたまま終了しないサーバーで永久に待ち続ける問題。300秒で失敗するように（CLAUDE_CODE_WEBFETCH_DEADLINE_MS で上書き可能、0 で無効化）
  • 永続的な高 CPU 使用率の修正: 長時間アイドルセッションのビジーループが CPU コアを占有する問題、セッション recap 中のターミナルフォーカス連打で CPU が高止まりする問題を解消
  • セキュリティ: シンボリックリンク経由のパーミッション回避: /etc・/tmp・/var（macOS）や /bin（Linux）等の symlink ディレクトリに対する deny/ask ルールが実体パスで指定された場合に適用されない問題、Bash コマンドが symlink パス表記の deny ルールを無視する問題を修正
  • セキュリティ: 解析不能コマンドでの deny ルール回避: 同一行に env -C・eval 等のパーミッションチェッカーが解析できないコマンドがあると Read/Edit deny ルールが適用されない問題を修正
  • シークレット漏えい修正: プラグイン・マーケットプレースのエラーが git ソース URL からトークンやパスワードを表示する問題、/mcp・/plugin サーバー詳細や claude mcp list/get、MCP ログインエラーが ${VAR} プレースホルダーから解決したシークレットを表示する問題を修正
  • 再スポーンされた in-process チーメイト: 信頼していないフォルダ内の同名エージェントファイルからツールやシステムプロンプトを引き継ぐ問題を修正
  • MCP ツール呼び出し後: 「your message came through empty」と返答することがある問題を修正
  • モデルアクセスの不整合: キャッシュされた古い拒否で再起動後や Desktop Code タブでモデルが制限表示される問題、別プロセスがモデルアクセスを更新すると実行中セッションが黙って組織既定モデルへ切替わる問題を修正
  • /compact の文字化け: /compact・auto-compact の会話サマリーが $ を含むテキストを壊す問題を修正
  • ワークロードアイデンティティフェデレーション: claude-code-action 構成でプロセス共有時に 401 … jti reused で実行途中に失敗する問題を修正
  • MCP OAuth: ローカルコールバックポート範囲をバインドできないと「No available ports for OAuth redirect」で失敗する問題を修正
  • 権限モデルの変更: タスクトラッキングツール（TaskCreate/Get/Update/List、TodoWrite）の提供対象を Claude 3.x、Opus 4.0–4.7、Sonnet 4.0–4.6、Haiku 4.5 に限定（他は CLAUDE_CODE_ENABLE_TODO_TOOLS=1 で有効化）
  • アーティファクト権限の厳格化: 承認スキップ設定のローカル Cowork セッションで、セッションフォルダ外や symlink の背後にあるローカルファイルの読み取りを拒否するように
  • Slack / Chrome / VSCode: managed settings の MCP allowlist で Slack セッションの Slack ツールが失われる問題、Chrome でナビゲーション URL のホスト解析不能時に "https" ホストの許可を求める問題、VSCode で CLAUDE_CONFIG_DIR 設定時にセッションリスト等が壊れる問題を修正
