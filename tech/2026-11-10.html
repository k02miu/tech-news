🧠 Claude Code — v2.1.321

v2.1.321（2026-11-10 05:24 JST 公開）は、新しい既定モデル Claude Fable 5.2 の投入が最大の話題です。あわせて remote-control の設定ファイル適用、パーミッション／サンドボックス周りの細かな挙動調整、Gateway とマーケットプレイスの管理強化が含まれています。

🔧 新機能・改善

  • Claude Fable 5.2 が既定の Fable モデルに: モデル ID は claude-fable-5-2。コンテキストは 100 万トークン、料金は入力 $8／出力 $40 per Mtok、キャッシュ読み取りは $0.20 per Mtok です。
  • claude remote-control の --settings <file>: 起動するすべてのセッションに設定ファイルを適用できます。ファイルが変更された場合は、claude remote-control を再起動するまで新しいセッションは開始されません。
  • [VSCode] 認証情報の二重設定を警告: 認証トークンと API キーが同時に設定されているとき、プロンプトボックスの上に警告を表示します（ターミナル側の起動時警告と同内容）。

♻️ 主な変更

  • Fable 5.1 の選択が fable へ移行: 保存済みのモデル選択が新しい既定へ移ります（Pro／Max は即時、Team／Enterprise は組織が許可した時点）。/model claude-fable-5-1 で戻せます。
  • パーミッションとモッド: Claude が書き込むモッドは auto／bypass モードで確認なしに有効化され、dontAsk モードでは読み込まれません。モッド自身のツール呼び出し（$.tool.call / $.mcp.call）は許可プロンプトを出さず、deny ルールと組織ポリシーは引き続き適用されます。
  • スキル読み込みの範囲: ~/.claude/plugins 配下の .claude/skills は、そこで作業しているときには読み込まれなくなりました。
  • Remote Control のフォルダ固定: セッションは開始時のフォルダを保持し、接続クライアントから別フォルダへ移動できなくなりました。
  • Gateway の上流設定: Bedrock／Vertex／Foundry の上流は Gateway 環境の ANTHROPIC_*_BASE_URL を無視するようになり、別エンドポイントを使う場合は上流の base_url を設定します。policy_mode: layered では管理対象 MCP サーバーが該当ポリシーすべてで加算されます。
  • マーケットプレイス管理: extraKnownMarketplaces で宣言した名前は別ソースから追加できず、他所からのエントリは非表示になります。宣言元のマーケットプレイスが列挙するプラグインはそこから再インストールされます。
  • コンテキスト節約: 1,000 文字を超えるバックグラウンドコマンド通知と TaskStop の結果は、開始部と終了部のみが Claude に渡されます。
  • その他: /fast・/config・/model の表示が現在のモデル名を使う形に統一、cp／mv をパス付き（/bin/cp 等）で書いた場合も同じパス検査を適用、Windows の実行ファイル探索で相対パス・UNC パスを除外、ヘッドレスセッションは .claude/skills のモッド変更を再読み込み（CLAUDE_CODE_PLUGIN_DIR_WATCH=0 で無効化）など。

🐋 Orca — v1.4.255

v1.4.255（2026-11-09 21:24 JST 公開）は、セッション履歴の検索をワーカースレッドへ移して大規模履歴でも UI を止めないようにした性能改善と、スマホ側で全デスクトップのエージェントを一覧できる「Agents タブ」が中心です。前日公開の v1.4.254（Git Graph、チャットのフォーク、オンデバイス音声入力）に続く短い間隔でのリリースとなります。

🔧 新機能・改善

  • セッション履歴の検索が高速化: 検索処理がアプリのメインスレッドから外れ、入力中も結果が消えません。再起動直後は最後の一覧を即座に表示したまま再スキャンし、SSH・リモートサーバー上のホストでも検索できます。
  • Agents タブ（スマホ）: 接続中の各デスクトップのエージェントを 1 か所に一覧表示し、既読・クリアが可能。アクティビティ状態はデスクトップ側から供給されます。
  • チャット切り替えの改善: Codex アカウントを切り替えると開いている Codex チャットも選択先へ移動。フォークは履歴を保持し、リッチテキスト貼り付けでリンクが残り、再起動後もキュー済みメッセージが再開します。
  • 設定 UI の整理: エージェント速度は 1 ボタンに統一、モデル設定は現在の選択がハイライトされた状態で開き、「codex」検索時は他エージェントの Codex 名モデルより Codex エージェント自体が優先されます（Enter 押下時も同様）。
  • Git Graph の操作拡張: チェックアウト・チェリーピック・リバートを Git Graph から実行可能。チャット入力欄下のブランチ名からブランチピッカーを直接開けます。
  • その他の改善: 親ワークスペース削除時に子ワークスペースを保持するオプション、空フォルダのワークスペースからリポジトリごとに worktree を作成、リポジトリ名が既存と衝突する場合は別フォルダへ clone、リモートブラウザタブの favicon 表示、PDF プレビューの幅フィット、ターミナルペインのサイズを他ウィンドウが保持している場合の説明と取り消し操作など。

🐛 主な修正

  • 日本語 IME を半角／全角キーでオフにした直後、最初の Enter が飲み込まれる問題を修正。
  • GitHub のレート制限キャッシュ失効後、PR ページと GitHub リクエストが無期限にハングする問題を修正。
  • チャット再マウント後にキュー済み送信が二重送信されるモバイルの問題、/clear 送信直後に旧トランスクリプトが残る問題を修正。
  • サイドバーの区切り線がワークスペース一覧をスクロールさせてしまう問題、長い設定一覧で検索可能なピッカーを使うよう修正。
