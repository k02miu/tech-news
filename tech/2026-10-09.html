🧠 Claude Code — v2.1.295 / v2.1.294

対象期間（2026-10-08 09:00 〜 2026-10-09 09:00 JST）内に、Claude Code の新バージョンが2件公開されました。大規模な機能追加を含む v2.1.295（2026-10-09 04:55 JST 公開）と、フックの挙動修正を行う v2.1.294（2026-10-08 14:14 JST 公開）です。

🔧 新機能・改善（v2.1.295）

  • フックの onFailure: "block": command / HTTP フックが起動できない・タイムアウト・想定外の終了コードで終わった場合に、アクションを通さずブロックできるようになりました。
  • Program Status Protocol（OSC 7501）対応: 対応ターミナルで、Claude Code が「作業中／入力待ち／完了」のどれかを表示できるようになりました。
  • /copy ピッカーに引用テキストを追加: 下書きメッセージを > マーカーなしでコピーできます。
  • Claude apps gateway の強化: timeouts.upstream_ttfb_ms によるストリーム開始の制限、上流ごとの models リスト（* ワイルドカード対応）、成功応答への request-id ヘッダ付与、inference 監査イベントへの upstream_request_id 追加など。
  • forceLoginMethod: "gateway" / forceLoginGatewayUrl: 管理設定のない端末のユーザー設定で指定可能になり、/login がその gateway で開きます。
  • mod 向け: $.ui.notify によるネイティブ通知、mod の Button に子要素（文字列・Text）を追加。
  • CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS: 無人リトライモードで 429 / 529 エラーの待機時間を制限できます。
  • [VSCode]: Claude が送ってきたファイル用のチャット行を追加。ファイル名クリックでエディタで開き、Focus ビューでも表示が維持されます。

🔄 主な変更（v2.1.295）

  • tool search 経由でモデルが読み込む MCP ツール説明の上限を 2,048 文字から 16,384 文字へ拡大。
  • サブエージェントが skills フィールドから先読みするスキルは最大 32 件（各1回）に。
  • claude.ai コネクタが既定で MCP プロトコル 2026-07-28 をネゴシエート（MCP_PROTOCOL_NEGOTIATION=legacy でオプトアウト）。
  • WebSocket（ws）MCP サーバーは 16 MiB 超のメッセージを解析せず接続を閉じるように（他トランスポートと同水準）。

🐛 主な修正（v2.1.294）

  • 命令文として書かれた prompt / agent フック（例: 「Block commands that...」）が、本来ブロックすべきものを通してしまう問題を修正。
  • Stop / SubagentStop の prompt フック（例: 「Carry on if the build is broken」）の判定を改善し、Claude が早期に停止しにくくなりました。

🐋 Orca — v1.4.223

対象期間内に Orca v1.4.223 が 2026-10-09 07:09 JST に公開されました。ネイティブチャット（実験的）の強化、SSH ワークスペースの復元性、リモートサーバー／スマホ連携、エージェントとターミナル、サイドバー、ファイル・検索、タスク・レビューにわたる広範な改善が含まれます。

🔧 新機能・改善

  • ネイティブチャット（実験的）: Settings → Chat UI の「Use updated structured native chat」を有効にすると、Grok が構造化チャットとして開きます（SSH / WSL はターミナルチャットのまま）。会話の巻き戻し、モデル一覧検索、@ によるワークスペースファイル選択、文字サイズ・コードサイズ・幅・コントラストの設定に対応。チャットは最初のメッセージから命名され、承認待ちで通知、未送信ドラフトはリロード／終了をまたいで保持されます。
  • SSH ワークスペース: ファイル、ライブのエージェントタブ、一時停止中の Claude / Codex の再開オファーが SSH 再接続と再起動をまたいで維持されます。
  • リモートサーバーとスマホ: ホストアプリ再起動後もペアリング済みターミナルが入力を受け付け、ネットワーク断後のリモートブラウザタブ復帰、orca serve 再起動後もスマホの全ターミナル維持に対応。
  • エージェントとターミナル: macOS / Linux での長い・複数行の起動コマンドが分割されず正しく届くように。Codex 起動ごとに ~/.codex フックを書き換える問題を解消し、Claude / Codex / OpenCode 用のヘルパープロセスは Orca 終了時に停止します。
  • アカウントとエージェント: Claude アカウント切替時に MCP サーバーのサインインを維持。モデル一覧に Grok 4.7 を追加。
  • サイドバー / ファイル / タスク: 左サイドバーの開閉状態を記憶。音声・動画ファイルの再生、Quarto / R Markdown のハイライト、Quick Open の複数語クエリ対応。GitHub Projects Board ビューをドラッグ可能な kanban として表示し、SSH ワークスペースの GitLab MR / Issue 操作が正しいサーバーに届くようになりました。
