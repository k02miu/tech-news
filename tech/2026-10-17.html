🧠 Claude Code — v2.1.302

対象期間内に v2.1.302（2026-10-17 06:03 JST 公開）がリリースされました。auto モードの分類器モデル選択、アイドル圧縮のオン／オフ設定、フォークサブエージェントの既定挙動の統一が中心です。

🔧 新機能・改善

  • auto モード分類器のモデル選択: 環境変数 CLAUDE_CODE_AUTO_MODE_MODEL が追加され、クライアント側 auto モードの分類器が使うモデルを選べるようになりました。サーバー側 auto モードのモデルは変わりません。
  • アイドル圧縮の切り替え: /config に Idle compaction 行が追加され、アイドル圧縮をオフ／オンにできます。アイドル圧縮後に表示される通知にも、オフにする方法が示されるようになりました。
  • Claude Design 終了の予告表示: /design-sync と /design-login に、スタンドアロンの Claude Design（claude.ai/design）が 2026年12月14日をもって終了する旨の通知が追加されました。
  • [Cloud sessions] ルーティンの実行失敗理由: ルーティンのページに、直近の実行が開始されなかった理由を示すバナーが追加されました（例: 組織の同時クラウドセッション上限への到達）。
  • フォークサブエージェントの既定化: フォークサブエージェント（subagent_type: "fork"）が claude -p、Agent SDK、デスクトップアプリ、VS Code でも既定で有効になりました（ターミナルでは従来から有効）。CLAUDE_CODE_FORK_SUBAGENT=0 で無効化でき、claude mcp serve では提供されません。
  • サブエージェントの実行位置の統一: デスクトップアプリと VS Code は、メイン会話のサブエージェントをターミナルと同様に常にバックグラウンドで実行するようになりました（Claude の判断に委ねない）。また claude -p、Agent SDK、デスクトップアプリ、VS Code で、サブエージェント自身の Agent 呼び出しは既定でフォアグラウンド実行になります。

🐛 主な変更・修正

  • 権限モードの既定: 権限モード指定のない claude -p と Agent SDK のセッションは、サードパーティプロバイダー・テレメトリ無効・新規インストールのいずれの場合も default モードで開始されます（--permission-mode auto は auto を維持）。
  • フックの同時実行数: プロンプトフックとエージェントフックは、1つのイベントにつき最大12件まで同時に実行し、残りは順番待ちになります。
  • プロンプトキャッシュ: Claude in Chrome の指示をシステムプロンプト内の別の位置へ移し、新しい会話が共有プロンプトキャッシュから読めるようにしました。
  • UI の細かな調整: セッション開始から10秒後に ← for agents のフッター表示が消えるようになりました（応答待ちのエージェント数の表示は残ります）。組織ポリシーで /feedback が無効な場合のメッセージは、組織管理者ではなく GitHub Issues を案内するようになりました。
  • [Claude Tag]: 管理設定が Bundles、Connectors、Skills and plugins、Channels の4タブに整理されました。組織設定の Roles ページは、Claude Tag のチャネル管理者向けに作成されたロールを折りたたみセクションにまとめるようになりました。

🐙 OpenClaw — v2026.10.4

対象期間内に安定版 v2026.10.4（2026-10-16 09:36 JST 公開）がリリースされました。2026.10.3 に対する安定性パッチで、新機能や設定変更は含まれません。本リリース時点の最新安定版は v2026.10.4 です。

🔧 新機能・改善

  • スリープ・時刻変更後の Gateway 維持: コンピューターがスリープした後やシステムクロックが飛んだ後に、所有権ハートビートが古いと見なされて Gateway が自己再起動してしまう問題が修正され、稼働を継続するようになりました。
  • シャットダウン／再起動のハング解消: 停止したトランスクリプトワーカーや処理中のセッションライフサイクルイベントによって、Gateway のシャットダウンと再起動がハングしなくなりました。
  • 手動 /compact の挙動: 手動 /compact がアクティブな実行を中断して保留中のリクエストを破棄するのではなく、実行の決着を待ってから圧縮するようになりました。
  • ヘッドレスブラウザ: サイトがパスキー待ちの間も、ヘッドレスページがクリックに応答し続けるようになりました。

🐛 主な修正

  • セキュリティ: Tlon のグループ DM が他の参加者をオーナーとして扱ってしまう、オーナーなりすましの経路を塞ぎました。
  • Gateway: 長い返信タグ付きストリーム中も応答し続け、ツールコール XML を引用した長文返信がトークンごとに Markdown を再解析しなくなりました。スリープやウォールクロック変更後に状態所有権を回復し、検証済みの外部 macOS ターミナルから openclaw gateway restart を実行できます。
  • エージェント: 起動されたプラグインのターンが writer-claim エラーで失敗しなくなり、Claude CLI セッションがメッセージ経路をまたいで履歴を分岐しなくなりました。
  • OpenAI: api.openai.com の Completions 経路で、推論モデルのツールターンが 400 で失敗しなくなりました。
  • 更新処理: スナップショット取得中にエージェントのデータベースが変更済みと誤判定されなくなり、Linux の更新が保護された systemd ユーザーマネージャー配下の放棄されたランタイムディレクトリを清掃できるようになりました。
  • その他: Doctor のオフライン状態修復、Tailscale の中断時処理と Doctor チェック、macOS のアプリ復旧、POSIX パスエイリアス（/tmp と /private/tmp）によるチャネル再起動の抑止、MCP OAuth のループバックリダイレクト対応、Telegram・Discord・Feishu・IRC の各修正が含まれます。
