🐋 Orca — v1.4.268 / v1.4.269

対象期間内に 2 つのリリースが公開されました。v1.4.268（2026-11-21 12:50 JST 公開）が Bots の対応エージェント拡大と Slack 連携の強化、v1.4.269（2026-11-22 02:57 JST 公開）が対応エージェントのさらなる追加とモバイルアプリの追従を中心としたアップデートです。

🔧 新機能・改善（v1.4.268）

  • Bots が対応するエージェントを拡大: Cursor、GitHub Copilot、Hermes 上で Bots を実行可能に。OpenCode 2.x の Bots には常設インストラクションが適用され、新しい Bot には識別カードが付与されます。Soul & Memory のエディタも刷新されました。
  • 画像・ファイルの送信: Bot チャット、グループチャット、アイテムのコメントに画像とファイルを添付可能に。ペアリング先コンピュータ上の Bot にも送信でき、Slack のリクエストに付いた画像は画像としてエージェントへ届きます。
  • Slack 連携の拡充: orca slack post --at による予約投稿、ならびに pin / canvas / list / scheduled コマンドを追加。Slack 接続はコピーしたトークンをそのまま利用でき、メンションは名前として表示されます。
  • 軽量化・応答性改善: アニメーションが約 1 秒に 1 回の描画から滑らかに戻り、スピナーとパルスのフレーム数も削減。認証情報の読み取りをメインスレッドから分離し、自動ヒーププロファイルを廃止。ディスク残量が少なくなるとワークスペースの整理を提案します。
  • ワーカーとチャットの信頼性: クラッシュや再起動で切れたチャットを継続可能に。ワーカーの最終レポートが起動元のエージェントを起こすようになり、チャット内のワーカー名からワーカーを開けます。
  • リモートホストのページ注釈: ブラウザの注釈機能がリモートホスト上でも動作します。

🔧 新機能・改善（v1.4.269）

  • Bots が 8 つのエージェントに追加対応: Kiro、Kimi Code、Auggie、Gemini CLI、Kilo Code、MiMo Code、Droid、Goose 上で Bots を実行可能に。Chat からも Kiro・Auggie・Goose を開け、Kiro のチャットはユーザー自身のフックを実行します。
  • モバイルアプリの機能拡充: エージェントへの質問回答、Google / Composio のセットアップカードの処理、Needs you でのツール承認とアクセスリクエストの確認、エージェントのツール・Webhook 管理、+ からの新規チャット開始、グループのスレッドとアイテムの閲覧に対応（対応するモバイルビルドが必要）。
  • Antigravity の選択肢: Google アカウントのユーザーは Orca 内蔵の Google サインインと agy エージェントを選択可能に。agy は設定画面に専用の Sign in を持ちます。
  • アイドル時の Mac を静かに: アイドル状態の Mac ターミナルの CPU 使用量を削減し、macOS と Linux では Git 処理をバックグラウンドのプロセスワーカー上で開始。
  • チャットの可読性: 古いメッセージにカレンダー日付を表示。一時停止中のキューで Resume が目立つようになり、設定により Full access がブロックされた Claude チャットはその旨と最も近い許可モードを表示します。
  • Bots のチーム連携: グループルームで Bot が @名前 で他メンバーを指名すると、そのメンバーがターンを引き継ぎます。結果は自分のコンピュータ上のパスではなくリンクや添付として共有され、Slack メッセージ内のローカルパスは読めるラベルに変換されます。
