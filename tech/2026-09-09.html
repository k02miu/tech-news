🧠 Claude Code — 2.1.265

2026-09-09 05:47 JST に 2.1.265 がリリースされました。対象期間内のリリースです。プラグイン管理の強化、セッション再開の信頼性向上、多数のバグ修正が含まれます。

🔧 新機能・改善

  • --plugin-dir のフォルダ対応: プラグイン群を格納したフォルダを指定できるようになり、各子フォルダの manifest を読み込み。実行中の子フォルダ追加・削除も検知されるようになりました。
  • ツール結果のディスク保存に 1 GB 上限: 会話内プレビューには、保存ファイルが切り詰められた場合にその旨が表示されます。
  • 大規模リポジトリでの --worktree 高速化: 新しい worktree のチェックアウトが並列実行されるようになりました（git 2.32+）。
  • /workflows のエージェント詳細改善: ツール呼び出しに running/failed/done の状態表示、サブエージェントのタスクリスト表示、Enter で入力と結果を展開。
  • スラッシュコマンド補完のリスト化: プロンプト入力中のコマンド候補がリスト表示になり（fullscreen 外では Tab で開く）、プラグインスキルが裸の名前でも検索可能に。
  • リモート MCP の OAuth 遅延登録: 実際に認証するまで OAuth クライアントを登録しなくなりました。
  • セッション再開の高速化: 多くのファイルを読んだ長いセッションの再開時間を短縮。
  • Telemetry: Claude Desktop / Cowork が送信するテレメトリに user.email / user.groups を追加（ターミナルセッションと同様）。
  • [VS Code] 非アクティブセッションの自動アーカイブを追加（「Archive inactive sessions」設定、デフォルト 14 日）。

🐛 主な修正

  • 非対話セッション（-p + stream-json、Agent SDK、クラウドセッション）でユーザーメッセージごとにシェル作業ディレクトリがリセットされる問題 — cd がターンをまたいで永続化されるようになりました。
  • レガシー HTTP+SSE トランスポートしか話さない http 設定の MCP サーバーが接続できない問題（MCP 仕様どおり SSE へフォールバック）。
  • バックグラウンド（--bg）セッションが、アイドルタイムアウト直前にメッセージが届くとターン途中で退去される問題。
  • /model opusplan[1m] が "Model not found" で拒否される問題。
  • tmux 内で 2 キーショートカットが 2 キー目の入力まで 1 秒超えると黙ってキャンセルされる問題（3 秒待ち + タイムアウト通知）。
  • セキュリティ: プラグインパスにバックスラッシュを含めることで macOS/Linux の symlink containment チェックをバイパスできる問題。
  • フォアグラウンドでスポーンされたサブエージェントの再開時にツールリストとシステムプロンプトのプレフィックスが変わり、プロンプトキャッシュが効かなくなる問題。
  • 前プロセスがツール実行中に死亡したあとの再開で、最後のプロンプトが書き換えられず中断ツール呼び出しが保持されるように。
  • Windows: AppContainer / restricted-token サンドボックス内で Read/Write/Edit が全ファイルを拒否する問題。
  • [VS Code] Reload Window / 再起動後にサイドバーのチャットが空白になる問題（10 分以上開いていた場合）。
