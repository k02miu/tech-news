🧠 Claude Code — v2.1.283

対象期間内（2026-09-26 07:00 JST 公開）に v2.1.283 がリリースされました。今回は エンタープライズ向けのモデル制御設定の追加、プラグイン管理まわりの堅牢化、エージェントゲートウェイの新機能が目玉です。vim モードの修正と、MCP サーバーのライフサイクルに関する修正も多数含まれます。

🔧 新機能・改善

  • モデル制御のマネージド設定を追加: availableModelsMatch（"exact" 指定時は、availableModels に列挙したモデルバージョンのみを許可し、新しいリリースはリストに追加されるまでブロック）と deniedModels（availableModels が許可していても特定モデルをブロック）が追加されました。
  • ゲートウェイのヒントヘッダ: 1 つのユーザープロンプトに対応するリクエストを LLM ゲートウェイ側でグループ化できるよう、x-claude-code-prompt-id が付与されます（CLAUDE_CODE_GATEWAY_HINT_HEADERS=1 でオプトイン）。
  • OpenTelemetry の拡充: OTEL_LOG_TOOL_CONTENT=1 のとき、MCP ツール・WebFetch・WebSearch の出力が tool.output スパンイベントに含まれるようになりました。
  • /doctor prompt-audit（/checkup prompt-audit）を追加: CLAUDE.md・スキル・エージェント・コマンドを監査し、旧モデル向けに書かれたプロンプティングパターンを検出します。古いパス・古いコマンド・矛盾する指示ファイルがレポートの先頭に来るよう改善されています。
  • Claude apps gateway: リクエストを構築・署名するが上流へは送らず、クライアントには定型応答を返す load_test_mode ブロック（オプトイン）と、Amazon Bedrock の Mantle エンドポイント向けの mantle アップストリームプロバイダが追加されました。
  • 起動・応答の高速化: claude -p と Claude Code Remote がインタラクティブ UI を読み込まなくなり、auto モード分類器のルールと Artifact ツールは起動時ではなく初回利用時に読み込まれます。事前接続済み API コネクションの再利用による初回リクエストの低遅延化、初回応答中のパターンコンパイル実行、claude.ai アカウントの初回起動時に最大 1.5 秒待たされる問題の解消も含まれます。
  • UI の改善: /mcp のツール一覧が一度に多く表示され、ページキー・マウスホイール・クリックに対応し、組織がブロックしたツールに警告アイコンが付きます。/tasks は行にステータスアイコンが付き、タイトルとキーヒントが画面に残るようになりました。/help・/hooks・/copy・/chrome・/memory・/ide・/release-notes・/rewind・/diff・/remote-env・/plugin などの一覧と、/skills・/artifacts のような検索ボックス付き一覧の操作性も改善されました。compaction のスピナーは所要時間と要約トークン数をストリーム中にカウントする表示に変わり、パーセントバーを置き換えます。
  • MCP ツール結果の改善: MCP ツールが返した画像がファイルにも保存され、Bash・Read などの他ツールから開けるようになりました。
  • そのほか: フルスクリーンモードで他セッションの切り詰められたメッセージをクリックで展開、--plugin-dir の読み込み失敗エントリに読み込めなかった path を追加、--system-prompt と --append-system-prompt がテキスト形式と -file 形式の併用に対応（ファイルのテキストが先）など。

🐛 主な修正

  • SDK セッションの取りこぼしを修正: ターンが早期に終了した際に遅延ツール呼び出しや完了済みツール結果が失われる問題、worker 再起動後に承認プロンプトが保持される問題、非ストリーミングフォールバックの result.usage の問題が解消されました。
  • MCP サーバーのライフサイクルを修正: 長時間実行ツールがバックグラウンドに移った後に進捗通知が破棄される問題、起動中にセッションが終了すると stdio MCP サーバーが残り続ける問題、ステートレスなリモート MCP サーバーの一時的な HTTP 404（再デプロイ中のプロキシなど）でそのセッション中ずっと使用不能になる問題、有効な URL を持たないサーバーへのサインインが不可解な SDK エラーで失敗する問題が修正されました。
  • プラグイン管理を多数修正: claude plugin validate がインストール不能なプラグイン／マーケットプレイス名を合格としていた問題（outputStyles・themes・monitors・lspServers のパス欠落やプラグイン外参照も検出）、claude plugin details が plugin.json 宣言の MCP サーバーを 0 と表示する問題、大文字小文字だけが異なるプラグイン ID を誤って削除する問題、バージョン未宣言プラグインがキャッシュ欠落時に最新コミットで復元される問題、ホーム／設定ディレクトリの移動後（bind mount された devcontainer など）に「cache-miss」で読み込めなくなる問題、installed_plugins.json が読めない場合の復旧経路（内容を退避したうえで再構築し、その退避ファイル名を claude plugin list が示す）が修正・改善されました。
  • モデル選択まわりを修正: 日付や -v1:0 サフィックス付きの Sonnet 4.6／Sonnet 5 ID で [1m] が受け入れられる不整合、ANTHROPIC_DEFAULT_HAIKU_MODEL で別モデルを固定しているのに /model ピッカーがハードコードされた Haiku のバージョンと価格を表示する問題、モデルフォールバック中に開始した動的ワークフローが全エージェントをフォールバックモデルで実行する問題、Haiku がセッションメインのときに DISABLE_PROMPT_CACHING_HAIKU が効かない問題が解消されました。
  • テレメトリを無効にすると有料プランで /usage の週次 Fable 上限が表示されない問題（VS Code の使用量メーターも同様）を修正しました。
  • マネージド sandbox 設定の適用漏れを修正: ネストした値が 1 つ不正だとブロック全体が無視されていた問題が解消され、不正値は fail closed で扱いつつ残りの設定は適用されます。
  • Remote Control を修正: DISABLE_TELEMETRY／DO_NOT_TRACK でテレメトリを切ると有料プランで利用できなくなる問題、狭いターミナルで /remote-control の QR コードヒントが語の途中で切れる問題が修正されました。
  • エディタ・ターミナル・シェル: vim モードの . が Shift+Enter の改行を落とす問題やアクセント付き文字内にカーソルが残る問題、正規モードで 10,000 文字超のプロンプトを呼び戻した際のカーソル位置、J の行結合が Vim と空白処理で異なる問題などを修正。type-ahead・キーリピート・ssh や tmux 経由のキー連打が古い状態に対して処理される問題、keybindings.json の綴り間違い修飾子（ctl+k など）が無言で受け入れられる問題も解消されました。Windows では PowerShell ツールが cmd /c rd・rmdir・del・erase でドライブ直下やホームフォルダを削除できてしまう問題が修正されました。
  • そのほか: スクリーンリーダーモードの権限ダイアログが引用コマンドを自身のテキストとして読み上げる問題、/context が MCP サーバーの instructions を計上しない問題、Warp ターミナルで Markdown リンクがクリック不能になる問題、sandbox 内などで設定ファイルに書き込めないのに claude mcp add 系が成功を報告する問題、クラウドセッションで応答の冒頭がストリームされず遅れて表示される問題、worktree チェックアウトが GIT_CONFIG_COUNT 経由の CA 証明書指定で証明書検証に失敗する問題、Claude 自身の auto-memory ノートへの編集が git リポジトリのサブディレクトリ起動時に機密ファイル書き込みとしてブロックされる問題などが修正されました。
  • VSCode / Cloud sessions / Claude Tag / Code Review: 権限モード表示が実態と異なる問題、Web から転送されたセッションで作業中に送ったメッセージが失われる問題、復元セッションの表示崩れ、実行中クラウドセッションへのリポジトリ追加（読み取りのみ可のプライベートリポジトリ対応）、サーバー再起動復帰後の重複プッシュ／重複コメント、ルーチン実行の既定時刻とタイムゾーン計算、Claude Tag のチャネル検索権限設定や二重投稿、Code Review の無音化・課金整合性などが修正されました。

⚙️ 動作変更

  • サードパーティプロバイダ利用時、またはテレメトリ無効時は、権限モード未設定ならインタラクティブセッションが auto モードで開始します（permissions.defaultMode が優先）。
  • 2.1.282 で行った claude-ai 名の予約を撤回しました。同名のスキル・コマンド・ワークフロー・MCP サーバーのスキルとプロンプトが再び読み込まれ、Skill(claude-ai:*) ルールは通常のプレフィックスルールとして扱われます。
  • Skill(anthropic-skills:<name>) の拒否ルールが、Claude Desktop がプラグインとして届けた同名スキルもブロックし、Skill(skill:<name>) の拒否がスキルの別名と表示名にも一致するようになりました。
  • アーティファクトのウォッチは、自動で武装されたもの（明示的に要求したものではない）が無操作 3.5 時間で終了します（再公開・再ウォッチで再武装）。
  • claude plugin eval は git がインストールされている場合に git 2.31 以降を要求します。--ultrareview の起動ダイアログは、ローカルブランチのレビューが未コミットの変更をアップロードし得る旨を表示するようになりました。

🐋 Orca — v1.4.212 / v1.4.211

対象期間内に v1.4.211（2026-09-25 15:17 JST 公開）と v1.4.212（2026-09-26 07:10 JST 公開）の 2 版がリリースされました。v1.4.211 が機能面の中心で、v1.4.212 は Codex 連携の障害修正のみを収めた小さなパッチです。

🔧 新機能・改善

  • Muse Code を第一級の supervised worker ハーネスとして追加（v1.4.211）: モデルと effort 設定を受け付け、ローカルの使用量レポート用プロバイダも追加されました。オーケストレーション側でも Muse のモデル／effort を supervised worker に渡せるようになっています。
  • ネイティブチャット: 確定した構造化ターンごとに通知が届き、ジャーナル行が生成元のエージェント名を示すようになりました。Codex のチャットでは composer の上にゴールが表示され、ゴールモードから設定できます。ツール呼び出し間でツール行が保持され、実行中のツールヘッダが呼び出し開始からターン終了まで 1 つに保たれます。
  • エージェント状態の扱いを改善: 稼働中の子ワークを持つ構造化セッションが「作業中」として扱われるようになり、子エージェントの親子関係はブール値ではなく Codex が表明した parentage を読む方式に変更されました。
  • ワークスペース・エディタ・ブラウザ: 大規模なローカルワークスペースでファイル名検索が可能になり、プレビュータブを無効化する設定が追加されました。サイドバーのコンテキストメニューからワークスペース名をコピーでき、Salesforce Apex 拡張子が apex 言語 ID にマップされます。作成前に取得した一覧が新規作成したワークスペースを退役させてしまう問題も解消されました。
  • 使用量レポート: GPT-6 Sol／Luna、Opus 5.5、Fable 5.1 の価格計算に対応し、GPT-5.6 の料金を修正しました。Codex の長コンテキストは集計単位ではなくリクエスト単位で課金計算されます。
  • ターミナル／リモート: バックグラウンドで作成されたターミナルが起動クエリに応答し、明示的なクローズにはデーモンの即時 kill 判定まで猶予が確保されます。macOS ではデーモンのコード同一性が adoption／フォルダ拒否イベントで報告されるようになりました。relay はアジアのセル容量を拡大しつつ、セル単位のゲート・テーブルロック convoy のアラート・安全な rehome が入っています。
  • モバイル（OTA ページ）: 端末の Back キーがページに届くようになり、未保存 Markdown 下書きでの離脱時に確認が入ります。認証失敗バナーから再ペアリングが可能になり、失敗した hybrid-shell 更新が端末側に記録されて Troubleshoot に表示されます。バンドル配信は capability ネゴシエーションと gzip 圧縮（384 KiB レンジ）に対応し、マニフェスト全体で 4 つのチャンク読み込みを並行実行します。

🐛 主な修正

  • Codex 0.157 以降が SUN_LEN で失敗する問題を修正（v1.4.212）: Orca 管理下のホームで起動するようになりました。
  • ブラウザのショートカットが、それを受け取った split／フローティングパネルに限定されるようになりました（back／forward／reload／zoom／grab）。
  • ランタイム接続の拒否を正しく報告: 従来は Orca が無応答に見えていたケースで、拒否であることが明示されます。
  • 構造化履歴の削除項目を非表示化するとともに、テキスト選択や GitHub コードのコピーなどチャット操作の不具合が修正されました。
  • opencode 連携: OpenCode 2 の session_v2 トークン集計の読み取りと、question ツールのフォームをペインブロッカーとして扱う条件が修正されました。
