🧠 Claude Code — v2.1.272 / v2.1.273

対象期間内に v2.1.272（9月15日 09:50 JST 公開、バグ修正・信頼性改善のみ）と v2.1.273（9月16日 05:30 JST 公開）の2件がリリースされました。v2.1.273 では LLM ゲートウェイ向けのリクエストヘッダ拡張、MCP 切断時の通知と再接続の改善、Remote Control セッションのフォーク機能などが追加され、パーミッションチェッカーまわりと長時間セッションの挙動に多数の修正が入っています。

🔧 新機能・改善

  • ゲートウェイ向けリクエストヘッダ（v2.1.273）: LLM ゲートウェイ向けに x-claude-code-request-class、x-claude-code-agent-type、x-claude-code-prev-tool-durations、x-claude-code-compaction、x-claude-code-context-compacted を追加。CLAUDE_CODE_GATEWAY_HINT_HEADERS=1 でオプトインします
  • MCP 切断時の通知: セッション途中で MCP サーバーが切断し、自動再接続も諦めた場合に通知が表示され /mcp へ誘導されます
  • Remote Control セッションのフォーク: claude --remote-control または /remote-control で開始したセッションを Claude アプリからフォーク可能に。フォークはお手元のマシン上のバックグラウンドセッションとして動作します
  • Artifact ツールの改善: 配信対象外のファイル形式を含む publish 時のエラー説明を具体化、ページ読み取り時にその artifact のケイパビリティとデータベース規則を提示、DB 書き込みで単一フィールドの削除が可能に、接続断後の publish 再送が安全になり重複バージョンを作らなくなりました
  • エラー診断の改善: Bedrock / Vertex / Foundry の 401・403 や Claude apps gateway の 403 で、更新すべき資格情報名やゲートウェイ管理者への連絡先を明示。/autofix-pr・/web-setup・SSL 証明書／プロキシ接続エラーも原因と対処（NODE_EXTRA_CA_CERTS など）を表示します
  • 長時間セッションの応答性改善: フックの進捗やサブエージェントの活動更新ごとに会話全体を再処理しなくなった
  • テレメトリ: OTEL_LOG_TOOL_DETAILS=1 がコスト・トークン指標に実際の agent / skill / plugin / MCP サーバー名を含めるように。/bug・/feedback はモデル挙動パラメータのみを送信し、リクエストメタデータや CLAUDE_CODE_EXTRA_BODY は除外されます
  • 挙動変更: Bedrock / Vertex / Foundry の auto モードは当面ローカル分類器を既定とし、サーバー側分類器を使うには CLAUDE_CODE_AUTO_MODE_SERVER=1 を設定します

🐛 主な修正

  • パーミッションチェッカーが完全に解析できない Bash コマンドが permissions.blockReadsOutsideWorkingDirectories 下でプロンプトをすり抜ける問題、およびバイパスモードでサブシェルが危険な rm を隠せる問題を修正
  • 組織が Skills を無効化した後も claude.ai から同期されたスキルが利用可能なままだった問題を修正（復元可能なゴミ箱へ移動）
  • MDM や managed-settings.json で設定した allowManagedMcpServersOnly・deniedMcpServers・disableClaudeAiConnectors が、サーバー管理設定が併存する場合に無視される問題を修正
  • /login・/upgrade・/extra-usage が会話中の thinking を破棄し、次リクエストでプロンプトキャッシュ全体の書き直しを強いていた問題を修正
  • コンテキストメーターと auto-compact が advisor ツールのターンを実際の約2倍で計上し、実ウィンドウの半分で auto-compact が発火していた問題を修正
  • サブエージェント／バックグラウンドエージェントが、最終ストリーミング応答にトークン使用量やモデル ID が無いと「失敗」扱いになり結果が届かない問題を修正
  • SDK と --output-format stream-json の出力で、実行途中にバックグラウンドへ移されたサブエージェントの残りのメッセージと最終レポートが欠落する問題を修正（CLAUDE_AUTO_BACKGROUND_TASKS など）
  • .claude/scheduled_tasks.json を別フォルダ（新しい worktree など）へコピーすると、保存済みスケジュールタスクが誤ったセッションで実行される問題を修正
  • macOS でドラッグしたスクリーンショットなどの Read が「symlink resolution changed after permission was checked」で拒否される問題を修正
  • /tui が、既に作業を終えて agents パネルに表示されていない agent-team のメンバーを理由に再起動を拒否する問題を修正
  • spinner が compaction ステータス行（「Running PreCompact hooks…」など）で省略記号を二重表示する問題、Artifacts の読み取り／publish 後に frontend-design プラグインを勧める誤ったヒントを修正
  • /install-github-app が SAML シングルサインオンによるブロックを「admin permissions required」と誤報する問題を修正
  • 2.1.268 の変更を一部巻き戻し: パーミッションチェッカーが解析できない Bash 行（eval、env -C）で Read / Edit の拒否ルールを適用していたため、time -p make build のようなコマンドは拒否ではなく再度プロンプト表示に戻りました
  • [VSCode] 完了ターン後に Windows で赤い「Claude Code process exited with code 4294967295」バナーが出る問題、フィードバック無効組織でも「Report a problem」が表示される問題を修正
  • [Claude Code on the web] 組織設定からのセルフホスト環境作成がサーバーエラーで中途半端に失敗する問題、管理者がコネクタを削除・再追加するとルーチンが古いコネクタを呼び続ける問題を修正
  • [Claude Tag] スケジュールタスクが組織共有の private Slack チャンネルで投稿されない問題、古いスレッドへの返信がタスクを最初からやり直して未 push の作業を失う問題などを修正
  • [Code Review] ベースブランチのマージで「Additional findings」がある PR が全量再レビューになる問題、REVIEW.md 全体が @メンションや行をまたぐコードスパンで無視される問題、/ultrareview --post のリトライで所見コメントが0回／2回投稿される問題を修正

🐋 Orca — v1.4.203

対象期間内に v1.4.203（9月15日 14:43 JST 公開）がリリースされました。信頼性・セキュリティ、エージェントとネイティブチャット、ワークスペースとモバイル、そして幅広い性能改善をまとめたリリースです。

🔧 主な内容

  • 信頼性・セキュリティ: glibc 環境の use-after-free に対処するため Electron を更新。ブラウザの Cookie 移行がより確実になり、worktree 作成が post-create 失敗後も正常に完了します
  • ブラウザ Cookie: Chromium の SameSite ストレージ値のデコードに対応（プロファイルあたり最大135件の Cookie が失われていました）。Cookie スコープを psl の古いサフィックスリストから切り離しました
  • エージェントとネイティブチャット: 再起動で宙に浮いた送信をプロバイダ履歴と突き合わせて判定、agent ステータスが保持されたランタイム行ストアに依存しないように変更、プロバイダが一覧に載せていない構造化モデルを拒否するなど検証を強化
  • 自動化: スケジューラの tick を分離し、サイズ超過の cron ステップを拒否するように
  • AI Vault: インデックス上のセッション検索クエリエンジンを追加。以前のサイズに書き戻されたトランスクリプトの再読み取りにも対応
  • モバイル: プッシュ通知とコールドスタート時の解除動作を復旧、型付き RPC 操作の追加と生リクエストの制限、Markdown 描画の無限ループ防止、通知タップ時に現在のワークスペースを再利用
  • ワークスペース・サイドバー: 保存済みフォルダワークスペースの名前とグループをリソースマネージャに表示、アニメーション付き並べ替えを保ったままサイドバーのネストを操作しやすく改善
  • 性能: コールドスイッチ、ブラウザ、ターミナル、SSH、モバイル、履歴、プラグイン、relay のオーバーヘッドを広範に削減。エディタの Markdown 空白走査による数秒単位の停止を解消し、20.7 MiB の重複・未使用メディアを削除
