🦞 OpenClaw — 2026.5.22 プレリリース（5月23日）

OpenClaw のプレリリース 2026.5.22 が公開されました。多数の機能強化・ドキュメント改善・バグ修正を含む大型アップデートです。

🤖 エージェント／サブエージェント

  • サブエージェントのブートストラップコンテキスト制限: デフォルトで AGENTS.md と TOOLS.md のみに制限され、ペルソナ・ID・ユーザー情報・メモリ・ハートビート・セットアップファイルが委譲先ワーカーに含まれないようになりました（#85283）
  • ツール表示の安定化: 旧 sender-owner ツールゲーティングパスを削除し、設定されたツールが常に可視化されるように

🔌 プラグインSDK

  • チャンネルメッセージポーリング: 汎用ポーリング送信機能を追加し、チャンネルプラグインがチャンネル固有の SDK ファサードに依存せずにポーリング配信を実装可能に
  • セッションワークフローヘルパー: 行レベルのセッションワークフロー操作を追加し、プラグインがレガシーなストア全体に依存せずセッションの読み書き・パッチが可能に（#84693）
  • Embedding Provider API: 汎用的な埋め込みプロバイダー機能契約と登録 API を追加

🎛️ コントロールUI／チャット

  • セッションピッカー改善: 検索機能と「さらに読み込む」ページネーションを追加し、古い会話も遡ってアクセス可能に（#85237）

🔧 その他の改善

  • Discord: agentComponents のコールバックレジストリに TTL（最大24時間）を設定可能に（#84189）
  • xAI/Grok: xAI OAuth 認証プロファイルの再利用、Grok モデルエイリアスの追加（#85182）
  • パッケージング: npm tarball からドキュメント画像・アセットを除外し、パッケージサイズを削減
  • 依存関係更新: protobufjs 8.4.0 への更新で npm advisory 対応、Claude ACP パッチを @agentclientprotocol/claude-agent-acp 0.36.1 に引き継ぎ

推奨アクション: OpenClaw ユーザーはリリースノートを確認し、特にサブエージェントのコンテキスト制限変更に注意してください。

🍃 Spring AI — 1.0.8 / 1.1.7 / 2.0.0-M7 リリース + セキュリティ修正（5月23日）

Spring AI の3つのリリースラインが同時更新されました。特に CVE-2026-41863（MEDIUM）への対応を含みます。

⚠️ CVE-2026-41863 — Anthropic Skills API のファイル書き込み脆弱性

要対応 Spring AI 1.1.x の Anthropic Skills API サポートにおいて、LLM が生成したファイル名が Path.resolve でサニタイズされずにファイル書き込みに使用される脆弱性が修正されました。悪意あるユーザーが意図したディレクトリ外へのファイル書き込みを行う可能性があります。

影響バージョン: Spring AI 1.1.0 〜 1.1.6
修正バージョン: 1.1.7

🔗 Spring Security Advisory: CVE-2026-41863

🚀 Spring AI 2.0.0-M7 の主な変更点

  • [破壊的変更] MCP トランスポート: SSE トランスポートが非推奨に。Streamable HTTP が新しいデフォルトサーバープロトコルに（#5969）
  • ToolCallAdvisor: ツール呼び出し処理のデフォルトかつ標準方式に（#5459）
  • 新しい ToolSpec Fluent API: プログラムによるツール定義が可能に（#6085）
  • Gemini 2.5 Flash 対応: Google Client Library BOM を更新（#6003, #6112）

🔧 1.0.8 / 1.1.7 のバグ修正

  • RedisVectorStore の delete 操作が先頭10件のみを削除していた問題を修正（1.0.8）
  • Ollama の GraalVM ネイティブイメージ互換性を修正（1.1.7）
  • OpenAiChatModel のストリーミングチャンク欠落問題を修正（1.1.7）

推奨アクション: Spring AI 1.1.x ユーザーは CVE-2026-41863 対応のため 1.1.7 へのアップグレードを推奨。2.0.0-M7 への移行を検討している場合は、MCP トランスポートの破壊的変更に注意。
