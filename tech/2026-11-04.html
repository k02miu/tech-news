🧠 Claude Code — v2.1.317

2026-11-03 10:30 JST 公開。ネットワーク送出前の確認、Agent SDK フックの onFailure、Claude apps gateway のコスト分析 API など、統制と可観測性まわりの追加が中心のリリースです。

🔧 新機能・改善

  • メールアドレス送出前の確認: Web ツールやシェルツールの呼び出しがアカウントのメールアドレスをネットワークへ送信しようとする前に、確認を求めるチェックを追加しました。
  • Agent SDK フックの onFailure: "block": コールバックが失敗した場合に、そのまま実行させるのではなくアクション自体をブロックできるようになりました。
  • /schedule の警告: 新しいクラウド定期タスクに、意図していないコネクタが付与された場合に警告と解除方法を表示します。
  • OTel 属性の拡張: メトリクス・イベント・スパンに anthropic.plan、anthropic.seat_type、anthropic.provider、anthropic.custom_base_url を追加しました。
  • コストレポート API: Claude apps gateway の管理 API に GET /v1/organizations/analytics/cost を追加。期間指定で、全体・開発者別・日別・IdP グループ別の支出を取得できます。
  • CLAUDE_CODE_DISABLE_NESTED_SESSION_ID: セルフホストランナー上で、セッション内の claude -p が従来どおりそのセッションの ID とトランスクリプトを使うよう固定できます。
  • auto mode の通知: サブエージェントのツール呼び出しに対して auto mode の判定が答えを持たない場合、これまでメインビューに何も残らなかったところに通知を表示します。

🔄 主な変更

  • SendMessage の到達が早く: 実行中のバックグラウンドエージェント宛メッセージがより早く届きます。実行中のコマンドは停止されず、バックグラウンドへ移されます。
  • サブエージェントの effort: メイン会話と異なるモデルを使うサブエージェント／チームメイトは、セッションの effort ではなく、そのモデルに保存された effort もしくは既定値を使うようになりました。
  • Read ツールのスタブ廃止: 「前回の Read 以降ファイルは未変更」というスタブを廃止し、未変更ファイルの再読み取りでも内容を返すようになりました。
  • plugin-authoring スキル: 自作した mod が動作した後に一度だけ、共有を促す提案を行うようになりました。
  • Cloud sessions / Claude Tag: MCP サーバーが提示するリンクを承諾・辞退できるリンクカードを追加。Slack に貼られた artifact リンクは、サイドパネルではなく Claude で開く「Open」ボタン付きの簡易カードで表示されます。

🐙 OpenClaw — v2026.10.10

2026-11-03 12:22 JST 公開。3,028 件の PR・454 名のコントリビューターを擁する大型リリースです。チャット詳細パネル、タスク中の軌道修正を促す Advisor、ブラウザ Talk の分離音声モードが柱となります。

🔧 新機能・改善

  • Chat Details パネル: セッション情報とタスク進捗を会話の横に集約。広いチャットペインでは会話を覆わずに横へ開き、自動で開いた場合はペインが狭まると隠れます。Details ボタンで手動切り替えも可能です。
  • Advisor（実験的）: エージェントの作業中内容を点検し、失敗したアプローチの繰り返しや要求からの逸脱など明確な誤りを検出した際に短い修正提案を出します。ツール実行や承認は行いません。Settings → System → Labs から有効化でき、確認間隔は Configure で調整できます。
  • 分離音声モード: ブラウザ Talk で、応答生成は通常のチャットと同じモデルを使いつつ、文字起こしと音声合成に別サービスを設定できる音声オプションが追加されました。
  • サブエージェント表示: 実行中・完了済みの swarm ワーカーを Subagents パネルに表示し、編集せずにトランスクリプトを閲覧できます。
  • 進捗の可視化: リトライやフォールバックの進捗、失敗時の通知と復旧アクションを表示。リロードや再接続を挟んでも失敗通知と復旧アクションが復元されます。

🐋 Orca — v1.4.247

2026-11-03 12:36 JST 公開。Chat UI の正式化、モバイルでのレビュー強化、テーマ／フォントの拡充、プラグイン API の拡張が中心です。

🔧 新機能・改善

  • Chat UI が実験的機能を卒業: Chat UI 設定でエージェントごとに Chat / CLI を選択可能に。権限モードを常時表示し、オプション再取得中もモデル・effort 操作が使えます。共有ローンチコントロールは Settings → Chat UI にも追加されました。
  • 利用上限リセット後の自動継続: オプション設定で、チャットの利用上限がリセットされた際に自動で会話を再開できます。
  • モバイルのレビュー強化: ブランチの各コミットを個別ページで確認し、ファイル間を移動、差分コンテキストを折りたたみ、コード横で PR レビューコメントを閲覧・追加できます。PR タブはマージを妨げる要素に焦点を当てます。
  • テーマ／フォント: GitHub・VS Code・カタログのテーマを外観設定から選択可能に。フォントは各書体でプレビューし、Ghostty の light/dark ペアや Kitty 設定ファイルも取り込めます。
  • プラグイン: 保存・リロードを跨いで保留編集を保持するカスタムエディタ、ライブのステータスバー項目、Box レイアウトのコンポーネントパネルを作成可能に。フックはエージェント起動・プロンプト・ツール呼び出し・ターミナル送信・ワークスペース作成に接続できます。
  • エージェント／オーケストレーション: コーディネータ終了後も実行中ワーカーを Agents リストに残し、ハンドオフカードで委譲作業を追跡しやすくしました。Codex / Claude のアカウント切り替えも簡素化されています。

⚠️ 既知の問題・注意点

  • 実験的オーケストレーションパネルは無効化: アプリ全体のラグ対応のため一時停止中。オーケストレーションコマンド自体は動作します。
  • チャット保存の容量: 会話の増加に伴い履歴がディスクを圧迫し続ける可能性があり、自動コンパクションは本リリースには含まれていません。
