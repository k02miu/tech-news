⭐ Claude Opus 4.8 (May 28, 2026)

Anthropic が Claude Opus 4.8 を正式リリースしました。Opus 4.7 から約1ヶ月での大型アップデートです。

  • ベンチマーク改善: コーディング 64.3% → 69.2%、Computer Use 82.8% → 83.4%、ナレッジワーク 1753 → 1890、財務分析 51.5% → 53.9%
  • honesty 向上: 不確実性のシグナルがより正確になり、根拠のない主張が減少
  • 価格は据え置き: $5/M input tokens, $25/M output tokens（Opus 4.7 と同額）
  • Fast Mode: 2.5倍速で $10/M input, $50/M output（旧Fast Mode比3倍安価）
  • 提供先: Claude API、claude.ai、Amazon Bedrock、Claude Platform on AWS

🆕 Claude Code v2.1.154

  • Opus 4.8 対応: デフォルトで high effort。/effort xhigh で最難タスク向け
  • Dynamic Workflows（Research Preview）: Claude が自律的にワークフローを作成し、数十〜数百のサブエージェントを並列実行。大規模タスクの自動化が可能に。 /workflows で実行状況を確認
  • Fast Mode on Opus 4.8: 標準の2倍のコストで2.5倍の速度
  • Lean System Prompt がデフォルトに: Haiku, Sonnet, Opus 4.7以前を除く全モデルで有効化
  • /simplify 改善: クリーンアップ専用レビュー（再利用性・簡素化・効率性・抽象度）を実行し修正を適用するように
  • /effort ラベル変更: "Speed"/"Intelligence" → "Faster"/"Smarter"
  • Streaming Tool Execution 常時有効化: telemetry無効時やBedrock/Vertex/Foundryでも利用可能に
  • 多数のバグ修正: サブエージェントのworktree分離違反、バックグラウンドセッションのゾンビ化、VS Codeでの端末描画破損など

⚠️ CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE は 2026-06-01 に削除予定。Opus 4.6のFast Mode利用者は /model claude-opus-4-6[1m] → /fast on に移行が必要。
