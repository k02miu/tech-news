🧠 Claude Code — v2.1.314

2026-10-30 10:16 JST 公開。permissions.blockWritesOutsideWorkingDirectories の追加により、作業ディレクトリ外への書き込みを作業モードに関わらず拒否できるようになりました。あわせて VS Code / Claude Desktop の Code タブにアイドル時コンパクションが入り、長時間放置した大規模会話を要約して再利用できるようになっています。

🔧 新機能・改善

  • 作業ディレクトリ外への書き込み禁止: permissions.blockWritesOutsideWorkingDirectories を追加。Write / Edit / NotebookEdit が、すべてのパーミッションモードで作業ディレクトリ外のパスを拒否します。
  • Claude apps gateway の IdP グループ制御: upstream に任意の groups リストを指定でき、指定グループ所属の開発者だけがその upstream に振り分けられます（フェイルオーバー時も同様）。
  • Bedrock guardrail のトレース: guardrail_trace を追加し、どの Amazon Bedrock ガードレールフィルタが発火したかを、一致したテキストを含めずにログ出力。
  • アイドル時コンパクション: VS Code と Claude Desktop の Code タブで、20万トークン超の会話を放置すると要約され、プロンプトキャッシュ失効後の次のメッセージでその要約が使われます。
  • クラウドセッションの細かな改善: 完了済みの単発タスクだけが隠れている場合に表示できる「Include completed」ボタン、およびセットアップスクリプトがエラー終了してもセッション自体は起動する挙動に変更。

🐛 主な修正・挙動変更

  • サーバー管理設定の保護: 組織のサーバー管理設定のローカルコピーを編集する前に確認を求めるように変更。
  • /permissions の承認制限: Recently blocked から、全体を読めない呼び出し（ターミナルが短すぎて表示しきれないものを含む）の承認を拒否。
  • Bash ツールの which 汚染対策: 継承した which のエイリアス／関数をクリアし、エクスポートされた which / unsetenv 関数をコマンドへ渡さないよう変更。
  • モデルフォールバック: ANTHROPIC_DEFAULT_OPUS_MODEL などの設定で古い Opus しか残らない場合に、拒否ではなく別モデルで再試行するよう変更。
  • macOS のメモリリーク回避: 多くのコマンドで git grep を C ロケールで実行し、非 UTF-8 ファイルに対する正規表現ライブラリのリーク報告を回避。
  • その他: FORCE_HYPERLINK=false（no / off）が逆にリンクを有効化していた挙動を修正、/ultrareview のワークスペース信頼チェック、監査系スキル（claude-api / dataviz）の記述更新など。

🐙 OpenClaw — v2026.10.10-beta.5

2026-10-30 12:57 JST 公開（プレリリース）。Node 互換性の復旧、Gateway ストリーミングの停止解消、更新・ロールバックの安全性、cron の取りこぼし修正が中心です。

🔧 新機能・改善

  • Node 互換性: Node >=24.16.0 <25 || >=26.1.0 でインストールと更新が再び動作。Node 24.22.1 / 26.12.1 は「ハード要件」から「セキュリティ推奨」に格下げされ、Node 26 のワーカーが stdin をファイルにした場合でも中断しなくなりました。
  • Gateway ストリーミング: ツール呼び出し風の XML を含む返信や、不完全なタグで終わる長い HTML によって Gateway が停止しなくなりました。
  • 更新とロールバック: npm ロールバック失敗時にインストール済みパッケージが孤立しない、Git ロールバックで運用者の編集が保持される、更新実行プロセスが落ちてもオフライン状態から復旧する、といった改善。
  • Cron: 保存された次回実行時刻が古いためにミススロットが捨てられる問題を修正し、再起動後の起動時キャッチアップ実行が受理されるように。

🐛 主な修正

  • セキュリティ境界: exec 許可リストモードで test / [ -v のオペランドに承認を要求、汎用 node invoke 経由のブラウザプロキシコマンドを拒否、サンドボックス内の子プロセスが CLI ベースのモデルを解決する場合は fail closed に。
  • ワークスペース制限の伝播: workspaceOnly を Gateway 経由で構築される delegate にも引き継ぎ。
