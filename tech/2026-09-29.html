🧠 Claude Code — v2.1.284

対象期間内に v2.1.284（2026-09-29 03:15 JST 公開）がリリースされました。公式 changelog の RSS フィードを第一の情報源として全エントリの pubDate を JST に換算して確認しております。今回の目玉は Claude Sonnet 5.5 の追加と Sonnet のデフォルトモデル刷新でございます。

🔧 新機能・改善

  • Claude Sonnet 5.5（claude-sonnet-5-5）を追加: Anthropic API におけるデフォルトの Sonnet モデルとなりました。1M コンテキスト、$2 / $10 per Mtok（キャッシュ読み出しは $0.20 / Mtok）。
  • 作業ディレクトリ外の読み取りに「Yes, but ask again next time」を追加: auto モードの確認プロンプトで、その 1 回だけ許可しつつ以後も確認を継続できます。
  • 対話ターミナルと VS Code セッションが auto モードで開始: 権限モード未設定時、すべてのプラン・プロバイダーで auto モードが既定に（permissions.defaultMode で上書き可能）。
  • Ultracode を /effort の独立トグルに変更: Tab もしくは /effort ultracode [on|off] で操作。xhigh effort を強制しなくなり、任意の effort レベルで有効にできます。
  • /mcp reconnect all を追加: 接続失敗・要認証の MCP サーバーをまとめて再試行できます。
  • 使用量上限の待機表示を改善: 上限の状態とカウントダウン、usage-credits オプションがプロンプト下の 1 ブロックにまとまりました。
  • /usage・ステータスラインに金額を表示: ゲートウェイの支出上限を「$271.40 / $500.00 spent this month」の形式で表示します。
  • auto-memory の読み込みを強化: MEMORY.md および想起メモ中の不可視文字や Claude Code 自身のマークアップを模したタグを無害化します。
  • [VS Code] 各プロンプト・応答に時刻表示（設定で既定オフ）、プラグイン読み込みエラーの表示、Effort スライダー下の Ultracode スイッチなどを追加。

🐛 主な修正

  • 応答ストリーム破損時に「JSON Parse error」等の生エラーが表示されたり回答中に「undefined」が混入したりせず、再試行または中断として扱われるよう修正。
  • thinking ブロック直後にオーバーロード／サーバーエラーが届いてターンがエラー終了する問題を修正。
  • compact 後も「Prompt is too long」が解消しない場合、もう一度 compact して直近会話の保持量を減らすよう修正。
  • 再開セッションで MCP ツール呼び出しが「No such tool available」で失敗する問題を修正（サーバー接続を最大 10 秒待機）。
  • vim モードの . 反復が高速入力・tmux / ssh 経由で動作しない問題、画像プレースホルダ周辺のカーソル破損を修正。
  • プラグインが管理ポリシー下で allowed-tools による自己ツール事前承認を行う問題を修正。
  • その他、多数の UI・フルスクリーン描画・プラグイン・ゲートウェイ関連の修正を含みます。
