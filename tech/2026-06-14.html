🧠 Claude Code — v2.1.176

対象期間中に v2.1.176（06/13 09:52 JST公開）がリリースされました。セッションタイトルの多言語対応、フッターリンクバッジのカスタマイズ設定、Bedrock 認証キャッシュの改善、多数のバグ修正（tmux SSH、Remote Control、バックグラウンドセッション、Windows 環境の修正を含む）が含まれます。

🔧 新機能・改善

  • セッションタイトルの多言語生成: 会話の言語でセッションタイトルが自動生成されるように。特定言語を固定するには language 設定を使用
  • footerLinksRegexes 設定追加: フッター行のリンクバッジを正規表現でマッチング可能に。ユーザーまたはマネージド設定で構成可能
  • Bedrock 認証キャッシュ改善: awsCredentialExport からの認証情報が固定1時間ではなく Expiration までキャッシュされるように

🐛 主な修正

  • availableModels 強制適用修正: エイリアスモデル選択が ANTHROPIC_DEFAULT_*_MODEL 環境変数経由でブロックされたモデルにリダイレクトされないように。/fast が許可リスト外モデルへの切り替えを拒否
  • Fable 5 auto モード修正: Opus 4.8 が有効でない組織で Fable 5 が失敗する問題を修正。分類子が利用可能な最適な Opus モデルにフォールバック
  • hook if 条件修正: Edit(src/**)、Read(~/.ssh/**)、Read(.env) などのパターンが正しくマッチするように
  • Linux サンドボックス修正: .claude/settings.json が絶対パスのシンボリックリンクの場合にサンドボックスが起動しない問題を修正
  • tmux SSH クリップボード修正: SSH 経由の tmux 内で /copy とマウス選択コピーがシステムクリップボードに届かない問題を修正。tmux 3.2 未満でのペーストバッファ読み込みも修正
  • Remote Control 修正: Web/モバイルからの接続がセッションのモデルをサイレントに切り替える問題、切断通知が数値コードのみ表示される問題、接続失敗時に会話トランスクリプトに重複行が追加される問題を修正
  • /cd とワークツリー移動修正: 移動後にセッションが前のディレクトリの git ブランチを報告し続ける問題を修正
  • バックグラウンドセッション修正: /bg 中にターンが残っていない場合に「Working」が永遠に表示される問題、PR URL によるエージェント検索がスケジュールウェイクアップ中に開かれた PR を見逃す問題を修正
  • Windows 修正: agents ビュー入力にテキストカーソルが表示されない問題、~/.claude/daemon に ReadOnly 属性が設定されている場合にバックグラウンドサービスデーモンが起動しない問題を修正
  • クラウドセッション修正: アイドル状態が長すぎる場合に「Could not resolve authentication method」で失敗する問題を修正
