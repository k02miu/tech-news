🧠 Claude Code — v2.1.175

対象期間中に v2.1.174 と v2.1.175（いずれも06/12 16:35 JST公開）の2リリースが公開されました。マネージド設定によるモデル制限の強化、マウスホイール設定の追加、VSCodeの使用量属性表示、多数のバグ修正が含まれます。

🔧 新機能・改善

  • enforceAvailableModels マネージド設定追加: 有効化すると availableModels 許可リストが Default モデルにも制約を適用。許可されていないモデルに解決する場合、最初の許可モデルにフォールバック。ユーザー・プロジェクト設定でマネージドリストを拡張できなくなる
  • wheelScrollAccelerationEnabled 設定追加: フルスクリーンモードでのマウスホイールスクロール加速度を無効化する設定
  • [VSCode] 使用量属性表示: /usage の Account & usage ダイアログにキャッシュミス、長コンテキスト、サブエージェント、スキル/エージェント/プラグイン/MCP別の内訳を過去24時間または7日間で表示

🐛 主な修正

  • /model ピッカー修正: Default が解決するモデルファミリーが非表示になっていた問題を修正。Opus が Max/Team Premium/Enterprise で個別行として表示されるように。ハードコードされた Sonnet バージョンラベルの表示も修正
  • 「Fable 5 is now consuming usage credits」バナー修正: 使用量ベース課金のエンタープライズアカウントで誤表示される問題を修正
  • Bedrock GovCloud region 修正: us-gov-* region で推論プロファイル接頭辞が global ではなく us-gov を使用するように修正（400エラーの原因を解消）
  • バックグラウンドセッションの環境変数継承修正: バックグラウンドデーモンを開始したシェルから別のセッションの ANTHROPIC_* プロバイダ環境変数が継承される問題を修正
  • macOS/Linux 退出時のポーズ修正: シェルコマンド中断直後に Claude Code を終了する際の1〜2秒の一時停止を修正
  • Git commit 共著者属性修正: 一部モデルで誤ったモデル名が表示される問題を修正
  • /advisor ダイアログ修正: availableModels 許可リストでブロックされた保存済みアドバイザモデルが事前選択される問題を修正
  • スキルホットリロード修正: 単一スキル変更時にスキル一覧全体を再送信していた問題を修正。変更されたスキルのみ再通知
  • Workflow agent() サブエージェント修正: エージェント別の属性ヘッダーが欠落していた問題を修正
  • プリウォームワーカー認証修正: アイドル状態のまま要求されたプリウォームバックグラウンドワーカーが「Could not resolve authentication method」で失敗する問題を修正
