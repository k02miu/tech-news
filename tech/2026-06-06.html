🧠 Claude Code — v2.1.165

2026年6月5日、Claude Code v2.1.165 がリリースされました。バグ修正と信頼性の改善に焦点を当てたアップデートで、51件の変更が v2.1.162 〜 v2.1.165（6/3〜6/5）の期間にわたって含まれています。

🔧 主なバグ修正・改善

  • バックグラウンドエージェントの自動更新対応: バックグラウンドセッションが新しい Claude Code バージョンに自動更新されるように改善
  • プロンプトキャッシュ TTL 修正: 1時間のプロンプトキャッシュ TTL が5分に勝手にダウングレードされていた問題を修正
  • 端末表示の位置ずれ修正: ターミナルの位置ずれと数秒間のハングを修正
  • macOS バックグラウンドジョブ修正: ~/Documents, ~/Desktop, ~/Downloads 配下のファイル読み取りで「Operation not permitted」エラーが発生していた問題を修正（Full Disk Access 付与済みでも発生）
  • Windows Terminal のストロビング修正: バックグラウンドセッション接続時に Windows Terminal で全画面ストロビングが発生する問題を修正
  • Windows ワークツリー修正: バックグラウンジョブのワークツリー削除時に NTFS ジャンクションを追跡してメインリポジトリに影響を与える問題を修正
  • ネストされた CLAUDE.md の再注入修正: CLAUDE.md が何十回も再注入される問題を修正
  • CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE 削除: 環境変数が no-op に（互換性のため残存）
  • パーミッションルールのセキュリティ修正: セキュリティ上の抜け穴を塞ぐ修正を含む
  • ネイティブターミナルカーソル修正: ターミナルがフォーカスを失ったときに入力カーソルが正しい位置に留まらない問題を修正

🔥 Hono — セキュリティアドバイザリ CVE-2026-47674

  • CVE-2026-47674 — hono/ip-restriction ミドルウェアが非正規形の IPv6 アドレスを正しく処理できず、deny ルールをバイパスされる脆弱性。攻撃者が特殊な形式の IPv6 アドレスを使用して IP 制限を回避可能

  • 推奨アクション: v4.12.21 以上にアップグレード
