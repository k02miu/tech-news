🧠 Claude Code — v2.1.167 / v2.1.166 / v2.1.165

2026年6月5日〜6日にかけて、Claude Code のメンテナンスリリース v2.1.165、 v2.1.166、および v2.1.167 がリリースされました。v2.1.166 には複数の新機能と修正が含まれています。

🔧 v2.1.166 新機能・改善

  • fallbackModel 設定: プライマリモデルが過負荷または利用不可の場合に試行される最大3つのフォールバックモデルを設定可能に。--fallback-model がインタラクティブセッションでも適用
  • Deny ルールの glob パターン対応: ツール名の位置で "*" ですべてのツールを拒否可能に。Allow ルールは非 MCP glob を拒否、不明なツール名は起動時に警告
  • クロスセッションメッセージングの強化: SendMessage 経由のメッセージはユーザー権限を持たなくなり、受信側はリレーされた権限リクエストを拒否。Auto モードはブロック
  • Thinking トグルの改善: MAX_THINKING_TOKENS=*** と --thinking disabled、およびモデル別 thinking トグルで、Claude API 経由でデフォルトで思考するモデルの thinking を無効化可能に
  • フォールバックモデルでのリトライ: API が予期しないリトライ可能エラーを拒否した場合、Claude Code はフォールバックモデルでターンを1回リトライ
  • claude update の改善: ダウンロード前にターゲットバージョンを通知するように
  • claude agents: リストに URL を入力すると、最初のプロンプトにその URL を含むセッションにフィルタリング

🐛 v2.1.166 主な修正

  • 処理不可画像の "image could not be processed" エラーと余分なトークン消費を修正
  • リモートセッションが起動時のワーカー登録中にバックエンド障害で永久スタックする問題を修正
  • JetBrains IDE (IntelliJ, PyCharm, WebStorm) 2026.1+ の flickering を同期出力で修正
  • Kitty キーボードプロトコル（WezTerm, Ghostty, kitty）での Shift+非ASCII文字（Shift+ä→Äなど）が欠落する問題を修正
  • PowerShell コマンドバリデーションが子プロセスによりハングする問題を修正
  • macOS でデーモン死亡後に孤児化した claude --bg-pty-host プロセスの100% CPU 問題を修正
  • 管理設定の無効エントリが残りの有効ポリシーの強制を無効化する問題を修正
  • ${VAR} 参照使用時の managed-settings allowedMcpServers/deniedMcpServers マッチングを修正
  • git worktree に入ったバックグラウンドエージェントセッションが "No conversation found" でクラッシュループする問題を修正
  • Ctrl+O トランスクリプトビューでの thinking テキスト重複を修正
  • /doctor がリモートセッション内部でも矛盾した "Not inside a remote session" チェックを表示する問題を修正
  • claude agents のマルチラインプロンプトでカーソルが先頭に固定される問題を修正
  • Unicode 未対応端末でのエージェントリストの空白行を修正
