🧠 Claude Code — v2.1.162

2026年6月3日付で v2.1.162 がリリースされました。エージェント管理、ツール呼び出し、UX改善を中心としたアップデートです。

🔧 新機能・改善

  • claude agents --json に waitingFor 追加: 待機中のセッションが何でブロックされているか（権限プロンプト待ちなど）を表示
  • --tools Grep/Glob 正式対応: 明示的にリストした場合、ネイティブビルドの専用検索ツールが提供されるように（従来は無視されていた）
  • /effort の永続化確認: 選択した effort レベルが新規セッションのデフォルトとして保存されることを明示
  • スラッシュコマンドのオートコンプリート改善: クリックで即時実行ではなくプロンプトに入力、Enter で実行
  • Remote Control 表示改善: 起動メッセージではなくフッターピルとして常時表示（セッションリンク付き）
  • Windsurf → Devin Desktop にリネーム: /ide メニュー、/terminal-setup、/scroll-speed での表記を変更
  • 起動UX改善: 通知を重要度でグループ化、セッション情報とアナウンスを1行に集約、警告文を短縮・具体化

🐛 主な修正

  • 起動ハング修正: config ディレクトリが読み取り専用でも起動可能に（インメモリ設定でフォールバック）
  • WebFetch 権限修正: 組み込みの事前承認ドメインより明示的な deny/ask/allow ルールが優先されるように
  • Windows パス修正: バックスラッシュやケース違いのパスで権限ルールがマッチしなかった問題を修正
  • 割り込み消失修正: ターン開始直後の Esc が stream-json/SDK セッションで無視される問題を修正
  • MCP タイムアウト修正: 1000ms 未満の設定値が全ツール呼び出しを中断していた問題を修正（閾値未満は無視してデフォルトにフォールバック）
  • LSP workspaceSymbol 修正: 結果が返らない問題を修正、query パラメータを受け付けるように
  • claude agents 表示修正: ライブステータスが60〜120桁で途切れる問題、セッション名が40桁で途切れる問題を修正
  • バックグラウンドセッション修正: 復帰失敗時の会話消失防止、クロスセッションメッセージングの深いディレクトリ問題を修正
  • API 400 エラー修正: 絵文字が切り詰め境界付近にある場合のサロゲートペアエラーを修正
