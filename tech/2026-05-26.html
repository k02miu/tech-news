☁️ GCP — Knowledge Catalog データプロダクト GA ＆ リモート MCP サーバー対応（プレビュー）

5月25日、Knowledge Catalog のデータプロダクト機能が 一般提供 (GA) となりました。また、リモート MCP サーバー対応がプレビューで追加されています。

🆕 新機能

  • 承認ワークフロー: データプロダクトの利用申請・承認・追跡が可能に
  • Gemini による自動ドキュメント生成: サンプルクエリ、ビジネスインサイト、ドキュメントテンプレートを自動生成
  • サービスアカウント対応: アクセスグループにサービスアカウントを設定可能、利用者もサービスアカウントでのアクセス申請が可能
  • リモート MCP サーバーサポート (Preview): 外部 IDE や LLM クライアントからデータプロダクトをプログラム操作可能。MCP 経由でデータプロダクトの作成・検出・メタデータ検査が可能

推奨アクション: データカタログを活用している組織は、MCP サーバー経由での AI エージェント連携を検討してください。データプロダクトの承認ワークフローを導入することで、データガバナンスの強化が可能です。

☁️ GCP — GKE JobSet グッドプットメトリクス（プレビュー）

5月25日、GKE のトレーニング JobSet の効率を監視するための2つのシステムメトリクスがプレビューで追加されました。

  • kubernetes.io/jobset/scheduling_goodput: 全リソースが利用可能だった時間の割合
  • kubernetes.io/jobset/proxy_runtime_goodput: 全アクセラレーターが生産的だった時間の割合（実効グッドプットの推定値）

これらのメトリクスは JobSet モニタリングダッシュボードで可視化可能です。

🔥 Hono v4.12.23 リリース（5月25日 JST）

Hono のパッチリリース v4.12.23 が公開されました。バグ修正と新機能を含みます。

🐛 バグ修正

  • serve-static: バックスラッシュを含むファイルパスの正規化を修正（先頭以外のバックスラッシュも処理対象に）
  • utils/ipaddr: 単一の 0 グループを :: に圧縮しないよう修正（非正規 IPv6 表記の比較問題に対応）

🆕 新機能

  • Context クラスの公開エクスポート: Context クラスがパブリックにエクスポートされ、外部から拡張可能に
  • compress ミドルウェア: contentTypeFilter オプションと COMPRESSIBLE_CONTENT_TYPE_REGEX の再エクスポートを追加

📝 その他

  • コントリビューションガイドに AI Usage Policy を追加

推奨アクション: serve-static や IP 制限、圧縮ミドルウェアを使用しているプロジェクトはアップデートを推奨。破壊的変更はありません。

⚡ Next.js — canary チャンネル開発状況（5月24〜25日）

Next.js の canary ブランチでは以下の変更が進行中です。安定版リリースではありませんが、今後の方向性を示唆する重要な変更が含まれています。

主な変更

  • 実験的機能のデフォルト有効化: experimental.varyParams、experimental.optimisticRouting、experimental.cachedNavigations（cacheComponents と併用）が canary でデフォルト有効に
  • Instant Navs DevTools 刷新: インスタントナビゲーションの開発者ツールがリニューアル
  • 新スキル追加: next-dev-loop および next-ppr-optimizer スキルが追加
  • App Shell: サーバーでの App Shell プリフェッチ対応、experimental.appShells フィーチャーフラグ追加
  • PPR: 動的セグメント下での静的メタデータの事前レンダリング改善

※ これらは canary（pre-release）チャンネルの変更であり、本番環境での利用は推奨されません。
