🧠 Claude Code — v2.1.224

自社マシンやコンテナをClaude CodeのWeb・モバイル・デスクトップセッションの実行場所にできるセルフホスト環境が追加されました。クロスセッションのメッセージ送受信、ZIPをHTTPSから取得するarchiveプラグインソース、Bedrockのリージョン推論プロファイル指定、サンドボックスの資格情報マスキング強化なども実装されています。

🔧 新機能・改善

  • セルフホスト環境: claude self-hosted-runnerで、自分のマシンまたはコンテナをセッション実行基盤として利用できます。
  • クロスセッション連携: macOS・Linuxで、ListAgentsによる検出とSendMessageによるセッション間通信に対応しました。
  • サンドボックス保護: 構造化環境変数、JWTクレーム、AWS SigV4を対象とした資格情報マスキング・再署名オプションが追加されました。
  • Remote Control: 接続失敗の常設表示、コンパクション進捗の表示、/clearの接続先反映など、Web・モバイル連携を改善しました。
  • 運用上限: セッションあたりのサブエージェント生成上限を撤廃しました（同時実行数・深度制限は継続）。

🐛 主な修正

  • 長いプロジェクトパスで別プロジェクトのセッションディレクトリへ解決される問題を修正しました。
  • SendMessageが配信失敗時に成功と表示する問題、Linux・macOSのサンドボックス拒否ルールを回避できる問題を修正しました。
  • MCPツール、プラグインの複数プロジェクト利用、Waylandのクリップボード、Remote Controlの再接続・履歴扱いなどを修正しました。
