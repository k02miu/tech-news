🧠 Claude Code — v2.1.179

6月17日 05:27 JST にリリースされた v2.1.179 は、ストリーミング接続の安定性改善、WSL2/サンドボックスの環境固有バグ修正、リモートセッションの信頼性向上を含むバグフィックスリリースです。

🐛 主な修正

  • ミドストリーム接続ドロップ修正: 部分レスポンスが保持されるようになり、rawエラー表示やスピナーの「running tool」での固着が解消
  • WSL2 マウスホイールスクロール修正: Windows Terminal 及び VS Code での WSL2 マウスホイールスクロールのリグレッション（v2.1.172 で発生）を修正
  • サンドボックス denyRead/allowRead glob 修正: 大規模ディレクトリツリーオーバーの glob パターンが Bash ツール説明を巨大化させセッションを不能にする問題を修正（Linux）
  • フィードバック調査修正: ターン完了直後に一桁の入力が即座にセッション評価として記録される問題を修正
  • ウェルカム画面バナー修正: 複数のプロモーションバナーが重複表示される問題を修正（セッションあたり最大1つに制限）
  • Ctrl+O サブエージェントトランスクリプト修正: サブエージェント表示時に Ctrl+O でサブエージェントのトランスクリプトが表示されない問題を修正
  • プロンプト入力フォーカス修正: プロンプト入力欄のクリックでサブエージェント/フッターパネルからフォーカスが戻らない問題を修正
  • リモートセッションバックグラウンドタスク修正: ターン間でバックグラウンドタスクが「still running」と表示され続ける問題を修正
  • リモートセッションプラグイン読み込み改善: リモートセッションでのプラグイン読み込みパフォーマンスを改善
