🧠 Claude Code — v2.1.267 / v2.1.266

対象期間内に v2.1.267（9月10日 05:10 JST）と v2.1.266（9月9日 09:02 JST）の2つのリリースが確認されました。v2.1.267 は設定機能の追加と大規模な修正波、v2.1.266 は LLM ゲートウェイ構成向けの回帰修正です。

🔧 新機能・改善

  • maxEffortLevel 設定: トップレベルまたは modelSettings 配下で設定可能。Bedrock、Vertex、Foundry を含む全プロバイダーの effort レベルに上限を設定でき、ユーザーはより低いレベルを選択可能
  • --system-prompt-snapshot off: 会話に記録されたプロンプトを再利用せず、リクエストごとにシステムプロンプトを新規生成（プロンプト文言の反復調整向け）
  • Bash ツールの説明改善: コマンドをそのまま表示する代わりに、平易な言葉でコマンドの内容を説明するようガイダンス改善
  • プロンプトキャッシュ安定性の向上: サブエージェントや --system-prompt 起動のセッションが、システムプロンプトとツール定義を再レンダリングせず一度だけ記録するように
  • /diff パネル改善: 「0 files changed」とスピナーが一瞬点滅する問題を解消、空状態をパネル中央に配置
  • サンドボックスガイダンス改善: pbcopy などのクリップボードコマンドがサンドボックス内で失敗した際、/copy を提案
  • 入力応答性の改善: キーストロークがスピナーやストリーミング再描画の背後でフレーム待ちになる問題を解消
  • --resume の初回描画高速化: 多数の Bash ツール呼び出しを含むセッションの再開が高速化
  • 自己ホストランナー: --use-anthropic-git-proxy を登録時にサーバーへ報告し、レガシー git プロキシ経由でクローンするセッションに警告を出力

🐛 主な修正

  • 2.1.265 のゲートウェイ回帰修正（v2.1.266）: CLAUDE_CODE_USE_GATEWAY 環境変数が単独で設定されていると Cloud ゲートウェイサインインが強制され、API キーや apiKeyHelper 併用構成で全リクエストが「Not signed in to the Cloud gateway」で失敗する問題。この変数単独は再び無視されるように
  • プロンプトキャッシュ破壊の広範な修正: /model 切り替え時の全ツール定義再送信、セッション再開時のツールリスト書き換え、MCP 再接続タイミング差によるキャッシュミスなど多数修正
  • 大規模セッション再開（5MB超）: 並列ツール呼び出しとフック出力が再読み込み時に欠落する問題を修正
  • /compact 後の再開: 「Continue from where you left off.」の不正なターンが挿入されなくなる
  • セキュリティ修正: バックスラッシュを含むマーケットプレースエントリパスが macOS/Linux の containment チェックを回避できる問題を修正
  • メンバ設定のフェイルセーフ: 読み取れない managed allowedHttpHookUrls 等が「何でも許可」ではなく「何も許可しない」ように修正
  • tmux/ssh 再接続後: shift+enter と option+backspace が効かなくなる問題を修正
  • Remote Control: サーバー認証情報失効（約30日）で全セッションが切断される問題。ホストが再登録して継続するように
  • usage-limit 警告の点滅: モデルやモード違いのリミット窓で警告が点滅する問題を修正
  • VSCode 拡張: 循環親リンクのあるトランスクリプトで拡張ホストが 100% CPU でハングする問題、WSL2/WSLg でのスクリーンショット貼り付け、CRLF ファイルの diff 編集失敗、@-メンションのスペース入りパス欠落など多数修正
  • Claude Code on the web: GitHub Enterprise Server セッションでトークン失効時にアカウントが切断表示になる問題、Claude GitHub App のない組織で gh 呼び出しが失敗する問題を修正
