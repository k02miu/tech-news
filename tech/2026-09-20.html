🧠 Claude Code — v2.1.278

対象期間内（2026-09-19 12:19 JST 公開）に v2.1.278 がリリースされました。auto mode の分類器がサーバーサイドで動くように変更された点が中心です。

🔧 新機能・改善

  • auto mode の既定がサーバーサイド分類器に: Claude API および Enterprise ユーザー、ならびに Bedrock・Vertex・Foundry・各種ゲートウェイ経由の利用において、auto mode の分類器がサーバー側で実行される構成が既定となりました。サーバーサイド分類器は分類器自体のオーバーヘッドに対して課金されません。Bedrock・Vertex・Foundry・ゲートウェイでは CLAUDE_CODE_AUTO_MODE_SERVER=0 でオプトアウトできます。課金対象のフォールバックへ切り替わる場合は警告が表示されます（詳細: auto-mode-classifier-billing）。
  • /status に Auto mode server 行を追加: 現在のセッションの auto mode 分類器がサーバー側で動作しているかどうかを /status で確認できるようになりました。

🐙 OpenClaw — v2026.9.5

対象期間内（2026-09-19 10:55 JST 公開）に v2026.9.5 がリリースされました。4,179 のプルリクエスト・64 の直接コミット・502 の貢献アカウントを含む大型リリースです。

🔧 新機能・改善

  • Atomic Updates（アトミック更新）: 対応する更新経路では、現行の Gateway を稼働させたままプライベートコピー上で次バージョンを検証し、問題なければ切り替えて更新後のインストールを検証します。失敗時はデータと設定の互換性が保たれていれば旧バージョンへ復旧できます。ただしアプリケーションのロールバックはデータベースのマイグレーションを巻き戻せないため、更新前の検証済みバックアップが別途必要です。
  • Gateway を再起動せずにプラグインをインストール: 稼働中の Gateway を止めずにプラグインの導入が可能になりました。
  • 会話の共有とアーカイブ: 会話を共有できるようになり、古い履歴は圧縮してアーカイブし後から開き直せます。ストレージ管理は Settings から行えます。
  • GPT Live: ミーティングや電話に GPT Live を組み込めるようになりました。
  • ブラウザページの並行作業: エージェントと並んでブラウザページ上で作業できるようになりました。
  • 専門エージェントチームのガイド付きセットアップ: chief of staff・researcher・writer・reviewer といったロールを選び、承認を経てチームを作成できます。Web UI の「New agent」からも同じロールを提案形式で利用できます。
  • Linux 更新チャンネル: Linux コンパニオンの最新版として v2026.9.5 が配信されています。

⚠️ 補足

  • Android の APK は対象バージョンではスキップされました（apps/android/version.json が 2026.8.2 のまま）。
  • 検証情報は npm パッケージ openclaw@2026.9.5、リリース SHA ec9c1a13db8938e5a3eaa51fca2e981cde2395a9 として公開されています。
