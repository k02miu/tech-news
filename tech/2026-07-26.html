🧠 Claude Code — v2.1.219

Claude Opus 5を既定のOpusモデルとして追加したほか、サンドボックス、MCP、stream-json、サブエージェント運用などを強化しました。

🔧 新機能・改善

  • Claude Opus 5: 1Mコンテキスト対応のclaude-opus-5を追加し、既定のOpusモデルに設定しました。
  • サンドボックス: 非許可ホストへの接続を確認なしで拒否できるsandbox.network.strictAllowlistを追加しました。
  • フックとstream-json: DirectoryAddedフック、MCP接続エラー情報、深い階層のサブエージェント転送を追加しました。
  • ワークフロー: 動的ワークフローの規模目安を設定できるようにし、サブエージェントの既定ネスト深度を3に拡張しました。

🐛 主な修正

  • claude -pでAPIエラー発生時に既生成の回答が失われる問題を修正しました。
  • MCP接続失敗時のHTTPステータス・エラー表示、モデルピッカー、Remote Control、GNU screenのコピー操作などを改善しました。
