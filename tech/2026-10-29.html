🐋 Orca — v1.4.243

2026-10-28 13:08 JST 公開。Orca のブラウザで Chrome 拡張機能（実験的）が使えるようになり、ターミナルのエージェントを終了した会話をそのまま Chat で継続できるようになりました。再起動後のワークツリー復元の高速化、ターミナル安定性の改善も含みます。

🔧 新機能・改善

  • Chrome 拡張機能（実験的）: Chrome ウェブストアの「Add to Orca」から拡張機能を追加でき、Bitwarden や 1Password などのパスワードマネージャーが Orca のブラウザ内でログイン入力に使えます。既定はオフで、ローカルのブラウザプロファイルにのみ適用。広告ブロッカーはインストールできるもののブロックは未対応、Tampermonkey など一部拡張は動作しません。
  • ターミナルのエージェントセッションを Chat へ継続: ターミナルで Claude や Codex を終了しても、同じ会話を Chat で継続可能。ターミナルタブは開いたまま残ります。Claude のチャットはモデル変更をまたいでも承認設定を保持し、動作中のチャットを閉じる際は確認が出ます。
  • ワークツリーの復元高速化: ローカルワークツリーをターミナル復元より先に読み込み、検出中は空リストではなくサイドバーに進行中の表示を出します。
  • ターミナルの安定化: Windows ターミナルは幅変更をまたいで履歴を保持、スリープしたターミナルは離脱時のフォルダで復帰、macOS 標準 bash は DEBUG トラップ変更後もコマンド追跡を維持、リモートホスト上の pi からのコピーがクリップボードに届くよう修正。
  • オーケストレーション: ワーカーのハートビート間隔を選択、またはオフに設定可能。待機済みワーカーのコマンドポーリングを止めて CPU 使用量を削減。既存ワーカーは従来の間隔を維持します。
  • UI・その他: ネイティブ風のコンパクトメニュー、VS Code 風の Markdown ハイライト（見出しのスティッキー表示）、Settings のプロキシ経由でのアップデート確認。Quit / Stop All Sessions、チャット内の数式、行範囲指定の Copy Remote URL、ターミナルの IME ハイライト、Windows の fnm、日本語・中国語翻訳の修正も含まれます。
  • モバイル／Web: スマートフォンにライト／ダークテーマ、折りたたみ iPhone Duo 対応、Quick Look での PDF 表示、チャットのコピーボタンを追加。多くの画面がデスクトップと同じルールに従うようになり、長いチャットの入力・スクロールも高速化しました。

⚠️ アップグレード時の注意

  • 新しいターミナルは新しいターミナルホストで起動します（今回のターミナル修正を反映するため）。更新前に開いていたターミナルは、閉じるまで旧ホスト上で動作を継続します。
  • ブラウザ拡張機能を使うには Settings → Experimental → Browser extensions を有効化して再起動が必要です。

🔧 主な変更

  • 4階層ツリー（4LT）ScaNN ベクトルインデックス: PostgreSQL 17 以降で、最大100億行のベクトルを扱える 4LT ScaNN インデックスをサポート。自動インデックスメンテナンスにも対応します。
  • ストリーミング動作: scann.satisfy_limit を relaxed_order に設定すると、LIMIT 句を満たすまで追加のリーフパーティションを検索し、フィルタ付き検索の再現率が向上。並列スキャン向けに scann.enable_parallel_satisfy_limit も用意されています。
  • Vector assist: 埋め込み生成、クエリ最適化、HNSW などのベクトル型インデックス作成を含め、本番向けベクトル検索の構築・管理を簡素化。
  • インデックス規模の拡大: PostgreSQL 17 以降で num_leaves の上限が 30,000,000 から 104,857,600 に拡大。
  • 外部検索連携: external_search_fdw 拡張で Elasticsearch / Solr / OpenSearch に接続し、データベースから直接クエリ可能に。
  • 全文検索: PostgreSQL 17 以前向けに rum 拡張をサポート。位置情報をインデックスに保持し、フレーズ検索と関連度ランキングを高速化します。
  • 修正: ScaNN 4階層インデックス構築時のメモリ使用量推定を精度向上し、OOM を防止。
