🧠 Claude Code — v2.1.191

対象期間内に Claude Code の v2.1.191（pubDate: 2026-06-25 07:16:33 UTC = 2026-06-25 16:16:33 JST）がリリースされました。前号で報じた v2.1.187（大型）と v2.1.190（後追いパッチ）に続く本号の1本は、/rewind の新機能追加と、バックグラウンドエージェントの「復活」バグ修正、MCP 信頼性・CPU 使用率削減など運用体験を磨く内容が中心です。

✨ 新機能・改善

  • /rewind が /clear 左右に対応: /clear 実行前の会話ポイントまで巻き戻して再開できるようになりました。直前のクリアで失われた文脈を取り戻す手段が追加
  • サンドボックス network パーミッションの記憶: ネットワーク許可ダイアログで "Yes" を選んだホストが同一セッション内で記憶され、接続のたびに再プロンプトされなくなりました
  • MCP server reliability 強化: tools/list・prompts/list・resources/list の capability discovery が一時的なネットワークエラーを短いバックオフで再試行するように
  • MCP OAuth 改善: discovery・token リクエストが一時的なネットワークエラー後に1回再試行。ヘッドレス環境ではブラウザポップアップをスキップし直接 paste-the-URL プロンプトへ遷移
  • MCP エラーメッセージ改善: HTTP 404 エラーが該当 URL を表示し MCP 設定へのヒントを提示
  • vim モードのプロンプト履歴検索（NORMAL /）: スラッシュコマンドへの到達方法をヒント表示するよう改善
  • ストリーミング応答の CPU 使用率を約 37% 削減: テキスト更新を 100ms 単位に coalesce
  • 長時間セッションのメモリ増加を抑制: ターミナル出力キャッシュに起因するメモリ成長を削減

🐛 主な修正

  • バックグラウンドエージェントが停止後に「復活」するバグを修正 — タスクパネルから停止したエージェントが再起動される問題を解消。停止は恒久的になりました
  • ストリーミング応答中に過去出力を読んでいるとスクロール位置が下に飛ぶ問題を修正
  • /voice が組織ポリシーで無効化時に汎用 "not available" でなく制限理由を表示 するよう修正
  • /login URL が Windows Terminal で行折り返し時に切れて開かれる問題を修正
  • Ghostty 上 ssh/tmux越しのフルスクリーンで Cmd+click がリンクを開かない問題を修正
  • claude agents がビルトインスラッシュコマンド（/usage 等）をバックグラウンドセッションにプロンプトテキストとして送信する問題を修正 — ヒントを表示
  • claude agents のジョブ行がペースト画像の完全ファイルシステムパスを表示する問題を修正 — [Image #N] プレースホルダーに
  • カンマ区切りの matcher を持つ hooks（例: "Bash,PowerShell"）が暗黙に発火しない問題を修正
  • /permissions Recently-denied タブ: 否認を承認しても close 時に暗黙破棄される問題を修正 — 永続化
  • agent panel のロスターがオーバーフロー上限を超えてスクロールすると1行分ジャンプする問題を修正
  • デフォルト 80×24 macOS Terminal ウィンドウで welcome splash アートが溢れる問題を修正
  • managed settings: forceRemoteSettingsRefresh を MDM・file policy 経由で設定した場合に反映、かつ fetch が Cache-Control: no-cache を送信しプロキシの古いレスポンスを防止
