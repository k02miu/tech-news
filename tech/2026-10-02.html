🧠 Claude Code — v2.1.287

2026-10-02 03:14 JST 公開。プラグインがより深い挙動まで改変できる「Claude Mods」機構の導入を筆頭に、MCP の URL プロンプト対応、画面読み上げモードの大量修正、Bedrock / Vertex / Foundry での 1M コンテキスト既定化などを含む大型リリースです。

🔧 新機能・改善

  • Claude Mods: プラグインがより深いレベルの挙動を変更できるようになりました。
  • 「You should know」組み込み mod: サイドエージェントが見落としがちな点を監視して指摘する組み込み mod が追加されました。/plugin enable cc-plugin-you-should-know@builtin で有効化します（テレメトリが有効なファーストパーティセッション向け）。
  • agents ビューの絞り込み: n:<text> フィルタでセッション名とタスクを照合できるようになり、折りたたまれたセクション内の一致も表示され、Enter で最初の一致を開けます。
  • OpenTelemetry の user_prompt イベント: ドット付きキーを入れ子にするバックエンド向けに、prompt の複製である prompt_text が追加されました（prompt を破棄・マスクする箇所では同様の扱いが必要です）。
  • MCP サーバーからの URL プロンプト: 2025-11-25 プロトコルで、サインインなどのための URL プロンプトに対応しました。更新後にサーバーへ接続できなくなった場合は、その MCP 設定に "bareElicitationCapability": true を追加します。
  • セルフホストランナーの gh api: GitHub CLI が未インストールの macOS / Linux でも、Anthropic 管理の git を使うセッション向けに組み込みの gh api（REST のみ）が利用可能になりました。
  • 1M コンテキストの既定化: Bedrock・Vertex・Foundry・Claude apps ゲートウェイにおいて、Opus 4.7 以降と Fable が [1m] サフィックスなしで 1M コンテキストを使うようになりました（CLAUDE_CODE_DISABLE_1M_CONTEXT=1 で 200K を維持）。
  • agents の応答がキュー投入型に: claude agents からの応答はキュー投入メッセージとして届き、ターン実行中に送った /stop 以外のスラッシュコマンドはターン終了時に実行されます。
  • /config の操作改善: 値を循環させる設定は ‹ › を表示して ←/→ で双方向に移動でき、狭いターミナルではラベルの下に値を積んで表示、PgUp/PgDn でページ送りできます。
  • /memory と /skill: /memory は左右の矢印キーで Auto-memory などのオン／オフを切り替えられます。メッセージ途中で入力した /skill 名は、disable-model-invocation のものを含めてスキルであると Claude に伝わるようになりました。
  • プラグイン関連の改善: マーケットプレイスのエラーが、無視・拒否された理由と対処を平易な言葉で説明します。依存が未インストールの場合はプラグイン一覧に表示され、プラグイン更新時に未完了のインストールを再試行します。

🐛 主な修正

  • Remote Control: 再接続要求への応答が無いまま数分間メッセージを受信できなくなる問題を修正。30秒で諦めて再試行するようになりました。macOS では Mac がアイドルスリープするとターン途中で停止する問題も修正されています。
  • フック: asyncRewake のスクリプトファイルが存在しない場合に「found issues」通知で Claude を繰り返し起こし続ける問題を修正。壊れたフックは1回だけ報告されます。
  • 危険な rm の保護: / やホームディレクトリを対象とするコマンドが、出力を ~ やワイルドカードへリダイレクトした場合に「常に確認」の保護を失う問題を修正しました。
  • モデルフォールバック: claude -p や SDK セッションで、応答実行中にモデルを切り替えた後、以降の毎メッセージでフォールバックが繰り返される問題を修正。Bedrock / Vertex の起動時モデルチェックが強制 availableModels リストを無視し、/model が Opus 1 行に潰れる問題も修正されました。
  • セッション復帰: 再開やコンパクション後にフォルダの CLAUDE.md が二重に添付される問題、コンパクション中に再起動したクラウドセッションで以前の会話が失われる問題、エージェント終了時に worktree が削除されて claude agents から再オープンできない問題を修正。
  • 画面読み上げモード: 検索ボックスやサインイン用コード入力でカーソルが入力テキストから離れる問題、ファイル編集承認プロンプトの変更行が読み上げられない問題、承認プロンプトに無効な「Tab to amend」ヒントが出る問題、/permissions や /mcp で動作しない矢印キーを案内する問題など、多数を修正しました。
  • MCP: サーバーが対応プロトコルバージョンを変えた際にツール呼び出しが二重実行される／再起動まで失敗する問題、ヘッドレスセッションで1回の拒否後に認証要否を誤報告する問題を修正。大きな MCP 結果を JSON として Read の offset/limit でページングするよう誤って指示していた問題も修正されました。
  • Windows: 入力がパイプ／リダイレクトされた際に Raw mode is not supported でハング・クラッシュする問題を修正し、理由を表示して終了するように（パイプ入力には -p を使用）。Bash ツールはコマンドごとに走っていたサブシェルを除去して高速化されました。
  • ファイル転送: クラウド／Remote Control セッションで 30 秒のタイムアウト直後に完了したアップロードが失敗する問題を修正（35 秒待機）。タイムアウト・ネットワークエラー・502/503/504 では1回再試行され、8,000 ピクセル超の PNG/JPEG/WebP は縮小コピーが送信されます。
  • その他: リモートセッションで fast mode がオフのままになる問題、Claude in Chrome のブラウザピッカーが JSON パースエラーを表示する問題、HTTP プロキシ配下で claude remote-control の登録に失敗し誤った権限エラーになる問題などを修正しました。
