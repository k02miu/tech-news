🧠 Claude Code — v2.1.332

v2.1.332 が 2026-11-25 10:37 JST に公開されました。MCP サーバー由来のスキルを扱う新しい仕組みと、スキル読み込み時のフック、マルチクラウドでのモデル既定値の更新が中心ですわ。

🔧 新機能・改善

  • MCP サーバーのスキル（ベータ）: MCP サーバーが提供するスキルを / メニューに server:skill 形式で表示。既存スキルは従来の名前のままです。
  • PreSkillShellCommand フック: スキルやコマンドの読み込み時、そのインラインシェルコマンドを拒否できる新しいフックイベント。なお 2.1.331 以前では、この名前を記述した設定ファイルを開くと起動時にダイアログが出ます。
  • セッション間メッセージ: 他セッションからの保留メッセージのプロンプトに「Always deliver」を追加。
  • モデル不一致の可視化: フラグ付きメッセージのセッションが別モデルで動いている間、/model で選び直すまでフッターに表示し続ける行を追加。
  • OpenTelemetry: 応答ログ有効時、SendUserMessage や Cowork のメッセージツール経由のテキストに対する assistant_response イベントを追加。
  • VS Code / Desktop: セッションの一部が保存できなかった場合の警告（/compact での保存方法を案内）、再開セッションの過去メッセージが読み込まれなかった旨の通知、プラグイン管理行へのインストール済みバージョン表示を追加。
  • モデル既定値の更新: Google Cloud の Agent Platform と Microsoft Foundry で sonnet エイリアスを Sonnet 5.5 に、Foundry の opus を Opus 5.5 に変更。Foundry の既定モデルも Sonnet 5.5 になりました（Amazon Bedrock の sonnet は Sonnet 4.5 のまま）。
  • 自動モード: Bedrock Mantle／Agent Platform／Foundry へ移されたターミナル・VS Code セッションで、モード未指定なら auto モードで開始するよう変更（disableAutoMode で無効化可能）。
  • --model default: 指定モデルが使えない場合にエラー停止せず、古いモデルへフォールバックするよう変更。
  • macOS の computer use: 新しい安全規則に更新され、一部の操作が拒否され、入力が遅くなる場合があります。computer-use は予約済みスキル名になりました。
  • 音声入力（タップモード）: マイクを維持する時間を延長（無音60秒または最大10分、従来は15秒／2分）。プロンプト送信時や編集開始時には停止します。
  • 自己ホストランナー: CLAUDE_CODE_OAUTH_TOKEN の接頭辞が oat02- も取るようになりました。プロキシ規則やログのマスク設定で oat01- を前提にしている場合は見直しが必要です。

🐛 主な修正・挙動変更

  • 破壊的な確認（エージェント視点の /clear など）で PgUp／Home が「No」に移動するよう変更。
  • Microsoft Foundry で Claude Sonnet 4／Opus 4／Opus 4.1 を retired 扱いにし、それらを指すピンには廃止の警告を表示。
  • awsCredentialExport が無限待機せず 10 分でタイムアウトするよう修正。
  • Desktop の Code タブで、ゲートウェイ指定と併用する自前設定内の claude 以外で始まるモデル id や 200K 未満の CLAUDE_CODE_AUTO_COMPACT_WINDOW を無視するよう変更。

🐙 OpenClaw — v2026.11.10 / v2026.11.9

v2026.11.10 が 2026-11-25 14:42 JST に、v2026.11.9 が同日 09:47 JST に公開されました。v2026.11.10 は 7,671 の PR・349 名のコントリビュータを束ねる大型リリースで、Deep Research・Knowledge・ブラウザ引き継ぎという三つの目玉機能が入っていますわ。

🔧 v2026.11.10 の主な内容

  • Deep Research: 複数の Web ソースやローカル文書を横断して調査し、引用付きレポートを返す機能。既定で有効（ポータブルエンジン、既存モデルと Web ツールを使用）。ソースが対立する場合は引用を並べて提示し、未解決点を明示します。Gateway 再起動をまたいだジョブ再開と、7日間のレポート保存に対応。Google のマネージド研究エンジンはオプトインです。
  • Knowledge: 会話・会議・メモ・ファイルを、人物・プロジェクト・決定・根拠抜粋からなるローカル Markdown Vault に変換するメモリプロバイダ。オプトイン（plugins.slots.memory を "knowledge" に設定）。Gateway 再起動なしでホットリロードし、既存の memory-core データはそのまま保持。Control UI のエクスプローラとプロジェクト Timeline から検索・追跡でき、改訂・撤回・統合はローカル Git チェックポイントで履歴を残します。
  • Browser handoff: エージェント操作中のブラウザタブでサインイン・2FA・CAPTCHA・機密フォームに当たった際、「Take control」で自動操作を一時停止して手動対応し、「Release control」で返せる機能（無入力5分で自動返却）。Chrome 設定やパスワードマネージャをエージェントに露出せずに開けます。
  • Quick Start の常駐化: オンボーディング端末を閉じても Gateway をバックグラウンドサービスとして継続。npx／dlx 経由のセットアップでも、パッケージランナーのキャッシュ削除後にサービスが動作し続けます。
  • プロバイダ設定の検証: Settings → Models で API キー保存時に即時検証し、成功なら確定・失敗なら理由を表示してフォームを開いたままにします。初回プロバイダ保存時はそのまま新しいチャットを開始できます。
  • セットアップ改善: GitHub Copilot を既定プロバイダ一覧に追加、Ollama／LM Studio が起動済みでモデル未ロードの場合の誤判定を修正、gateway install 後は Gateway 起動まで待機。

🔧 v2026.11.9 の主な内容（パッチ）

  • プロンプトキャッシュ: Anthropic のセッションフォーク（Advisor レビューや /btw）が独自サフィックスでキャッシュチェックポイントを書かないよう修正。OpenAI Responses のフォークも親会話のキャッシュを再利用できるよう、キャッシュキー・ホストツール・reasoning 設定を揃えました。
