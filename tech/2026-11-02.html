🟠 Hono — v4.13.16（セキュリティ修正）

2026-11-01 12:10 JST 公開。ルーティングとミドルウェアの適用範囲に関わる 2 件のセキュリティ問題が修正されました。同日、これに先立って v4.13.15（2026-11-01 11:02 JST 公開）もリリースされています。

🔒 セキュリティ修正

  • mount() がマウント接頭辞内のミドルウェアを回避しうるパスを転送: hono/mount の mount() と app.mount() が対象。動的な接頭辞（/api/:tenant/* など）がルートパターンの長さ分だけ除去され、転送パスが URL パーサで再正規化されることで、デコードされた \ が / になり .. が畳み込まれていました。両者が組み合わさると、細工したリクエストがマウント接頭辞内のミドルウェアをスキップできました。/assets* のようなルートやパラメータ名の重複は例外を投げるようになりました（GHSA-4m76-xfj5-7975）。
  • RegExpRouter が特定のルートパターンでワイルドカードミドルウェアをスキップ: RegExpRouter（既定の SmartRouter を含む）が対象。ミドルウェア側のパスにのみ {[^/]+} と書かれたパラメータ、/prefix* ルートと /prefix/* ミドルウェアの併存、エンコードされた改行文字を含むパスの 3 ケースでワイルドカードミドルウェアが適用されていませんでした。RegExpRouter は他のルーターと同じルートを対象とするようになり、{[0-9]*} のように空文字列にマッチしうるカスタムパターンは UnsupportedPathError を投げます。PreparedRegExpRouter の再生成が必要です。

🐛 主な修正（v4.13.15）

  • 認証: WWW-Authenticate の realm 内のバックスラッシュをエスケープ。
  • コンテキスト: レスポンスボディの消費後に c.header() を呼べるように修正。
