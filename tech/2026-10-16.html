🧠 Claude Code — v2.1.301

対象期間内に v2.1.301（2026-10-16 04:52 JST 公開）がリリースされました。OpenTelemetry による可観測性の拡充、mod（プラグイン）API の細かな整備、VSCode 拡張の使い勝手向上が中心です。

🔧 新機能・改善

  • 無人リトライの待機上限を制御: 環境変数 CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS が追加されました。無人リトライモード（CLAUDE_CODE_RETRY_WATCHDOG）において、利用上限のリセットが遠すぎる場合は待ち続けずにリクエストを終了できます。
  • OpenTelemetry の判定情報を拡充: tool_decision イベントに classifier_verdict と permission_mode が追加され、自動モードの分類器による判断と権限ルールによる判断を区別できるようになりました。あわせて classifier_category も追加され、OTEL_LOG_TOOL_DETAILS=1 のときに分類器がブロックした組み込みルール名が分かります。
  • claude-api スキルのトレーシング指針: claude-api スキルに OpenTelemetry トレーシングのガイダンスが追加され、ant CLI でトレース送信先を設定する手順も含まれます。
  • vim モードの % モーション: 対応する括弧へジャンプする % が vim モードに追加されました（単独、または d/c/y と組み合わせて使用可能）。
  • mod の複数行入力: mod の Input に rows が追加され、ターミナル上で複数行のテキストフィールドを扱えます。Enter で送信、Shift+Enter または Enter 前のバックスラッシュで改行します。
  • モデル切替時のコンテキスト処理: コンテキストウィンドウが小さいモデルへ切り替える際、新モデルに対して長すぎる会話は先に旧モデルで要約されるようになりました。
  • 描画パフォーマンス: 長時間稼働するサブエージェントの進捗表示が、毎回全体を再処理するのではなく差分更新されるようになりました。
  • [VSCode] LaTeX 数式レンダリング: Claude の応答で LaTeX 数式が描画されます（$$、複数行の \[ … \]、インラインの $…$ と \(…\) に対応）。あわせて Pro / Max プラン向けに、利用上限バナーへ「Get more usage」リンクが追加されました。
  • mod の $.env.set とフックの .catch: $.env.set は変数の設定／解除が済むと {} で解決し、書き込みが行われない場合は理由を示す { deny } を返すようになりました。また mod フックの .catch はフックが例外を投げたかタイムアウトした場合のみ実行されます。
  • アーティファクトと mod の表示改善: Claude が書き出すページが、スティッキーヘッダー上の帯を塗るようになり、モバイルアプリでスクロール時にテキストが透けなくなりました。mod では VS Code・デスクトップ／モバイルアプリで質問ダイアログ上部のツリーが Markdown と最大48行を保持できます（ターミナルは従来どおり12行）。

🤖 Hermes Agent — v0.22.2

対象期間内に v0.22.2（2026-10-15 17:21 JST 公開）がリリースされました。v0.22.1 が誤ったコミットからビルドされ未リリースのゲートウェイ作業を含んでいたため、それを正した版です。既知の問題として、v0.22.1 のゲートウェイで動いたセッションは v0.22.2 では削除できない点が挙げられています。

🔧 新機能・改善

  • 再起動後にゲートウェイが起動するように: 再起動後、Linux が早期の PID を無関係なプロセスへ割り当てると、ゲートウェイが稼働中と誤認し、systemd / launchd / Docker 配下の監視対象ゲートウェイが起動を拒否される問題が修正されました。起動したブートを記録し、判別できない場合は稼働中ゲートウェイのみが保持するホストロックに問い合わせます。
  • ノート PC でのローカルモデル実行の安定化: ローカルリクエストは常にプロンプト読込の進捗を伴ってストリーミングされ、ストール判定タイマーはマシンがスリープしていた時間を除外します。復旧したローカルサーバーは再度試行され、長い会話をサーバーが読み込んでいる間の圧縮がタイムアウトしなくなりました。Windows のユニファイドメモリ機では、モデル起動とプロンプトキャッシュが空きメモリに合わせて調整されます。
  • モデル関連: nemotron super 3.5 の既定パラメータ、NVIDIA NIM の既定モデル一覧への nemotron 追加、モデルピッカー上部への厳選モデル一覧表示が入りました。
  • プラグインカタログ: 韓国語デスクトップ言語パック（hermes-lang-ko）、ブラジルポルトガル語パック（hermes-lang-pt-br）、TeamoRouter、author-feed、wait-ledger などが追加され、aux-ledger は 1.4.0 に更新されました。
  • リリース基盤: Microsoft Store バンドルが専用の windows-store レーンに分離され、安定版リリースのビルド／テスト内容をレーンで選択できるようになりました。
