🧠 Claude Code — v2.1.271

対象期間内に v2.1.271（9月15日 07:22 JST 公開）がリリースされました。リモートセッションの fast mode、サンドボックス時のコマンド単位 allowed_domains、サブエージェントの CLAUDE.md 読み込み制御などが追加され、Bash パーミッションチェックまわりの修正が多数含まれています。

🔧 新機能・改善

  • リモートセッションの fast mode: Claude Code Remote（クラウド／セルフホストランナー）で fast mode が利用可能に。ホスト側の設定、またはセッション内で入力した /fast が組織の許可範囲で適用されます
  • /config パネルのマウス操作: フルスクリーン表示時にホイールで設定リストをスクロール、値のクリックで変更、ポインタ位置の行がハイライトされます
  • コマンド単位の allowed_domains: サンドボックス併用の auto モードで、Bash・PowerShell・Monitor の各コマンドが必要とするホストをコマンドと一緒にレビューし、そのコマンド専用に開放。他のホストは拒否されます
  • omitClaudeMd: エージェントの frontmatter と --agents JSON で指定でき、カスタム／プラグインのサブエージェントがユーザー・プロジェクト・ローカルの CLAUDE.md を読まずに動作します（マネージドポリシーファイルは引き続き読み込み）
  • プラグイン導入の検証強化: claude plugin install と update に --accept-command <sha256> を追加。-y の代わりに、直前の --json 実行が表示したコマンドを正確に承認できます
  • 課金レートのカスタマイズ: マネージド設定 modelPricing とゲートウェイの pricing ブロックで、1〜10 の multiplier（社内チャージバック用の上乗せ率）が指定可能に
  • セルフホストランナー: claude self-hosted-runner --drain-marker-file <path> を追加。SIGTERM ドレイン時に指定ファイルが存在すれば、ホストドレインとして終了を報告します（テレメトリ用途）
  • 描画・起動の性能改善: 大きな差分や長いトランスクリプトの描画が高速化し、起動時の組み込みモデルデータの冗長な検証をスキップして起動時間を短縮
  • フックのフィードバック改善: SessionStart / UserPromptSubmit / PreToolUse / SessionEnd フックの実行中はスピナーに実行中である旨と経過時間を表示し、Esc で待機中のプロンプトをキャンセルできます
  • 動的ワークフロー: 利用上限に達した際は一時停止し、リセット後に自動再開するようになり、対象エージェントが失われなくなりました

🐛 主な修正

  • アカウント・組織・API キーを切り替えた後もキャッシュされた組織ポリシーが再利用され、毎時のチェックまで更新されない問題を修正
  • 組織ポリシーの読み込み完了後やセッション途中の変更がツール／コマンド一覧に反映されない問題を修正
  • 読めない・解析できない企業向け managed-mcp.json が無視されていた問題を修正。排他的な MCP 制御を維持し、起動時に警告を表示します
  • クラウドセッションで worker 再起動後に承認が適用されると、すべてのサブエージェントのツール呼び出しがスキーマ検証エラーで拒否される問題を修正
  • 組織が fast mode を無効化している場合に /fast off が「Fast mode unavailable」と応答してしまう問題、および CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK 利用時に毎ターン fast リクエストを再送する問題を修正
  • Bash パーミッションチェックが、認識されないオプションの後に続くファイル（fmt・column など）を見落とす問題、および grep -v dir/* file のようにワイルドカードがパターンやオプション値にある場合に展開先ファイルをスキップする問題を修正
  • サンドボックス化されたコマンドの起動失敗後に残る .git/config.lock が、そのセッション中の git checkout -b や git push -u を壊す問題を修正（Linux）
  • MCP サーバーが list_changed を高頻度で送り続けると CPU 使用率が高止まりし、ツール一覧リクエストが繰り返される問題を修正
  • MCP OAuth のクライアント登録の不整合（同意拒否での再登録強制、別 redirect URI の登録の再利用、並行書き込みによる有効登録の削除）を修正
  • ToolSearch が使えない状況で Claude in Chrome のプロンプトが ToolSearch 経由のツール読み込みを指示してしまう問題を修正
  • コンテキスト圧縮後に、まだ動作中のバックグラウンドコマンド（watch タスクや開発サーバー）を Claude が二重起動する問題を修正
  • フルスクリーンモードで /resume と /continue が短い端末で 1〜2 件しか表示されない問題、--resume 時に 1M コンテキスト（[1m]）が失われる問題を修正
  • /resume・/teleport が前の会話のファイル読み取り追跡を引き継ぎ、再開した会話が読んでいないファイルを編集できてしまう問題を修正
  • VSCode 拡張: Hooks／Permission rules ダイアログの保存結果が誤って失敗と表示される問題、セッション一覧のフィルタ不具合、新規チャットが直前のチャットに戻る問題などを修正
  • 端末終了時にケイパビリティ問い合わせの応答（^[[?1;2c）がシェルプロンプトやエディタに表示される問題を修正
