🧠 Claude Code — v2.1.193

対象期間内に Claude Code の v2.1.193（pubDate: 2026-06-26 00:33:59 UTC = 2026-06-26 09:33:59 JST、期間開始から34分後）がリリースされました。前号の /rewind × /clear・MCP 信頼性強化・CPU 37% 削減を詰め込んだ v2.1.191 に続く今号の1本は、auto-mode の分類対象拡張・可観測性の強化・バックグラウンドエージェントの信頼性向上が中心で、MCP 認証・プラグイン自動リネーム・bash 操作系の細かい改善も揃っています。

✨ 新機能・改善

  • autoMode.classifyAllShell 設定を追加: Bash / PowerShell コマンドを「任意コード実行パターン」だけでなくすべて auto-mode classifier に通すようルーティング可能に
  • auto-mode の否認理由を記録・表示: 否認理由がトランスクリプト、否認トースト、/permissions の recent denials に記録されるように。何を・なぜ止めたかを後から追跡可能
  • claude_code.assistant_response OpenTelemetry ログイベント: モデル応答テキストを OTel に送信。デフォルトで redact され OTEL_LOG_ASSISTANT_RESPONSES=1 でのみ有効化、未設定時は OTEL_LOG_USER_PROMPTS に従う。注意: 既に prompt content をログ取得しているデプロイはアップグレードで自動的に応答も取得し始めるため、prompts-only を維持したい場合は OTEL_LOG_ASSISTANT_RESPONSES=0 を明示的に設定すること
  • bash モード（!）にライブファイルパス補完を追加
  • MCP サーバが認証を必要とする場合の起動通知: 起動時に /mcp への導線を提示
  • アイドル中のバックグラウンドシェルコマンドをメモリ圧迫時に自動 reaping: CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1 で無効化可能
  • バックグラウンドエージェント起動時の挙動を改善: 起動結果メッセージが Claude に「response を end する」よう指示しなくなり、エージェント実行中も他のタスクを継続できるように
  • MCP headersHelper 認証の自動再接続: ツールコールが 401/403 を返した際、helper が自動で再実行・再接続
  • プラグイン自動リネーム追従: marketplace の renames マップに従って自動であなたの settings を新名称に更新
  • /add-dir のメッセージを改善: 指定ディレクトリが既に作業ディレクトリである場合の案内を明瞭化

🐛 主な修正

  • /model などクライアントデータ依存 UI が /login 直後に古い/空の状態を表示する問題を修正
  • バックグラウンド化（←←）が誤ってキャンセルされる問題を修正 — 全実行タスクが新セッションに引き継がれるのに「N 個のバックグラウンドタスクが放棄されます」と表示されるケース
  • ピン留めされたバックグラウンドエージェントが毎 auto-update 後に「Continue from where you left off」で再プロンプトされる問題を修正
  • メインターンのバックグラウンド化で「general-purpose (resumed)」の幽霊サブエージェントが生成されメイン会話を再実行してしまう問題を修正
  • サブエージェント表示時にエージェントパネルが兄弟エージェントを隠す問題を修正
