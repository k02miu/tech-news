🧠 Claude Code — v2.1.286

2026-10-01 04:19 JST 公開。権限プロンプトの使い勝手、フルスクリーン表示、認証・ログイン周り、サブエージェント、クラウドセッション、VSCode 拡張まで幅広く手を入れた大型リリースです。

🔧 新機能・改善

  • 権限プロンプトの件数表示: 複数の権限リクエストが溜まったとき、プロンプトに「2 of 5」のような進捗カウントが表示されるようになりました。
  • フルスクリーンでのマウス操作: リストの「N more」行をクリックしてリストの端へジャンプできるようになり、ホバー／押下状態も表示されます。
  • commit 前の verify スキル: プロジェクトまたはユーザーのスキルに verify という名前のものがある場合、コミット直前に実行するよう Claude に指示されます（ドキュメントのみ・テストのみのコミットを除く）。
  • 外部エディタ（Ctrl+G）: 行番号を受け取るエディタでは、プロンプト内のカーソル行で開くようになりました。
  • 出力スタイル／テーマピッカー: 出力スタイルは「Default」ではなく現在のスタイルで開き、説明が名前の下の行に表示されます。テーマピッカーはターミナルに収まるスクロールリストになりました（いずれも数字キーでの選択は廃止）。
  • /hooks の刷新: イベント別にグループ化した1つのリストで開くようになり、フックの確認が Enter 1回で済みます。
  • フォールバック通知の明確化: フォールバックでコンテキストウィンドウが 1M から 200K に縮小した場合、その旨を通知するようになりました。
  • --bare の挙動変更: コマンドラインで指定した MCP サーバーのみを接続し、モデルへシステムリマインダーを送らず、バックグラウンドタスクも開始しません。タイムアウトしたシェルコマンドはバックグラウンドへ移行せず停止します。
  • リトライ方針の変更: 1つのモデル呼び出し全体で上限を管理するようになり、既定設定では失敗した呼び出しの送信は最大14リクエストに抑えられます。
  • [VSCode] ブックマーク: Claude の応答を保存し、Bookmarks サイドパネルで見続けられるようになりました。質問カードの回答履歴や選択肢プレビューも追加されています。

🐛 主な修正

  • 認証・ログイン: gcpAuthRefresh / awsAuthRefresh の資格情報失効時に、複数の Claude Code プロセスや IDE 拡張がそれぞれログイン用ブラウザを開いてしまう問題を修正。macOS で /login 成功後も「Not logged in」と表示される問題も修正されました。
  • セッション復元: claude --resume / --continue で、並列ツール呼び出しのバッチ後にセッションがクラッシュ・強制終了されると以降のターンが失われる問題を修正。
  • API 400 エラー: ツールやフックがテキスト以外（オブジェクト・数値・真偽値）を返した場合に 400 エラーになる問題を修正（再開セッション含む）。
  • MCP: 再認証成功後も「MCP servers require authentication」が繰り返し表示される問題、サーバーが旧ハンドシェイクを切った後最大1日ツールが列挙されない問題、再サインイン要求が保留中のリンクを上書きして壊す問題などを修正。
  • シークレットのマスキング: エラーメッセージに Bearer/Basic 資格情報の値が表示される問題、パーセントエンコードされたトークンが部分的にしか隠されない問題、ゼロ幅スペースなど不可視文字を含むキー名のシークレットが露出する問題を修正。
  • サブエージェント: タスク追跡ツール（TaskCreate/Get/Update/List、TodoWrite）がフォアグラウンドのサブエージェントで欠落する問題、worktree 分離時に CLAUDE.md とその import を二重ロードする問題、接続停滞時に元のプロンプトで再起動される問題などを修正。
  • /compact・/clear・/rewind: バックグラウンドエージェントのトランスクリプト表示中に入力すると、無言でメイン会話に作用してしまう問題を修正。対象を明示して確認するダイアログが表示されます。
  • モデルフォールバック: 既定モデルまたはモデルエイリアスが Anthropic API に拒否された場合に全ターン失敗する問題を修正。同一ティアの旧モデルで1回だけ再試行します。
  • リモートコントロール: 組織ポリシーで Remote Control が無効化された後も接続が残る問題、終了中に届いたメッセージが配信済み扱いになり応答されない問題を修正。
  • クラウドセッション: 回答済みの質問カードや承認済みツール呼び出しへの返信が来ない問題、履歴が非常に大きいセッションが復帰しない問題、ルーチン実行が「Succeeded」と誤表示される問題などを修正。
  • Windows: 信頼記録の大文字小文字が異なる場合に claude --bg がフォルダを拒否する問題を修正。

🐙 OpenClaw — v2026.9.7

2026-09-30 13:44 JST 公開。負荷時の応答性と長い会話のなめらかさを改善し、更新時のバックアップとロールバック保護を強化したリリースです。2026.9.5 からのアップグレード修正も含みます。リリース規模は 2,818 プルリクエスト・518 直接コミット・344 コントリビュータです。

🔧 新機能・改善

  • オンボーディングの高速化: セットアップが最初の質問に早く到達し、サインイン・ペアリング・インストールで注意が必要な場合の案内が明確になりました。openclaw setup --baseline --skip-bootstrap は選択を記憶し、既存ファイルを保持します。

  • Windows ホストでデスクトップアプリ再起動後、Codex ターミナルでのスマホのスワイプが誤入力を起こす問題を修正。
