🧠 Claude Code — v2.1.331

2026-11-24 06:40 JST 公開。マルチクラウド環境での Code Mode 対応拡大、Claude apps gateway の運用系オプション追加、VSCode 拡張の編集支援強化が中心のリリースですわ。

🔧 新機能・改善

  • Code Mode の対応環境拡大: Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、AWS 上の Claude Platform のターミナルセッションで Code Mode が利用可能に。
  • gateway のグループ読み取り: oidc.groups_jsonpath を追加。JSONPath（RFC 9535）のサブセットで、オブジェクト配列の該当エントリからグループを読み取れます。
  • claude doctor の接続診断: API 到達可否と HTTP ステータスまたはエラー内容、実施しなかった場合はその理由を表示するセクションを追加。
  • 音声入力の停止通知: タップモードの音声ディクテーションが15秒間の無認識、または2分の上限で自動停止した際に通知。
  • CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION: 圧縮レスポンスを途中で切るプロキシ向けに非圧縮応答を要求。セルフホストランナーや Remote Control では未推奨。
  • トレース属性の拡充: claude_code.llm_request スパンに gen_ai.usage.*、gen_ai.response.model、gen_ai.operation.name を追加。gen_ai.usage.input_tokens はプロンプトキャッシュ分を含みます。
  • プラグインの optionalDependencies: マニフェストで任意依存を宣言でき、単独で無効化・アンインストール可能に。
  • VSCode 拡張: 「Add Cell to Chat」（セルと出力／エラーを添付）、「Fix with Claude Code」クイックフィックス、Source Control の変更ファイル右クリック「Add to Chat」、「Resolve Merge Conflicts」を追加。

🔁 主な変更

  • /ide の自動接続停止や /clear・/compact・/rewind の確認で「Yes」を先頭に表示（初期選択は従来どおり No）。
  • PermissionDenied フックの retry: true は、利用者がその呼び出しを要求した場合に限り再実行する挙動に変更。
  • 2026-11-30 以降、マネージド設定の extraKnownMarketplaces のプラグインマーケットプレイスが既定で自動更新に。除外するには "autoUpdate": false を設定。
  • Windows: レジストリのマネージド設定は HKLM ポリシーが managed-settings.json より優先されるため、アップグレード前に確認が必要。

🐙 OpenClaw — v2026.11.7 / v2026.11.10-beta.2

🔧 v2026.11.7 の主な内容

  • 会話の復旧: Gateway 再起動をまたいで中断された応答と子エージェントの結果を失わずに復元。
  • 自動化の信頼性: 自動化のオーナー会話から失敗を修復でき、復旧済み・意図的スキップと真の失敗を区別。
  • 更新処理の堅牢化: スキーマ変更・DB ビジー・復旧状態の保持があっても Git／パッケージ更新を完了。
  • Gateway の応答性: 低速なファイルシステム操作や大きな復旧パック処理中も、チャットやヘルスチェックが応答し続けるよう改善。
  • ブラウザペアリング: Gateway ホストで承認する短いコードによる別ブラウザのペアリングに対応。
  • ChatGPT カタログ: 新規サブスクリプションモデルを OpenClaw のリリースを待たずに検出可能に。
  • 破壊的変更（SDK）: セッションキー付き setActiveEmbeddedRun(...) の登録方法と、chatAbortControllers／chatQueuedTurns への直接アクセスが変更されました。

🔧 v2026.11.10-beta.2 の主な内容

  • 更新の復旧: パッケージ置換が中断しても OpenClaw を実行可能な状態に保ち、クラッシュや再起動後も次の更新を安全に完了。
  • バックグラウンド処理: 完了したサブエージェント結果を保持し、Gateway 再起動・親ターンの中断後も配信を再開。
  • 初回会話の高速化: モデルカタログ読み込み中でも最初のチャットを受け付け、長い履歴を Gateway メモリに全保持せず圧縮。
  • プラグインのサイド質問: プラグインがセッションのライブコンテキストをフォークし、独自ツールとポリシー制御下でバックグラウンド作業を実行可能に。
  • Webhook: 最大 1 MiB のボディを受け付け、拒否理由を報告し、Gmail 通知のバッチを分配。
  • 修正: SecretRef 値が平文で上書きされる問題、再起動復旧をまたぐ権限境界、チャット配信の取りこぼしなどを修正。
