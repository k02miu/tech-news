🧠 Claude Code — v2.1.211

2026年7月16日 09:32 JST に v2.1.211 がリリースされました。30件以上の修正・改善を含む大規模なアップデートです。

🔧 新機能・改善

  • --forward-subagent-text フラグ追加: CLAUDE_CODE_FORWARD_SUBAGENT_TEXT 環境変数とともに、サブエージェントのテキストと思考内容を stream-json 出力に含めることが可能に
  • 整数環境変数の入力形式拡張: タイムアウト値やトークン予算などの整数環境変数が科学表記（1e6）や桁区切り（64_000）を受け付けるように
  • 「常に許可」ルールの保存場所変更: リポジトリルートに保存するようになり、git worktree をまたいで承認が永続化
  • Vim モード改善: s / S（文字/行の置換）が NORMAL モードで動作するように（vim の挙動に準拠）
  • ターミナルレイアウト・レンダリング性能の改善
  • バックグラウンドエージェントの結果報告改善: 実行中のエージェントのステータスを報告し、実際の完了を待つように（結果の捏造を防止）
  • メモリインデックスの超過警告改善: frontmatter と HTML コメントを除いた実コンテンツのみを計測

🐛 主な修正

  • セキュリティ修正: パーミッションプレビューで双方向オーバーライド文字・ゼロ幅文字・類似引用符が中和されない問題を修正（ツール入力が承認メッセージを視覚的に改変できる脆弱性）
  • auto mode × PreToolUse フック: フックの ask 決定を auto mode が上書きしていた問題を修正（フックの ask が最低でもプロンプトを表示するように）
  • 並行セッションの一斉ログアウト: スリープ復帰時に複数の Claude Code セッションが同時にログアウトする問題を修正
  • プラグイン MCP サーバー再接続: アイドル状態の Web セッション復帰後に MCP サーバーが再接続されない問題を修正
  • Vertex / Bedrock モデル指定: モデルが明示的に設定されている場合にデフォルト Opus を試行しスプリアスなフォールバック通知が表示される問題を修正
  • サブエージェントモデル継承: 明示的なモデルオーバーライドで生成されたサブエージェントが再開時に親モデルに戻る問題を修正
  • ファイルアップロード検証: DOS デバイスサフィックス（.prn）や末尾ドット付きファイル名の受付、複数ハードリンクファイルの拒否
  • プロンプトキャッシュ回帰修正: Bedrock・Vertex・Mantle・Foundry で後続のシステムコンテキストブロックが毎回新規入力トークンとして課金される問題を修正
  • headless print-mode セッション: Windows で stdin が読めない場合のクラッシュ・サイレント終了を修正
  • /clear 後のコストカウンターリセット: ステータスラインのコストが /clear 後に $0 から開始されるように
  • バックグラウンドジョブの auto-respawn 防止: ユーザーが kill したバックグラウンドエージェントが自動復活する問題を修正
  • Claude in Chrome: ファイルアップロードパス検証の強化、save_to_disk がスクリーンショット画像を実際にディスクに書き込むように
