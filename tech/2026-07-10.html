🧠 Claude Code — v2.1.206

対象期間内に 1件のリリース（v2.1.206）が公開されました。バックグラウンドエージェントの改善、操作性向上、多数のバグ修正を含む安定化リリースです。

🔧 新機能・改善

  • /cd のパス補完: /cd にディレクトリパスのサジェスト機能を追加（/add-dir と同様の動作）
  • /doctor の CLAUDE.md 診断: チェックイン済みの CLAUDE.md ファイルから Claude がコードベースから導出可能な冗長内容を削除する提案機能を追加
  • /commit-push-pr のプッシュ自動許可: リポジトリに設定された push リモート（remote.pushDefault、または単一リモート時はそのリモート）への git push を自動許可（origin に加えて拡張）
  • Gateway: パブリックゲートウェイ対応: /login が Anthropic 運営のパブリックゲートウェイエンドポイントをサポート
  • EnterWorktree の安全性強化: プロジェクトの .claude/worktrees/ 外にある git worktree に入る前に確認ダイアログを表示
  • バックグラウンドエージェントの即時アップグレード: Claude Code 更新後、バックグラウンドエージェントがアタッチ時ではなく即座に新バージョンへアップグレード（遅延解消）
  • /code-review 品質向上: claude-opus-4-8 使用時のコードレビュー精度を全 effort レベルで改善
  • agents view の表示改善: ステータス列が64文字で切り詰められず、ターミナル幅を最大限使用するように改善
  • agents view の操作性変更: Ctrl+X で完了セッションを恒久的に削除可能に。セッションの二重表示を解消し、削除したバックグラウンドジョブは確実に削除されるように修正

🐛 主な修正

  • ログイン期限切れ: ログイン切れ時に「選択されたモデルに問題があります」という誤解を招くエラーではなく、/login 実行を促す適切なメッセージを表示するように修正
  • claude --resume / --continue: 起動時にキーボード入力が効かなくなる問題を修正
  • MCP サーバーのタイムアウト: --mcp-config や .mcp.json で設定された MCP サーバーが、サーバーごとの request_timeout_ms を無視して新鮮なセッションで60秒のデフォルトタイムアウトになる問題を修正
  • CLAUDE_CODE_EXTRA_BODY: バックグラウンドワーカー（claude agents / --bg）で環境変数が黙って無視される問題を修正（dispatching セッションに追従するように）
  • OAuth MCP サーバー: トークンリフレッシュが1回失敗するだけで手動再認証が必要になる問題を修正
  • --permission-prompt-tool のクラッシュ: MCP サーバーが接続完了する前のコールドスタート時に「MCP tool not found」でクラッシュする問題を修正
  • /model ピッカーの修正: 別のモデルの価格を誤表示する問題と、課金しないプロバイダで定価を表示していた問題を修正。エンタイトルメント制限による行の配置ずれも修正
  • Bedrock: 起動ハング修正: エグレス制限のあるネットワークで awsCredentialExport ヘルパー使用時に数分間ハングする問題を修正
  • デスクトップセッションのスタック: ターン途中でスラッシュコマンド送信後に「running」表示のまま固まる問題を修正
  • Windows: agents view: ベアの claude --resume 前にセットアッププロンプトが表示されるとキーボード入力が無視される問題を修正
  • claude rm: 削除したジョブが daemon ロースターに残り claude agents で再表示される問題を修正
  • /remote-control: ログアウト時に「Unknown command」と表示される問題を修正し、サインイン方法を表示するように改善
  • LSP プラグイン: 実際には診断・ナビゲーションリクエストに応答している LSP プラグインが誤って「不使用」と判定される問題を修正
  • /doctor の Homebrew チェック: アップデート確認を settings チャンネルではなく cask のチャンネルと比較するように修正
  • フルスクリーンのショートカット表示: macOS で Ctrl+End を提案せず、リバインドされたコードを表示し、トランスクリプトを覆わないように修正
  • その他、Windows のキーボード入力、フルスクリーン、workflow ビューの矢印操作、/status の重複警告など多数の修正を含む
