🤖 Hermes Agent — v0.23.1

v0.23.1（2026-11-10 10:42 JST 公開）は、v0.23.0 以降に取り込まれた約 618 件の PR を安定版としてまとめたパッチリリースです。CLI／インストーラ、Microsoft Store アプリ、Docker、Hermes Cloud が対象で、詳細なキュレーション済みノートは v0.24.0 で公開される予定です。

🔧 新機能・改善

  • プラグインカタログの上限を 16 MiB へ拡大: 11 月 9 日のプラグインカタログ配信以降、公開された plugin-catalog.json がクライアントの 2 MiB 上限を超えていたため、すべてのインストールが同梱カタログへ静かにフォールバックしていました。本リリースで上限が 16 MiB に引き上げられ、ライブカタログが再び使用されます（#151860、#151856 を修正）。
  • hermes plugins install の挙動が正常化: 直前の更新以降に追加されたプラグインが見つからない、リリース同梱のピンがインストールされる、新しい removed エントリが反映されない、といった問題が解消されます。v0.23.0 以前に留まる環境では、更新するまでフォールバックが続きます。
  • その他の内容: TUI／CLI の Esc バックトラック、Desktop を介さないゲートウェイ上のグループチャット、Desktop と Webapp で共有される保存済みゲートウェイ接続、hermes gateway attach、hermes clipboard image --json、新しいプラグイン API（セッションスコープの環境値、JSON-RPC メソッドとイベント、llm.oneshot 補助タスク、圧縮に強い conversation_id、on_session_open／post_curator_run フック）などが含まれます。

⬆️ アップデート方法

  • Microsoft Store 版: Store 経由で更新。
  • インストーラ版 Desktop: 本リリースでは変更なし。次回のバンドルリリースで更新されます。
  • CLI: hermes update、またはインストーラのワンライナーを再実行。
  • Docker／Hermes Cloud: nousresearch/hermes-agent:stable（または :latest）。

🐙 OpenClaw — v2026.11.3 / v2026.9.37

対象期間内に 2 件のリリースが公開されました。最新版は v2026.9.37（2026-11-11 05:42 JST 公開）で、これは extended-stable 用のゲートウェイ限定リリースです。通常系列の最新は v2026.11.3（2026-11-11 03:53 JST 公開）です。

🔧 新機能・改善（v2026.11.3）

  • プライベートなタスク結果: サブエージェントの非公開の完了内容が、ストリーミングされるチャット返信に混ざらないようにしました（#188490）。
  • 子タスクの引き継ぎを確実に: 子タスクをキャンセルした後、キャンセル済みタスクの完了レシートが引き継ぎをブロックせず、親が代替作業へ移れるようにしました（#178893）。
  • ツール失敗の可視化: 応答のないツール失敗を、成功として黙ってターンを終えるのではなく報告します（#182458）。
  • 認証の時間制限: 停止したプロバイダー認証を実行期限で打ち切り、キャンセルを認証処理全体へ伝播します（#189144）。
  • サンドボックス内の画像アクセス: Full Access モードでも、必須サンドボックスの画像プレビューを許可フォルダ内に留め、管理者による明示的な画像許可は維持します（#176203）。
  • ワークスペース接続の検証: 空のフィンガープリントが渡された場合に保存済みのノード証明書ピンを保持し、ワークスペース転送の証明書を資格情報やデータ送信前に検証します（#125646、#190002）。
  • Gateway の高速化: 起動時のモジュールファイル読み込みのオーバーヘッドを削減し、中断コマンド検出が長い句読点の連続に遭遇した際の停止を回避します（#192217、#184433）。

🐛 主な修正（v2026.11.3）

  • 資格情報の分離: 再利用・キャッシュされたプラグイン結果を接続資格情報のスコープ内に限定し、他プラグインのトランスポートフックをプロバイダーのオリジン上に保持します。
  • 検索・メモリの資格情報: Firecrawl の検索／スクレイプキーをスコープ済みエンドポイントと共に保ち、埋め込み資格情報を送信先と結び付けます。
  • 資格情報の伏字化: 設定読み出し時のインライン環境資格情報、および Exa エラーに反映される検索資格情報を伏字化します。
  • 子プロセスの環境: 管理対象の Signal デーモンや同梱ランゲージサーバーが、無関係な Gateway のシークレットを継承しないようにしました。
  • 認証エラー: 資格情報の読み取り失敗を「資格情報なし」として扱わず、エラーとして表面化します。

🐋 Orca — v1.4.256

v1.4.256（2026-11-11 06:31 JST 公開）は、音声入力（ディクテーション）の初期設定を簡略化し、スマートフォン側の下書き復元とワークスペース操作を強化したアップデートです。スマホ関連の改善の一部は、対応するスマホアプリの更新が必要です。

🔧 新機能・改善

  • ディクテーションの設定簡略化: 言語に応じたオンデバイスモデルを音声設定が提案し、セットアップを 1 ボタンで実行できます。個人用・リポジトリ用の語彙を追加でき、フィラーワードの除去、ショートカットの長押し／タップ切り替えを選べる Auto モードも用意されました。オンデバイス認識は区切りで逐次挿入され、Orca 内ブラウザの入力欄にも音声入力できます。
  • 続きから再開: スマホアプリを再起動しても、再接続中にチャットの直近メッセージが表示されます。コミットメッセージ、PR 説明、コメント、レビューノート、タスク、新規ワークスペースの下書きがアプリ終了後も残ります。
  • スマホからの操作拡張: ターミナルのキー行に Shift・Ctrl・Alt のラッチと、エージェント操作をまとめた Smart レール（任意）を追加。画面を移動しながら話し続けられるフローティングのディクテーションピルも加わりました。
  • チャットからエージェントを準備: 未導入の対応エージェントは、チャット開始位置でインストールとサインインの案内を表示します。OpenCode のサブエージェントは専用カードに表示され、作業中もチャットを維持。Codex の返信はリワインド後にフォークできます。
  • UI の整理: ブラウザのツールは Annotate ボタンと 1 つのメニューに集約。設定画面はスキャンしやすくなり、レシピベースの VM ワークスペースは Suspend／Resume 付きでライフサイクルを表示します。

🐛 主な修正

  • 音声モデルの更新をディクテーション開始時に提案し、ダウンロード進捗・キャンセル・再試行に対応。GPU 使用スイッチ、モデル品質情報、OpenAI 互換の文字起こしサービスにも対応しました。
  • ディクテーション中に Send／Enter を押した場合、入力済みの語が確定するまで送信を待つようにしました。
  • ホーム画面は最後に使用したワークスペースで開き、訪問済みのターミナルはマウントを維持して切り替えを高速化。フォルダワークスペースはスマホ側で Source Control を利用でき、大きなファイルの差分でも未変更行が保持されます。
