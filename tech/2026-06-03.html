🧠 Claude Code — v2.1.161 / v2.1.160

📦 v2.1.161 (June 2, 2026)

テレメトリ・エージェント管理・並列実行・Linux クリップボード対応など多岐にわたる改良が行われました。

🔧 新機能・改善

  • OTEL リソース属性: OTEL_RESOURCE_ATTRIBUTES の値がメトリクスデータポイントのラベルとして含まれるようになり、チームやリポジトリなどのカスタムディメンションで使用量をスライス可能に
  • claude agents 表示改善: ファンアウト時に done/total を表示、peek で最長実行中のアイテムを表示
  • /mcp 改善: 一度もサインインしていない claude.ai コネクタを折りたたみ表示に
  • 並列ツール呼び出しの独立性: 同一バッチ内の Bash コマンドが失敗しても他ツールはキャンセルされず、各ツールが独立して結果を返すように
  • Linux クリップボード強化: フルスクリーンモードで wl-copy/xclip/xsel 対応、クリップボードと PRIMARY selection の両方にコピー、ネイティブ選択キーのヒント表示修正

🐛 主な修正

  • Managed Settings 修正: forceLoginOrgUUID/forceLoginMethod がサードパーティプロバイダー（Bedrock, Vertex, Foundry, Mantle）セッションをブロックしていたリグレッションを修正（v2.1.146 での退行）
  • stdout 破損修正: バックグラウンドサブエージェントの出力が claude -p の --output-format text/json の stdout を破損していた問題を修正
  • OpenTelemetry ログ: テレメトリ初期化完了前に user_prompt, api_request, tool_result, tool_decision ログイベントが欠落していた問題を修正
  • /effort ダイアログ修正: 「Reduce motion」設定が /effort ダイアログ、ワークフローアニメーション、プロンプトキーワードに反映されていなかった問題を修正
  • Windows 修正: bash を明示的に呼び出すフックの失敗を修正、WSL でのクリップボード修正（PowerShell 相互運用）、IME 表示位置修正
  • セッション復元修正: --resume で git worktree 外のディレクトリからセッションが表示されない問題を修正、完了済みサブエージェントが実行中表示のままになる競合を修正
  • パフォーマンス: レイアウトエンジン JIT コンパイルの安定化、大規模ファイル書き込みのレンダリング改善
  • [VSCode] ターミナル GPU アクセラレーション無効化または /terminal-setup 実行を提案するチップを追加

📦 v2.1.160 (June 2, 2026)

🛡️ セーフティ機能追加

  • シェル起動ファイル保護: .zshenv, .zlogin, .bash_login および ~/.config/git/ への書き込み前にプロンプトを表示（意図しないコマンド実行を防止）
  • ビルドツール設定ファイル保護: acceptEdits モードで .npmrc, .yarnrc*, bunfig.toml, .bazelrc, .pre-commit-config.yaml, .devcontainer/ などコード実行権限を付与するファイルへの書き込み前にプロンプト表示
  • edit 最適化: grep/egrep/fgrep の単一ファイル検索結果が read-before-edit チェックを満たすように（Read の二度手間を削減）

🐛 主な修正

  • バックグラウンドセッション安定性: 復元済み完了セッションがチャット履歴を失う問題、一晩でリタイア後に復帰したセッションが会話を失う問題、claude --bg のコールドスタート失敗を修正
  • エージェント一覧のフリーズ修正: auto-updater が毎回再チェックすることで claude agents が数秒フリーズする問題を修正
  • Windows CPU 高負荷時の応答性: ホストが高 CPU 負荷時の Esc・矢印キー・タイピング無反応を修正
  • 音声モード修正: プロジェクトディレクトリやブランチ名に非ASCII文字や特殊文字が含まれる場合の接続失敗を修正
  • auto mode 改善: ルーティンアクションの推論を削減しレイテンシ改善、「could not evaluate this action」ブロックを低減
  • バックグラウンドセッション終了改善: claude rm/stop、アイドル刈り取り時に SIGTERM → SIGKILL の順で子プロセスを終了（クリーンアップハンドラが実行されるように）
  • その他: CJK IME 表示位置、vim モードの p ペースト位置、file:///C:/... リンクの Windows での破損、CJK 端末での出力マーカー表示の問題など多数の修正
