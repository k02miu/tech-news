🧠 Claude Code — v2.1.183

6/19 10:27 JST にリリースされた v2.1.183 では、auto モードのセキュリティ強化と多数のバグ修正が含まれます。破壊的な git コマンドや IaC の destroy 操作に対する安全ブロックが導入されたことがハイライトです。

🔧 新機能・改善

  • auto モードのセキュリティ強化: git reset --hard、git checkout -- .、git clean -fd、git stash drop など、ローカル作業の破棄を伴う git コマンドが auto モードでブロックされます。また、git commit --amend はエージェントが作成したコミットでない場合にブロック、terraform destroy/pulumi destroy/cdk destroy は明示的な指定がない限りブロックされます
  • 非推奨モデルの警告: リクエストされたモデルが非推奨、または新しいモデルに自動更新された場合に stderr に警告を表示。print モード（-p）および agent frontmatter のモデル設定にも対応
  • attribution.sessionUrl 設定: Web や Remote Control セッションでコミット・PR から claude.ai セッションリンクを省略可能に
  • /config --help: /config key=value の利用可能なショートカットキー一覧を表示
  • /config トグル動作変更: Enter と Space 両方で設定変更、Esc で保存して閉じる（以前はリバート）
  • スタートアップ簡素化: ロゴ下の「setup issues」行を削除。代わりに /doctor で確認可能に

🐛 主な修正

  • サブエージェント spawn 時の 400 エラー修正: thinking.disabled.display 設定に起因する「Extra inputs are not permitted」エラーを解決
  • サブエージェントの WebSearch 空結果修正: サブエージェントで WebSearch が空の結果を返す問題を修正
  • Windows Terminal の TUI 腐敗修正: ネストされたサブエージェント負荷時のステータスライン中間表示、スピナー行の重複、テキストのマージを修正
  • thinking ブロックのみのターン修正: モデルが thinking ブロックのみ返した場合にターンがサイレントに完了する問題を解決。Claude が再プロンプトするように
  • tmux チームメイトペイン修正: シェルの rc ファイル初期化が遅い場合のペイン起動失敗と、エージェント spawn 中のキーストロークリークを修正
  • スケジュールタスク/Webhook トリガー修正: auto モードで保留中のアクション承認やセッションタイトル設定ができなくなるよう、キーボード入力として分類されないように修正
  • MCP 認証サーバー修正: ヘッドレス/SDK モードで auth-stub ツールがモデルに公開される問題を修正
  • vim モードのヒストリカーソル修正: ネイティブカーソル有効時、vim モードでヒストリナビゲーション後にプロンプト上にカーソルが残る問題を修正

🤖 Hermes Agent — v0.17.0「The Reach Release」

6/19 リリースの v0.17.0 は、v0.16.0 から約1,475コミット・800マージPRに及ぶ大規模アップデートです。iMessage 対応、Raft エージェントネットワーク統合、デスクトップアプリの大幅強化、バックグラウンドサブエージェント、画像編集機能、Automation Blueprints など多数の新機能が含まれます。

✨ ハイライト

  • iMessage 対応（Photon Spectrum）: Mac リレー不要で iMessage の送受信が可能に。Photon のマネージドラインプールを利用し、hermes photon login でデバイスコード認証のみ。BlueBubbles の後継として位置づけ
  • Raft エージェントネットワーク: Raft へのゲートウェイチャネルとして参加。Wake チャネルブリッジ経由で外部エージェントとして接続し、プライバシー契約設計でメッセージ本文は送信されない
  • デスクトップアプリの大幅強化: リバインド可能なキーボードショートカット、ネイティブ OS 通知、ライブサブエージェントウォッチウインドウ、コンポーザーモデルセレクター、自動 RTL/双方向テキスト、リサイズ可能な VS Code テーマターミナルパネル、VS Code Marketplace テーマのインストール対応
  • バックグラウンド/非同期サブエージェント: delegate_task(background=true) でサブエージェントをバックグラウンドで即座にディスパッチ。完了時に結果が会話に新しいターンとして戻る
  • 画像編集（image-to-image）: image_generate がソース画像の編集・変換に対応。背景除去、スケッチからレンダリングへの変換などが同じツールで可能に
  • Automation Blueprints: cron 構文を学ぶことなく自動化をスケジュール。名前を選択するだけで必要な情報を Hermes が質問。ダッシュボード、CLI、メッセンジャー、ドキュメントで統一的に表示
  • Cursor Composer モデル対応: xAI Grok サブスクリプション経由で grok-composer-2.5-fast（200k コンテキスト）を利用可能に
  • ダッシュボードのフルプロファイルビルダー: ブラウザからモデル選択、スキル設定、MCP サーバー接続を完結。マルチプロファイル管理をワンビューに統合
  • Skills Hub ブラウザ刷新: 接続ハブ、Featured セクション、インストール前のフルプレビュー、セキュリティスキャンを搭載した新 UI
  • memory ツールのバッチ操作: operations 配列によるアトミックな一括編集（add/replace/remove）。文字数制限を超過してもスペースを確保しつつ新規追加が可能に
  • セキュアなダッシュボードログイン: OAuth ゲート、WebSocket 認証の強化、public_url オーバーライドの警告追加
  • WhatsApp Business Cloud API 公式対応: Meta の第一者 API 経由で WhatsApp に対応。QR スキャン不要
  • Telegram リッチテキスト（Bot API 10.1）: ネイティブマークアップでのリッチメッセージ配信。デフォルトで有効
  • キュレーターコスト最適化: 通常のバックグラウンド運用品キュレーションがゼロトークンに。LLM による統合パスは opt-in に変更
