🧠 Claude Code — v2.1.214

2026年7月18日 10:29 JST に v2.1.214 が公開されました。権限チェックの安全性を高める修正を中心に、長時間ツール呼び出し、OpenTelemetry、バックグラウンドセッション、Windows の PowerShell 周辺まで幅広く改善しています。

🔧 新機能・改善

  • EndConversation ツール: 迷惑行為や jailbreak 試行が続くセッションを Claude が終了できるように
  • 長時間ツールの進捗通知: これまで無言になっていた長時間実行中のツール呼び出しに、定期的な heartbeat を追加
  • メモリの更新日時: memory ファイルの frontmatter に ISO 形式の modified タイムスタンプを追加
  • OpenTelemetry の相関情報: ログイベントに message.uuid、client_request_id、tool_source を追加し、CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH で内容の切り詰め上限を設定可能に
  • 推論情報の拡張: subagentStatusLine にモデルと reasoning effort を追加
  • Docker 権限プロンプト: daemon リダイレクト用オプションを含む docker / Podman コマンドに確認を要求

🐛 主な修正

  • 権限チェックの安全性: dir/** の許可ルールが想定外の階層まで書き込みを自動許可する問題、Windows PowerShell 5.1 のバイパス、Bash のリダイレクト・長大コマンド・zsh 構文の誤判定を修正
  • 危険なコマンドの自動許可: 特定の help / man / file コマンドが安全と誤認される問題を修正
  • バックグラウンドセッション: daemon のソケット競合、アイドル後のプロセス残留、完了セッションの削除不能、非 Git フォルダーからの削除失敗などを修正
  • ストリーミングと SDK: corporate proxy 配下の Socket クローズ、遅い consumer での stream-json 切り詰め、累積 message_delta によるコスト・トークン二重計上を修正
  • Windows の安定性: PowerShell の標準入力待ち、非 UTF-8 入力、非 ASCII 出力、リダイレクトによる UTF-16LE ファイル生成などを修正
  • その他: GrowthBook の null 評価によるクラッシュ、MCP 更新時のリソース消失、スケジュール済みタスクの信頼性、フックの終了コード 2 の扱いを修正
