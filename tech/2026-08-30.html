🐋 Orca — v1.4.192

8月29日 17:18 JST に v1.4.192 がリリースされました。前版 v1.4.191（全ホストのオートメーション管理）に続き、マルチエージェントオーケストレーションの回復性強化と、UI・ワークスペース・モバイルにわたる幅広い改善が含まれます。

🔧 新機能・改善

  • リモート HTML ドキュメントのプレビュー: リモート接続先の HTML ドキュメントを Orca 内で直接プレビュー可能に
  • ネストされたワーカーの深度: マルチエージェントオーケストレーションでネストワーカーの深度を表示・ホスト間で伝播させ、深すぎる実行を適正に制御
  • 巨大 Markdown ファイルの回避策: サイズ超過のリッチ Markdown ファイルに対し「Open anyway」ボタンを追加
  • 親 worktree の選択: ワークスペース作成時に親 worktree を選択可能に。フローティングワークスペースでもタブのドラッグ並べ替えに対応
  • チェック実行のコピー: チェック実行（check run）詳細セクションにコピーボタンを追加
  • i18n 強化: スキルインストールのダイアログやエラーメッセージを翻訳対象に
  • GitLab 改善: タスクページの Issue を 50 件超もページネーションで取得。AI 生成の PR 説明が空でも PR 作成を許容

🐛 主な修正

  • ソース管理ビューでファイル選択のたびに全 git 読み取りを再実行していたパフォーマンス問題を修正
  • ホスト間で worktree の同一性が衝突する問題、未スタンプのローカル worktree がローカルホストに解決されない問題を修正
  • 送信済みプロンプトが stalled（停止）と誤報告される問題、Orca 再起動中に発火したフックイベントが失われる問題を修正
  • Codex/WSL 関連: アカウントホームの信頼状態の保持、起動時の全セッション履歴再スキャン停止、信頼付与時のメインスレッドブロック停止
  • Enter キーでの重複ファイルリネーム、画像プレビューがレイアウト前に自然サイズで展開される問題を修正
  • モバイルでホストの worktree 保持設定を尊重するよう修正
