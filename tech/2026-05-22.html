⚛️ Next.js — canary プレリリース（5月21日〜22日）

Next.js canary ブランチにて、複数の実験的機能がデフォルト有効化されました。安定化に向けた重要なマイルストーンです。

5月22日の変更

  • experimental.varyParams デフォルト有効化: 動的パラメータに基づくキャッシュバリエーションがデフォルトで動作（#94010）
  • experimental.optimisticRouting デフォルト有効化: 楽観的ルーティングが標準動作に（#94011）
  • experimental.cachedNavigations デフォルト有効化（cacheComponents併用時）: キャッシュナビゲーションが標準で有効に（#94012）
  • App Shell プリフェッチ: サーバーサイドでの App Shell プリフェッチ対応（#93998）
  • PPR ルートの dynamicRoutes 包含: revalidate 時間に関わらず PPR ルートを dynamicRoutes に含めるように（#94025）
  • Turbopack: node_modules/next が一時的に解決不能な場合の dev server クラッシュ防止（#93877）、rustc nightly-2026-05-15 へのアップグレード（#94021）
  • --debug-build-paths の src/ 対応（#94016）

5月21日の変更

  • experimental.appShells フラグ追加: App Shell 機能のフィーチャーフラグ（#93997）
  • Prerender HTTP access fallbacks: Cache Components セマンティクスでのフォールバック対応（#93988）
  • Turbopack: サブパスインポートの外部パッケージ対応修正（#93308）、クラッシュする webpack loader のエラーレポート改善（#93926）、module-sync エクスポート条件の尊重（#93970）

推奨アクション: いずれもプレリリース（canary）のため、本番適用は慎重に検証を。varyParams・optimisticRouting・cachedNavigations のデフォルト有効化は既存プロジェクトの挙動に影響を与える可能性があるため、canary での早期テストを推奨。
