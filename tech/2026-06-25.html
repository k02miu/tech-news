🧠 Claude Code — v2.1.187 + v2.1.190（2回リリース）

対象期間内に Claude Code が2バージョン連続でリリースされました。まず v2.1.187（pubDate: 2026-06-24 00:12 UTC = 2026-06-24 09:12 JST、対象期間開始直後）がセキュリティ・組織設定・操作体験・多数のバグ修正を束ねた大型リリースとして公開され、その後 v2.1.190（pubDate: 2026-06-24 16:18 UTC = 2026-06-25 01:18 JST）が後追いで「Bug fixes and reliability improvements」のみのマイナーパッチとして発行されました。

✨ v2.1.187 の新機能・改善

  • sandbox.credentials 設定: サンドボックス実行コマンドが認証情報ファイルやシークレット環境変数を読めないようにブロックできる新設定。信頼できない/サンドボックス化したコマンドからクレデンシャルを守る
  • 組織設定によるモデル制限をモデルピッカー全経路に反映: org-configured model restrictions が --model、/model、ANTHROPIC_MODEL の全ピッカー経路に適用され、制限モデルを選んだ場合は "restricted by your organization's settings" のメッセージを表示
  • フルスクリーンモードで選択メニューをマウスクリック可能に: パーミッションプロンプト、/model、/config などをマウスで操作可能
  • /install-github-app 改善: GitHub Actions workflow セットアップをスキップ可能になり、GitHub App のインストールだけを単独で行えるように
  • /btw に ←/→ 矢印ナビゲーション: 前の回答を順にステップスルー
  • /plugin 改善: 最近使っていないプラグインを上位に表示し、クリーンアップを促進

🐛 v2.1.187 の主な修正

  • リモート MCP ツール呼び出しが無応答のまま5分間ハング — タイムアウトでエラー中断するよう変更（環境変数 CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT で上書き可能）
  • --json-schema・Workflow agent({schema}) 構造化出力: 成功済み呼び出しの後にモデルが StructuredOutput を無限再呼出しせず、追補ターンでも確実に構造化出力を返すよう修正
  • --resume が "No conversation found" で失敗 — 元の -p 実行が1回もモデル返答を生まなかった場合に生じていた
  • Claude Code Remote 起動が約2.7秒遅延 — agent proxy CA system-trust install 追加後のリグレッションを解消
  • 韓国語 / CJK のペーストが文字化け — ターミナルがペーストを per-byte 拡張キーイベントで渡す場合の修正
  • /update が Remote Control 上でハング — 起動時のトラストダイアログが表示される状況で
  • agents view のバックグラウンドジョブが "working" で永遠にスタック — 構造化出力未生成でターンを終えた場合
  • チャンネル接続のドロップ — agents view への移動と復帰、および /bg//tui//update 実行後
  • サブエージェントの depth 追跡: resumed サブエージェントは元の spawn depth を復元、forked サブエージェントも depth cap にカウントされるよう修正
  • リークした worktree 登録の自動クリーンアップ — kill されたエージェントが残した .git/worktrees/ のロックを自動解放
  • macOS Ghostty 上のフルスクリーンで Cmd+click が URL を開かない
  • claude --help に --bg/--background フラグが載らない
  • Esc / Ctrl-C / Ctrl-D が /share のアップロード中に効かない
  • VSCode 拡張が大きなセッションを resume すると無応答に
  • エージェント停止通知の帰属を修正し、「finished」/「stopped」という用語へ改善
