🧠 Claude Code — v2.1.170

Claude Code v2.1.170 がリリースされました。Anthropic が「Claude Fable 5」と名付けた Mythos クラスの新モデルへのアクセスが可能になります。Fable 5 は Anthropic が一般公開した中で最も強力なモデルと位置づけられています。加えて、セッション保存不具合の修正やバックグラウンドエージェントの改善、多数のバグフィックスが含まれています。

🔧 新機能・改善

  • Claude Fable 5 モデル対応: v2.1.170 への更新で Mythos クラスの新モデル「Claude Fable 5」にアクセス可能に。Anthropic が一般公開した中で最も能力の高いモデル
  • fallbackModel 設定: プライマリモデルが過負荷または利用不可の場合に順番に試す最大3つのフォールバックモデルを設定可能に。--fallback-model は対話型セッションにも適用
  • deny ルールの glob パターンサポート: ツール名の位置にglobパターン（"*" で全ツール拒否）を使用可能に。allow ルールは非 MCP glob を拒否し、deny ルールの未知ツール名は起動時に警告
  • クロスセッションメッセージング強化: 他の Claude セッションからの SendMessage 中継がユーザー権限を持たないように変更。受信側は中継された権限リクエストを拒否し、自動モードではブロック
  • 思考制御の改善: MAX_THINKING_TOKENS=0、--thinking disabled、モデルごとの思考トグルが Claude API 経由でデフォルト思考のモデルでも思考を無効化可能に（サードパーティプロバイダーは変更なし）
  • フォールバックモデル自動リトライ: API が予期しない非リトライ可能エラーを返した場合、フォールバックモデルで1回リトライ。認証・レート制限・リクエストサイズ・トランスポートエラーは即座に通知
  • requiredMinimumVersion / requiredMaximumVersion 管理設定: Claude Code がバージョンが許容範囲外の場合に起動を拒否し、承認されたバージョンを案内
  • /plugin list コマンド: インストール済みプラグインを一覧表示。--enabled / --disabled フィルタ付き
  • /btw のコピー機能: マークダウン回答をクリップボードにコピーするショートカット「c to copy」を追加
  • Hooks の additionalContext: Stop / SubagentStop フックが hookSpecificOutput.additionalContext を返して Claude にフィードバック可能に。ターンをフックエラー扱いせずに継続
  • スキルの \$ エスケープ構文: コマンド本文で数字の前にリテラル $ を含めるためのエスケープ構文を追加
  • stdio MCP サーバーのセッション ID 継承: --resume 時に hooks/Bash と同じ CLAUDE_CODE_SESSION_ID を受信

🐛 主な修正

  • セッション保存不具合修正: VS Code 統合ターミナルや Claude Code 環境変数を継承したシェルから起動した場合にセッションがトランスクリプトに保存されない（--resume に表示されない）問題を修正
  • claude -p ハング修正: バックグラウンドコマンドが終了しない場合の最終結果後に永久にハングする問題を修正。stdin クローズ後約5秒でバックグラウンドシェルを停止
  • Bedrock/Vertex/Foundry の claude -p 修正: CI=true で Anthropic API キー未設定時の「ANTHROPIC_API_KEY required」エラーを修正
  • Bazel / EDR 保護 Go ワークフロー修正: $TMPDIR がサンドボックス化コマンドのみではなく全コマンドに上書きされていた問題を修正（v2.1.154 のリグレッション）
  • Windows EEXIST エラー修正: OneDrive 内や読み取り専用属性を持つセッション環境ディレクトリでの「file already exists」エラーを修正
  • WebFetch 権限ルール修正: 組み込み承認済みドメインに明示的な WebFetch(domain:...) deny/ask/allow ルールが適用されるように修正
  • Windows パス権限修正: バックスラッシュや大文字小文字の異なるパスで権限ルールが一致しない問題を修正
  • JetBrains ツールバーちらつき修正: 2026.1+ の IntelliJ/PyCharm/WebStorm で同期出力を有効化しちらつきを解消
  • Kitty キーボードプロトコル修正: WezTerm/Ghostty/kitty で Shift+非ASCII文字がドロップされる問題を修正
  • 並列ツール呼び出し改善: 同一バッチ内の Bash コマンド失敗が他の呼び出しをキャンセルしなくなり、各ツールが独立して結果を返すように
