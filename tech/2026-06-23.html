🧠 Claude Code — v2.1.186

対象期間内に v2.1.186（2026-06-23 05:45 JST 公開）がリリースされました。MCP サーバの CLI 認証、ワークフローのステータスフィルタ、プラグインタブの Skills セクション追加など、多数の新機能と修正が含まれる大型リリースです。

✨ 新機能・改善

  • MCP 認証の CLI 化: claude mcp login <name> と claude mcp logout <name> を追加。対話型 /mcp メニューを開かずに CLI から MCP サーバの認証が可能。--no-browser で SSH 経由の stdin リダイレクトにも対応
  • ワークフローのステータスフィルタ: /workflows エージェント詳細ビューで f キーによるステータスフィルタリングを追加
  • プラグインタブに Skills セクション: /plugin の Installed タブに Skills セクションを追加
  • iTerm2 チームメイトモード: teammateMode: "iterm2" 設定を追加。it2 CLI が見つからない場合は警告を表示
  • AWS 認証情報リフレッシュ: awsAuthRefresh 設定時に /login に「Claude Platform on AWS - refresh credentials」オプションを追加
  • ! bash コマンドの自動応答: ! bash コマンドが Claude の自動応答をトリガーするよう変更。従来の context-only 動作に戻すには "respondToBashCommands": false を設定
  • メモリの圧縮リマインダー: MEMORY.md インデックスがサイズ上限に近づくと、エージェントに圧縮を促すリマインダーを追加
  • スキルフロントマターの柔軟化: display-name、default-enabled、fallback、metadata.* が kebab-case、snake_case、camelCase いずれも受け付けるよう改善
  • 不正な SKILL.md のハンドリング改善: YAML フロントマターが不正な場合、空のメタデータでスキル本体を読み込むよう改善（サイレント失敗を回避）
  • MCP コマンドの改善: claude mcp get と claude mcp remove がタイプミス時に最も近いサーバ名を提案し、長いサーバリストをtruncate

🐛 主な修正

  • スリープ復帰後のストリーミングリクエスト失敗（「Content block not found」や JSON パースエラー）を修正
  • サブエージェントのトランスクリプトスクロール位置が終了時にメイントランスクリプトに漏れ出す問題を修正
  • バックグラウンドタスクプレビューがエージェントのプラン読み込み前に生のツール名をちらつかせる問題を修正
  • Chrome タブグループ分離がプロダクト内パーミッションゲート無効時に並行 CLI セッションで適用されない問題を修正
  • バックグラウンドセッションの要約（recap）が重複する問題を修正。エージェント自身のターン終了要約が recap 行として表示されるように
  • Agent(type) 否認ルールと Agent(x,y) 許可タイプ制限が名前付きサブエージェント起動時に適用されない問題を修正
  • バックグラウンドエージェント実行中に Esc と Ctrl+C が応答しない問題を修正
  • パーミッションプロンプトのオプション番号がテキスト溢れ時にずれる問題を修正
  • 終了したサブエージェントで x を押しても閉じられない問題を修正
  • ~~strikethrough~~ が取り消し線ではなくリテラルチルダとして表示される問題を修正
  • --tools がコールド起動時にフィーチャーゲート前のツールを通過させる問題を修正
  • 使用量ベースの Enterprise/Team 加入者にセッションコストが表示されない問題を修正
  • エージェントチーム: tmux/pane バックエンド経由のチームメイトがリーダーの --effort レベルを継承するよう修正
  • Workflow agent({schema}) サブエージェントがスキーマ検証失敗時に無限ループする問題を修正（5回で中断）

🔄 主な変更

  • リトライ上限: CLAUDE_CODE_MAX_RETRIES の上限を15にキャップ。無人セッションには CLAUDE_CODE_RETRY_WATCHDOG を推奨
  • バックグラウンドサブエージェントのパーミッション: バックグラウンドサブエージェントが自動拒否ではなくメインセッションにパーミッションプロンプトを表示するよう変更。Esc でそのツールのみ拒否可能
  • /review の統一: /review <pr> が /code-review medium と同じレビューエンジンを使用するよう変更

🐙 OpenClaw — v2026.6.10-beta.2（ベータ）

  • フック構成時の信頼ポリシー保持: 構成されたフックレジストリが承認フローに必要な信頼ツールポリシーを保持するよう修正（#94545）

  • ファストモードのフォールバックカットオフとリセット通知がバウンドされ、繰り返し進捗イベントが可視化を維持

  • AWS Marketplace Storefront GA: パートナーが独自ブランドのソリューションカタログを数時間で作成・デプロイ可能に
