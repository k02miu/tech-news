🧠 Claude Code — v2.1.304

2026-10-20 06:50 JST に v2.1.304 が公開されました。自動モードのセットアップ支援、Managed Agents のセキュリティ照合、Code Review のレビューレベル設定などが追加されています。

🔧 新機能・改善

  • /auto-mode-setup: プロジェクトと直近のセッションを読み取り、自動モードに環境を学習させるガイド付きセットアップ。Bedrock、Vertex、Foundry、Claude apps ゲートウェイ、テレメトリ無効のセッションでも利用可能になりました。
  • /claude-api managed-agents-secure: Managed Agents エージェントの設定を Anthropic が公開するセキュリティガイドと照合します（設定は変更しません）。
  • mod の tool.check 拡張: decider: "person"（権限ダイアログかホストのコールバックのみが承認でき、誰も確認できない場面では mod の理由付きで拒否）と、読み取り専用のツール呼び出しを示す e.isReadOnly が追加されました。
  • コンパクション要約の改善: トランスクリプト表示（Ctrl+O）の圧縮サマリーに、それ以前に呼び出されたツール名が含まれるようになりました。
  • 使用量の警告: Pro / Max プランで、非アクティブな会話を再開すると5時間の使用量上限を大きく消費する場合に警告が表示されます。
  • [VSCode]: Amazon Bedrock、Google Vertex AI、Microsoft Foundry、LLM ゲートウェイ経由、テレメトリ無効のセッションでもチャットパネルに mod の描画が表示されます。バックグラウンドのサブエージェントは各ステップを流し込む代わりに、Agent カード下の1行ステータスとして表示されます（全文は /tasks）。
  • [Code Review]: 組織単位でレビューレベル（Quick / Standard＝既定 / Deep）を選べ、リポジトリごとに個別レベルも設定可能に。GitHub 組織内の全リポジトリ（後から追加されたものも含む）を個別選択なしでレビューする管理オプションも追加されました。

🐛 主な変更

  • カスタム ANTHROPIC_BASE_URL 配下でツール検索が既定で有効になりました（ゲートウェイが 400 / 422 を返した場合はツール検索なしで再試行）。
  • コンパクション後にスキル一覧を再送するようになり、/reload-skills は新規・変更分のみを送信します。スキルフックは出所（リポジトリ・自分のフォルダ・プラグイン）ごとにセッションあたり最大 1,024 フック・16,384 マッチャ文字に制限されます。
  • /artifacts の削除確認が番号選択（1 または Enter で保持、2 で削除）になりました。
  • /claude-api スキルは Claude Platform on AWS 上で SDK や curl にフォールバックせず ant CLI を使うよう更新されました。Opus 5.5 の /fast ダイアログから「(research preview)」表記が外れています。

🐋 Orca — v1.4.230

2026-10-19 15:30 JST に v1.4.230 が公開されました。実験的なネイティブチャットの拡充、アカウント切り替え時のセッション再起動、SSH・リモートワークスペースの安定化が柱となっています。

🔧 新機能・改善

  • ネイティブチャット（experimental）: Antigravity をチャットで利用可能に。どのエージェントをチャットで開くか選択でき、チャットのホストに必要なエージェントが無い場合は Install を提示します。コピーしたファイルの貼り付けが添付として扱われ、画像メッセージはテキスト同様にキューに並びます。キュー操作や添付が処理中の間はコントロールがグレー表示になり、進行状況が分かりやすくなりました。
  • アカウントとエージェント: Claude アカウントを切り替えた後、実行中のセッションを新しいアカウントで再起動できます。設定からダウンロード済みのエージェントランタイムを削除でき、Orca CLI 経由で Linear のコメントを編集・削除できます。
  • モバイル: キュー内のメッセージをその場で編集でき、デスクトップ風のカードでツール実行を追跡。履歴から再開すると会話が即座に表示されます。横向きのスマートフォンではセッションタブがトップバーに配置され、Tasks 画面で使用中のデスクトップが分かります。
  • SSH・リモートワークスペース: 切断した接続は切断のまま維持され、スリープ中のワークスペースはスリープを保ち、閉じたタブは再接続後も閉じたままになります。サーバー更新や再ペアリング時のメッセージが明確になり復旧しやすくなりました。
  • 日々の磨き込み: Quick Command のショートカットがフォーカス中の分割に追従し、タブプレビューはホバー待ち時間を経てから表示されます。ファイルヘッダに Reveal in Finder が追加され、ワークスペースのクリーンアップは他マシン上の同一パスプロジェクトをより保護するようになりました。
