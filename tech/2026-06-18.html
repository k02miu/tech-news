🧠 Claude Code — v2.1.181

6月18日 07:16 JST にリリースされた v2.1.181 は、新しい /config コマンドによる設定変更、Bun ランタイム 1.4 への更新、ストリーミング表示の改善、自動リトライの強化、そして多数のバグ修正を含む大規模なリリースです。

🔧 新機能・改善

  • /config key=value コマンド追加: プロンプトから直接設定を変更可能に（例: /config thinking=false）。対話モード、-p、Remote Control で動作
  • sandbox.allowAppleEvents 設定追加: macOS でサンドボックス化されたコマンドから Apple Events 送信を許可するオプトイン設定
  • CLAUDE_CLIENT_PRESENCE_FILE 環境変数追加: マーカーファイルを指定して、端末にいる間のモバイルプッシュ通知を抑制
  • Bun ランタイム 1.4 に更新
  • 長文ストリーミング表示改善: 最初の改行を待たずにテキストが行ごとに表示されるように改善
  • 自動リトライ改善: thinking 中の API 接続切断時に自動リトライ（「Connection closed while thinking」エラーを解消）
  • サブエージェントパネル改善: アイドル状態のサブエージェントは30秒後に自動非表示、リストは5行に制限（スクロールヒント付き）、キーボードヒントをフッターに表示
  • MCP OAuth ブラウザページのデザイン更新: Claude Code のビジュアルスタイルに合わせ、成功時に自動クローズ
  • フルスクリーンモードの URL オープン変更: Cmd+Click（macOS）/ Ctrl+Click 必須に（ネイティブターミナルの動作に合わせる）
  • 「Improved N memories」表示変更: verbose モード以外では個別ファイル名を表示しないように変更

🐛 主な修正

  • プロンプトキャッシュ読み込み修正: カスタム ANTHROPIC_BASE_URL や Foundry でのプロンプトキャッシュが、ターンごとの認証トークン変更により読み込まれなかった問題を修正
  • Write/Edit の 0 バイトファイル問題修正: ネットワークドライブやクラウド同期フォルダでファイルが 0 バイトまたは切り詰められる問題を修正
  • macOS Apple Events エラー修正: open、osascript、ブラウザベースの認証フローでエラー -600 が発生する問題を Apple Events エンタイトルメントの追加で修正
  • スタートアップ回帰修正: v2.1.169 で導入された新規環境での起動時約120ms 遅延を修正（MCP サーバー未設定時の managed-settings 取得待機を解消）
  • ネットワーク劣化時の起動ブロック修正: アカウント設定取得が遅い場合に最大15秒間ブランクターミナルでブロックされる問題を修正
  • 破損した .claude.json での起動クラッシュ修正: null のプロジェクトエントリを含む場合の TypeError: Cannot read properties of null を修正
  • macOS TUI フリーズ修正: Spotlight が再インデックス中にセッション開始でフリーズ（Ctrl+C 応答なし）する問題を修正
  • 長時間アイドルセッションの履歴消失修正: 他の Claude Code プロセスが30日トランスクリプトクリーンアップを実行した際の問題を修正
  • フォアグラウンドサブエージェントのネスト制限修正: 無制限のネストチェーンを生成していた問題を、バックグラウンドと同様の5レベル制限に修正
  • /recap とモデル切替修正: モデル切替直後に前のモデルを使用する問題を修正
  • サブエージェント「Thinking」時間表示修正: 親エージェントの経過時間を表示していた問題を修正
  • AWS 認証情報リフレッシュ修正: 短い残存寿命の awsCredentialExport 認証情報が毎分リフレッシュされる問題を修正し、aws configure export-credentials の JSON 形式を受け入れるように
  • claude mcp get/list 表示修正: tools/list が失敗しても ✓ Connected と表示されていた問題を修正
  • /remote-control 表示修正: 接続後に「connecting...」が残る問題を修正
  • ExitWorktree Windows 修正: bare git が解決できない場合の「Could not verify worktree state」エラーを修正
  • 相対シンボリックリンクでの設定変更修正: ~/.claude/settings.json が相対シンボリックリンクの場合の ENOENT エラーを修正
  • IDE コンテキスト行番号修正: IntelliJ と VS Code で行番号が1つずれる問題を修正
  • クリップボード修正（Linux / macOS）: Ctrl+C/Ctrl+V とコピー関連の複数問題を修正
  • AskUserQuestion 修正: プレビューコンテンツの切断、マルチ選択での「Other」テキスト回答が無視される問題を修正
  • /stats 日付表示修正: UTC マイナスタイムゾーンで「Most active day」が1日前に表示される問題を修正
  • タブインデントコード表示修正: Write プレビューでインデントが正しく表示されない問題を修正
  • Ghostty スピナー修正: アクティビティスピナーのパルスが間違ったグリフサイズで表示される問題を修正
