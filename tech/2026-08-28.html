🧠 Claude Code — v2.1.248 / v2.1.247

対象期間内に v2.1.248（2026-08-27 22:19 GMT = 28日 07:19 JST）と v2.1.247（2026-08-27 01:16 GMT = 10:16 JST）の2件のリリースが公開されました。

v2.1.248 — 主な新機能・改善

  • --restricted モード: コマンド実行・コード実行系ビルトインツールと WebFetch を除去（--tools で指定しない限り）、作業ディレクトリ内にファイルツールを制限、bypassPermissions を拒否、各種設定ファイルを無視する実行モード。環境変数は CLAUDE_CODE_RESTRICTED=1
  • experimental.cacheTtl: agent frontmatter に per-agent のプロンプトキャッシュ TTL（"5m"/"1h"）を設定可能に
  • cross-session messaging: Bedrock / Vertex / Foundry、および telemetry 無効時にも同一マシン上のセッション間 SendMessage/ListAgents を拡大
  • claude self-hosted-runner --client-label、/usage-credits（AWS Marketplace 経由の Enterprise 顧客向け）、サーバー管理型設定の診断強化など

v2.1.248 — 主な修正

  • 長時間セッションで約1時間に1回発生していたプロンプトキャッシュミス（拡張思考コンテキスト消失）を修正
  • Claude Desktop / Cowork セッションが30日後に消える問題を修正（アプリ使用中は保持）
  • Workflow ツールの説明を約 5.7k→1k トークンに削減、workflow-authoring スキルへ集約

v2.1.247 — 主なトピック

  • SendFeedback ツール: セッション中に問題が起きた際、Claude がフィードバック報告の下書きを生成（feedbackDrafts 設定で無効化可）
  • /claude-api cost-optimize: 既存プロジェクトの Claude API 支出をプロファイリングし、コスト削減施策を測定しながら適用
  • Sonnet 5 の自動コンパクト窓をフル 1M コンテキストに変更
  • プラグインマーケットプレイスの堅牢化（制御文字・不可視文字を含む名前を拒否）
