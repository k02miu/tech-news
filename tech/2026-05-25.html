🤖 Claude Code — v2.1.149 / v2.1.150 リリース（5月23日 JST）

週末にかけて Claude Code の連続アップデートが公開されました。v2.1.149 はユーザー向け新機能と多数のバグ修正を含む大型アップデート、v2.1.150 は内部インフラ改善リリースです。

🆕 v2.1.149 — 新機能

  • /usage のカテゴリ別内訳表示: 利用上限の消費要因をスキル・サブエージェント・プラグイン・MCPサーバー単位で可視化。どのワークロードがコストを押し上げているか把握可能に
  • /diff キーボードスクロール: 差分詳細ビューで矢印キー・j/k・PgUp/PgDn・Space・Home/End によるスクロール操作が可能に
  • GFM タスクリストチェックボックス: Markdown 出力で - [ ] todo / - [x] done がチェックボックスとしてレンダリングされるように
  • Enterprise: allowAllClaudeAiMcps 設定: claude.ai クラウド MCP コネクターを managed-mcp.json と併用して読み込めるマネージド設定を追加

🐛 v2.1.149 — 主なバグ修正（全22件）

  • PowerShell 権限バイパス: ビルトイン cd 関数（cd.., cd\, cd~, X:）によるワーキングディレクトリ変更が未検出だった問題を修正（ワークスペース外読み取りの可能性）
  • Git worktree のサンドボックス許可リスト: メインリポジトリルート全体を許可してしまう問題を修正（.git ディレクトリのみ共有、hooks/ と config は拒否）
  • PowerShell ワイルドカード許可ルール: PowerShell(dotnet.exe build *) のようなプレフィックス/ワイルドカードルールがネイティブ実行ファイルを事前承認しない問題を修正
  • 大規模ディレクトリツリーでの find コマンド: macOS のシステムファイル/vinode テーブルを使い果たしてホストがクラッシュする問題を修正
  • マネージド設定の承認ダイアログ: 起動時に承認後もターミナルがフリーズしたままになる問題を修正
  • その他: 権限解析の変数追跡ギャップ、/ultraplan の失敗、otelHeadersHelper のサイレント失敗、thinking スピナーの表示、Bash 出力の行数カウント、スラッシュコマンドの引数ヒント、Ctrl+O トランスクリプトビュー、プロンプト履歴編集など多数の修正

🔧 v2.1.150 — 内部インフラ改善

ユーザー向けの変更はありません。内部インフラの改善のみ。

推奨アクション: Claude Code ユーザーは claude --update で最新版へのアップデートを推奨。特に PowerShell 環境での利用者は、権限バイパス修正を含む v2.1.149 への更新が重要です。
