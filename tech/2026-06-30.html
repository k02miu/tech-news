🔒 Threat Technique Catalog June 2026 — 新規5エントリ

  • EKS Workload Modification: 脅威アクターが Kubernetes 認証情報/IAM ロールを取得し稼働中ワークロードを改変（コンテナイメージ差し替え、サイドカー注入、pod 仕様変更）。admission controller でのイメージ署名検証、RBAC 制限、GuardDuty EKS Protection で軽減
  • Exploit Public-Facing Application — EKS: 公開された Kubernetes API server / 誤設定 ingress controller を起点に EKS ワークロードを攻撃。pod 内からメタデータサービス・サービスアカウントトークン参照・ラテラルムーブ。API server の公開制限、network policies、最小権限サービスアカウントで軽減
  • Assume Root into Organization Member Account: 管理アカウントを侵害した攻撃者が sts:AssumeRoot でメンバーアカウントの root を奪取。SCP で sts:AssumeRoot を制限し CloudTrail で監視
  • Compute Hijacking — EKS: 暗号資産マイニング等の不正ワークロードを EKS クラスタ内に展開。resource quotas/limit ranges、レジストリ制限、GuardDuty EKS Protection で検出
  • Invite Accounts to Unknown Organization: 攻撃者が管理する organization にアカウントを招待し、SCP で正規オーナーをロックアウト。organizations:InviteAccountToOrganization / AcceptHandshake の監視と脱退防止 SCP で軽減
