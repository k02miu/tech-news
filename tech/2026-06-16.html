🧠 Claude Code — v2.1.178

6月16日 07:12 JST にリリースされた v2.1.178 では、サブエージェント制御の強化、ネイティブスキルの階層化対応、および多数のバグ修正が含まれています。

🔧 新機能・改善

  • Tool パラメータベースのパーミッションルール: Tool(param:value) 構文でツールの入力パラメータにマッチするパーミッションルールを設定可能に（例: Agent(model:opus) で Opus サブエージェントをブロック）。ワイルドカード * にも対応
  • ネストされた .claude/skills 対応: サブディレクトリ内のスキルがそのディレクトリで作業時に自動ロード。名前衝突時は <dir>:<name> 形式で両方を保持
  • ネストされた .claude/ ディレクトリの優先順位: 作業ディレクトリに近い方のエージェント・ワークフロー・出力スタイルが名前衝突時に優先
  • Auto モード改善: サブエージェントの起動前に分類器による評価が実行され、ブロックされたアクションを要求するサブエージェントがレビューなしで起動するギャップを解消
  • /doctor 改善: 全セクションで統一されたフラットツリーレイアウト、明確なステータスアイコン、コマンド名のハイライト表示
  • Remote Control エラーメッセージ改善: 接続失敗時にフッターに赤い "/rc failed" インジケーターを永続表示。エラー種別（ゲート・チェック失敗・期限切れエンタイトルメント・組織ポリシー）を明示
  • ワークフロープロンプトキーワード変更: 紫のシマーハイライト表示に変更。「run a workflow」や「workflow:」といった明示的なフレーズでのみトリガー（「workflow」単語の出現では発火しなくなった）

🐛 主な修正

  • OOM クラッシュ修正: 親プロセスから継承した古い websocket/OAuth ファイル記述子環境変数によるメモリ枯渇を修正
  • Chrome OAuth 接続修正: Claude Code ロインと異なるアカウントの OAuth トークンによる Chrome 接続のサイレント失敗を修正
  • サブエージェント関連の複数修正: トランスクリプト表示でツール結果とライブ進行状況が表示されるように、処理完了中に送信されたメッセージがドロップされないように、ctrl+b でのバックグラウンド化が再起動を引き起こさないように修正
  • claude agents 401 エラー修正: カスタム API ゲートウェイ経由でデーモン起動時のワーカー 401 Invalid bearer token エラーを修正
  • コンパクション修正: --fallback-model を正しくフォールバックチェーンに従うように修正
  • 認証リフレッシュ修正: セッション外で資格情報が更新された後の認証エラー持続問題を修正
  • バックグラウンドセッション "Working" 永久表示修正: /bg や ←← で作成したバックグラウンドセッションがエージェント一覧で永久に「Working」と表示される問題を修正
  • MCP サーバーレベル仕様修正: サブエージェント disallowedTools での MCP サーバー仕様（mcp__server 等）がサイレントに無視される問題を修正
  • vim モード undo 修正: u が素早く連続したコマンドを単一の undo ステップにマージしていた問題を修正
  • [VSCode] CJK IME 修正: Esc キーで CJK IME 候補ウィンドウを閉じた際に Claude タスクがキャンセルされる問題を修正
