🧠 Claude Code — v2.1.231 / v2.1.229

対象期間内に2件の更新が公開されました。v2.1.231では、Slackのように事前登録済みOAuthクライアントを利用するMCPサーバーで、OAuthサインインがリダイレクトURI不一致になる問題を修正しました。v2.1.229ではRemote Control、セルフホストRunner、プラグインマーケットプレイス、VSCode拡張、ストリーミング安定性などが大幅に改善されています。

🔧 新機能・改善

  • Remote Control: claude remote-control --continueで直近のRemote Controlセッションを再開できるようになりました。
  • セルフホストRunner: サーバー提供のClaude Codeフックに対応し、管理環境と同等の動作になりました。
  • ゲートウェイ: 長時間の思考停止中もSSE keepalive pingを送信し、Vertex・Bedrock upstreamでのアイドル切断を防ぎます。
  • プラグイン: ローカルコマンドを再解決するマーケットプレイスソースと、再起動不要で適用できるmode: "link"を追加しました。
  • VSCode: セッションをグループ化できるサイドバー機能を追加し、/btwの質問パネルもリサイズ可能になりました。
  • ワークフロー: 同一プレフィックスの兄弟エージェントをずらして起動し、プロンプトキャッシュを再利用しやすくしました。

🐛 主な修正

  • MCP OAuthの事前登録済みクライアントで発生するリダイレクトURI不一致を修正しました。
  • ストリーミング中の長い応答が一部消失したり、ターミナルに二重表示されたりする問題を修正しました。
  • 不正な型のツール引数、狭いターミナルでのプログレスバー・Markdownテーブル描画、Windowsの拡張長パスによるクラッシュを修正しました。
  • OAuth、Remote Control、Claude Code Review、IDE診断、プラグインキャッシュ、SDKの空白メッセージ処理など、多数の安定性問題を修正しました。
