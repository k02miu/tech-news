🐙 OpenClaw — v2026.10.5-beta.1

対象期間内に v2026.10.5-beta.1（プレリリース）が 2026-10-11 22:08 JST に公開されました。更新処理の堅牢化、Gateway 再起動をまたぐ会話の復帰、ターン／サブエージェントの信頼性向上、X（Twitter）チャンネルと音声通話の拡充が中心の更新です。安定版の最新は v2026.10.1（2026-10-11 08:54 JST 公開）です。

🔧 新機能・改善

  • 更新処理の安全性（Safer updates）: デバイス・ファイルシステム・Windows の昇格・中断されたアクティベーションをまたいで更新が完了するようになり、古いリースや変化した証跡からも復旧するため、インストールが孤立したり将来の更新がブロックされたりしなくなりました。
  • 再起動に耐える会話: 中断されたターン、worktree 準備中に届いた最初のメッセージ、遅延されたタスクが Gateway 再起動後に再開し、ユーザー入力とコミット済みセッションデータが再起動・並行書き込み・公開失敗をまたいで保持されます。
  • Gateway の高速化・安定化: セッション・トランスクリプト・履歴・メタデータの読み取りがワーカースレッドへ移り、1ターンあたりの SQLite 処理が大幅に削減。起動時のメンテナンスはレディネス後に実行されるため、混雑した Gateway でも応答性が保たれます。
  • ターンとサブエージェントの信頼性: 停止したストリーム、再利用されたツール呼び出し ID、失効した ChatGPT WebSocket からターンが復旧し、不完全なターンは可視化された通知で終了。サブエージェントの結果はフォローアップ・再起動・配信期限切れをまたいで返り続けます。
  • X（Twitter）チャンネル: Activity API のストリーミングとバックフィルに対応した X メンション用チャンネルプラグインを追加。リポジトリに関する質問向けのゲストモード、GitHub 検証済みのリポジトリ書き込み、X API の日次・月次コスト上限を備えます。
  • 音声通話: 通話ごとのブリーフ、通話レポート、ライブステアリング、コールバック、ボイスメール検出を追加しました。
  • 賢くなったモデルピッカー: 各プロバイダーの推奨モデルを先頭に表示し、Claude・ChatGPT・Ollama の新着モデルを OpenClaw のリリースを待たずに表示。カタログ読み込み中も操作可能です。
  • Gateway 内の ClawHub: Gateway から ClawHub のプラグインとスキルを閲覧・検索でき、プラグインは実行中の OpenClaw が対応する最新の公式リリースを自動選択します。
  • その他の Changes: ネイティブの worker 推論ランタイム（Gateway ディスパッチ・配置・ポリシー検査付き）、Claude Haiku 5.5 のサポート、OpenAI のカスタム realtime 音声エンドポイント、組み込み Nerd Font アイコン付きのターミナルフォント設定、iOS の Cloudflare Access 経由の Gateway 接続、Workboard のピン留め・削除、GitHub の非同期 PR マージ、セッション読み取りのワーカースレッド化など。

🐛 主な修正

  • セッションデータ: 保存された更新証跡の検証、破損したレコードへの対処、長期実行エージェントのローカルメモリ使用量の計測を改善。
  • 自動化（Automation）: 失敗した自動化を所有者の会話から修復できるようにし、エラーが変化した場合は2回目の修復ターンを与え、修復ターンがタイムアウトした場合は明確な警告を表示。
  • メモリ: トリガーリコールがスキップされた理由と埋め込みレスポンスが拒否された理由を説明し、managed Ollama／LM Studio の埋め込みレディネスを報告。
  • チャンネル表示: Telegram・Discord の進捗表示を既定で有用な内容にし、Discord の進捗ドラフトにツールごとのグリフを追加、Telegram のツール行に絵文字を復元、Slack の定型的なリアクション行を非表示に。
