🧠 Claude Code — v2.1.173

対象期間中に v2.1.172（06/11 09:39 JST）と v2.1.173（06/11 16:39 JST）の2リリースが公開されました。サブエージェントのネスト化、Bedrock region 改善、パフォーマンス最適化、多数のバグ修正が含まれます。

🔧 新機能・改善

  • サブエージェントの再帰的ネスト: サブエージェントがさらにサブエージェントをspawn可能に（最大5段階）。複雑なタスクの委譲が大幅に柔軟化
  • Amazon Bedrock region 自動検出: AWS_REGION 未設定時に ~/.aws config からregionを読み込むように。SDKと同じ優先順位に。/status で取得元を表示
  • /plugin 検索バー追加: マーケットプレイスのプラグイン一覧に検索バーが追加
  • OTELメトリクスに model 属性追加: claude_code.lines_of_code.count にモデル情報が付与
  • パフォーマンス改善: 長い会話での冗長なメッセージ正規化を排除、ストリーミング中の不要な変換を削減
  • CPU使用率削減: /goal ステータスチップのアイドル時5Hz再描画を停止、サブエージェント並行時の不要な再描画を削減
  • Claude in Chrome 改善: ブラウザツールのロードを各ツール個別から単一バッチ呼び出しに変更
  • Remote Control 表示短縮: フッターインジケータを「/rc active」に短縮、狭いターミナルでは非表示

🐛 主な修正

  • Fable 5モデル名 suffix 修正: [1m] suffixの正規化が行われていなかった問題を修正。Fable 5はデフォルト1M contextのためsuffixは自動除去
  • Windows sandbox 警告修正: sandbox有効時に「sandbox dependencies missing」の誤った警告が表示される問題を修正
  • 1M context 使用量クレジットなしセッション修正: 1M context使用時に永続的に固まる問題を修正。自動的に標準context limit内にcompaction
  • 複数画像エラー修正: 会話に複数の画像を含む場合の「an image could not be processed」の繰り返しエラーを修正
  • エージェントビューbusy表示修正: ワーカー応答後30秒間busyスピナーが残る問題を修正
  • バックグラウンドエージェントのプロジェクト設定修正: プレウォームワーカーにディスパッチ時、他ディレクトリの設定(.mcp.json)を読み込む問題を修正
  • EAUTH修正: Claude Code自動アップデート後に開始されたセッションのバックグラウンドセッション接続失敗を修正
  • /model ピッカー多数修正: Bedrockでプロバイダが提供しないモデルが表示される問題、利用可能モデル制限がサブエージェントに適用されない問題、1M suffixの二重付与を修正
  • WebFetchワイルドカード修正: *.example.com がサブドメインにマッチしない問題、Read(secrets-*/config.json) 等のミドパターンワイルドカードが起動時に拒否される問題を修正
  • メモリrecall修正: リモートセッションでマウントされたチームメモリストアが見つからない問題を修正
