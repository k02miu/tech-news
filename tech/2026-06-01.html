🐙 OpenClaw — 2026.5.31 Pre-release

5月31日付のプレリリースでは、前日に続く大規模な改良が行われています。主なハイライト:

🛠️ Skill Workshop — スキル作成のガバナンス強化

  • Skill Workshop の導入: スキル提案の作成・レビュー・適用・却下・隔離を行うガバナンスフローが追加。CLI・Gateway・エージェントツールから操作可能
  • 提案のバージョン管理: 保留中のスキル提案を承認前にインプレースで改訂でき、日付付きのフロントマターで管理
  • サポートファイル承認: スキル提案が承認済みサポートファイルを標準のスキルフォルダ配下に持ち運べるように（スキャナー・ハッシュ・ロールバック保護つき）

🔌 プラグイン — Tokenjuice / Copilot の外部化

  • @openclaw/tokenjuice と @openclaw/copilot が公式プラグインとして npm / ClawHub に公開
  • SecretRef プロバイダー統合マニフェストの追加、共有 LLM コアパッケージの抽出

📱 チャンネル・モバイルの安定性強化

  • Telegram, WhatsApp, iMessage, Slack, Discord, Microsoft Teams, Google Chat, Google Meet, iOS realtime Talk の各チャンネルで配信の堅牢性が向上
  • Discord, Telegram, Slack, Matrix, Teams でプログレスドラフトの開始失敗リカバリーが改善
  • iOS: ホスト型プッシュリレーデフォルト、realtime Talk 再生、WebSocket ping パスの保護を追加

🎛️ Control UI / Gateway

  • Dreaming タブにエージェントセレクターを追加し、選択エージェントがステータス・日記・アクションに反映されるように
  • Communication Notifications 設定タブを Settings に追加
  • Gateway: Tailscale Serve サービス名バインディングのサポート

⚡ プロバイダー・タイマー制御

  • OpenAI, Runway, xAI, MiniMax, Google など各プロバイダーのメディア生成ダウンロード、OAuth/デバイスコード有効期限、ローカルサービスプローブ、生成コンテンツポーリングにタイマー上限を設定し、無期限ハングを防止

🐛 主な修正

  • エージェント/Codex: 非同期メディア生成が Codex ターンを早期終了させないよう修正、Codex OAuth セッションの永続化改善
  • メモリ: 並行 Gateway/CLI アクセス時の QMD 書き込みの直列化、ロールオーバー時のトランスクリプトパス再生成
  • スキル: 無効化されたスキルの SecretRef がチャンネルターンを中断させないよう修正
  • Cron: SQLite 移行のレガシー互換性を維持
  • CLI: openclaw agents add 時のカタログ検証依存を除去
