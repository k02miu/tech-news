🧠 Claude Code — v2.1.238 / v2.1.237

対象期間内に v2.1.238（8月21日 06:52 JST公開）と v2.1.237（8月20日 11:08 JST公開）の2バージョンがリリースされました。v2.1.238はキーバインド設定・プラグインマーケットプレイス・自己ホストランナーなどの拡充と、多数の不具合修正を含みます。

🔧 新機能・改善（v2.1.238）

  • keybindingFlavor設定: "readline" に設定するとプロンプト内の Ctrl+W が Bash のように直前の空白まで削除する挙動になり、既定（"classic"）は従来通りです。
  • プラグインマーケットプレイスの headersHelper: url型マーケットプレイス／カタログエントリ上で、カタログや同一オリジンの archive 取得用に HTTP ヘッダ（例: 短期トークン）を発行するコマンドを実行できます。インストール・更新時にのみ実行され、[y/N]（または -y）で確認します。
  • claude self-hosted-runner --defer-shutdown-max-min: SIGTERM 時に接続中セッションの提供を継続し、指定分数後に残りを退避して終了するようになりました。
  • 自己ホストランナーのプロキシ認証: 接続ごとに新しい Proxy-Authorization ヘッダを要求する egress プロキシ向けに --proxy-authorization-command／--proxy-authorization-file を追加しました。
  • 「Concise」出力スタイル（v2.1.237）: 組み込みの簡潔出力スタイルが追加され、結果を先頭に示し前置き・ナレーションを省略しつつ同じ徹底度で作業します。/config の Output style から選択できます。
  • startup 改善: macOS で裸の claude の起動が高速化。自動更新チェックが起動後約10秒に遅延され、起動時の CPU 競合を回避します。

🐛 主な修正

  • 長期対話セッションでの無制限メモリ増加を修正 — サブエージェントのツール結果が最近の表示ウィンドウから外れると解放されるようになりました。
  • カスタム・プロジェクト・プラグイン出力スタイルがセッション途中で既定ボイスに戻る問題を修正しました。
  • ワークツリー分離の Bash 拒否メッセージで、リダイレクトが無いのに削除を促す問題を修正しました。
  • 権限プロンプトの diff で絵文字等のワイド文字やタブを含む行が切れる問題を修正しました。
  • Ctl+C（Suspend）されたセッションを kill した際、ターミナルが bracketed-paste モードのままカーソル非表示になる問題を修正しました。
  • stdio MCP サーバーが initialize 前に server/discover を受信する問題を修正し、遅延起動のバックエンドが毎セッション起動されるのを防ぎました。
  • Remote Control の接続耐性を改善 — ネットワークエッジ・VPN・プロキシでの一時的な HTTP 403 を最大3分間許容し、持続時は拒否側を明示するようになりました。
  • プロンプトキャッシュ・LLM ゲートウェイ（カスタム base URL）利用時のキャッシュ問題を修正しました（v2.1.237）。

🐋 Orca — v1.4.186

🔧 新機能・改善

  • ワークスペースの可視性デフォルト: 表示するワークツリーソースのグローバルデフォルトを設定可能になりました。フォルダプロジェクトは Orca 外で git init 後に git リポジトリになります。

  • computer-use: macOS ミドルクリック対応を追加し、サイレントな左クリックフォールバックを廃止しました。

🐛 主な修正

  • Windows で一時的にファイルがロックされる場合のログアウトや誤アカウントでのセッション再開を修正しました。
  • 一時的なファイルシステムエラーでアクティブアカウントがログアウトされる問題を修正しました。
  • ターミナルで、貼り付けたニューラインがドラフトを誤送信しないよう agent ペイン入力を bracketing しました。
  • ブラウザで UA 書き込みによるリダイレクトキャンセルや requestStorageAccess() 拒否を修正しました。
