🧠 Claude Code — v2.1.290

2026-10-06 08:53 JST 公開。プラグイン／mod フックの拡張、WebFetch の長文ページ対応、長時間セッションの安定性向上など、多数の改善と修正を含むリリースです。

🔧 新機能・改善

  • mod の turn.step フックに serverToolUses: API 自身が実行したツール呼び出し（advisor）の id・名前・入力・開始／終了時刻を結果として取得可能に。
  • plugin hooks の tool.check に agentId: サブエージェントの権限チェックとメインセッションのものを区別できるようになりました。
  • claude attach <name> / claude logs <name>: セッションIDの代わりにセッション名の一部を指定可能に。
  • Claude apps gateway のサインイン承認ページに Deny ボタン: 保留中のサインインを打ち切れるようになり、待機中のターミナルが数秒で停止します。
  • /claude-api managed-agents-onboard: Managed Agents パターンのセットアップと Console クイックスタートテンプレートの構築を CLI から実行可能に。
  • WebSearch 予算の方式変更: 200回で終了する方式から、時間あたり100回で回復する方式へ（CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR で調整可）。
  • プラグイン検証の強化: claude plugin validate が各フックに .catch があるかを一覧表示（--json の gatingHooks）。
  • macOS で秘密情報マスクの予算方式変更: 予算方式から時間回復方式へ変更し、長時間の処理での枯渇を防ぎます。
  • VSCode 拡張の改善: ファイルピルのホバーでプロジェクトフォルダからのパスを表示、メッセージのタイムスタンプを既定で表示、スクリーンリーダー対応の強化など。

🐛 主な修正

  • プロキシやゲートウェイが beta ヘッダを 400 以外のステータスで拒否する環境で、リクエストが失敗する問題を修正。
  • 数百枚の画像を含む長時間セッションが「Request rejected as unprocessable by the model」で停止する問題を修正。
  • WebFetch が 100,000 文字を超えるページ本文を黙って破棄していた問題を修正。未読量を表示し、offset で続きを読み込めるようになりました。
  • 数千階層にネストしたリストや引用で「Maximum call stack size exceeded」クラッシュが発生する問題を修正。
  • コンパクション後にスケジュールタスク（/loop・リマインダー）が復帰しない問題、およびフォアグラウンド設定のタスクが発火しない問題を修正。
  • ヘッドレス --json-schema 実行で、構造化出力の配送後に接続が切れると成功結果でも非ゼロ終了していた問題を修正。
  • macOS / Windows で画像読み込み時、承認範囲外のファイルをリンク差し替えで読めてしまう問題を修正（セキュリティ）。
  • Linux・WSL におけるサンドボックスの read ルール、フリーズ、設定リロード周りの不具合を多数修正。
  • MCP サーバーの巨大レスポンスによるメモリ無制限使用、サブエージェントのworktree権限喪失、再開時のトランスクリプト喪失などの問題を修正。
