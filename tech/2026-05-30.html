🆕 Claude Code v2.1.157 (May 29, 2026)

v2.1.154 に続く機能強化と多数のバグ修正を含むリリースです。

  • Skills ディレクトリ自動読み込み: .claude/skills 配下のプラグインがマーケットプレイス不要で自動ロードされるように
  • claude plugin init <name>: .claude/skills に新しいプラグインをスキャフォールドするコマンドを追加
  • /plugin 引数の自動補完: サブコマンド、インストール済みプラグイン名、既知のマーケットプレイスから補完
  • claude agents: settings.json の agent フィールドが dispatching セッションで反映されるように（--agent <name> で上書き可）
  • EnterWorktree 改善: セッション中に Claude 管理のワークツリー間を切り替え可能に
  • 破損画像の堅牢化: ゼロバイトや破損画像（貼り付け/MCP/ダイアログ経由）がクラッシュせずテキストプレースホルダーとして扱われるように
  • WSL 改善: 画像貼り付け（alt+v）、Windows 11 でのスクリーンショット貼り付け、Windows Explorer からのドラッグ画像に対応
  • パフォーマンス改善: 長い/再開セッションでの冗長なメッセージ再レンダリングを排除
  • サンドボックスネットワーク許可プロンプト: デスクトップアプリ・IDE拡張・SDK 利用時の auto/bypass-permissions モードでプロンプトが表示されないよう修正
  • 多数のバグ修正: バックグラウンドエージェントのワークツリー孤立化、クリップボード重複、ターミナルフリーズ、VS Code/Cursor/Windsurf 統合ターミナルの描画破損など
