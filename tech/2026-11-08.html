🐋 Orca — v1.4.252 / v1.4.253

対象期間内に2件のリリースが公開されました。v1.4.252（2026-11-07 13:03 JST 公開）は「任意の応答からのチャット分岐」「Plan モード」「スマホ体験の改善」を柱とした大型アップデート、v1.4.253（2026-11-07 19:47 JST 公開）はホスト状態更新と Linux のプロセス起動時刻読み取りの効率化を中心とした小規模な改善リリースです。

🔧 新機能・改善（v1.4.252）

  • 任意の応答からチャットを分岐: Chat UI で完了済みの応答を起点にフォークし、元のチャットをそのまま残したまま別方向を試せるようになりました。
  • ネイティブ Plan モード: Claude / Codex のチャットで /plan を入力すると Plan モードに切り替わり、チャットを開き直しても状態が保持されます。
  • スマホ版の強化: 起動・再接続が高速化し、Markdown と数式の描画、スクロールとストリーミングが滑らかに。接続断をまたいで未送信のチャット・レビュー・Tasks の下書きが保持されます。
  • ワークスペースの階層化: フォルダ型ワークスペースの下に、他マシン上のものを含めてワークスペースを入れ子にできるようになりました。
  • エージェント対応の拡充: 実行中のサブエージェントをチャットから開く、Codex の承認画面で提案ファイルと diff を確認する、OpenCode の選択式質問に回答する、Antigravity Chat に Gemini Enterprise でサインインする、といった操作に対応しました。
  • ターミナルの信頼性向上: ペインのズームと復元済みスクロールバックが維持され、コピーしたファイルはフルパスで貼り付き、出力が多いターミナルの描画コストも削減されました。
  • 音声入力の改善: 入力言語の選択、最初と最後の語の取りこぼし防止、モデル読み込み中の「Listening」表示、オンデバイス認識の約3割高速化が入りました。
  • チャットの実行場所の可視化: コンポーザー下にマシン・ワークスペース・ブランチが表示され、エージェントが開いた PR はチャット内にカードとして表示されます。
  • デスクトップの応答性改善: 1つのチャットの状態変化が他の全チャットを起こさないようにし、モデルピッカーの表示や長文応答のストリーミングを軽量化しました。

🔧 改善（v1.4.253）

  • ホスト状態更新の重複処理を削減: ホスト状態の更新時に同じ処理を繰り返さないようにしました。
  • Linux のプロセス起動時刻の読み取りを効率化: プロセス起動が少なくなるよう実装を見直しました。
  • チャットのメッセージレール: ホバー・フォーカス・スクロールするまで暗く表示されるようになりました。

⚠️ 互換性・アップグレード注意（v1.4.252）

  • macOS 13.4 以上が必須: 従来の macOS 12 から引き上げられました。macOS 13.0〜13.3 の Mac は最後に互換性のあるビルドに留まり、Homebrew もアップグレードを拒否します。macOS 13.7 へ更新すれば継続して受け取れます。
  • 音声入力モデルの廃止: Zipformer EN モデルの提供が終了し、選択していた場合は Parakeet v2 へ移行します（設定 › Voice でのダウンロードが必要な場合があります）。
  • ペアリングコードの有効期限: 未使用のコードはスマホ用 QR が10分、別コンピュータ用リンクが60分で失効します（既存のペアリング済み端末は影響なし）。
  • ローカルブラウザプロキシ: セッションごとのトークンが必須になり、Orca 自身が起動した agent-browser 以外は利用できなくなりました。
  • ダウングレード不可: Plan モードを使ったチャットは v1.4.251 では開けません（再度アップグレードすると開けます）。

🟨 Hono — v4.13.17

2026-11-07 13:58 JST 公開。Cookie のプレフィックス判定、URL クエリのパース、ETag の扱いなど、細かな仕様準拠の修正を中心としたパッチリリースです。

🐛 主な修正

  • Cookie: __Secure- / __Host- プレフィックスの判定を大文字小文字を区別せずに行うよう修正（CookieConstraint 側も同様）。
  • utils/url: 区切り文字をまたいでクエリキーが一致してしまう問題を修正。
  • ETag / Pretty JSON: 破棄されたレスポンスボディをキャンセルするようにし、引用符内のカンマや二重引用符・バックスラッシュの扱いも修正しました。
  • クライアント: メディアタイプのパラメータ前に空白がある場合でも JSON を判定できるよう修正。
  • Server-Timing: setMetric の精度 0 を尊重し、説明文字列のエスケープも修正しました。
  • MIME / SSG: メディアタイプを大文字小文字を区別せず比較。toSSG の複数回実行で作成済みディレクトリを再利用しないよう修正しました。
  • JSX: ErrorBoundary が生成するすべてのスクリプトに CSP nonce を付与。
  • AWS Lambda: API Gateway v2 イベントで非 ASCII のヘッダー値をサニタイズ。
