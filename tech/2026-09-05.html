🧠 Claude Code — v2.1.261

2026-09-05 09:00 JST 現在、対象期間内（9/4 20:04 GMT リリース）に v2.1.261 が公開されました。組織ポリシー可視化、出力上限設定、スキル健全性診断など開発者体験向上と、Remote Control / VS Code 拡張を中心とした大量の修正が含まれます。

🔧 新機能・改善

  • 組織ポリシーの可視化: /status と claude doctor に「Organization policy」行を追加。プロキシがエンドポイントを通していない等、ポリシーがロードできない理由を表示
  • 出力上限の拡張設定: bashOutputMaxChars / taskOutputMaxChars を追加。コマンドやバックグラウンドタスクの出力をファイル保存前にインラインで受け取れる量を最大128K文字まで拡張
  • /skill-doctor: 使われていないスキルと、それが消費しているコンテキストコストを可視化し、 pruning（整理）を支援する新コマンド
  • サブエージェント プロンプトのファイル指定: --append-subagent-system-prompt-file で、コマンドラインに収まらない大きなシステムプロンプトをファイルから読み込み可能に
  • /model の改善: ピッカーと VS Code のモデル表示で、認識できるモデルは生の Bedrock / Vertex AI / LLM ゲートウェイ ID ではなくモデル名を表示。VS Code のモデルピッカーは全モデルのフラットなリストに変更
  • ストリーミング性能向上: 描画済みブロックをレイアウトが毎回再チェックしなくなり、表示が高速化
  • 危険な rm の安全確認強化: 位置パラメータやダブルクォート内の sh -c スクリプトに含まれる rm -rf も検出対象に
  • 自動モードの安全性: 公開ダイアグラムレンダラの URL に内容を詰め込んだリンクは、そのサイトへのアップロードとして扱われ、明示的に要求しない限り自動承認されない
  • キーバインドの Bash 統一: Ctrl+W は空白まで削除、Alt+F / Alt+D は単語末で停止など Bash と一致する挙動に。keybindingFlavor は無効化
  • [VS Code] 「Build a custom style」ウォークスルー、MCP サーバーの追加/削除 UI、セッションリストのアーカイブ操作など新機能を多数追加

🐛 主な修正

  • 高速入力・キーリピート時に入力文字の順序が入れ替わったり欠落する問題を修正
  • Bedrock セットアップウィザードが AWS 認証ヘルパー無応答でハングする問題（タイムアウト+明確なエラーに改善）と、TLS 検査プロキシ配下でのモデルチェック失敗を修正
  • Remote Control 関連の多数の修正（古い権限モード表示、停止後のスピナー残存、TLS 検査プロキシでの受信ストリーム失敗など）
  • セッション再開時に並列ツール呼び出し周辺のフック出力やコンテキストが失われ、リクエストが変化する問題を修正
  • SDK / クラウドセッションで最初のプロンプト直後の Stop / interrupt が無視され、ターンが最後まで実行される問題を修正
  • 再開できないバックグラウンドエージェントの起床リトライがタイトループし高 CPU を消費する問題を修正
  • /usage と VS Code 使用量パネルが、レート制限時や起動直後にモデル別週次上限行を欠落させる問題を修正
  • Vertex AI 起動時に gcloud プロセスが余分に起動する問題を改善。API 応答ヘッダーなし時のリトライ待機を API_TIMEOUT_MS（既定10分）まで延長
