🐙 OpenClaw — v2026.11.5-beta.2

ベータ版 v2026.11.5-beta.2 が 2026-11-12 09:43 JST に公開されました。長大な会話の閲覧性向上と、セキュリティ修正が中心のリリースです。

🔧 新機能・改善

  • 双方向のページング履歴: 大規模な会話でも履歴の境界が可視化され、アーカイブ読み込みも上限付きで行えるようになりました。
  • macOS アプリの認証情報保持: 設定保存に失敗した場合や Tailscale 公開を無効化した際にも、保存済みシークレットと Gateway 認証が失われなくなりました。
  • Android の Talk 終了時: Talk を終了しても、Gateway が既に受理した処理が取り消されなくなりました。
  • Google 連携: 公式エンドポイントの Gemini Flash 系モデルで Interactions API を使用するよう変更（カスタムエンドポイントの上書きは維持）。

🐛 主な修正

  • セキュリティ: fast-uri 4.2.3 へ更新し、不正な URI 識別子を拒否しつつ有効な相対参照は維持。Discord SDK とその依存の Zod 3 パーサーでは、上限超過のコレクションを早期に拒否します。
  • メッセージ配信: 再試行されたコミット済み入力の二重ターン起動を防止し、インライン編集中もキュー済みメッセージを保持します。
  • チャット復元: 完了済みの推論内容とスナップショットを保持し、コンパクション後も進行中リクエストの来歴を維持します。
  • セッション: 一覧・履歴インポート・集計の読み取りを上限付きとし、書き込み側をブロックしないよう改善しました。
  • PostgreSQL: 繰り返し検索時もセッション検索がテキストインデックスを使い続けるよう修正。
  • ファイル: ワークスペースパスの読み書きで Unicode キーの同一性を保持します。

🐋 Orca — v1.4.257

v1.4.257 が 2026-11-12 10:20 JST に公開されました。長時間チャットの安定性と、音声入力・ターミナル操作の使い勝手が改善されております。

🔧 新機能・改善

  • 長い会話の高速化: 複数の長い Chat UI 会話が同時にストリーミングされる際のフリーズを軽減し、返信到着時の処理量を削減しました。
  • ブラウザのフィードバック保持: 未送信のテキストメモがリロード・再起動後も復元されます。未送信メモのあるタブを閉じる際は確認が入り、デスクトップ上のエージェントは送信前に orca tab annotations で内容を読めます。
  • 音声入力の無音待機時間: 設定 → Voice → Input → Stop After Silence で 30 秒・1 分・2 分・オフを選択可能に。同じ画面に録音と再生を試せる Test ボタンも追加されました。
  • ターミナル接続中のペースト: 起動中・再接続中のターミナルに貼り付けたコマンドが破棄されず、シェルの準備を待つようになりました（最大 64 KB、ローカル・SSH・リモートに対応）。
  • フォルダワークスペースの自動化: フォルダワークスペース作成時にセットアップスクリプト、削除前にアーカイブスクリプトが実行されます（CLI 経由の作成も対象）。
  • 分割ペインの検索: 空の分割ペインで / を押すとエージェントやファイルを検索でき、キーボードのみで開けます。
  • モデル選択の保持: Chat UI のモデルピッカーが、前ターンの返信到着時に選択を巻き戻さなくなりました。
