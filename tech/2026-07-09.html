🧠 Claude Code — v2.1.203 · v2.1.204 · v2.1.205

対象期間内に 3件のリリース（v2.1.203, v2.1.204, v2.1.205）が公開されました。主にバックグラウンドエージェントの安定性向上とバグ修正が中心です。

🔧 v2.1.205（最新）

  • /doctor コマンド: フルセットアップチェックアップとして刷新。問題の診断と修正が可能に（エイリアス: /checkup）
  • 自動アップデートのメモリ効率化: バイナリダウンロードをストリーム方式に変更し、ピークメモリ使用量を約400MB削減
  • セッション保護: セッション記録ファイルの改ざんをブロックする自動モードルールを追加
  • --json-schema 修正: 無効なスキーマ時に非構造化出力が黙って生成される問題、および format キーワード使用時に拒否される問題を修正
  • agent view 改善: セッション行に色付き状態表示と分類器生成の見出しを追加。PR 編集/マージ/コメント時にリンク表示
  • バックグラウンド通知の安全性向上: 人間の入力が行われていないことを明示的に通知し、偽造された承認が実行されるのを防止

🔧 v2.1.204

  • フック修正: ヘッドレスセッションの SessionStart フック中にフックイベントがストリーミングされず、リモートワーカーがアイドルタイムアウトで停止する問題を修正

🔧 v2.1.203（主な項目）

  • ログイン期限切れ警告: ログインの有効期限が近づくと警告を表示し、バックグラウンドセッションが中断される前に再認証が可能に
  • 手動モード表示: 手動パーミッションモード時にフッターへグレーの ⏸ バッジを表示
  • macOS ストール修正: 誤った低メモリ検出により macOS でバックグラウンドセッションの切り替えが15〜20秒停止していた問題を修正（v2.1.196 回帰）
  • daemon セッショントークン失効対応: トークン期限切れでバックグラウンドセッションが永続的に応答不能になる問題を自動回復
  • 対話セッションのパフォーマンス改善: 毎ターンごとにトランスクリプト全体を再解析していたコンテキスト使用量インジケータの回帰を修正
  • Windows バックグラウンド修正: バックグラウンドエージェントが daemon から古い PATH を継承してツール不足になる問題を修正
  • バイナリサイズ削減: 大規模バンドル依存を遅延ロードに変更し、約7MB削減
  • 操作性改善: 左矢印でビューを閉じる動作を廃止（Esc で閉じる方式に統一）、ストリーミング中のライブプレビュー更新の再レンダリング効率化
  • その他、バックグラウンドエージェント・worktree・MCP・プラグイン関連の多数の修正を含む
