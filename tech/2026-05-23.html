⚠️ TLS 1.0 / 1.1 廃止予定 — Azure App Service / Functions / Logic Apps

要対応 Azure App Service、Azure Functions、Azure Logic Apps において、2027年5月31日以降 TLS 1.0 および TLS 1.1 接続が受け付けられなくなります。古いクライアント・アプリケーションが TLS 1.0/1.1 を使用している場合は、TLS 1.2 以上への移行が必要です。

影響: App Service / Functions / Logic Apps を利用中の全ユーザー。猶予期間は約2年間あるため、計画的に対応可能。

推奨アクション: 対象サービスの TLS 設定を監査し、TLS 1.0/1.1 に依存するクライアントがないか確認を。TLS 1.2 以降への移行計画を策定してください。

🔗 Azure Updates: TLS 1.0/1.1 Retirement

🔐 Azure Functions Flex Consumption — TLS/SSL 証明書サポート（パブリックプレビュー）

Flex Consumption プラン向けに、サイトスコープの TLS/SSL 証明書モデルがパブリックプレビューとして提供開始。従来の webspace スコープ証明書（同一リージョン+リソースグループ内で共有）とは異なり、アプリ単位での証明書管理が可能に。

推奨アクション: Flex Consumption でカスタムドメイン運用を検討している場合は、プレビュー機能のテストを推奨。

🔗 Azure Updates: TLS/SSL for Flex Consumption

🪪 Azure Files — Entra-only アイデンティティの一般提供開始

Azure Files の SMB アクセスにおいて、Active Directory やハイブリッド ID 基盤を不要とし、Entra ID（旧 Azure AD）のみでの認証が GA となりました。クラウドネイティブなファイル共有アクセス管理が可能に。

🔗 Azure Updates: Entra-only identities for Azure Files

🗄️ Azure SQL — T-SQL 正規表現関数の LOB 型対応

Azure SQL および SQL Server 2025 のネイティブ正規表現関数（7種すべて）が varchar(max) および nvarchar(max) に対応。最大 2 MB の LOB データに対して正規表現処理が可能になりました。
