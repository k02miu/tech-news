🧠 Claude Code — v2.1.212

2026年7月17日 09:33 JST に v2.1.212 がリリースされました。30件以上の修正・改善を含む大規模なアップデートで、特にバックグラウンドセッション管理とレート制限に関する重要な機能追加が目立ちます。

🔧 新機能・改善

  • /fork の動作変更と /subtask 新設: /fork は会話を新しいバックグラウンドセッション（claude agents に独立行として表示）にコピーし、作業を継続可能に。旧来のインセッションサブエージェントは /subtask に名称変更
  • claude auto-mode reset: デフォルトの auto-mode 設定を復元するコマンドを追加（--yes で確認スキップ可）
  • WebSearch 呼び出し制限: セッション全体の WebSearch ツール呼び出し上限を追加（デフォルト 200、CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION で調整可）。暴走検索ループを防止
  • サブエージェント生成数制限: セッションあたりのサブエージェント生成上限を追加（デフォルト 200、CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION で上書き可）。/clear で予算リセット
  • MCP ツール自動バックグラウンド化: 2分以上実行中の MCP ツール呼び出しを自動的にバックグラウンドへ移動（CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS で閾値調整・無効化可）
  • /resume ピッカー: エージェントビューで /resume を入力すると、削除済みセッションを含む過去セッション一覧から選択・バックグラウンド再開が可能に
  • バックグラウンドエージェント添付の改善: cold-attach 時にセッション起動中もフォーマット済みトランスクリプトを即座に表示
  • プロンプトキャッシング改善: 中間会話のシステムブロックが LLM ゲートウェイやカスタム Base URL（Bedrock, Vertex, 1P）越しでも動作するように
  • Web 検索・フェッチの信頼性向上: 529 エラーとレート制限リクエストを backoff 付きでリトライ
  • エージェント間メッセージングのトークン削減: SendMessage 本文がリプレイ履歴とツール結果に重複して含まれないように
  • /btw の動作変更: 引数なしで /btw を実行すると直近のやり取りのサイド質問パネルを再オープン
  • フッターヒント改善: バックグラウンドエージェント完了時、← ヒントが一瞬 N done とパルス表示
  • Task ツール mode パラメータ非推奨化: サブエージェントはデフォルトで親セッションのパーミッションモードを継承
  • Enterprise forceLoginMethod 適用範囲拡大: VS Code 拡張・SDK・setup-token・install-github-app ログインにも適用
  • セッショントランスクリプト: 各アシスタントメッセージの推論努力レベルを記録
  • headless/SDK セッション: set_model 制御リクエストをターン途中で適用（次のモデルラウンドトリップで新モデル使用）
  • エージェントビュー改善: サンドボックス・MCP入力・管理設定待ちのセッションが「Working」ではなく「Needs input」と表示

🐛 主な修正

  • plan mode のセキュリティ修正: plan mode がファイル変更を伴う Bash コマンド（touch, rm など）を許可プロンプトや SDK canUseTool コールバックなしで自動実行していた問題を修正
  • worktree のセキュリティ修正: リポジトリにコミットされたシンボリックリンク（.claude/worktrees）を辿ってリポジトリ外にファイルを作成できた問題を修正
  • フックの信頼性修正: continue:false フックの停止がツール失敗/途中完了時に破棄される問題、およびフックインフラエラーがユーザー拒否と誤報告される問題を修正
  • SIGTERM 処理: 実行中の Bash ツールが SIGTERM で orphan 化していた問題（print/SDK モード）。CLI がターンをアボートしプロセスツリーを kill、exit 143
  • Windows /background 修正: グループポリシーで PowerShell 5.1 がブロックされている環境での EUNKNOWN: unknown error, uv_spawn を修正（PowerShell 7 を優先）
  • OpenTelemetry 修正: Azure Monitor などチャンク転送エンコーディング非対応エンドポイントへの HTTP エクスポート 411/400 エラーを修正
  • OTLP 修正: SDK/headless モードで TRACEPARENT 設定時にイベントログレコードの trace_id/span_id が欠落する問題を修正
  • 多数画像の会話: 画像多数の会話が「Request too large」で誤って失敗する問題を修正し、エラーメッセージを改善
  • Web 検索・フェッチ: API 過負荷時に検索結果やページコンテンツとして「API Error」テキストが返される問題を修正
  • /ultrareview 多数修正: PR 参照の拒否、リモートブランチ非fetch、/clear 後の課金確認スキップ、Claude Desktop でのエラーメッセージ改善など
  • ファイル編集エラー: offset/limit 付きで読み込んだファイルの編集時に「File has not been read yet」が誤表示される問題を修正
  • ExitWorktree: --continue/--resume でのセッション再開後に「no active EnterWorktree session」で失敗する問題を修正
  • /fork バックグラウンドセッション: 状態書き込み失敗後に live-parent 保護が失われる問題を修正
  • エージェントチーム: チーム初期化の再実行時に停止中のチームメイトがリーダーに重複 idle 通知を送る問題を修正
  • 差分プレビュー: 狭いレイアウトで行番号と +/- マーカーが消える問題を修正
  • 認証ステータスパネル: タイトルを「Cloud authentication」から「Authentication」に更新
  • tmux リリースノート訂正: v2.1.200 の tmux 3.6 系列に関する記載を訂正（同期出力非対応、新しい tmux は自動検出）
