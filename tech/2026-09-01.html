🧠 Claude Code — v2.1.252

対象期間内に v2.1.252 がリリースされました（2026-09-01 04:53 JST）。今回はバグ修正中心のリリースです。なお、前回大きな変更を含んだ v2.1.251（2026-08-29 公開）の内容も併せて掲載します。

🐛 v2.1.252 の主な修正

  • Mac での Bash コマンド失敗: 「task output swap refused (tasks dir moved or linked)」エラーで Bash コマンドが失敗する問題を修正
  • 「always allow」が保存されない: まだ .claude/settings.local.json が存在しないプロジェクトで許可設定が保存されない問題を修正
  • Remote Control のスタール: Claude Desktop / VS Code ホストの Remote Control セッションで、claude.ai への接続が不安定な場合にツール完了後数分間停止する問題を修正
  • 巨大な失敗出力: ディスクフル時の git エラーなど非常に大きいバックグラウンドタスクの失敗出力が API リクエストサイズ上限を超える問題を修正

🔧 参考: v2.1.251 の新機能（前回リリース）

  • PreModelSwitch / PostModelSwitch フック: モデル切り替えをブロック・確認・注釈できる新しいフックイベントを追加。SessionStart resume フックはセッションの陳腐化情報と再キャッシュ推定コストを受け取るように
  • フォアグラウンド subagent のライブストリーミング: 実行中のサブエージェントのツール呼び出しと結果を Remote Control クライアントへリアルタイム表示
  • /usage に Spend limit バー: Claude apps gateway の利用上限額を可視化。status line に rate_limits.spend_limit フィールドも追加
  • /cost にセッション別プロンプトキャッシュ行: ヒット率・ミス・再キャッシュトークン・warm/cold を表示
  • セキュリティ修正が多数: シンボリックリンク経由での権限チェック後のファイル読み書き逸脱、プラグインコマンドのパストラバーサル、詳細ベータトレースの有効化回避、Grep/Glob の deny ルール回避などを修正
  • デフォルトモデル変更: シートベースの Enterprise サブスクリプションのデフォルトモデルを Opus 5 に変更。/effort はモデルごとにデフォルト effort レベルを保存するように
  • サイズ削減: ネイティブバイナリを約 5 MB 縮小、使用頻度の低い 6 言語のシンタックスハイライトを削除してさらに 2.5 MB 縮小
  • その他: /radio を Bedrock/Vertex/Foundry 等で利用可能に、Claude in Chrome の操作を常に Claude Code の権限チェック経由に変更、非 Claude モデル利用時のコミットトレーラーを Co-Authored-By: Claude Code に変更など

🤖 Hermes Agent — v2026.8.31 (v0.21.0 「The Pantheon Release」)

2026-09-01 04:29 JST にメジャーリリース v0.21.0 が公開されました。v0.20.0 以来 約5,800コミット・約2,475 PR・約2,100 issues クローズという大規模リリースで、「神々の集結」をテーマに Bot Mode を中心とした多剤的なアップデートです。

🔧 新機能・改善

  • Bot Mode 内蔵: デスクトップアプリに Bot Mode がバンドルされデフォルト有効化。各エージェントプロファイルに名前とアバター顔が付き、複数のボットと人間が同じチャットルームで会話できる Discord 風グループチャットを実現
  • hermes peer — ボット間 DM: プロファイルや gateway を越えて、エージェント同士がハンドル名でメッセージを送受信可能。返信は各エージェントの Bot Chat に永続化され検査可能
  • 記憶する Cron ジョブ: cron エージェントが永続メモリを読み書きし、continuity=true で前回実行の出力を次回に引き継ぎ。各ジョブに永続メモパッド、変化なしなら LLM をスキップする monitor モード、cron 出力を Bot Chat に配信
  • サブエージェントのライブ操縦: 実行中のサブエージェントを中断せず途中で指示変更・軌道修正が可能に
  • MCP コマンドセンター化: MCP サーバ管理面が大幅強化
  • デスクトップブラウザの自動運転: エージェントがデスクトップ自身のブラウザを操作可能に
