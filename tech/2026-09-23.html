🧠 Claude Code — v2.1.280

対象期間内（2026-09-23 01:48 JST 公開）に v2.1.280 がリリースされました。最大のトピックは Claude Opus 5.5（claude-opus-5-5）の追加で、既定の Opus モデルとなっています。コンテキストは 1M トークン、料金は $4 / $20 per Mtok（キャッシュ読み出しは $0.20/Mtok）です。あわせて、Pro および Team Standard プランの既定モデルが Sonnet から Opus へ変更され、Max・Team Premium・Enterprise と揃いました。

🔧 新機能・改善

  • Claude Opus 5.5 を追加: 既定の Opus モデルとなり、1M コンテキスト・$4/$20 per Mtok（キャッシュ読み出し $0.20/Mtok）を提供します。
  • フルスクリーンモードのマウス操作拡張: ホイールで /skills の一覧をスクロールでき、/plugin のスキル状態オプションをクリックできるようになりました。選択リストに隠れた項目がある場合（/model、/permissions など）もホイールでスクロールできます。
  • CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH を追加: セッション内の全 MCP サーバーに対する MCP ツール説明文・サーバー指示の 2,048 文字上限を変更できます。
  • OpenTelemetry イベントの拡充: hook_execution_complete イベントにフック出力サイズと、サイズ超過でファイル保存された出力の件数が追加されました。
  • 既定モデルの変更: Pro および Team Standard プランの既定モデルが Sonnet から Opus へ変更されました（Max・Team Premium・Enterprise と同一）。
  • effort レベルの扱いを整理: /effort がモデル単位になる前に保存された effort レベルは、Opus 5.5 のような新規モデルへ適用されなくなり、既定値から始まります。Opus 4.7 / 4.8 / Fable 5 は、-p・Agent SDK・プロジェクト設定・管理設定・--settings の effortLevel よりも起動時の既定 effort を保持しなくなりました。
  • UI の細かな改善: /permissions でルール閲覧・追加・削除後にフォーカスがルール一覧へ戻り、削除確認の既定が No になりました。/artifacts・/workflows の長い一覧にスクロールバーが付き、ワークフロー進捗ツリーの実行中エージェントは ⟳ ではなく淡いドットで表示されます。/btw はツール実行中に尋ねられた場合、その呼び出しが失敗ではなく実行中であると認識します。
  • プラグイン／マーケットプレイスの保護: 予約名を模倣するマーケットプレイス名は追加時に拒否され、既に追加済みのものも読み込まれなくなります。

🐛 主な修正

  • シンボリックリンク経由の書き込み判定を修正: ツリー内での表記ではなく実際の書き込み先で判定されるようになり、acceptEdits・許可ルール・auto モードが本来のツリー外への書き込みを承認しなくなりました。
  • auto モードのリトライ暴走を修正: 安全チェックがレビューを拒否した場合に同じ操作を繰り返さず 1 度だけ拒否し、回答が得られない場合はリトライをバックオフして連続 10 回でターンを終了します。
  • Write 呼び出しの検証失敗を修正: モデルが file_path / content の代わりに path・file_text・file_content などを送った場合の検証失敗を解消しました。
  • ダイアログ操作の不具合を多数修正: 各種ダイアログで Ctrl+C / Ctrl+D の 2 回押しが Claude Code 終了ではなくダイアログ閉鎖になる、クリックが前面化のみでも配下の項目を発火してしまう、迷子の n がダイアログを閉じ y が確定してしまう、テキスト欄がキーバインドに 1 文字を奪われる、といった問題が修正されました。
  • Windows ターミナルの表示崩れを修正: 不可視文字削除後にプロンプト行が乱れる問題が解消され、送信される正確なテキストが再描画されるようになりました。ペルシア語・アラビア語が接尾辞接続に使う ZWNJ を誤って削除する問題も修正されました。
  • 音声入力の不具合を修正: Ctrl+C で録音が止まらずプロンプトだけ消える、文字起こし処理中に Esc でキャンセルできない、transcript 表示や vim NORMAL モードで Space 長押しが入力開始してしまう問題が修正されました。
  • API エラーでの全ターン失敗を修正: 「role 'system' must precede an 'assistant' message」、プロキシ／ゲートウェイ配下での advisor_20260301 タグ 400 エラー、MCP ツール読み込み失敗の不正な通知が履歴に残った場合の失敗などを解消しました。
  • サブエージェント関連を多数修正: fork したサブエージェントがツール一覧を再構築してプロンプトキャッシュを壊す、ヘッドレス／SDK セッションでサブエージェントへのメッセージが失われる、報告前に会話が compact されると報告が失われる、LSP ツールが使えない、背景シェルが無害な非ゼロ終了を失敗扱いする、といった問題が修正されました。
  • セッション復帰・クラッシュ系を修正: 不正なシステムメッセージやメモリ保存通知を含む transcript からの復帰時クラッシュ、破損したキャッシュメッセージ一覧による unrecoverable interface error、名前付きパイプへの差し替えによるハング、設定ファイルの退行値による /config クラッシュなどが修正されました。
  • アーティファクト関連を修正: 組織ポリシーが読み込めない場合（Web プロキシ配下など）に Artifact ツールが黙って消える問題を、ブロック理由を明示するよう改善しました。再公開時にデータベースアクセスルールが無音でリセットされる問題は拒否されるようになりました。
  • その他: 背景セッション（claude --bg）が環境変数の NUL 文字で git やフックを実行できない問題、背景サブエージェント実行中の Ctrl+C が 3〜4 回必要だった問題、/ultrareview の状態誤報告、Remote Control／クラウドセッションのコンテキスト使用量表示などが修正されました。

⚡ Next.js — セキュリティアップデート v16.3.6 / v15.5.26

対象期間内（2026-09-23 02:15 JST / 02:14 JST 公開）に、重大な上流脆弱性へのアウトオブバンド・セキュリティアップデートが公開されました。Active LTS の v16.3.6 と Maintenance LTS の v15.5.26 が出ています。

  • 影響: next/og の Node.js 版 ImageResponse におけるリモートコード実行（Critical）。対象は Next.js >=16.2.0 <16.3.6。Satori が生成する SVG 出力のエスケープ不備と、他の上流依存の脆弱性が組み合わさることで RCE に至る可能性があります。修正は上流依存（Satori を含む）のアップグレードによるものです。
  • 影響を受けない構成: Edge 版 ImageResponse を使うアプリケーションは影響を受けません。また、攻撃者が制御する値を SVG の内容・属性・スタイルへ渡していないアプリケーションも影響を受けません。
  • Next.js 15.x について: 15.5.26 は関連する堅牢化を含みますが、15.x は本 RCE の影響を受けません。
  • 対処: npm install next@16.3.6（16.3 系）／npm install next@15.5.26（15.5 系・堅牢化のみ）。直ちにアップグレードできない場合は、Node.js 版 ImageResponse が描画する SVG の内容・属性・スタイルに攻撃者制御の値を渡さないでください。
  • 関連アドバイザリ: GHSA-vcvr-r3jv-pc5j（Next.js）、GHSA-wx4j-mvgx-mqwp（Satori）。
