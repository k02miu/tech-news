🧠 Claude Code — v2.1.216

2026年7月21日 07:21 JST に v2.1.216 が公開されました。ファイルシステム分離の設定追加に加え、長時間セッション、バックグラウンドエージェント、worktree、権限確認などを幅広く改善しています。

🔧 新機能・改善

  • ファイルシステム分離の無効化設定: sandbox.filesystem.disabled により、ネットワークの送信制御を維持したままファイルシステム分離を無効化可能
  • 長時間セッションの高速化: メッセージ正規化の二次的な遅延を修正し、長い会話での停止や再開を高速化
  • バックグラウンドセッション: エージェント設定の復元、入力待ち要求の扱い、再開や削除の信頼性を改善
  • 開発者体験: /context のコンテキスト超過警告、/fork の確認表示、/rewind のリンク対策などを改善

🐛 主な修正

  • OAuth トークンの期限切れ・ローテーション後に、auto mode が HTTP 401 を理由にコマンドを拒否する問題を修正
  • worktree 分離サブエージェントが git -C や GIT_DIR などを通じて共有チェックアウトを操作する問題を修正
  • symlink を介した .claude への workflow・scheduled task 書き込みを修正
  • MCP 再認証、Bash 権限確認、Windows の PowerShell、OTel Prometheus メトリクス、Claude-in-Chrome 再接続など多数の不具合を修正
