🧠 Claude Code — v2.1.296

対象期間（2026-10-09 09:00 〜 2026-10-10 09:00 JST）内に、v2.1.296 が 2026-10-10 04:44 JST に公開されました。Claude apps gateway のポリシー制御、サブエージェントのコンテキスト管理、コスト計算まわりの調整を含む更新です。

🔧 新機能・改善

  • gateway の managed.policies[] に code キーを追加: cli と同じ設定を Claude Desktop の Code タブにも適用でき、desktop と併記すると Claude Desktop の gateway モードが有効になります。
  • autoCompactWindow: サブエージェントの frontmatter と --agents 定義で指定可能に。サブエージェントをメイン会話より早く自動コンパクトできます。
  • CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL: 他のサブエージェントのモデルを変えずに、ワークフロー系エージェントだけを1つのモデルで実行できます。
  • CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS: 過負荷（529）リクエストの再試行バックオフの最大待機時間を長めに設定できます。
  • Read ツールに allow_large オプションを追加: コンテキストに余裕がある場合、通常のサイズ上限を超えたテキストファイルを1回の呼び出しで読み込めます。
  • /plugin の注意表示: 同名の別プラグインが有効なためフックが省略されたプラグインについて、その旨を表示します。
  • [Cloud sessions]: セルフホスト環境の Activity タブで、Sessions / Runners リストにステータスフィルタ（複数選択可）を追加。
  • [Claude Tag]: Claude Tag Admin 権限のメンバーが、Activity ページの Memory タブでワークスペース／チャンネルのメモリファイルを作成・編集・削除できるように。

🔄 主な変更

  • Sonnet 5.5 のキャッシュ読み取り価格を $0.10/百万トークンに変更（従来 $0.20）。/cost、ステータスライン、--max-budget-usd、SDK のコスト表示に反映されます。
  • MCP ツール説明の既定上限を 2,048 文字から 4,096 文字へ拡大（事前送信分および MCP サーバー指示）。
  • ← の挙動変更: セッションがバックグラウンドへ移る間に開始されたターンや ! コマンドは、完了させず停止するようになりました。
  • 同梱 dataviz スキルを更新: ライトモードの第7系列に薄いバイオレット、ダークモードの主要テキストを柔らかく、1K のようなコンパクトな Y 軸ラベルに対応。
  • [VSCode]: Claude in Chrome が、@browser で接続したセッションを含むすべてのセッションで、ブラウザ操作の前に確認するように（ターミナルと同様）。
  • [Claude Tag]: Slack のフッター（セッションリンク・モデル・コスト）は、スレッド内の最新の返信にのみ表示されるように。
