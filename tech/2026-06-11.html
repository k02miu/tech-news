🧠 Claude Code — v2.1.170（追加ドキュメント公開）

Claude Code v2.1.170（Claude Fable 5 対応リリース）の公式 changelog に、前号で未報告の多数の新機能・修正エントリが追加で確認されました。新規バージョンのリリースはありませんが、--safe-mode フラグや /cd コマンドなど注目すべき改善が含まれています。

🔧 追加確認された新機能・改善

  • --safe-mode フラグ: トラブルシューティング用に、すべてのカスタマイズ（CLAUDE.md、プラグイン、スキル、フック、MCP サーバー）を無効化して Claude Code を起動可能に。環境変数 CLAUDE_CODE_SAFE_MODE でも設定可能
  • /cd コマンド: プロンプトキャッシュを壊さずに、セッション中に作業ディレクトリを移動可能に
  • disableBundledSkills 設定: モデルにバンドルスキル・ワークフロー・組み込みスラッシュコマンドを非表示にする設定と CLAUDE_CODE_DISABLE_BUNDLED_SKILLS 環境変数を追加
  • Self-hosted Runner の post-session ライフサイクルフック: セッション終了後・ワークスペース削除前にスナップショットやログ出力を実行可能に。子プロセスの SIGTERM→SIGKILL ウィンドウも設定可能に
  • アップデーター改善: claude update がダウンロード前にターゲットバージョンを表示するように変更
  • claude agents URL フィルタ: リストに URL を入力すると、最初のプロンプトにその URL を含むセッションにフィルタ可能に
  • /workflows 即時起動: ターン実行中でもワークフローが即座に開くように改善
  • TaskCreate 信頼性向上: 不正な入力が自動修復され、未ロードツールのバリデーションエラーにスキーマが含まれるように
  • Vertex/Foundry アイドルタイムアウト復元: デフォルト5分のアイドルタイムアウトを復元。API_FORCE_IDLE_TIMEOUT=0 で無効化可能
  • リモート管理設定の検証エラー処理改善: 無効なエントリがあっても残りの有効なポリシーを適用し、検証エラーを表示するように変更
  • CLAUDE.md 長さ警告の動的調整: 「CLAUDE.md is too long」警告の閾値がモデルのコンテキストウィンドウに応じてスケールするように
  • OTEL_RESOURCE_ATTRIBUTES メトリクスラベル: OpenTelemetry リソース属性値がメトリックデータポイントのラベルとして使用可能に
  • claude agents 行の進捗表示: 作業分散時に詳細の前に done/total を表示

🐛 追加確認された主な修正

  • 矢印キーの長い入力行修正: 折り返された長い入力行で Up/Down 矢印がコマンド履歴にジャンプしていた問題を修正。各行を順に移動してから履歴にアクセスするように変更
  • エンタープライズ MCP ポリシー修正: allowedMcpServers/deniedMcpServers の管理ポリシーが再接続時・IDE 設定・初回セッション時に正しく適用されない問題を修正
  • macOS UI ストール修正: claude.ai 資格情報でログインした macOS ユーザーに各ターン開始時に30〜50ms の UI ストールが発生していた問題を修正
  • claude -p Windows 遅延修正: スラッシュコマンド/スキルスキャン待機中の Windows での遏延・ハングを修正（v2.1.161 のリグレッション）
  • Remote Control 再接続修正: セッション再開時に OAuth トークン更新が同時発生すると Remote Control が「reconnecting」で停止する問題を修正
  • Git Credential Manager ポップアップ修正: キャッシュされていない資格情報でバックグラウンド git コマンドを実行した際の Windows スタートアップ時の GitHub 接続ポップアップを修正
  • フッターヒント表示修正: カスタムステータスラインを持つユーザーに「esc to interrupt」等のフッターヒントが表示されない問題を修正
  • リモートセッション承認プロンプト修正: ワーカーがプロンプトを待機中に停止したリモートセッションに再接続するたびに古い承認・ダイアログが再表示される問題を修正
  • claude agents --json 出力修正: ブロックされたセッションと直前にディスパッチされたバックグラウンドセッションが省略される問題を修正。--all フラグで完了済みセッションも含め、id と state フィールドを追加
  • バックグラウンドエージェントのプロジェクト設定修正: プリウォームされたワーカーにディスパッチされたバックグラウンドエージェントがプロジェクトレベルの env 値（例: ANTHROPIC_MODEL）を無視していた問題を修正
  • MCPB プラグインキャッシュ修正: Windows で MCPB プラグインキャッシュが誤って無効化され、不要な再展開が発生していた問題を修正
  • プラグイン .in_use PID ロック修正: .in_use PID ロックファイルが無制限に蓄積する問題を修正。クラッシュしたセッションのマーカーは1日1回掃除
  • OTEL クライアント証明書パス修正: 信頼確認なしで OTEL クライアント証明書パスを設定できる非信頼プロジェクト設定を修正
  • Windows の自動更新修正: claude.exe が別のプロセスによって保持されている場合、セッション内でリトライを停止するように修正
  • モーション設定の適用修正: /effort ダイアログ・ワークフロー动画・プロンプトキーワード shimmer が「Reduce motion」設定を遵守しない問題を修正
  • forceLoginOrgUUID/forceLoginMethod ポリシー修正: サードパーティプロバイダーのセッション（Bedrock/Vertex/Foundry/Mantle）を誤ってブロックする問題を修正（v2.1.146 のリグレッション）
  • バックグラウンドサブエージェント出力修正: --output-format text または json 使用時の claude -p stdout がバックグラウンドサブエージェント出力で破損する問題を修正
  • acceptEdits モードのビルドツール設定確認: コード実行を許可するビルドツール設定ファイル（.npmrc、.yarnrc*、bunfig.toml 等）への書き込み前にプロンプトを表示するように
  • grep 後の Read 不要化: 単一ファイルの grep/egrep/fgrep コマンドが「読み取り-before-編集」チェックを満たすように。ファイル表示後に別途 Read が不要に
  • WSL クリップボード修正: WSL で copy-on-select が Windows クリップボードに書き込まれない問題を修正。MobaXterm 等で動作しない OSC 52 の代わりに PowerShell インターオップを使用
  • シェルスタートアップファイル書き込み確認: .zshenv、.zlogin、.bash_login、~/.config/git/ への書き込み前にプロンプトを表示するように
