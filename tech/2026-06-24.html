⚛️ Hono — v4.12.27（セキュリティリリース）

対象期間内に Hono の v4.12.27（2026-06-23 02:51 UTC = 2026-06-23 11:51 JST 公開）がリリースされました。本リリースはセキュリティ修正のみで、3件の脆弱性（GHSA）に対処しています。前回の v4.12.26（6/18 公開）からの後継です。

🔐 セキュリティ修正

  • hono/jsx のリクエスト間コンテキスト非分離（GHSA-hvrm-45r6-mjfj）: hono/jsx・hono/jsx-renderer で、SSR 時にコンテキストがリクエスト単位ではなくプロセス全体で保持されていた。非同期コンポーネント内の await 後に useContext() / useRequestContext() を呼ぶと、別の同時実行リクエストの値を返す可能性があり、リクエスト間のデータ漏洩や誤ったリクエストに対する認可チェックにつながる
  • cx() における JSX エスケープバイパス経由のサーバーサイド XSS（GHSA-w62v-xxxg-mg59）: hono/css の cx() が入力をエスケープせずに合成クラス名を「既にエスケープ済み」とマークしていた。信頼できない入力をクラス名として渡すと SSR 時に JSX の class 属性から脱出してマークアップを注入（XSS）可能
  • API Gateway v1 アダプタが重複ヘッダ値を欠落（GHSA-xgm2-5f3f-mvvc）: hono/aws-lambda の API Gateway v1（および VPC Lattice）アダプタが、重複ヘッダ値を部分文字列一致ではなく完全一致でなく部分一致で de-dup していた。ある値が別の値の部分文字列の場合に欠落（例: 203.0.113.10 存在時に 203.0.113.1 が消失）し、X-Forwarded-For ベースの IP 制限などに影響

hono/jsx / hono/jsx-renderer、hono/css（cx()）、または hono/aws-lambda の API Gateway v1 / VPC Lattice アダプタを利用している場合はアップグレードが推奨されます。

✨ AWS Lambda MicroVMs — 新サーバーレス計算プリミティブ

  • 概要: AWS Lambda に新しいサーバーレス計算プリミティブ「Lambda MicroVMs」を追加。ユーザー生成コードや AI 生成コードをVM レベルの分離のあるステートフル実行環境で実行可能
  • Firecracker 採用: Lambda Functions を支えるのと同じ軽量仮想化技術（月15兆回超の Lambda 呼び出しを支える）を使用。コンテナのような共有カーネルではなく、セッション間でカーネル/リソースを共有しない
  • ライフサイクル制御: ほぼ瞬時の起動・レジューム、環境ライフサイクルと状態の直接制御、最大8時間の状態保持。ユーザー離席時は低アイドルコストで一時停止し autoResumeEnabled で自動再開
  • ユースケース: AI コーディングアシスタント、インタラクティブなコード環境、データ分析プラットフォーム、脆弱性スキャナー、ユーザー提供スクリプトを実行するゲームサーバーなど、信頼できないコードを安全に実行するマルチテナントアプリ
  • 使い方: アプリ+Dockerfile の zip を S3 にアップロードし aws lambda-microvms create-microvm-image でイメージ作成（Firecracker スナップショット）、run-microvm で起動。Claude Managed Agents のマネージドサンドボックスプロバイダとしても利用可能
