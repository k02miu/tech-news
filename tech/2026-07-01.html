🧠 Claude Code — v2.1.197 & v2.1.196（Claude Sonnet 5 デフォルト化）

対象期間内に2本のリリースが公開されました。いずれも pubDate: Tue, 30 Jun 2026 18:47:17 GMT = 2026-07-01 03:47:17 JST に RSS へ同時刻で登録されています。目玉は Claude Sonnet 5 のデフォルトモデル化です。

✨ 新機能・改善

  • Claude Sonnet 5 が Claude Code のデフォルトモデルに（v2.1.197）: ネイティブ 1M トークンコンテキストウィンドウを搭載。プロモーション価格は8月31日まで $2 / $10 per Mtok（入力/出力）。アクセスには v2.1.197 以降へのアップデートが必要。Anthropic の発表と同日
  • organization default models（v2.1.196）: 管理者が org console で既定モデルを設定可能。/model で「Org default」（または「Role default」）として表示される
  • セッションの判読しやすいデフォルト名（v2.1.196）: 起動直後から識別しやすくメッセージングが容易に
  • チャット内のファイル添付がクリック可能に（v2.1.196）: Cmd/Ctrl-click で Finder/Explorer に該当ファイルを表示
  • /code-review ワークフロー改善（v2.1.196）: 5つのクリーンアップ finder を1つに統合し、トークン使用量を約 25% 削減
  • streaming idle watchdog のデフォルト有効化（v2.1.196）: 全プロバイダで、5分間応答ストリームのイベントがない場合に自動 abort & retry。CLAUDE_ENABLE_STREAM_WATCHDOG=0 で無効化
  • background session 信頼性向上（v2.1.196）: 長時間コマンド/ワークフローがセッションプロセスの停止・再起動・アップデートをサバイブ。Windows では background shell が kill されず hand-off される。daemon restart で kill された worker は agents view を開いた際に自動 resume
  • Remote Control の非 Anthropic ホスト無効化（v2.1.196）: ANTHROPIC_BASE_URL が Anthropic 以外を指す場合は Bedrock/Vertex/Foundry と同様に Remote Control を無効化
  • agents view の ← 操作変更（v2.1.196）: foreground session からの agents view オープンが2回押しから1回 ← に
  • terminal UI のレンダリング負荷低減（v2.1.196）: streaming 中の no-op subtree walk をスキップ

  • PowerShell の git diff/grep, egrep/fgrep, | 含む検索パターンの exit 1 を成功と判定（v2.1.196）: Bash 挙動に揃え失敗報告を除去
  • claude agents side panel の複数修正（v2.1.196）: キーボードフォーカスが stuck する問題、background job の subagent type がオープン時に消える問題、stucked session 表示修正。--dangerously-skip-permissions が auto モードにフォールバックせず bypass disclaimer を表示。--dangerously-skip-permissions モードを spawn agents に適用
  • Remote session の mid-turn crash recovery（v2.1.196）: server restart で中断されたセッションが次 worker で auto-resume
  • /cd で移動したセッションが旧ディレクトリの resume リストに混入するのを修正（v2.1.196）: 特殊文字含むパス・非 gracesful exit 時
  • claude plugin validate が source="." の local plugin をスキップしない（v2.1.196）: 最初のエラークラスで止まらない
  • Esc Esc の rewind メニュー呼出回帰を修正（v2.1.196）: background agent 停止は Ctrl+C または Ctrl+X Ctrl+K
  • MCP OAuth が scopes_supported 全件を要求するのを修正（v2.1.196）: GitLab self-hosted 等の enterprise IdP で invalid_scope 失敗を解消
  • Bedrock で /context が全 tool group 0 token 表示になるのを修正（v2.1.196）
  • /deep-research が verifier 失敗を「all claims refuted」と誤報告するのを修正（v2.1.196）: 正しく unverified 表示に
