🧠 Claude Code — v2.1.292 / v2.1.291

対象期間（2026-10-06 09:00 〜 2026-10-07 09:00 JST）内に、Claude Code の新バージョンが2件公開されました。v2.1.291 が 2026-10-06 13:05 JST、v2.1.292 が 2026-10-07 04:14 JST の公開です。v2.1.292 は、プラグイン／mod フック周りの修正とセキュリティ修正を多数含む大型の更新となっています。

🔧 新機能・改善（v2.1.292）

  • Agent ツールの effort パラメータ: サブエージェントを任意の effort レベルで実行できるようになりました。
  • claude plugin install --marketplace <source>: 必要に応じてマーケットプレイスを追加し（claude plugin marketplace add と同じポリシーチェック下）、そこからプラグインをインストールします。
  • 過負荷リトライの調整: 環境変数 CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS で、529（overloaded）リトライ時のバックオフ基準遅延を引き延ばせます。
  • mod 向け API 拡充: prompt.autocomplete イベント、$.model.complete のプロンプトキャッシュ（cache: true）、agent.spawn フックへの workflow agents 追加。
  • 起動の高速化: claude -p および Agent SDK セッションの初回ターンが、HTTP/SSE MCP サーバーの resources/list 応答を待たなくなりました。
  • MCP プロトコル交渉の既定変更: ローカル（stdio）MCP 接続が全インストールで既定でプロトコル版 2026-07-28 を交渉するようになりました（Bedrock / Vertex / Foundry を含む）。MCP_PROTOCOL_NEGOTIATION=legacy でオプトアウト可能です。
  • レンダリング性能: 長い箇条書き・番号付きリストの返答が、トランスクリプト（ctrl+o）でのストリーミング・リサイズ・再展開ともに大幅に高速化されました。
  • Artifact ツール: 公開済み artifact の件数を Claude が把握でき、一覧取得が 50 件から最大 200 件に拡大しました。
  • sandbox auto-allow の緩和: 厳格な sandbox モードでも FOO=bar python3 app.py のような環境変数プレフィックス付きインタプリタコマンドがプロンプトなしで実行されます。

🐛 主な修正（v2.1.292）

  • プラグイン／mod のフックまわりを多数修正（tool.check が承認必須ツールをダイアログなしで許可してしまう問題、config.set/state.set/env.set/agent.spawn が next(e) 後に deny した場合の扱い、フック worker 再起動中の tool call が権限フックを通らない問題、claude plugin validate の誤検出など）。
  • permissionMode: auto のサブエージェント定義が、auto モード利用不可時に auto モードへ入ってしまう問題を修正。
  • スケジュールタスク関連: /resume・/branch・/clear 以降に作成した保存済みタスクが発火しない問題、タスクファイルへのミリ秒差の2回書き込み後に以降の作成・削除が無視される問題を修正。バックグラウンドセッションの /loop がプロセス再起動で無音停止する問題も修正。
  • Read ツール: PDF の pages に "6,9,15" のようなリストを渡した際、先頭のみを無言で返していた問題を修正（各ページ／範囲を個別に読むようエラーを返す）。256KB 超の @ メンション付きテキストファイルが無言で除外される問題も修正。
  • Grep / Glob が読み取り不能なファイル・フォルダに対して「一致なし」を返していた問題を修正（1回リトライするか、その旨を報告）。
  • NO_PROXY が HTTPS_PROXY 設定時に Claude Code 自身の API リクエストで無視される問題、128文字超の MCP ツール名で全リクエストが失敗する問題を修正。
  • No launch: claude -p のワンショット実行が最終結果の5秒後にバックグラウンドコマンドを停止していた問題、スケジュールされた wakeup が失われる問題を修正。
  • ターミナル UI: vim モードのカーソル行末越え、/add-dir のパス入力欄、iTerm2 検出時の全画面クリア多発、高速タイピング時の入力欠落などを修正。

🔒 セキュリティ（v2.1.292）

  • UNC パスのファイル読み取り: PreToolUse フックの承認と auto モードが、ネットワーク（UNC）パスからのファイル読み取りで権限プロンプトを迂回していた問題を修正。
  • sandbox 化されたコマンドが ~/.claude/seed-admin 配下の /ultrareview アップロードのステージング済みコピーを読める問題、macOS/Windows での notebook・PDF 読み取りが読み取り中に差し替えられたリンク経由で承認範囲外のファイルを返し得る問題を修正。
  • サーバー管理設定のディスクキャッシュ改竄により、設定取得失敗中に組み込みポリシープラグインを無効化・除名できてしまう問題、管理 sandbox の read-deny パスが再指定された際にプロジェクト権限が残る問題を修正。

☕ Django — セキュリティリリース 6.1.2 / 6.0.9 / 5.2.18

2026-10-06 22:00 JST、Django チームがセキュリティリリースを公開しました。対象は main / 6.1 / 6.0 / 5.2 系で、早急なアップグレードが推奨されています。

  • CVE-2026-77050（severity: low）: get_supported_language_variant() における DoS。多数の長大な言語コードを処理する際、長さ制限前にキャッシュキーとして使われメモリを消費し得ました。500文字超の言語コードは拒否または切り詰められます。
  • CVE-2026-84429（severity: moderate）: HTTP ヘッダ解析時の DoS。parse_header_parameters() が引用符付きパラメータ内に多数の区切り文字を持つ値を解析する際に二次時間計算量となり、Accept や Content-Type 経由の未認証リクエストから到達可能でした。Python の email.message.Message を用いる実装に変更されています。
  • CVE-2026-87890（severity: moderate）: 空間ルックアップにおけるリクエスト偽造。raster 値を GDALRaster でラップせずに bytes で渡せてしまい、外部ソースを参照する VRT 文書によって GDAL がネットワークリクエストを発行し得ました。CVE-2026-15307 の修正で見落とされていたもので、後方互換性がありません。
  • CVE-2026-87975（severity: moderate）: 編集可能な主キーを持つモデルフォームセットにおける権限濫用。
