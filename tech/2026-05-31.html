🧠 Claude Code — v2.1.158

🆕 Bedrock / Vertex / Foundry で Auto Mode 対応 (May 30, 2026)

Claude Code v2.1.158 がリリースされました。今回の最大のトピックは、Auto mode が Bedrock、Vertex AI、Foundry 上の Opus 4.7 / Opus 4.8 で利用可能になったことです。

  • Auto mode のマルチプラットフォーム対応: 従来は Anthropic API 直接利用時のみだった Auto mode（Claude が自律的にタスクを遂行するモード）が、Bedrock・Vertex AI・Foundry 経由でも利用可能に
  • 利用方法: CLAUDE_CODE_ENABLE_AUTO_MODE=1 環境変数を設定してオプトイン
  • 対象モデル: Opus 4.7 および Opus 4.8
