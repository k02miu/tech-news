🐙 OpenClaw — v2026.7.2-beta.5

2026年7月28日に v2026.7.2-beta.5 が公開されました。永続データの隔離・復旧、ゲートウェイ再起動後も失われないメッセージ配送、会話の巻き戻し・分岐、インタラクティブな MCP Apps、構造化された質問と承認、Teams・Zoom・Google Meet対応、Wear OS companion、ローカル推論を大きく強化しています。

🔧 主な変更

  • データ保全: SQLiteスナップショットやファイル公開処理のクラッシュ復旧、スキーマ更新時のデータ損失拒否、破損した主データベースを保護する隔離ストアを追加。
  • メッセージ配送: ゲートウェイやローカルプロセスの再起動・クラッシュ後も、受理済みメッセージを回復できる耐久配送とデッドレター復旧を導入。
  • セッション: 個別メッセージからの巻き戻し・フォーク、Webとネイティブアプリ間のブランチ切り替え、キュー済み送信の分岐安全性を追加。
  • MCP Appsと質問: ツール・リソース付きのMCP Appsをダッシュボードへ固定でき、各種クライアントで選択式の質問や承認通知を利用可能に。
  • モデルと端末: Claude Opus 5、Kimi K3、GPT Liveを追加し、Teams・Zoom・Google Meet、Wear OS companion、llama.cpp/Gemmaによるローカル推論に対応。

🔗 v2026.7.2-beta.5

🐋 Orca — v1.4.159

2026年7月27日に v1.4.159 が公開されました。ワークスペース管理、接続の復旧、GitHub連携、音声入力、永続化、Windows・macOSの安定性を改善しています。

🔧 主な改善・修正

  • ワークスペース管理: CLIで作成したワークスペースの識別・絞り込みと、detached HEADのワークスペースを隠すフィルターを追加。
  • 接続・永続化: モバイルの不安定なリレー接続を復旧し、状態書き込みをfsyncしてリネーム後の永続性を向上。
  • GitHub連携: SSH Host alias経由のowner/repository解決と、PRのソース・レビュー先の整合性を修正。
  • 音声・エディター: 韓国語対応のstreaming zipformer STT model、SenseVoice、Parakeet TDT-CTC 0.6B JA voice modelを追加し、Word Wrap切り替えにも対応。
  • 安定性・安全性: Windowsの未知のPTY識別子をフェイルクローズし、履歴の読めない復旧世代を隔離。
