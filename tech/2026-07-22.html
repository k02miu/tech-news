🧠 Claude Code — v2.1.217 / v2.1.216

対象期間内に v2.1.216 と v2.1.217 が公開されました。プロンプト入力、トランスクリプト保存、メモリ管理、バックグラウンドセッションの安全性と運用性が強化されています。

🔧 新機能・改善

  • 絵文字ショートコード: プロンプト入力で :heart: のようなショートコード補完に対応し、設定で無効化可能
  • サブエージェントの制御: 同時実行数の既定値を20に制限し、既定では入れ子のサブエージェントを起動しないよう変更
  • 保存状態の可視化: トランスクリプト書き込み失敗や、環境変数によってセッション保存が無効になった場合に警告を表示
  • 運用性の改善: フッターのPRバッジをSSH・tmuxでもクリック可能にし、ログイン期限の警告時期を期限3日前へ変更

🐛 主な修正

  • MCPツール出力の切り詰め後に完全な結果を保持し続けるメモリリークを修正
  • symlinkを含む作業ディレクトリの正規化不足により、バックグラウンドセッションがワークスペース外へ出られる可能性を修正
  • --resume・--continue・/resume が壊れた添付エントリを含むトランスクリプトで失敗する問題を修正
  • Bedrock上のClaude Opus 4.8で自動compactが発動しない問題、バックグラウンドシェルを停止できない問題などを修正
  • v2.1.216では長時間セッションの正規化遅延、worktree分離、MCP再認証、PowerShell、OTelメトリクスなども修正
