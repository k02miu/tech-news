🧠 Claude Code — v2.1.293

対象期間（2026-10-07 09:00 〜 2026-10-08 09:00 JST）内に、Claude Code の新バージョン v2.1.293 が 2026-10-08 03:26 JST に公開されました。既定の Haiku モデルが Claude Haiku 5.5 に切り替わり、サブエージェントやスキル、Remote Control まわりを含む多数の修正が入っています。

🔧 新機能・改善

  • Claude Haiku 5.5 を追加（claude-haiku-5-5）: Anthropic API における既定の Haiku モデルとなりました。1M コンテキスト対応、100K トークンまでのプロンプトで $0.10 / $0.50 per Mtok（100K 超は $0.50 / $2.50）。
  • agentType を subagentStatusLine ペイロードに追加: スクリプトからカスタムサブエージェント種別を判別できます。
  • $.tool.register に isDeferred を追加（mod 向け）: false を指定すると、ツールスキーマが tool search の背後ではなく最初からプロンプトに列挙されます。
  • Team / Enterprise の起動改善: ポリシーおよび管理設定をより早く取得し、停滞したリクエストは 3 秒後に再試行します。
  • Claude in Chrome の改善: タブ報告が遅いブラウザでのページ操作拒否が減少。クラウドセッションでブラウザに到達できない場合のメッセージも、複数組織所属時に拡張機能のサインイン先に関する案内を行うようになりました。
  • Artifact: ライブラリを「2週間以上前の正確なバージョン」に固定します。
  • その他の変更: claude.ai スキル同期のチェック間隔を約10分から約40分へ。エージェント一覧と MCP サーバー告知順で非 ASCII 名は ASCII 名の後にソート。OpenTelemetry の claude_code.at_mention ログは1プロンプトあたり最大100件ずつに。

🐛 主な修正

  • コンパクション後の誤動作: コンテキスト圧縮の直前に行った自身の操作を「完了済み」と誤認し、完了した作業を取り消したりやり直したりする問題を修正。
  • HTTP MCP 接続のメモリリーク: 接続が閉じるまで送信済みの全リクエストを保持していた問題を修正。
  • ← によるバックグラウンド移行時のメッセージ消失: 移行できないキュー済みメッセージがある場合、← はその場に留まり警告するようになりました。プロンプト未送信テキストがある状態での10秒後の強制バックグラウンド化も取り消されます。
  • サブエージェント関連: ホスト・権限ルール・--tools リストにより SendMessage が除去されたセッションで、サブエージェントへの継続指示が送られてしまう問題を修正。
  • claude logs/stop/kill/rm・daemon 操作: ログイン期限切れ・期限間際に意図せずサインアウトされる問題を修正。
  • その他の修正: /model の effort ←/→ の巻き戻り（Low 既定の誤保存）、/tui の Chrome 切断、Bash ツールの単一ファイル cat/head/tail/sed -n/grep 表示時にパス限定ルールやネストした CLAUDE.md が読み込まれない問題、貼り付けたテキストが誤って「入力済み」扱いされる問題、vim モードの各種挙動など多数。
  • Windows: ステータスライン・フック・シェルコマンドの停止が、同じプロセス ID を持つ無関係なプロセスを終了させることがある問題を修正。

🐋 Orca — v1.4.222

対象期間内に v1.4.222 が 2026-10-07 11:20 JST に公開されました。OpenCode ワーカーのタスク受け渡し、サイドバー操作、CSV ビューア、エディタ、日本語・中国語・韓国語入力まわりなど、幅広い改善と修正が含まれます。

🔧 新機能・改善

  • CSV ファイル: 大きな CSV をファイル全体を読み込まずに開けるようになりました。列幅の変更、リンクのオープン、セルの編集、行・列の追加削除、範囲のコピー＆ペースト、並べ替え・絞り込みに対応し、列幅は記憶されます。
  • OpenCode ワーカー: マシンが混雑していても、タスクが OpenCode の入力欄に未送信のまま残らず、送信可能になってから渡されるようになりました。ワーカーは他の起動に影響を与えずに指定モデルを使えます。
  • 利用状況メニュー: Claude の利用クレジット、OpenCode Zen の残高、Codex のクレジットを利用上限と並べて表示します。
  • Jira: Issue 作成時に担当者を選択できます。
  • アカウント切替: Codex アカウント切替後の再起動で、空のターミナルではなく同じ会話が再開されます。

🐛 主な修正

  • 日本語・中国語・韓国語の入力: テキスト確定の Enter が、フィールドの送信・ファイル作成・コメント送信を同時に引き起こさなくなりました（Orca 全体）。
  • ネイティブチャット（実験的）: チャットを開いても履歴が削除されなくなりました（新しい Orca で保存された履歴も含む）。メッセージはホスト確認まで「Sending…」、配信失敗時は理由付きの「Not sent」を表示します。
  • サイドバー / ワークスペース: サイドバーで表示したリモートコンピュータが設定保存中に再び消える問題、子が折りたたまれたワークスペースをドラッグできない問題、ワークスペースのドラッグでクラッシュし得る問題を修正。
  • エディタ: プロジェクト外ファイルのタブが再起動後に「Access denied」で復帰する問題、別コンピュータ上の同一パスファイルがテキスト・Undo 履歴を共有してしまう問題を修正。
  • その他: リモートタブで Claude Code に戻った際に古いシェル出力が Claude の画面越しに見える問題、同じフラグを二重送信してエージェントが起動しない問題、Cursor の利用状況が誤ったアカウントを参照する問題などを修正。
