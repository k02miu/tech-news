🧠 Claude Code — v2.1.236

対象期間内（8月20日 07:51 JST公開）にv2.1.236がリリースされました。新環境変数ANTHROPIC_DEFAULT_MODELやクロスセッション通知のnotify_when_idleの追加をはじめ、サンドボックス・フルスクリーン・auto mode・Remote Control などの改善と、多数の不具合修正が含まれます。

🔧 新機能・改善

  • ANTHROPIC_DEFAULT_MODEL環境変数: 新規セッションが開始時に使用するモデルを設定できます。/modelでの選択は上書きして再起動後も維持され、ANTHROPIC_MODELとは挙動が異なります。
  • クロスセッション通知notify_when_idle: このマシン上の別のClaude Codeセッションに、次にアイドルになった際に1回だけ通知を送るよう依頼できます（opt-in・ワンショット・ポーリング不要、macOS/Linux）。
  • macOSサンドボックス強化: ワイルドカード読み取り拒否ルール（例: **/.env）が、許可読み取り領域の内部では優先され、対象ディレクトリの内容もカバーし、拒否ファイルのリネームによるバイパスもできなくなりました。
  • auto mode改善: 自動モード有効中はMonitor許可ルールを保留し、Bashコマンドと同様にレビューされるように。Bedrock／Vertex AI／Foundry／テレメトリ無効時もClaude APIと同様の分類デフォルト（severityスコア付き）を適用。git statusの未追跡ファイル隠し設定による改ざんも防止。
  • /goal自動チェックイン: 長時間バックグラウンド作業の背後にゴールが置かれたアイドルセッションが、30分（以降1時間・2時間）で自動チェックインするようになりました。
  • /usage強化: Team／Enterpriseメンバーの利用クレジット支出行を表示し、支出前に0%上限行を表示します。
  • [VSCode] スクリーンリーダー対応: トランスクリプトにライブアナウンス（返信・権限要求・エラー・状態変化）とターン単位の見出しナビゲーションを追加しました。

🐛 主な修正

  • セッションが切り替えていたディレクトリが削除された際に、クリップボードコピー・バックグラウンドハウスキーピング・バックグラウンドセッション・ローカルMCPログが壊れる問題（2.1.229以降）を修正しました。
  • フルスクリーンレンダラーが一度の起動失敗で恒久的に動作しなくなる問題を修正し、以降の起動ではクラシックレンダラーにフォールバックするようにしました。
  • サブプロセス起動失敗時のunhandled promise rejectionを修正しました（例: WSLでWindows interop無効時のpowershell.exe。2.1.234で退行）。
  • 自己ホストランナーセッションが、ポストセッションフック完了前に別ランナーで再開される問題を修正しました。
  • 暴走セッション要約を修正し、要約テキストを400文字・語境界で上限にしました。
  • SIGTERM（print/SDKモード）で、終了前のinterrupted turnや合成ツール拒否を記録しないようにし、実行中コマンドは終了、終了コード143を維持。
  • Remote ControlがCLI終了・ターミナルクローズ時にセッションを短時間でオフラインとしてマークするように。
