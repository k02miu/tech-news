🚀 2. Opus 4.8 登場 + Dynamic Workflows

今回の最大の目玉。v2.1.154 (5/28) で発表され、後続バージョンで安定化が進んだ。

🧠 Claude Opus 4.8 — デフォルト high effort · /effort xhigh で最難タスクに対応 全モデルに Lean system prompt がデフォルト適用。Fast mode は標準の 2x コストで 2.5x 速度に。

Dynamic Workflows NEW

  • 数十〜数百のエージェントをバックグラウンドで編成し、大規模タスクを自律実行
  • /workflows で実行状況を確認可能
  • trigger キーワードは v2.1.160 で workflow → ultracode に変更（プロンプト内の自然な "workflow" が誤発動するのを防止）
  • /config に "Workflow keyword trigger" 設定を追加（誤発動オフ可能）
  • Backspace でワークフローリクエストをキャンセル可能
  • EnterWorktree で Worktree 間のスイッチが可能に [v2.1.157]

Auto Mode 拡大

  • Bedrock / Vertex / Foundry で Opus 4.7 / 4.8 の Auto mode が利用可能に [v2.1.158]
  • CLAUDE_CODE_ENABLE_AUTO_MODE=1 でオプトイン
  • データ流出検出（特にリポジトリ内容の一括転送）を強化 [v2.1.154]
  • 分類器のレイテンシ改善、"could not evaluate" ブロックを低減 [v2.1.160]

Fast mode 変更

  • CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE は非推奨→v2.1.160 で削除
  • Opus 4.6 Fast mode を使うには /model claude-opus-4-6[1m] で切り替え→ /fast on [v2.1.154]

📝 総括

11日間で12バージョン（v2.1.155 はスキップ）というハイペースなリリースサイクル。最大のハイライトは v2.1.154 の Opus 4.8 + Dynamic Workflows。Claude Code が単なるコーディングアシスタントから、大規模タスクを自律実行できる「エージェントプラットフォーム」へと進化する転換点となった。

v2.1.157 以降は安定化フェーズで、Background Sessions の信頼性向上に多くの工数が割かれた。Windows/WSL 対応も着実に改善。セキュリティ面では、シェル起動ファイルやビルドツール設定への書き込み前確認が導入され、より安全に。
