🧠 1. Gemini 3.5 シリーズ & Gemini Omni

Google I/O 2026 最大のモデル発表。Day 1 基調講演で発表された内容の詳細が Day 2 で明かされた。

Gemini 3.5 Flash

⚡ 全ベンチマークで Gemini 3.1 Pro 超え · 他社比 4倍高速 Google 史上最強のエージェント・コーディングモデル。AI Mode / Gemini アプリ / Antigravity / Gemini API で即日利用可能。
  • データサイエンス分野でパートナーが複雑データからのインサイト抽出に活用中
  • 安全性も強化：推論前のチェックで有害出力・不当拒否を低減
  • コスト：他フロンティアモデルの半額以下でタスク完遂

Gemini 3.5 Pro（6月リリース予定）

Pro モデルは 2026年6月に登場。Flash のスピードと Pro の深い推論を両立する設計。

Gemini Omni Flash

「あらゆる入力からあらゆる出力を生成」するマルチモーダルモデル。テキスト・画像・音声・動画 → 動画出力に対応（画像・音声出力も今後対応予定）。

  • マルチターン会話型の動画編集：環境・スタイル・アングル変更がプロンプトで可能
  • 自分の声のアバター生成 → 本人そっくりの動画出力
  • 全出力に SynthID デジタル透かし付与
  • Google AI Plus/Pro/Ultra 加入者は Gemini アプリ & Google Flow で利用可能
  • 一般ユーザーは YouTube Shorts & YouTube Create App で無料体験（今週から）

🤖 2. Google Antigravity — エージェント開発基盤の全貌

今年の I/O で最も開発者の注目を集めた発表。Antigravity は「エージェント・ファースト」の開発プラットフォームとして大幅進化した。

🖥️ Antigravity 2.0

単体デスクトップアプリ。複数エージェントの並列オーケストレーション、動的サブエージェント、バックグラウンド自動化タスク、AI Studio / Android / Firebase 統合。

⌨️ Antigravity CLI

ターミナルから即時エージェント作成。軽量・高速。Gemini CLI ユーザーは移行推奨。GUI不要で CI/CD パイプラインに組み込み可能。

📦 Antigravity SDK

Google 製品を支えるエージェントハーネスをプログラムから制御。Gemini モデルに最適化済み。独自インフラでホスト可能。

☁️ Managed Agents（Gemini API）

API 1コールで sandbox 付きエージェントをスピンアップ。隔離Linux環境、マルチターンセッション、カスタム指示/スキル定義。Gemini 3.5 Flash 採用。

料金プラン

  • Google AI Ultra：$100/月 — Antigravity 5倍の利用上限
  • 期間限定：新規・既存 Ultra 加入者に $100 ボーナスクレジット（5/25まで）
  • Google AI Pro → YouTube Premium Lite 同梱 / AI Ultra → YouTube Premium 同梱

Google AI Studio の進化

  • 📱 モバイルアプリ：今週事前登録開始。外出先でアイデア→プロトタイプ
  • 🔗 Workspace 統合：エージェントが Gmail/Calendar/Drive などの API をネイティブコール
  • 📤 Antigravity エクスポート：AI Studio から Antigravity へワンクリック移行
  • 📱 ネイティブ Kotlin 対応：プロンプトだけで Android アプリ開発（vibe coding）
  • 🏪 Google Play Console 統合：テストトラックへの直接公開

📱 3. Android 開発 & Android 17 "Cinnamon Bin"

Android 17 の正式発表は I/O 前週（5/12 The Android Show）だったが、Day 2 では 開発者ツール に焦点。

開発者ツール

🔧 Android CLI（安定版）

AIエージェントが Android Studio の機能を直接利用。SDK ダウンロード、デバイス実行、ビルドなど。あらゆる LLM/ツールと組み合わせ可能。Android Skills もオープンソース化。

📊 Android Bench

Android 開発タスクの LLM リーダーボード。Gemma 4 などオープンウェイトモデルも追加。モデル選定の指標に。

🔄 Migration Agent

React Native / Web フレームワーク / iOS → ネイティブ Kotlin Android アプリに自動変換。数週間の移行が数時間に。Android Studio 新機能としてプレビュー。

🧪 Google AI Studio × Android

Kotlin vibe coding 対応。プロンプトから高品質 Android アプリを生成し、Play Console テストトラックに直接公開可能。

Android 17 主要機能

  • 🔒 ロック画面ウィジェット
  • 🫧 マルチタスクバブル
  • 🖥️ 強化デスクトップモード
  • 🔄 Continue On：Apple Handoff に相当。複数 Android デバイス間でアプリ利用をシームレスに移行
  • 🧠 Gemini システムレベル統合：アプリではなく OS ネイティブの AI 機能
  • 📱 対応デバイス：Pixel 6 〜 Pixel 10 シリーズ
  • 📅 安定版リリース：2026年6月〜7月予定

🌐 4. Web 開発の未来

💡 Web を「AI エージェントが操作可能なプラットフォーム」に再定義 3つの大型発表で Web 開発のパラダイムシフトを提示。

WebMCP（Web Model Context Protocol）

  • 📡 ウェブサイトが AI エージェントに 構造化ツール（JS関数・HTMLフォーム）を公開するオープン標準
  • 🎯 従来の「クリック操作の模倣」ではなく、バックエンドAPIを直接クエリ可能に
  • 🧪 Chrome 149 で Origin Trial 開始 · Gemini in Chrome 対応予定
  • 💬 「複数都市の旅行計画」などの複雑タスクをエージェントが自律実行

Modern Web Guidance

  • 📚 エキスパートが精査した パフォーマンス・アクセシビリティ・セキュリティ ベストプラクティス集
  • 📊 100以上のユースケース対応 · Baseline 統合
  • ⚡ Antigravity でワンクリック導入 / CLI：npx modern-web-guidance install

Chrome DevTools for Agents

  • 🤖 AI エージェントが Chrome DevTools の全機能を利用可能に
  • ✅ コード検証・デバッグ・パフォーマンス最適化を自律実行
  • 🔍 品質監査の自動化、実ユーザー体験のエミュレーション

HTML-in-Canvas API

  • 🎮 WebGL/WebGPU Canvas 内に実際の DOM 要素を統合
  • 🔍 検索・アクセシビリティ・インタラクションが可能な没入型3D体験
  • 🧪 Origin Trial 開始

Personal Intelligence 拡大
